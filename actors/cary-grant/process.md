# Cary Grant — 角色塑造过程规格 process.md（给视频模型）

> 只按角色的塑造逻辑写，不编造演员的生活场景；无排练记录可考者按作品反推，不声称复刻原过程。流程：读本 / 排练 / 走位 / 拍摄 / 调整。

## (1) 角色塑造步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 演什么、演哪里 | 表演状态 | 最容易演错 |
|---|---|---|---|---|---|
| 1 读本 | 定角色、定关系、定弧线 | 剧本标注 / 人物小传 / 排练本 | 只定骨架：角色目标、与他人的关系、情绪弧线、开头与结尾 | 约 10–20% 完成，人物骨架可见、表演未定 | 一开始就定台词的语调，人物没立住 |
| 2 排练 | 试演、找形体与声音 | 即兴 / 排练场走位 / 对词 / 形体练习 | 全场贯通，不回头改，试多种演法 | 约 40–50%，人物初现、粗糙 | 一回头改就停，人物断了 |
| 3 走位 | 定镜头/舞台调度 | 走位图 / 镜头排练 / 灯光走位 | 只定调度与节奏，不改表演细节 | 约 60–70%，调度已定、细节未满 | 一改调度就乱，节奏散了 |
| 4 拍摄 | 正式拍摄 | 按演员习惯正式拍摄，保留即兴空间 | 只演定稿的调度与台词 | 约 85–90%，表演已立，个别段落仍可调整 | 一紧张就收，幅度没了 |
| 5 调整 | 看回放/复盘、补拍/再演 | 看样片 / 导演反馈 / 补拍 / 下一场调整 | 全场薄薄统一，不改角色骨架 | 100%，完成态 | 一改骨架就散，人物变了 |

## (2) 每一阶段的表演状态变化（5 个检查点）

1. 第 1 步结束：只有人物小传与关系骨架，表演未定。
2. 第 2 步结束：全场贯通，人物初现、粗糙，形体与声音有了雏形。
3. 第 3 步结束：调度已定，骨架清晰、细节未满。
4. 第 4 步结束：表演密度骤升，风格已立，个别段落仍可调整。
5. 第 5 步结束：完成态，通读统一、定型。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：读本 10%、排练 30%、走位/彩排 15%、拍摄/演出 35%、调整 10%（按演员特点调整：默片演员形体步可占 50%，方法派排练步可占 50%）。
- 节奏提示：读本慢、排练中速、拍摄放慢、调整停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：排练场/片场逐场出现，关键调整处用前后对比并排显示；每步左上角出小字步骤名（读本 / 排练 / 走位 / 拍摄 / 调整），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：排练场全景 / 镜头特写 / 局部放大三机位轮换；读本用全景，拍摄用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放剧照，不放肖像写真）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡画面；不要把过程剪成跳切，保留表演的连续性；不要虚构演员本人的生活场景。

## (4) 过程示例（以本演员塑造现代题材角色的逻辑为例，不声称复刻原过程）

- 读本：定一个场景（深夜便利店买关东煮）、两个人、一句未说出口的话；角色目标定为“想留下来，又不敢开口”。
- 排练：试三种演法，定下该演员的形体与声音。
- 走位：定镜头从全景推到特写，台词只在特写时说。
- 拍摄/演出：他西装笔挺地走进便利店，关东煮的汤溅到袖口上，他眉毛一扬，镇定地掏出手帕擦净，顺手向店员眨眼一笑，仿佛什么都没发生。
- 调整：看样片，删去一句解释性台词，只留停顿与眼神。
- 节奏：读本 10%、排练 30%、走位 15%、拍摄 35%、调整 10%。
