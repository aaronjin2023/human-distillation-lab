# Denzel Washington — 角色塑造过程规格 process.md（给视频模型复刻过程）

> 只按角色的塑造逻辑写，不编造演员的生活场景；有排练记录/访谈可考者以公开访谈与排练记录为准，无记录者按作品反推，不声称复刻原过程。

## (1) 角色塑造步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 表演状态 |
|---|---|---|---|
| 1 读本 | 定角色、定关系、定弧线 | 剧本标注 / 人物小传 | 约 10–20% 完成，人物骨架可见、表演未定 |
| 2 排练 | 试演、找形体与声音 | 即兴 / 排练场走位 / 对词 | 约 40–50%，人物初现、粗糙 |
| 3 走位 | 定镜头/舞台调度 | 走位图 / 镜头排练 | 约 60–70%，调度已定、细节未满 |
| 4 拍摄 | 正式表演 | 按演员习惯表演，保留即兴空间 | 约 85–90%，表演已立，个别段落仍可调整 |
| 5 调整 | 看回放/复盘、补拍/再演 | 看样片 / 导演反馈 / 补拍 | 100%，完成态 |

每一步最容易演错的地方：
- 读本一步：先定道德权威的来源，别先定情绪。
- 排练一步：一靠音量就丢克制。
- 走位一步：静止太久会拖节奏。
- 拍摄一步：一煽情就破。
- 调整一步：别为冲突加咆哮。

## (2) 每一阶段的表演状态变化（过程视频的节奏）

- 第 1 步（读本）结束时：约 10–20% 完成，人物骨架可见、表演未定。
- 第 2 步（排练）结束时：约 40–50%，人物初现、粗糙。
- 第 3 步（走位）结束时：约 60–70%，调度已定、细节未满。
- 第 4 步（拍摄）结束时：约 85–90%，表演已立，个别段落仍可调整。
- 第 5 步（调整）结束时：100%，完成态。
- 节奏建议：读本慢（让观者看清人物关系）、排练中速（看人物生长）、拍摄放慢（看关键场次的表演落点）、调整停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。时间分配：读本 10%、排练 30%、走位 15%、拍摄 35%、调整 10%。

## (3) 过程呈现的镜头与字幕建议

- 呈现：排练场/片场逐场出现，关键调整处用前后对比并排显示；每步左上角出小字步骤名（读本 / 排练 / 走位 / 拍摄 / 调整），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：排练场全景 / 镜头特写 / 局部放大三机位轮换；读本用全景，拍摄用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放剧照，不放肖像写真）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡画面；不要把过程剪成跳切，保留表演的连续性；不要虚构演员本人的生活场景。

## (4) 过程示例（以丹泽尔·华盛顿塑造角色的逻辑为例，不声称复刻原过程）

- 读本：定一个场景（深夜便利店）、两个人、一句未说出口的话；角色目标定为“想留下来，又不敢开口”。
- 排练：试三种演法（低语、沉默、爆发），定下该演员标志性的处理。
- 走位：定镜头从全景推到特写，台词只在特写时说。
- 拍摄：按演员习惯表演，保留即兴空间，不解释动机。
- 调整：看样片，删去一句解释性台词，只留停顿。
- 节奏：读本 10%、排练 30%、走位 15%、拍摄 35%、调整 10%。
