# Willem Janszoon — 航海方法与探索风格规格 style.md（给文本/图像模型）

> 只描述航海方法与风格，不描述人生。引用日志原文时只引短句并注明出处。

## (1) 一句话风格（prompt-ready）

- EN: `In the style of Willem Janszoon: hug the coast, chart segment by segment, name each river mouth after the land, turn back where supplies run thin, no open-ocean crossing`
- ZH: 威廉·扬松风格：贴岸航行、逐段测绘，离开海岸线的开阔海横渡。

## (2) 导航方法

- 沿岸领航为主：紧贴海岸航行，靠岬角、河口与测深辨位；信风季顺风南下，逆风时贴岸锚泊等待；对未知海岸先绘草图再深入。 `impression`

## (3) 造船与帆装

- 杜伊夫肯号（Duyfken，“小鸽子”，约60吨小帆船）：吃水浅、操纵灵活，适于河口与浅滩探查；船员约20人，补给有限。 `impression`

## (4) 航线规划习惯

- 沿岸逐段推进：从班达出发沿新几内亚海岸东行，折入卡奔塔利亚湾，沿约克角西岸南下至折返角；不横渡开阔海域。 `impression`

## (5) 日志与海图语言

- 日志已佚，航线靠1670年摹本海图还原；海图注记以荷兰语地名为主（双河、鱼河、折返角），命名多记地貌与事件。 `impression`

## (6) 该探索什么 / 不该探索什么

- 该探索：沿岸逐段测绘的海岸线、河口登陆与原住民接触、折返角的果断回航。
- 不该探索：离开海岸线的开阔海横渡。
- Negative prompt: `No open-ocean crossing, no sailing away from the coast, no pushing on without supplies, no modern GPS fix as the only position`
