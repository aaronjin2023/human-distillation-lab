# Alexander Dalrymple — 语言与记录方式 language.md（Interaction，只限航海成果）

- 日志体例：著作体例为海图集与航行指南：《南太平洋航行记》（1770年）、《航行指南》系列；海图注记以英文为主，港口、水深、锚地逐一标明。 `impression`
- 海图符号：海岸线、测深点、锚地、危险礁石分层标注；注记密度随测绘精度而定。`impression`
- 命名习惯：新地多以赞助人、船员、圣人或地貌命名；命名即主权宣示，须注明命名者。`impression`
- 与船员与原住民的记录方式：船员记职务与分工，原住民记接触与补给经过；只记航行相关，不记私生活。`impression`
- 留白与省略：未测绘处留白，不凭推算填岸；未记录处即未知，不补写。`impression`
- 语言样本：达尔林普尔海图集注记：港口、水深、锚地逐一标明，多源交叉核对。（达尔林普尔《南太平洋航行记》（1770年）与海图集）`artifact`。
