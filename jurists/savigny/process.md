# Friedrich Carl von Savigny — 法律工作过程规格 process.md（给文本/视频模型）

> 只按法律工作的逻辑写，不编造法律人物本人的生活场景；有手稿/草案/异议草稿可考者以文献证据为准，无手稿者按文本结构反推，不声称复刻原过程。角色：法学家（历史法学派）。

## (1) 工作步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 写什么、写哪里 | 文本状态 | 最容易写错 |
|---|---|---|---|---|---|
| 1 问题提出 | 定问题、定论题、定射程 | 问题史梳理 / 争点清单 / 文献检索 | 只定骨架：问题、论题、反对意见、论证终点 | 约 10–20%，问题可见、论证未定 | 一开始就下结论，问题被结论吞掉 |
| 2 文献/法源梳理 | 找法源、找先例、找学说 | 法典 / 判例汇编 / 学说检索、先例区分表 | 全面检索，不先下结论，只列法源与学说清单 | 约 30–40%，法源已齐、立场未定 | 只引支持自己的文献，反对学说一句不提 |
| 3 论证展开 | 先溯源、再以概念体系整理历史材料 | 历史方法 / 体系方法 / 语言类比、反法典化论证 | 只搭骨架：历史—体系—民族精神 | 约 50–60%，论证骨架已定、语言未满 | 不溯源就立法，法典化就仓促了 |
| 4 逐段打磨 | 逐段写、逐句推敲 | 按人物习惯逐段写（先定义再演绎 / 先警句再说理 / 先事实再规则） | 全篇贯通，逐段打磨术语与句式 | 约 85–90%，文本已立，个别段落仍可留空 | 一写长句堆砌就散，声口变了 |
| 5 定稿 | 校对、定稿、发布 | 通读 / 校对 / 定标题与篇名 | 全篇统一，不改论证结构 | 100%，完成态 | 定稿时改动已定的论证结构 |

## (2) 每一阶段的文本状态变化（5 个检查点）

1. 第 1 步结束：只有问题（例如网络社区规则从何而来），正文未定。
2. 第 2 步结束：历史材料清单已齐（社区早期记录、习惯做法、平台规则变迁），立场未定。
3. 第 3 步结束：论证骨架已定（历史—体系—民族精神），语言未满。
4. 第 4 步结束：论证密度骤升，体系概念已立，个别处仍可留空。
5. 第 5 步结束：完成态，通读统一、定名。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：问题 10%、溯源 30%、体系 30%、打磨 25%、定稿 5%（溯源与体系步占大头）。
- 节奏提示：问题慢（让观者看清争点）、检索中速（看法源生长）、论证放慢（看原则权衡）、起草再放慢（看逐句换词）、定稿停顿（看完成态）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：文书 / 判决书 / 法典草案逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 溯源 / 体系 / 打磨 / 定稿），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，起草用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放文本封面 / 判决书页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构法律人物本人的生活场景。

## (4) 过程示例（以本法律人物写现代题材的逻辑为例，不声称复刻原过程）

- 问题：定争点（网络社区习惯是否算法律渊源）、定论题、定射程。
- 溯源：找社区早期记录、习惯做法、平台规则变迁，列历史清单。
- 论证：搭骨架（习惯先于成文规则—法如语言—仓促法典化有害），预设反驳（“民族精神无法证伪”）并回应（共同信念可见于习惯）。
- 打磨：把长句拆成体系段落，逐句统一术语（习惯、信念、体系）。
- 定稿：通读一遍，只改标点与换行，定标题。
