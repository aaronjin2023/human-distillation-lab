# Tribonian — 法律语言与文体 language.md（Interaction，只限法律成果物）

> 只写法律文本怎么跟读者说话，不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 语言风格：汇编体，引文并列，编者按语极简；术语承原作者，不统一口径；语气为中立的编者，不作价值判断。 `artifact` / `impression`
- 句式与术语：见 style.md 第 (3) 节；禁词/禁句式见 style.md 第 (6) 节。
- 文体：立法者体例：《学说汇纂》五十卷按编目排列，《法典》按敕令时序修订，《法学阶梯》按盖尤斯体例重写。 `artifact` / `impression`
- 与读者的距离：立法者 / 法典编纂者的口吻——立法者居高临下、法官不偏不倚、律师针锋相对、学者平实说理，本人物见 style.md 第 (3) 节。`impression`
