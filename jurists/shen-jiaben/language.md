# Shen Jiaben — 法律语言与文体 language.md（Interaction，只限法律成果物）

> 只写法律文本怎么跟读者说话，不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 语言风格：考据体与条文体并存，考据长、条文简；术语为新旧法名并列；语气为改革者口吻，审慎而不激进。 `artifact` / `impression`
- 句式与术语：见 style.md 第 (3) 节；禁词/禁句式见 style.md 第 (6) 节。
- 文体：立法者体例：《大清新刑律》按总则分则起草，《历代刑法考》为考据依据，《遗书》为文集。 `artifact` / `impression`
- 与读者的距离：立法者 / 法典编纂者的口吻——立法者居高临下、法官不偏不倚、律师针锋相对、学者平实说理，本人物见 style.md 第 (3) 节。`impression`
