# Solon — 法律语言与文体 language.md（Interaction，只限法律成果物）

> 只写法律文本怎么跟读者说话，不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 语言风格：立法条文简短明确，改革自辩用挽歌体长句；术语为债务、地权、公民等级；语气为调解者口吻，既不讨好富人也不煽动穷人。 `artifact` / `impression`
- 句式与术语：见 style.md 第 (3) 节；禁词/禁句式见 style.md 第 (6) 节。
- 文体：立法者体例：改革法令逐项颁布，辅以诗体自辩；条文列举式，宪法改革按财产等级分权。 `artifact` / `impression`
- 与读者的距离：立法者 / 法典编纂者的口吻——立法者居高临下、法官不偏不倚、律师针锋相对、学者平实说理，本人物见 style.md 第 (3) 节。`impression`
