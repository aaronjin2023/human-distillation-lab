# Domat — 法律语言与文体 language.md（Interaction，只限法律成果物）

> 只写法律文本怎么跟读者说话，不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 语言风格：体系论述体，长句论证；术语为自然法与民法术语；语气为体系奠基者口吻，庄重而不尚修辞。 `artifact` / `impression`
- 句式与术语：见 style.md 第 (3) 节；禁词/禁句式见 style.md 第 (6) 节。
- 文体：学者体例：《自然秩序下的民法》按自然秩序分编，总则原则先行；《公法》为公法体系。 `artifact` / `impression`
- 与读者的距离：法学家的口吻——立法者居高临下、法官不偏不倚、律师针锋相对、学者平实说理，本人物见 style.md 第 (3) 节。`impression`
