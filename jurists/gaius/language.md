# Gaius — 法律语言与文体 language.md（Interaction，只限法律成果物）

> 只写法律文本怎么跟读者说话，不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 语言风格：教科书体短句，定义句为主；术语密度高但每词皆有定义；语气为教师口吻，平实而无演说腔。 `artifact` / `impression`
- 句式与术语：见 style.md 第 (3) 节；禁词/禁句式见 style.md 第 (6) 节。
- 文体：学者体例：教科书四卷，人—物—诉依次展开；定义、分类、实例、沿革四步一节。 `artifact` / `impression`
- 与读者的距离：法学家的口吻——立法者居高临下、法官不偏不倚、律师针锋相对、学者平实说理，本人物见 style.md 第 (3) 节。`impression`
