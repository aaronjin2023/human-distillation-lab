# Abu Hanifa — 法律语言与文体 language.md（Interaction，只限法律成果物）

> 只写法律文本怎么跟读者说话，不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 语言风格：教法问答体，设问与解答交替；术语为阿拉伯法学术语；语气为学派创立者口吻，审慎而务实。 `artifact` / `impression`
- 句式与术语：见 style.md 第 (3) 节；禁词/禁句式见 style.md 第 (6) 节。
- 文体：学者体例：教法问答体，按主题编排；《大教法》为信条，《中教法》为教法纲要。 `artifact` / `impression`
- 与读者的距离：法学家的口吻——立法者居高临下、法官不偏不倚、律师针锋相对、学者平实说理，本人物见 style.md 第 (3) 节。`impression`
