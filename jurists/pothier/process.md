# Robert Joseph Pothier — 法律工作过程规格 process.md（给文本/视频模型）

> 只按法律工作的逻辑写，不编造法律人物本人的生活场景；有手稿/草案/异议草稿可考者以文献证据为准，无手稿者按文本结构反推，不声称复刻原过程。角色：法学家（债法）。

## (1) 工作步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 写什么、写哪里 | 文本状态 | 最容易写错 |
|---|---|---|---|---|---|
| 1 问题提出 | 定问题、定论题、定射程 | 问题史梳理 / 争点清单 / 文献检索 | 只定骨架：问题、论题、反对意见、论证终点 | 约 10–20%，问题可见、论证未定 | 一开始就下结论，问题被结论吞掉 |
| 2 文献/法源梳理 | 找法源、找先例、找学说 | 法典 / 判例汇编 / 学说检索、先例区分表 | 全面检索，不先下结论，只列法源与学说清单 | 约 30–40%，法源已齐、立场未定 | 只引支持自己的文献，反对学说一句不提 |
| 3 论证展开 | 定义先行、按来源与标的双重分类 | 定义先行 / 区分法 / 分类表、罗马法引证 | 只搭骨架：定义—区分—分类、例外收束 | 约 50–60%，论证骨架已定、语言未满 | 定义不下，区分就无从下手 |
| 4 逐段打磨 | 逐段写、逐句推敲 | 按人物习惯逐段写（先定义再演绎 / 先警句再说理 / 先事实再规则） | 全篇贯通，逐段打磨术语与句式 | 约 85–90%，文本已立，个别段落仍可留空 | 一写长句堆砌就散，声口变了 |
| 5 定稿 | 校对、定稿、发布 | 通读 / 校对 / 定标题与篇名 | 全篇统一，不改论证结构 | 100%，完成态 | 定稿时改动已定的论证结构 |

## (2) 每一阶段的文本状态变化（5 个检查点）

1. 第 1 步结束：只有问题与论题（例如债的定义），正文未定。
2. 第 2 步结束：法源与学说清单已齐（罗马法原文、习惯法、判例），立场未定。
3. 第 3 步结束：论证骨架已定（定义—区分—分类），语言未满。
4. 第 4 步结束：论证密度骤升，定义精确、分类完整，个别处仍可留空。
5. 第 5 步结束：完成态，通读统一、定名。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：问题 10%、文献 25%、论证 30%、打磨 30%、定稿 5%（定义与分类步占大头）。
- 节奏提示：问题慢（让观者看清争点）、检索中速（看法源生长）、论证放慢（看原则权衡）、起草再放慢（看逐句换词）、定稿停顿（看完成态）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：文书 / 判决书 / 法典草案逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 文献 / 论证 / 打磨 / 定稿），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，起草用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放文本封面 / 判决书页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构法律人物本人的生活场景。

## (4) 过程示例（以本法律人物写现代题材的逻辑为例，不声称复刻原过程）

- 问题：定争点（关东煮摊租赁是何种债）、定请求、定适用法（债法一般原理）。
- 文献：找罗马法原文（债的定义）、找习惯法、找判例，列分类表。
- 论证：搭骨架（定义租赁—区分出租人与承租人义务—按标的分类），预设反驳（汤底算不算租赁标的）并回应。
- 打磨：逐段写定义，逐句删形容词，把模糊词换成已定义的术语。
- 定稿：通读一遍，只改标点与换行，定标题。
