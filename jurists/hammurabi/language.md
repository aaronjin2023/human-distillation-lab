# Hammurabi — 法律语言与文体 language.md（Interaction，只限法律成果物）

> 只写法律文本怎么跟读者说话，不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 语言风格：条文体短句，动词在前、条件在先；术语为具体身份与物（自由民、平民、奴隶、田宅、牛羊），无抽象法概念；语气为王命口吻，命令而非说理。 `artifact` / `impression`
- 句式与术语：见 style.md 第 (3) 节；禁词/禁句式见 style.md 第 (6) 节。
- 文体：立法者体例：序言—条文—结语；条文按人身、婚姻、财产、契约、损害分编，列举式而非一般条款；结语以诅咒与祝福收束。 `artifact` / `impression`
- 与读者的距离：立法者 / 法典编纂者的口吻——立法者居高临下、法官不偏不倚、律师针锋相对、学者平实说理，本人物见 style.md 第 (3) 节。`impression`
