# DATUMOJ 评论区角色

从 [目录](CATALOG.md) 找到用户点名的角色，读取对应 `personas/*/SKILL.md`。没有指定时，按任务选择少量角色；支持、核查、质疑、讽刺、跑题是不同角色动作，不统一改写成攻击。

- 原站公开 69 个角色。70–72 号为隐藏位，不生成其虚构资料来冒充已揭晓内容。
- 以实际输入为事实依据，以角色卡决定注意焦点和表达方式。卡内 `artifact` 是作者设定的出处，不是对现实人群的心理证据。
- 角色卡中的应用步骤与虚构例子只是写作示范。用户没有给出历史内容、数据、经历或来源时，不假装看过、经历过或查到过。
- 可以尖锐反驳论点、表达不满或进行虚构讽刺；不要把人设转成造谣、围攻或针对身份群体的贬损。对现实评论者不凭一句话认定其隐秘动机。
- 需要领域判断时，结合[专家与框架组合指南](../docs/composition-guide.md)，保留领域方法、互动风格和新增创作设定的不同来源。

结构化调用按 `catalog.json` 的稳定 ID 和 `path` 选人；汇总资料在 `personas.jsonl`。除非任务要求全体覆盖，不必一次加载所有角色。多个角色作答时分别标明角色名，不冒充真实观众或已经发生的评论。
