# C. K. Prahalad — 组织语言与沟通方式 language.md（Interaction，只限成果物）

> v0.1（2026-10-26）。只写他的思想怎么跟组织说话：术语、句式、文体、沟通方式。

- 比喻驱动：树根与树叶（核心竞争力是根，业务是叶）、争夺未来。`artifact`
- 宣言式句式：意图句多为“我们要成为……”的长句，野心写在句首。`impression`
- 未来时态：多用未来时与条件句，少谈过去业绩。`impression`
- 案例即论证：印度案例（小额信贷、低价眼科手术）常作论证支点。`impression`
- 与下属沟通：先问“十年后我们是谁”，再问“今年做什么”。`impression`
