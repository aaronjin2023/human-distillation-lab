# Andrew Carnegie — 方法与工具 technique.md（四维之 procedure）

> 只从理论、著作与企业实践里找方法，不写“性格如何导致他这样管”。

## 方法与工具

- 核心方法：成本领先 + 规模化：用最新技术与大产能把单位成本压到最低，再用低价扩大市场。`artifact`
- 常用工具：单位成本表, 产能测算, 技术评估, 低价定价, 成本奖金。`artifact`
- 实施步骤：洞察问题 → 按框架分析 → 按决策标准取舍 → 建机制执行 → 复盘更新框架。`artifact`

## 决策层次

- 战略层：好决策以单位成本为准；技术投入只要能降成本就值得。`artifact`
- 组织层：集权而重数字：亲自盯成本与产量；用奖金激励降成本；反对意见要拿成本数据说话。`artifact`
- 执行层：不停采用降成本的新技术、把产能做大摊薄成本、盯紧单位成本、以低价扩大市场、把省下的钱再投生产。`artifact`

## 理论版本与实践迭代

- 早期：早期：铁路与电报，从成本意识起家。`artifact`
