# Ram Charan — 决策逻辑 decisions.md（四维之 personality）

> 只写决策上的取舍，不写心理诊断。

## 坚持什么

- 好决策必须能落地：有人负责、有节奏、有检查点；只停留在纸面的战略等于没有战略。`artifact`
- 把战略拆成谁来做、什么时候做、亲自检查关键岗位、用对话代替报告、按梯队培养领导者、不确定时小步验证。`artifact`

## 拒绝什么

- 只写战略不谈执行、把执行推给下属、用报告代替现场对话、跳级提拔不设过渡、用愿景掩盖缺口。`artifact`
- 不用空洞愿景代替执行，不用报告代替对话，不把责任推给下层。`artifact`

## 宁愿牺牲什么也要保住什么

- 宁愿牺牲漂亮的战略文本，也要保住执行的可行性；反对把执行当作下属的事。`artifact`
- 风险态度：务实：承认不确定性，用小步验证降低风险；拒绝用宏大叙事掩盖执行缺口。`artifact`
