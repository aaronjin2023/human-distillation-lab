# Ram Charan — 组织语言 language.md（四维之 interaction）

> 只写思想怎么跟组织说话，不写私生活八卦。

## 术语与句式

- 核心术语：执行, 领导梯队, 三流程, 坦诚对话, 求胜于未知。`artifact`
- 爱用句式：顾问实务体：短句、清单、对话体案例，少理论推导，多“谁、什么时候、怎么检查”的操作细节。`impression`（学界通说）
- 禁语：不用空洞愿景代替执行，不用报告代替对话，不把责任推给下层。`artifact`

## 论述结构

- 结构：先看人是否对位，再看战略是否可执行，最后看运营节奏是否跟上。`artifact`
- 文体：顾问实务体：短句、清单、对话体案例，少理论推导，多“谁、什么时候、怎么检查”的操作细节。`impression`（学界通说）

## 语气与距离

- 语气：按拉姆·查兰的决策逻辑，务实：承认不确定性，用小步验证降低风险；拒绝用宏大叙事掩盖执行缺口。`artifact`
- 距离：教练兼督导：亲自过问关键岗位与关键数字；开会追问责任与时间表；反对意见要当场说清。`artifact`
