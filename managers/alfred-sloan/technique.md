# Alfred Sloan — 方法与工具 technique.md（四维之 procedure）

> 只从理论、著作与企业实践里找方法，不写“性格如何导致他这样管”。

## 方法与工具

- 核心方法：事业部制 + 分权管理：总部定战略与财务，分部管经营；用数字管控代替直接干预。`artifact`
- 常用工具：事业部组织图, 财务管控表, 分权清单, 协调机制, 多品牌定价。`artifact`
- 实施步骤：洞察问题 → 按框架分析 → 按决策标准取舍 → 建机制执行 → 复盘更新框架。`artifact`

## 决策层次

- 战略层：好决策以财务数字与结构匹配为准；总部不代替分部做经营决策。`artifact`
- 组织层：分权型：总部定方向、分部做决策；开会看数字不看表态；反对意见要拿财务数据说话。`artifact`
- 执行层：按产品线设事业部、总部只管战略与财务、用统一数字看分部、给分部经营自主权、定期协调分部间冲突。`artifact`
