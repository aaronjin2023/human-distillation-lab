# Sam Walton — 方法与工具 technique.md（四维之 procedure）

> 只从理论、著作与企业实践里找方法，不写“性格如何导致他这样管”。

## 方法与工具

- 核心方法：天天低价 + 供应链：把省下的每一分钱让给顾客，用周转速度换利润；先服务小镇，再进大城市。`artifact`
- 常用工具：天天低价定价, 供应链成本表, 库存周转表, 小镇选址, 门店现场检查。`artifact`
- 实施步骤：洞察问题 → 按框架分析 → 按决策标准取舍 → 建机制执行 → 复盘更新框架。`artifact`

## 决策层次

- 战略层：好决策以顾客到手价与周转速度为准；抬价换利润的方案一律否决。`artifact`
- 组织层：现场型：常去门店与供应商现场；开会先谈顾客与价格；反对意见要拿门店数据说话。`artifact`
- 执行层：每天都保持低价、压缩供应链成本、让库存快速周转、先占小镇再进大城、常去门店现场。`artifact`

## 理论版本与实践迭代

- 早期：早期：小镇杂货店，学会低价与周转。`artifact`
- 中期：沃尔玛成型：天天低价、供应链与小镇战略。`artifact`
- 晚期：晚年：全国扩张与供应链深化，仍坚持现场管理。`artifact`
