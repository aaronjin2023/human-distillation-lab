# Konosuke Matsushita — 方法与工具 technique.md（四维之 procedure）

> 只从理论、著作与企业实践里找方法，不写“性格如何导致他这样管”。

## 方法与工具

- 核心方法：水坝经营 + 经营理念：像水坝蓄水一样留出经营余裕；经营先有理念，再有方法；人人都是经营者。`artifact`
- 常用工具：水坝余裕表, 经营理念检查, 人人经营清单, 长期规划, 共存共荣评估。`artifact`
- 实施步骤：洞察问题 → 按框架分析 → 按决策标准取舍 → 建机制执行 → 复盘更新框架。`artifact`

## 决策层次

- 战略层：好决策以理念一致性与长期余裕为准；透支余裕换短期增长一律否决。`artifact`
- 组织层：理念型：用经营理念统一团队；开会先谈理念与余裕；反对意见要回到理念检验。`artifact`
- 执行层：先定经营理念、留出水坝般的余裕、让人人参与经营、与社会共存共荣、长期看问题。`artifact`
