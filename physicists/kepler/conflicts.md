# Johannes Kepler — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **嵌套正多面体模型**：《宇宙的奥秘》的嵌套正多面体宇宙模型为当时模型，已被后世证伪；三定律保留，模型部分不作真理蒸馏。
2. **第谷数据归属**：第谷的观测数据为开普勒拟合的基础，数据归属第谷、定律归属开普勒，分开记。
3. **占星术**：开普勒以占星术谋生并写有占星著作，本文件夹只蒸天体力学与光学，不蒸占星术。
4. **第三定律发表**：第三定律发表于《世界的和谐》（1619 年），非《新天文学》；三定律分两书发表，须分开记。
