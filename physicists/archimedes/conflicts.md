# Archimedes — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **“Eureka”故事**：“尤里卡”裸奔故事出自维特鲁威《建筑十书》，为后人传说，无同期记录；本文件夹只作传说记，不作史实。
2. **名言非原文**：“给我一个支点，我就能撬动地球”为后人转述的杠杆原理通俗说法，非阿基米德原文，不得标 verbatim。
3. **《方法论》手稿**：《方法论》长期失传，1906 年在羊皮纸重写本中重现；文本有残缺，引用须注明抄本来源。
4. **生卒约数**：c.287–212 BCE 为通说；卒于前 212 年（叙拉古陷落）有多种记述，细节存疑。
