# Sadi Carnot — 研究方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写研究上的内容，不写私生活。

- 理想模型抽象：从蒸汽机抽出高低温热源与循环
- 可逆循环构造：等温膨胀、绝热膨胀、等温压缩、绝热压缩
- 反证法论证：若有更高效热机，可造永动机
- 效率上限推导：只与温度有关
- 与工程对照：真实热机效率低于上限的原因分析

## 方法要点

- 核心套路：观察 → 假设 → 实验 → 建模 → 验证。
- 工具与证据的关系：方法决定了能看到什么，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：实验/推导中的失败与反例是方法的一部分。
