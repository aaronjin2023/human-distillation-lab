# Thales — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **无原著传世**：泰勒斯无任何著作传世，全部说法来自亚里士多德、希罗多德等后人转述；本文件夹不引任何泰勒斯“原文”，不标 verbatim。
2. **日食预言归属**：前 585 年日食预言常归于泰勒斯，但无同期记录，学界对其是否真由他作出存疑；本次只记“归属存疑”，不作定论。
3. **水的本原说**：水为万物本原是当时模型，作为物理学说已被后世证伪；作为“以自然原因解释自然”的方法论起点保留，不作真理蒸馏。
4. **生卒约数**：c.624–c.546 BCE 为通说约数，个别来源作 c.626/623–c.548/545 BCE；本次用草稿口径，异说见此。
