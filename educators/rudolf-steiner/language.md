# Rudolf Steiner — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：诗意、哲理的论述体，比喻多（生长、节奏、呼吸）；对儿童多用故事与歌谣。 `impression`
- 教材语言：讲演体：《儿童的教育》由讲演而成，语言形象。 `artifact`
- 禁语/禁句：不用过早抽象、不用统一考试、不用压制艺术的教法。 `impression`
- 教师角色与语言：教师是陪伴者与艺术家，陪一个班多年，了解每个儿童。 `artifact`
- 学生角色与语言：学生是故事的听者与艺术的创造者，能自由表达；教师不能拔苗助长。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
