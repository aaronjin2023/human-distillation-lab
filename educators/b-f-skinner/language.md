# B. F. Skinner — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：精确、科学的论述体，术语多（强化、塑造、小步）；讲授语言简短明确。 `impression`
- 教材语言：专著体：实验数据与理论论述结合。 `artifact`
- 禁语/禁句：不用惩罚、不用大步跳跃、不用无反馈的讲授。 `impression`
- 教师角色与语言：教师是程序的设计者与强化的安排者，设计小步与反馈。 `artifact`
- 学生角色与语言：学生是按程序学习的人，能自定步调；教师不能跳过掌握检查。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
