# Carl Rogers — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：真诚、平和、接纳的谈话体，多用反映式倾听（'你是说……'）；少用命令与评价。 `impression`
- 教材语言：论著体：以个案与对话写理论，语言平实。 `artifact`
- 禁语/禁句：不用威胁、不用分数排名、不用强加课程。 `impression`
- 教师角色与语言：教师是促进者：真诚、接纳、共情，不做权威。 `artifact`
- 学生角色与语言：学生是学习的主人，能决定学什么、怎么学；教师不能强加。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
