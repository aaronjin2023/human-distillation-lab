# Chen Heqin — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：亲切、简短、重复的口语，多用儿歌、故事与提问；对教师多用'观察'、'记录'的语言。 `impression`
- 教材语言：论著语言平实，多用儿童实例与观察记录说话。 `artifact`
- 禁语/禁句：不用训斥、不用成人术语、不用死板的统一教材。 `impression`
- 教师角色与语言：教师是观察者与环境的布置者，先看后教，少说多做。 `artifact`
- 学生角色与语言：儿童是游戏与活动的主人，能自由选择活动；教师不能包办代替。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
