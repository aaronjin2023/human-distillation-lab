# Anton Makarenko — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：生动、叙事的文学体，多用集体生活的实例；对青年多用尊重与要求的语言。 `impression`
- 教材语言：《教育诗》以叙事写教育实践，故事多、对话多。 `artifact`
- 禁语/禁句：不用体罚、不用只讲个人不讲集体的教法。 `impression`
- 教师角色与语言：教师是集体的组织者与榜样，与学生同劳动。 `artifact`
- 学生角色与语言：学生是集体的一员，能自治、能劳动；个人服从集体，集体保护个人。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
