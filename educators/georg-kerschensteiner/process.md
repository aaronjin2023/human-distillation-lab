# Georg Kerschensteiner — 教学过程规格 process.md（给文本/视频模型）

> 只按教学逻辑写，不编造教育家本人的生活场景；有课堂记录/教案可考者以记录为准，无记录者按著作与教材结构反推，不声称复刻原课堂。

## (1) 教学步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 工具 | 教什么、教哪里 | 课堂状态 | 最容易教错 |
|---|---|---|---|---|---|
| 1 观察学生 | 看学生的动手能力、职业兴趣与公民意识 | 观察 / 谈话 / 手艺摸底 | 只定起点：学生水平、兴趣点、误解点 | 约 10–20% 完成，目标可见、内容未定 | 一开始就凭印象判断学生水平，不留观察记录 |
| 2 设计课程 | 定劳作任务、工场安排与公民课内容 | 任务单 / 工场安排 / 教案 | 只定骨架：目标、环节、材料、评价方式 | 约 30–40%，结构已定、细节未满 | 只定目标不定材料与评价，结构就立不住 |
| 3 教学 | 学生在工场劳作，教师巡回指导，讲授只讲要领 | 劳作教学 / 项目法 / 示范 | 全课贯通，学生动手、教师引导 | 约 60–70%，内容已展开、理解未稳 | 第 3 步劳作变机械重复，公民教育就落空；第 2 步不了解学徒的职业，任务就脱离生活。 |
| 4 反馈 | 检查劳作成品与合作表现，指出改进点 | 作品检验 / 观察 / 谈话 | 只改理解与方法，不改课程目标 | 约 85–90%，多数已会，个别仍需补 | 只看分数不看理解，补救就无从下手 |
| 5 修订 | 调整劳作任务难度，把公民课的新问题编进下一课 | 修订计划 / 延伸任务 | 全课统一，不改核心理念 | 100%，完成态，下一课目标已定 | 改动核心理念，或把下一课目标定得脱离学生实际 |

- 每步注明：这一步**最容易教错**的地方见上表最后一列，其中第 3 步最关键：第 3 步劳作变机械重复，公民教育就落空；第 2 步不了解学徒的职业，任务就脱离生活。

## (2) 每一阶段的课堂状态变化（过程视频/文本生成的节奏）

1. 第 1 步结束：只有观察笔记与学生起点，课程未定。
2. 第 2 步结束：目标、环节、材料与评价已定，细节未满。
3. 第 3 步结束：学生动手、教师引导，内容已展开、理解未稳。
4. 第 4 步结束：多数已会，错误被纠正，个别仍需补。
5. 第 5 步结束：完成态，下一课目标已定。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：观察 15%、设计 20%、劳作教学 40%、反馈 15%、修订 10%（按教育家特点分配）。
- 节奏提示：观察慢（让观者看清学生起点）、设计中速（看课程生长）、教学放慢（看师生互动）、反馈停顿（看理解变化）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：教案/黑板/教具/学生作品逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（观察学生 / 设计课程 / 教学 / 反馈 / 修订），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：教室全景 / 教师特写 / 学生小组特写三机位轮换；观察用全景，反馈用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放著作封面/教案页/学校照片，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡教案；不要把过程剪成跳切，保留教学的连续性；不要虚构教育家本人的生活场景；不要把学生拍成摆拍的“标准答案”。

## (4) 过程示例（以本教育家上一堂课的逻辑为例，不声称复刻原课堂）

- 观察学生：看学生的动手能力、职业兴趣与公民意识。
- 设计课程：定劳作任务、工场安排与公民课内容。
- 教学：学生在工场劳作，教师巡回指导，讲授只讲要领。
- 反馈：检查劳作成品与合作表现，指出改进点。
- 修订：调整劳作任务难度，把公民课的新问题编进下一课。
- 节奏：观察 15%、设计 20%、劳作教学 40%、反馈 15%、修订 10%。
