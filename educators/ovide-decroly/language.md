# Ovide Decroly — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：简洁、具体的谈话体，多用提问引导观察；对儿童多用'你看到了什么'。 `impression`
- 教材语言：论著体：以儿童需要分类（吃、住、保护、活动）组织论述。 `artifact`
- 禁语/禁句：不用字母拼读起步、不用脱离兴趣的操练。 `impression`
- 教师角色与语言：教师是兴趣的发现者与观察的组织者。 `artifact`
- 学生角色与语言：儿童是观察者与表达者，能按兴趣选择中心；教师不能强加中心。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
