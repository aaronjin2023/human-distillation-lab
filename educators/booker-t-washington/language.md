# Booker T. Washington — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：质朴、恳切的自传与演说体，多用生活实例与'做'字句；善用'尊严'、'自立'。 `impression`
- 教材语言：自传体：《从奴隶到自由》以亲身经历讲教育道理。 `artifact`
- 禁语/禁句：不用空谈权利的论调、不用轻视体力劳动的话。 `impression`
- 教师角色与语言：教师是工场的师傅与学校的建设者，以身作则。 `artifact`
- 学生角色与语言：学生是劳动者与建设者，能动手建校；教师不能替学生劳动。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
