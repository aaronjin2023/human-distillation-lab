# G. Stanley Hall — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：科学、系统的论述体，数据多、术语多；善用'阶段'、'生长'、'调查'。 `impression`
- 教材语言：专著体：调查数据与理论论述结合。 `artifact`
- 禁语/禁句：不用脱离儿童研究的空谈、不用不分阶段的统一教法。 `impression`
- 教师角色与语言：教师是儿童的研究者，先调查后教学。 `artifact`
- 学生角色与语言：学生是生长中的人，能按阶段学习；教师不能拔苗助长。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
