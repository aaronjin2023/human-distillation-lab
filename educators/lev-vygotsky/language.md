# Lev Vygotsky — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：严谨、哲理的论述体，概念多（最近发展区、支架、内化）；善用对话体例证。 `impression`
- 教材语言：专著体：理论论证与实验结合，概念层层推进。 `artifact`
- 禁语/禁句：不用只测独自水平的评价、不用脱离交往的讲授。 `impression`
- 教师角色与语言：教师是支架的搭建者与对话的组织者，搭好脚手架再撤掉。 `artifact`
- 学生角色与语言：学生是合作者与对话者，能在帮助下做到更多；教师不能包办，也不能放任。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
