# Francis Wayland Parker — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：生动、口语化的谈话体，多用提问与故事；对儿童多用鼓励，少用命令。 `impression`
- 教材语言：《会说话与教学》以谈话体写教学法，实例多。 `artifact`
- 禁语/禁句：不用拼写课本、不用描红本、不用体罚与刻板纪律。 `impression`
- 教师角色与语言：教师是儿童活动的组织者与师范的培养者，先观察儿童再设计活动。 `artifact`
- 学生角色与语言：儿童是做事与展示的主人，能决定活动方式；教师不能包办。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
