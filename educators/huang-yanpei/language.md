# Huang Yanpei — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：质朴直白的白话，多用职业术语与车间实例，少空论；提问多问'这件活怎么做'。 `impression`
- 教材语言：教材按职业流程写，先做后讲，步骤清楚；少抒情，多操作说明。 `artifact`
- 禁语/禁句：不用空洞的道德说教、不用脱离职业的纯理论、不用文言套话。 `impression`
- 教师角色与语言：职业导师兼工场师傅，示范在先，巡回指导。 `artifact`
- 学生角色与语言：学徒兼劳动者，动手者；能决定自己的职业方向，不能脱离工场纪律。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
