# Tao Xingzhi — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：大白话，晓庄体：短句、口语、比喻多，农民与儿童都听得懂；善用'做'字句。 `impression`
- 教材语言：文章如说话，一事一议；多用生活实例，少用术语。 `artifact`
- 禁语/禁句：不用文言、不用洋术语、不用脱离生活的空论。 `impression`
- 教师角色与语言：教师是生活的同行者与'小先生'的组织者，先做后教。 `artifact`
- 学生角色与语言：学生是做事的人，也是'小先生'，能教别人；教师与学生互教互学。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
