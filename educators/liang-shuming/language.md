# Liang Shuming — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：深沉、恳切的讲演体，长句说理，多用'吾人'、'问题在'；善用对比与追问。 `impression`
- 教材语言：论著体：系统论述，概念多（伦理本位、团体组织），论证层层推进。 `artifact`
- 禁语/禁句：不用技术万能论、不用空洞口号、不用照搬西方的办法。 `impression`
- 教师角色与语言：讲学者与乡建干部，教师是乡村的组织者与启发者。 `artifact`
- 学生角色与语言：农民是乡建的主体，能自己组织合作社与村学；教师不能包办。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
