# Mei Yiqi — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：温和、简练、克制的白话，少修饰，多判断；讲话慢而准，不煽情。 `impression`
- 教材语言：论著语言平实，说理不尚雄辩，常用'吾以为'式的商榷口吻。 `artifact`
- 禁语/禁句：不用大话空话、不用行政命令式语言、不用煽动性口号。 `impression`
- 教师角色与语言：校长是服务者与守护者，少露面，多做事；教授是大学的主体。 `artifact`
- 学生角色与语言：求学者与研讨者，能自由选课、提问、质疑；不能破坏学术自由。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
