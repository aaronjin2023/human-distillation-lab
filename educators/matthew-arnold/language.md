# Matthew Arnold — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：优雅、警句式的论述体，长句分明，比喻多（甜美与光明、机械）；督学报告语言实。 `impression`
- 教材语言：论文与报告体：论证与视察记录结合。 `artifact`
- 禁语/禁句：不用机械的考试论调、不用只重实用的课程论。 `impression`
- 教师角色与语言：教师是文化的传授者，督学是标准的守护者。 `artifact`
- 学生角色与语言：学生是文学的读者与鉴赏者，能朗读、能品味；不能只背答案。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
