# Johann Heinrich Pestalozzi — 教育语言与表达 language.md（Interaction，只限教育成就）

- 讲授语言：温和、恳切、重复的谈话体，多用提问与故事；对儿童多用鼓励，少用命令。 `impression`
- 教材语言：小说体与书信体：《林哈德与葛笃德》以乡村故事讲教育道理。 `artifact`
- 禁语/禁句：不用抽象定义开讲、不用体罚、不用脱离实物的空谈。 `impression`
- 教师角色与语言：教师是慈爱的父亲与母亲，先爱学生再教知识。 `artifact`
- 学生角色与语言：儿童是观察者与劳动者，能动手、能提问；教师不能代替儿童看与做。 `artifact`
- 提问方式：提问多从学生的经验与观察出发，追问多于给答案。`impression`
- 留白与启发：讲授留有余地，结论由学生自己得出；沉默与等待也是教学语言。`impression`
