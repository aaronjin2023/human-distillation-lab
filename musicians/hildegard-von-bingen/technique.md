# Hildegard von Bingen — 技法与工序 technique.md（Procedure，只限乐曲）

- 素歌旋律公式：同一旋律细胞加音、减音、移位，构成长句。`verbatim`（《美德剧》82 段旋律中反复出现）
- 大跳音程：四度、五度跳进是标志，素歌常例只用二度三度，希尔德加德反其道而行。`artifact`
- 调式写作：以多利亚等调式为骨架，旋律从中心音出发、爬升、回落。`artifact`（Grove 通说）
- 词曲同源：歌词与旋律同为作者所作，旋律随词义起伏。`artifact`
- 记谱：德国纽姆谱，音高较明确、节奏解释多歧义，现代演绎须注明版本。`artifact`
