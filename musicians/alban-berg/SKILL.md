## 一句话

- **这是谁：** 现代主义 / 第二维也纳乐派作曲家，代表作《沃采克》、《露露》、《小提琴协奏曲》。
- **什么时候用他：** 需要按他的风格为一个现代题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Berg style, twelve-tone row with tonal allusion, lyrical atonality, expressive dissonance, large-scale opera form, leitmotif, tragic climax
- **中文：** 贝尔格风格，带调性暗示的十二音音列，抒情无调性，表现性不协和，大型歌剧曲式，主导动机，悲剧高潮。
- **过程一句话：** 动机 / 音列 / 细胞 → 草稿 → 展开 → 配器 → 定稿（详见 process.md）。

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音上可听、可指认）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression` 三级证据，见各文件标注。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 证据分级：`verbatim`（乐曲本身）/ `artifact`（成果物 / 文献）/ `impression`（他人印象，须标明谁的印象）。矛盾记入 `conflicts.md`。
