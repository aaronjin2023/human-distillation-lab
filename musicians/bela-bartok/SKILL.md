# Béla Bartók — 贝拉·巴托克 (1881–1945) · 音乐家蒸馏 v0.1

> 状态：草稿 v0.1，2026-10-26。只蒸行业内成就与成果物（乐曲与作曲技法），不蒸私生活。名单位置：musicians-top100-draft.md #26–50 段。模板：该草稿第 7 节（画家模板音乐版）。

## 一句话

- **这是谁：** 现代主义 / 民族乐派作曲家，代表作《乐队协奏曲》、《弦乐、打击乐与钢片琴音乐》、《第四弦乐四重奏》。
- **什么时候用他：** 需要按他的风格为新题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Folk modes made modern, polymodality, arch form, night music, rhythm as drive, string writing of percussive clarity
- **中文：** 民间调式现代化，复调式，拱形曲式，夜之音乐，节奏即驱动力，打击性清晰的弦乐写法
- **过程一句话：** 动机 → 草稿 → 展开 → 配器 → 定稿（见 process.md；动机常是一句民间式短旋律，先定其调式；草稿定拱形曲式与调式布局；展开靠动机在复调式中变形；配器分层精细，打击乐是结构；定稿只调拱形对称与夜之音乐的位置。）

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression`（见草稿第 7.2 节）。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 矛盾记入 `conflicts.md`，不强行统一。
