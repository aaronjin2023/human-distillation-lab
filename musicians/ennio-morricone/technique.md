# Ennio Morricone — 技法与工序 technique.md（Procedure，只限乐曲）

> v0.1（2026-10-26）。

## 核心技法

- 先写主题动机：两三个音的核心动机先定，再为不同场景变奏。`impression`
- 音色先于和声：先选口哨 / 人声 / 小号的音色，再定伴奏的和声密度。`artifact`
- 稀疏伴奏：伴奏常只留一个持续音或简单节奏型，主题独奏占前景。`artifact`
- 非常规乐器：口哨、电吉他、口琴进入管弦乐队，制造画面感而非异国情调。`artifact`
- 主题再现：同一主题在片中多次出现，每次换配器，听者靠音色认场景。`impression`

## 层序

- 层序：动机 → 草稿（结构骨架）→ 展开（动机发展）→ 配器（音色与声部）→ 定稿（统一、收尾）。
- 修改痕迹：以发表乐谱与录音为准；草稿—定稿的修改只按乐谱版本差异写，不推测作曲家本人的意图。
- 不写：私生活、心理诊断、“他性格如何导致他这样写”。
