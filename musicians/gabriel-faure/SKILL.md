# Gabriel Fauré — 加布里埃尔·福雷 (1845–1924) · 音乐家蒸馏 v0.1

> 状态：草稿 v0.1，2026-10-26。只蒸行业内成就与成果物（乐曲与作曲技法），不蒸私生活。名单位置：musicians-top100-draft.md #26–50 段。模板：该草稿第 7 节（画家模板音乐版）。

## 一句话

- **这是谁：** 浪漫主义晚期 / 法国作曲家，代表作《安魂曲》(Requiem)、《帕凡舞曲》(Pavane)、《佩莱阿斯与梅丽桑德》。
- **什么时候用他：** 需要按他的风格为新题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Modal subtlety, quiet harmony, restrained lyricism, late style austere and luminous, French understatement
- **中文：** 调式微妙，静谧和声，克制抒情，晚期风格简省 而明亮，法国式含蓄
- **过程一句话：** 动机 → 草稿 → 展开 → 配器 → 定稿（见 process.md；动机常是一句窄音域歌唱旋律，先定其静谧性格；草稿定调式与曲式；展开靠和声微妙转调；配器轻、透明；定稿只改力度，绝不加高潮。）

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression`（见草稿第 7.2 节）。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 矛盾记入 `conflicts.md`，不强行统一。
