# Amy Beach — 艾米·比奇 (1867–1944) · 音乐家蒸馏 v0.1

> 状态：草稿 v0.1，2026-10-26。只蒸行业内成就与成果物（乐曲与作曲技法），不蒸私生活。名单位置：musicians-top100-draft.md #26–50 段。模板：该草稿第 7 节（画家模板音乐版）。

## 一句话

- **这是谁：** 浪漫主义晚期 / 美国作曲家，代表作《盖尔交响曲》(Gaelic Symphony)、《升 C 小调钢琴协奏曲》、《降 E 大调弥撒曲》。
- **什么时候用他：** 需要按他的风格为新题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** American Romantic grandeur in classical forms, Gaelic folk colour, piano virtuosity made symphonic, first large forms by an American woman composer
- **中文：** 古典曲式里的美国浪漫主义宏大，盖尔民间色彩，钢琴炫技交响化，美国女性作曲家写出的第一批大型曲式
- **过程一句话：** 动机 → 草稿 → 展开 → 配器 → 定稿（见 process.md；动机常是一句民间式旋律，先定其可唱性；草稿定大型曲式与调性；展开靠民间主题在各乐章间互引；配器厚实分层；定稿只调民间色彩与古典骨架的平衡。）

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression`（见草稿第 7.2 节）。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 矛盾记入 `conflicts.md`，不强行统一。
