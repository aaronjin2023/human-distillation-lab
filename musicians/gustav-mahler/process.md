# Gustav Mahler — 作曲过程规格 process.md（给音乐 / 视频模型）

> 只按乐曲的制作逻辑写，不编造作曲家本人的生活场景。不声称复刻某一首原作的原过程。

## (1) 作曲步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么材料、写哪里 | 乐曲状态 | 最容易写错 |
|---|---|---|---|---|---|
| 1 动机 | 找核心动机 | 哼唱 / 钢琴试弹 / 纸上草稿 | 只写 2–4 个音的核心动机与节奏型，不写全曲 | 约 10–20%，动机可见、结构未定 | 动机太长、太满，后面无处发展 |
| 2 草稿 | 搭结构骨架 | 和声草稿 / 曲式图 / 声部骨架 | 主调性与曲式一次定稿，定冷暖与张力 | 约 30–40%，结构已定、细节全无 | 曲式未定就写细节，后面推倒重来 |
| 3 展开 | 按动机发展 | 变奏 / 模进 / 对位 / 配器分层 | 每段只展开一层关系（先旋律，再和声） | 约 60–70%，体积与空间初现 | 展开一乱就散，动机认不出来 |
| 4 配器 | 定音色与声部 | 配器表 / 乐器组合试听 / 力度标记 | 只写焦点段落的配器与高潮点的音色 | 约 85–90%，主体已立，细节仍可留空 | 配器一厚就脏，盖住动机 |
| 5 定稿 | 统一、收尾 | 校对总谱 / 排练反馈 / 演奏指示 | 全曲薄薄统一，不改结构，只改记谱与力度 | 100%，完成态 | 定稿时改结构，前面白写 |

- 本作曲家版本：动机常是一句民间式短旋律或一个进行曲节奏；草稿定多乐章弧线与调性；展开靠动机在各乐章间互引与变形；配器占全曲一半以上时间；定稿只调高潮位置与收束方式。

## (2) 每一阶段的乐曲状态变化（过程音频 / 视频的节奏）

1. 动机结束：核心动机可听清，结构未定。
2. 草稿结束：结构已定，细节全无。
3. 展开中段：动机变形出现，体积初现。
4. 配器结束：音色已立，高潮点可听。
5. 定稿定格：完成态停 3 秒。

- 节奏：演示版 60–90 秒；过程版 3–5 分钟。动机慢、草稿中速、展开中速、配器最长（占 60%）、定稿停顿。
- 分配建议：动机 10%、草稿 15%、展开 45%、配器 25%、定稿 5%（按本作曲家特点微调，展开 / 配器谁是本体谁占大头）。

## (3) 过程视频 / 音频的呈现建议

- 机位 / 声道：俯拍总谱 / 钢琴键盘特写 / 排练全景三机位轮换；动机用钢琴特写，配器用总谱全景。
- 呈现：每步左上角出小字步骤名（动机 / 草稿 / 展开 / 配器 / 定稿），不配画外音讲人生，只配步骤字幕与总谱滚动；背景音乐就是正在写的乐曲本身，无解说也可。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 首原作小段对照（只放乐曲，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡总谱；不要把过程剪成跳切，保留动机发展的连续性。

## (4) 过程示例（按本作曲家逻辑，不声称复刻原作原过程）

- 动机：常是一句民间式短旋律或一个进行曲节奏。
- 草稿：定多乐章弧线与调性。
- 展开：靠动机在各乐章间互引与变形。
- 配器：占全曲一半以上时间。
- 定稿：只调高潮位置与收束方式。
