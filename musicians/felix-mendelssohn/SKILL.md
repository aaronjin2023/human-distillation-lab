# Felix Mendelssohn — 菲利克斯·门德尔松 (1809–1847) · 音乐家蒸馏 v0.1

> 状态：草稿 v0.1，2026-10-26。只蒸行业内成就与成果物（乐曲与作曲技法），不蒸私生活。名单位置：musicians-top100-draft.md #26–50 段。模板：该草稿第 7 节（画家模板音乐版）。

## 一句话

- **这是谁：** 浪漫主义 / 德国作曲家，代表作《仲夏夜之梦》、《E 小调小提琴协奏曲》Op. 64、《无词歌》。
- **什么时候用他：** 需要按他的风格为新题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Classical clarity with Romantic lightness, elfin scherzo sparkle, singing melody, balanced phrases, transparent orchestration
- **中文：** 古典的清晰 + 浪漫的轻盈，精灵谐谑曲的闪烁，歌唱性旋律，均衡乐句，透明配器
- **过程一句话：** 动机 → 草稿 → 展开 → 配器 → 定稿（见 process.md；动机常是一句均衡歌唱旋律；草稿一次定曲式与调性；展开靠模进与声部交替，不破坏乐句平衡；配器分层轻、木管点彩；定稿校对乐句呼吸。）

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression`（见草稿第 7.2 节）。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 矛盾记入 `conflicts.md`，不强行统一。
