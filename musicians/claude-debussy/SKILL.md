# Claude Debussy — 克劳德·德彪西 (1862–1918) · 音乐家蒸馏 v0.1

> 状态：草稿 v0.1，2026-10-26。只蒸行业内成就与成果物（乐曲与作曲技法），不蒸私生活。名单位置：musicians-top100-draft.md #26–50 段。模板：该草稿第 7 节（画家模板音乐版）。

## 一句话

- **这是谁：** 印象主义作曲家，代表作《牧神午后前奏曲》、《大海》(La Mer)、《佩莱阿斯与梅丽桑德》。
- **什么时候用他：** 需要按他的风格为新题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Whole-tone and pentatonic colour, parallel chords, sound as light and water, suggestion before statement, orchestration like mist
- **中文：** 全音阶与五声色彩，平行和弦，声音如光与水，暗示先于陈述，配器如雾
- **过程一句话：** 动机 → 草稿 → 展开 → 配器 → 定稿（见 process.md；动机常是一两个音的碎片，先定其色彩；草稿定调式（全音/五声）与曲式轮廓；展开靠色彩换调而非动机发展；配器轻、透明；定稿只改音色，绝不加属—主收束。）

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression`（见草稿第 7.2 节）。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 矛盾记入 `conflicts.md`，不强行统一。
