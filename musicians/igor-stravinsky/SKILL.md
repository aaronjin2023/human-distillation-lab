## 一句话

- **这是谁：** 现代主义作曲家，代表作《春之祭》、《彼得鲁什卡》、《火鸟》。
- **什么时候用他：** 需要按他的风格为一个现代题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Stravinsky style, irregular accents, ostinato blocks, bitonal clashes, sharp orchestral colour, block juxtaposition, no smooth transition
- **中文：** 斯特拉文斯基风格，不规则重音，固定音型块状并置，双调性冲突，锋利的管弦乐色彩，段落硬切，无平滑过渡。
- **过程一句话：** 2–4 音核心细胞与不规则重音型 → 草稿 → 展开 → 配器 → 定稿（详见 process.md）。

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音上可听、可指认）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression` 三级证据，见各文件标注。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 证据分级：`verbatim`（乐曲本身）/ `artifact`（成果物 / 文献）/ `impression`（他人印象，须标明谁的印象）。矛盾记入 `conflicts.md`。
