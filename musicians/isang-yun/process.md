# Isang Yun — 作曲过程规格 process.md（给音乐 / 视频模型）

> 只按乐曲的制作逻辑写，不编造作曲家本人的生活场景。不声称复刻某一首原作的原过程。

## (1) 作曲步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么材料、写哪里 | 乐曲状态 | 最容易写错 |
|---|---|---|---|---|---|
| 1 动机 | 找核心碎片 / 声音事件 | 钢琴试弹 / 录音试听 / 纸上草稿 | 只写 2–4 个音的核心碎片或一个声音事件，不写全曲 | 约 10–20%，碎片可见、结构未定 | 碎片一写满，静默就没了 |
| 2 草稿 | 搭结构骨架 | 音列变形表 / 曲式图 / 静默位置 | 主结构与静默位置一次定稿 | 约 30–40%，结构已定、细节全无 | 静默位置定错，全曲没呼吸 |
| 3 展开 | 按碎片发展 | 变奏 / 音色传递 / 织体分层 | 每段只展开一层（先音色，再织体） | 约 60–70%，体积初现 | 展开一密，音色就糊了 |
| 4 配器 | 定音色与声部 | 配器表 / 乐器组合试听 / 力度标记 | 只写焦点段落的配器与高潮点的音色 | 约 85–90%，主体已立 | 配器一厚，碎片就没了 |
| 5 定稿 | 统一、收尾 | 校对总谱 / 排练反馈 / 演奏指示 | 全曲薄薄统一，不改结构，只改记谱与力度 | 100%，完成态 | 定稿时改结构，全曲散掉 |

- 本表是“音列 / 声音事件—草稿—展开—配器—定稿”的尹伊桑版本：每步只做一件事，每段只展开一层关系。

## (2) 每一阶段的乐曲状态变化（过程音频 / 视频的节奏）

1. 动机结束：找核心碎片 / 声音事件，只写 2–4 个音的核心碎片或一个声音事件已定，结构未定，听者能听清最小材料。
2. 草稿结束：搭结构骨架，主结构与静默位置一次定稿已定，细节全无，听者能感到全曲的走向。
3. 展开中段：按碎片发展，每段只展开一层（先音色，再织体）已现，体积与空间初现，是最长的一段。
4. 配器结束：定音色与声部，只写焦点段落的配器与高潮点的音色已定，主体已立，细节仍可留空。
5. 定稿定格：统一、收尾完成，定稿，停 2–3 秒听完成态。

- 节奏：演示版 60–90 秒；过程版 3–5 分钟。分配建议：动机 10%、草稿 15%、展开 50%、配器 20%、定稿 5%（按作曲家特点可调，展开步最长，因为那是风格本体）。
- 节奏提示：动机慢（让听者听清核心动机）、草稿中速（听结构生长）、展开放慢（听动机变形）、定稿停顿 2–3 秒（听完成态）。

## (3) 过程视频 / 音频的呈现建议

- 机位 / 声道：俯拍总谱 / 钢琴键盘特写 / 排练全景三机位轮换；动机用钢琴特写，配器用总谱全景。
- 呈现：每步左上角出小字步骤名（动机 / 草稿 / 展开 / 配器 / 定稿），不配画外音讲人生，只配步骤字幕与总谱滚动；背景音乐就是正在写的乐曲本身，无解说也可。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 首原作小段对照（只放乐曲，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡总谱；不要把过程剪成跳切，保留动机发展的连续性。

## (4) 过程示例（按本作曲家逻辑，不声称复刻原作原过程）

动机：找核心碎片 / 声音事件（只写 2–4 个音的核心碎片或一个声音事件）。草稿：搭结构骨架（主结构与静默位置一次定稿）。展开：按碎片发展（每段只展开一层（先音色，再织体））。配器：定音色与声部（只写焦点段落的配器与高潮点的音色）。定稿：统一、收尾（全曲薄薄统一，不改结构，只改记谱与力度）。
