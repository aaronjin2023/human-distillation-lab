# Miles Davis — 迈尔斯·戴维斯 (1926–1991) · 音乐家蒸馏 v0.1

## 一句话

- **这是谁：** 爵士 / 冷爵士—融合作曲家，代表作 Kind of Blue、《Bitches Brew》、《So What》。
- **什么时候用他：** 需要按他的风格为一个现代题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Miles Davis style, modal jazz, cool muted trumpet, space and silence, minimal notes, modal scale, electric fusion, less is more
- **中文：** 戴维斯风格，调式爵士，冷峻弱音小号，留白与静默，少即是多，调式音阶，电声融合。
- **过程一句话：** 主题旋律与和声进行 → 草稿 → 展开 → 配器 → 定稿（详见 process.md）。

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音上可听、可指认）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression` 三级证据，见各文件标注。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 证据分级：`verbatim`（乐曲本身）/ `artifact`（成果物 / 文献）/ `impression`（他人印象，须标明谁的印象）。矛盾记入 `conflicts.md`。
