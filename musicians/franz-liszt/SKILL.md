# Franz Liszt — 弗朗茨·李斯特 (1811–1886) · 音乐家蒸馏 v0.1

> 状态：草稿 v0.1，2026-10-26。只蒸行业内成就与成果物（乐曲与作曲技法），不蒸私生活。名单位置：musicians-top100-draft.md #26–50 段。模板：该草稿第 7 节（画家模板音乐版）。

## 一句话

- **这是谁：** 浪漫主义 / 匈牙利作曲家，代表作《匈牙利狂想曲》、《B 小调钢琴奏鸣曲》、《前奏曲》。
- **什么时候用他：** 需要按他的风格为新题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Thematic transformation, virtuoso piano and orchestra, symphonic poem, Hungarian fire and Faustian drama in a single span
- **中文：** 主题变形，炫技钢琴与管弦乐，交响诗，匈牙利火焰与浮士德式戏剧在一跨之中
- **过程一句话：** 动机 → 草稿 → 展开 → 配器 → 定稿（见 process.md；动机常是一个短主题，先定其可变形性；草稿定单乐章弧线；展开即主题变形（换调、换节奏、换音色）；配器把钢琴织体译成管弦乐；定稿只调高潮位置与收束。）

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression`（见草稿第 7.2 节）。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 矛盾记入 `conflicts.md`，不强行统一。
