# Benjamin Britten — 布里顿 (1913–1976) · 音乐家蒸馏 v0.1

> 状态：草稿 v0.1，2026-10-26 网络核对后编写。只蒸行业内成就与成果物（乐曲与作曲技法），不蒸私生活。名单位置：musicians-top100-draft.md #60，现代主义 / 英国。模板：该草稿第 7 节（画家模板音乐适配）。

## 一句话

- **这是谁：** 现代主义 / 英国作曲家，代表作《彼得·格莱姆斯》、《战争安魂曲》、《青少年管弦乐队指南》。
- **什么时候用他：** 需要按他的风格为一个现代题材作曲、或复刻他的作曲过程时，用这个 skill。
- **风格一句话：** Britten style, clear vocal line, English lyricism, transparent orchestration, passacaglia, sea imagery, dramatic opera with chamber clarity
- **中文：** 布里顿风格，清晰的人声线条，英国抒情，透明配器，帕萨卡利亚，海的意象，室内乐清晰度的戏剧歌剧。
- **过程一句话：** 调式动机 / 色彩和弦 → 草稿 → 展开 → 配器 → 定稿（详见 process.md）。

## 蒸馏范围（只限成果物）

- 材料：乐曲本身（总谱 / 录音上可听、可指认）+ 作曲家本人关于作曲的公开文字 + 权威乐谱分析。`verbatim` / `artifact` / `impression` 三级证据，见各文件标注。
- 不写：私生活、心理诊断、传记轶事、歌词剧情、影片剧情。
- 证据分级：`verbatim`（乐曲本身）/ `artifact`（成果物 / 文献）/ `impression`（他人印象，须标明谁的印象）。矛盾记入 `conflicts.md`。
