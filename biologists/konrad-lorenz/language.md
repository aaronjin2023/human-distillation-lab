# Konrad Lorenz — 论证语言 language.md（四维之 interaction）

只限成果物。`artifact`

- 句式：观察—模式推理：先长期观察自然行为，再找触发行为的关键刺激（释放者），最后以固定行为模式与印随说明本能；不靠条件反射解释一切。以陈述与限定为主，少用绝对化断言。
- 术语：动物行为学的核心术语按本人用法，不混用后世术语。
- 图示习惯：按本人代表作的图示方式（谱系、食物网、生态位图、行为序列、染色体图、化石图等，视本人而定），不套用别类模板。
- 论证结构：问题—方法—结果—讨论，或观察—分类—理论；回应质疑靠可重复证据，不靠权威。
- 语气与距离：克制、留有余地，明确标出未知与适用边界。
