# Drummond Matthews — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 海上调查船实测：西北印度洋“欧文号”航次沿测线采集磁异常，先看条带的宽度与间距，再看对称性；野外数据先行，假说随后。
- 磁性证据：条带是地磁倒转的记录，左右对称是海底扩张的指纹；单侧条带不作定论，对称性才是关键检验。
- 从观测到假说：先有对称条带的观测事实，再与瓦因一起提出磁条带—扩张假说；假说的好坏看它预言了什么新条带，而不看它解释了多少旧数据。
- 代表作：海底磁条带、海洋磁异常、剑桥海洋地球物理。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
