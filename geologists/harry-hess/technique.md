# Harry Hess — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 海上以回声测深与重力、地磁测量为主：先画海底地形，看中脊裂谷、深海平原与海沟的空间排列；一条测线不下结论，多条测线拼出洋盆格局。
- 年龄与磁性证据：洋壳越离中脊越老，磁异常条带左右对称；地形、年龄、磁性三者指向同一方向才算证据汇合，单一测线不作定论。
- 类比建构：把洋中脊比作传送带——新洋壳在中脊生成、向两侧移走、在海沟消亡；类比只用于说明机制，检验靠磁条带对称性与洋壳年龄梯度。
- 代表作：海底扩张说、地幔对流、洋中脊研究。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
