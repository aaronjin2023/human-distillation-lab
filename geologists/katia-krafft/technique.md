# Katia Krafft — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 近距离影像记录：走到能看清喷发口的位置，用照片与胶片逐帧记录熔岩流、火山碎屑流与火山灰柱；远距离的推测代替不了近处的影像。
- 影像证据：喷发类型靠影像里的产物行为分（熔岩流的流动、碎屑流的速度与方向、灰柱的高度），影像的时间顺序就是喷发的过程记录。
- 灾害教育：把影像变成防灾教材——让住在火山边的人看到火山碎屑流的速度与范围；影像的价值看它能不能让人提前撤离。
- 代表作：火山喷发影像记录、火山灾害、火山喷发类型。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
