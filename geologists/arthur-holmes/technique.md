# Arthur Holmes — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 野外以岩石露头与地质图为底，先看岩石的野外关系再取样：哪一套地层叠在另一套之上、火成岩侵入了谁、变质程度如何；取样点必记层位与野外关系，否则年龄数无处安放。
- 年龄证据：铀—铅等放射性衰变是时钟，矿物年龄须与地层层序互相核对；单一矿物年龄不作定论，老年龄要能被多矿物、多方法复现才采信。
- 从年龄数据到全球机制：放射性衰变提供地球内部热源，地幔对流把热变成运动——大陆漂移的驱动力不必再求诸未知力；理论用可算的热流与对流速度约束，不靠修辞。
- 代表作：地幔对流说、放射性地质定年、《物理地质学原理》。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
