# Harold Urey — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 质谱测同位素：先测化石碳酸盐的氧同位素比值，再与现代生物的温度—同位素关系标定；标定曲线是证据链的一环，缺了它比值只是数字。
- 同位素证据：氧 18/氧 16 比值随温度系统变化，化石壳的比值就是古温度计；成岩改造会改写比值，改造过的样品先剔除。
- 从实验室到行星：同位素分馏原理既解释古温度，也约束太阳系起源（《行星》）；原理通用，应用时每类样品的标定与改造史要分别交代。
- 代表作：氧同位素古温度计、同位素地球化学、《行星》。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
