# Vladimir Vernadsky — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 跨尺度综合：先看矿物与岩石，再看土壤、水体与大气，最后看生物活动留下的化学痕迹；单一圈层不下结论，多圈层汇合才谈生物圈。
- 循环证据：元素在生物—土壤—水—岩之间的迁移量可估算，生物富集的证据是浓度异常与同位素分馏；量级对不上，学说就不采信。
- 概念建构：把“生物圈”定义为生命改造过的地球表层，用物质循环与能量流组织全书；概念的好坏看它能不能组织新观测，而不看它是否动听。
- 代表作：生物圈学说、生物地球化学、《生物圈》。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
