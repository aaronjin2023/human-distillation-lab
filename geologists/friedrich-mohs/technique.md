# Friedrich Mohs — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 标本互刻：拿已知矿物逐一刻划未知标本，看谁刻得动谁；硬度是相对的，刻划顺序就是标尺。
- 操作证据：硬度等级来自成对刻划试验，可复现、可传递；一次刻划不作定论，多次、多个标本一致才定级。
- 实用分类：把硬度与晶形、解理、光泽拼成野外可用的鉴定表；分类的好坏看野外能不能快速认矿，不看理论是否优雅。
- 代表作：莫氏硬度计、矿物分类体系。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
