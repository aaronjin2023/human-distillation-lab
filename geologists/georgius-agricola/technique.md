# Georgius Agricola — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 矿井实地观察：下井看矿脉的走向、倾角与围岩关系，记录采矿方法与选矿流程；书斋推测不作证据，矿井所见才算。
- 实测证据：矿脉产状、矿物共生与围岩蚀变，三者互相印证；同一矿脉多处观测一致才写进分类。
- 系统编纂：把零散的采矿经验编成可传授的体系——矿脉成因、找矿标志、采矿与冶金流程；体系的价值看它能不能指导下一座矿。
- 代表作：《论金属》、矿脉理论、矿物分类。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
