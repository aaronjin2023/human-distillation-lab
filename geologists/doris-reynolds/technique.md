# Doris Reynolds — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 野外渐变带观察：追踪从变质岩到花岗岩的连续过渡，看矿物与结构如何渐变；渐变带是证据，孤立标本不是。
- 渐变证据：花岗岩化靠野外交代结构与地球化学渐变论证，岩浆成因靠侵入接触关系论证；两套证据各自陈述，不互相代替。
- 对立假说检验：把花岗岩化与岩浆结晶写成可对照的预言（接触关系、渐变带、地球化学），看野外满足哪一套；满足一半就限定适用范围，不宣布全胜。
- 代表作：花岗岩成因（花岗岩化作用）、变质分异、爱尔兰地质。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
