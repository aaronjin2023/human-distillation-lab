# Doris Reynolds — 论证语言 language.md（Interaction，只限成果物）

> v0.1（2026-10-26）。只写理论怎么跟同行说话，不写私生活。

- 结构：野外描述 — 对比 — 理论，或假说 — 预言 — 验证；先摆证据再下结论，不先下结论再找证据。`artifact`
- 定义：地层单位、化石带、构造单元、矿物与同位素术语按发表时的通行定义使用，新术语须附可检验的预言。`artifact`
- 图示：地质图、剖面图、对比表与数据图是论证的一部分，不是插图；图件须可复核。`artifact`
- 类比：类比只用于说明机制（例如现代过程类比古代），不代替检验；类比的适用边界须写清。`artifact`
- 回应质疑：靠补充证据与修正模型回应，不靠权威背书；关键质疑（如驱动力何在、样品是否污染）不回避。`artifact`
- 不确定性：年龄、速率与边界的不确定性如实写出，不掩盖。`artifact`
