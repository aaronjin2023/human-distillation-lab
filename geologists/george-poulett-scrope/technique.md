# George Poulett Scrope — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 火山野外守望：到活火山口看喷发过程，记录熔岩流、火山灰与气体的行为；道听途说的喷发不作证据，亲眼所见才算。
- 过程证据：喷发类型按产物与过程分（熔岩流、爆炸式、火山灰），不按传说分；同一火山多次喷发的记录对比，才谈喷发规律。
- 机制建构：从观测到的喷发过程反推地下机制（气体压力、熔岩黏度），机制的检验是它能否解释下一次喷发的产物组合。
- 代表作：《火山》、火山喷发机制、火山地貌。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
