# Alfred Lacroix — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 灾后野外调查：喷发后到现场看火山碎屑流的堆积、方向与破坏范围，逐个地点记录；不在现场的推测不作证据。
- 堆积证据：火烧云（火山碎屑流）的识别靠堆积物的分布、粒度与温度痕迹，不是靠目击者的形容词；堆积图就是喷发的 footprint。
- 分类建构：按喷发产物与过程给火山分类，培雷式（火山碎屑流主导）成为一类；分类的检验是新喷发能不能对号入座。
- 代表作：培雷火山喷发研究、火山分类、马达加斯加矿物学。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
