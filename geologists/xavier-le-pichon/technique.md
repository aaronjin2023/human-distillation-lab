# Xavier Le Pichon — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 全球综合：先收齐各洋盆磁条带、地震带与热点轨迹，再定六大板块的边界与相对速率；一块边界对不上，全图就要返工。
- 综合证据：六大板块模型同时满足磁条带速率、地震滑动矢量与板块边界几何；某一类证据对不上，就改边界，不改其他证据。
- 综合建模：把分散的区域模型拼成全球模型，写出每块板块的运动速率与方向；全球图是可检验的——新测的磁剖面与地震都可拿来核对它。
- 代表作：板块构造综合模型、《板块构造》、六大板块模型。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
