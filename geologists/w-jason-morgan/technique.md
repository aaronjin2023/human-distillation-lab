# W. Jason Morgan — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 全球地震与磁异常图件：先标出地震带定板块边界，再用球面几何算板块相对运动；边界画错，运动就算错。
- 几何证据：板块在球面上绕欧拉极转动，转换断层的走向与小圆方向一致；几何预言（断层走向、扩张速率分布）可被观测逐一检验。
- 综合建模：把地震、磁条带、地形拼进一个刚性板块几何模型，十几块板块一次定出；模型的好坏看它同时解释了多少独立观测。
- 代表作：板块构造几何学、热点 / 地幔柱、板块运动模型。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
