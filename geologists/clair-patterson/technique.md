# Clair Patterson — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 洁净实验室：样品一污染年龄全错，先建洁净室、酸洗全部器皿、蒸馏全部试剂，再测数；污染控制是方法的一部分，不是后勤。
- 同位素证据：陨石铅同位素落在同一直线（等时线）上，斜率给出 4.55 Ga；深海沉积物铅点落在同一等时线上，地球与陨石同龄的推论才成立。
- 从测年到公共议题：同一套铅数据既定地球年龄，也揭示环境铅污染——工业铅让现代人骨铅含量比古代高数百倍；数据公开、方法可复现，结论才站得住。
- 代表作：地球年龄测定、铅同位素定年、铅污染研究。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
