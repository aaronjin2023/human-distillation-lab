# Claude Lorius — 论证语言 language.md（Interaction，只限成果物）

- 配对记录语言：论文以二氧化碳曲线与温度曲线并置组织；结论克制而坚定——先给数据，再给判断；面向科学界与公众。 `artifact`
- 术语定义：地层单位、化石带、构造单元或本领域对应概念的命名规则严格，定义先行，论证随后。`impression`（学界共识）
- 图示习惯：地质图、剖面图、对比表或本领域对应图件（地震剖面、冰芯曲线、海底地形图、波形图）是论证的一部分，文字只作图注与衔接。`artifact`
- 回应质疑：以追加证据、限定适用范围或修正模型回应，而非回避质疑。`impression`（学界共识）
