# Gerald Wasserburg — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 质谱与洁净流程：月球样品珍贵，先定最小破坏的分析流程，再测多同位素体系（铷—锶、钐—钕、铀—铅）；一个体系是线索，多体系一致才是年龄。
- 多体系证据：不同同位素体系给出同一时代，年龄才采信；体系之间对不上，先查样品改造与污染，再谈地质意义。
- 从月球到太阳系：月球年龄约束月球形成，难熔包体年龄约束太阳系最早固体；每一步外推都写清它依赖哪个年龄、哪个假设。
- 代表作：同位素地球化学、月球样品定年、太阳系早期演化。

## 方法要点

- 核心套路：野外考察 → 采样与分析 → 对比与综合 → 理论建构与修正 → 发表，已记入 process.md。
- 工具与证据的关系：方法决定了能看到什么证据，也决定了论证的边界；换方法要重新核对结论。
- 失败记录：各步的失败与反例是方法的一部分，已记入 process.md 各步“最容易出错”与 conflicts.md。
