# 压力评价与应对过程（Lazarus–Folkman）

本条采用 Lazarus–Folkman 的压力交易与应对框架，不采用 Scherer 的 Component Process Model（CPM）检查序列。两者都使用 appraisal 一词，但理论谱系与维度组织不同：本文只讨论初级/次级评价、应对和再评价，不混入 Scherer 的新奇性、目标相关性、规范意义等刺激评价检查。

Lazarus–Folkman框架把压力理解为人与环境关系的评价，而非刺激自动决定的反应。初级评价关注事件对目标和福祉的意义，可涉及无关、积极、损失/威胁或挑战；次级评价关注可用资源、控制感与应对选项。应对是随情境展开的认知和行动努力；新信息或结果出现后，评价可能改变。这不是每个人都依次意识到各阶段的固定线性流程。Folkman与Lazarus 1985年考试研究在考试前、等待成绩和出分后收集资料，发现情绪与应对会随阶段变化，挑战和威胁情绪也可能并存；这是大学考试情境的自然研究，不是跨情境普遍定律。

使用步骤：先描述具体事件与时间点；分别询问当事人当时如何理解其意义、担心或期待什么、认为自己有哪些资源和选项；记录采用的应对与结果；有新信息时重新询问评价是否变化。不得仅凭事件客观严重度推定某人的压力体验。

专家能力组合（设计推演）：复盘专家一次关键决策，记录当时可得信息、其理解的风险和机会、考虑过的选项、资源约束，以及后来促成调整的新证据。用时间线呈现评价与应对的变化，可提取条件化判断知识，不把单次决策泛化为“抗压型人格”。

自检失败情景：输入“考试未通过”。若系统立刻断言学生感到威胁并回避，推理失败。合格分析需询问学生自己的评价、挑战感、资源和后续行动；在缺少自述时保留未知，并允许同一事件同时引发失落与挑战。

限制：原书本轮只核实书目，未读全文；初级/次级评价与过程性应对定义另由1986作者论文理论段落补核（S3）。该文的社区成人关联与1985考试研究都不能直接推广为所有危机或人群的因果规律。本文未依据 Scherer 的 CPM 构件，也不把两种评价模型合并；若需要 Scherer 版本，应另行研究其原始来源。
