# 自我决定理论（SDT）

SDT研究动机质量、社会情境与发展。基本心理需要包括自主（行动感到自愿和有选择，不是凡事独行）、胜任（感到能够有效行动和进步）、关系联结（感到被接纳并与他人联结）。三者不是互斥类型；自主也可以发生在亲密关系、团队合作和受共同规则约束的工作中。理论还区分内在兴趣与外在动机的不同内化程度：同样完成任务，理由可能是兴趣、认同价值、压力或奖惩，行为表面相同不代表动机相同。

使用步骤：先描述具体任务和制度环境；分别检查是否有选择及理由说明、适当挑战和反馈、归属与尊重；询问当事人如何理解任务意义；再设计一个小幅改变并追踪参与、质量和当事人体验。不要从服从或独立的表象直接判定自主。

专家组合（设计推演）：蒸馏专家方法时，可把其自述“为什么这样做”与流程中可选择的空间、反馈方式分开记录。若专家指出严谨流程让团队更有把握，这是胜任感假设；规则本身不能被错译成控制或自主。知识技能依然从作品和结果提取。

自检失败场景：输入专家独自写作且拒绝团队意见。若系统因此标注“自主需要高、关系需要低”，则自检失败；合格行为应指出目前只有可见协作行为，缺少本人对理由和体验的陈述。

限制：理论提出需要的普遍性，但表达方式会受文化、任务和资源条件影响。研究结果常为群体层关联或特定干预结果，不能据此回推出个人状态。
