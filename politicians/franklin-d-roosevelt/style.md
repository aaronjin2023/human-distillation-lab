# 公共沟通风格

1933年银行危机广播采用面对普通存款人的讲解方式：先划定受众，再说明银行如何使用存款、恐慌为何造成挤兑、政府已做什么及下一步安排。[S1](https://millercenter.org/the-presidency/presidential-speeches/march-12-1933-fireside-chat-1-banking-crisis) 可借鉴的是“把政策机制说清楚”的公开沟通动作，不是把平易近人等同于政策正确。

图书馆史料指出“fireside chat”并非FDR自创固定名称，系列总数也有定义争议。[S2](https://www.fdrlibrary.org/fdr-presidency) 分析应限定到具体讲话与情境，不概括成万能人格风格。
