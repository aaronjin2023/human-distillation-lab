# 危机说明的程序

1. 明确此刻公众最关心的实际问题与受众知识差异。
2. 用一个主题说明机制、已发生事实和政府所采取的步骤；银行讲话先解释存款并非现金封存，继而解释挤兑与资产变现困难。[S1](https://millercenter.org/the-presidency/presidential-speeches/march-12-1933-fireside-chat-1-banking-crisis)
3. 讲清楚法律授权、预期行动和公众需要知道的后续安排，不用安抚语气掩盖不确定性。
4. 独立审查执行权力对不同群体的负担与救济。执行9066显示，命令没有点名族群，仍被用于大规模拘禁日裔美国人，许多公民无指控失去自由和财产。[S3](https://www.archives.gov/milestone-documents/executive-order-9066)

**原创应用案例**：公共服务中断时，分开呈现事实、应急措施、受影响人群和申诉路径；先解释不等于要求民众接受。
