# 文书决策的可见过程

1. 识别危机中的目标及总统可用的法律权限，不把道德目标与行政权力混为一谈。
2. 先形成政策草案，征求内阁意见并审查文本与时机；解放宣言曾多次修订，林肯等到军事节点后发布。[S2](https://www.archives.gov/publications/prologue/1993/summer/emancipation-proclamation.html)
3. 分别说明即时工具能做到什么、不能做到什么：宣言在法律上只覆盖规定的叛乱地区，直接解放作用有限。
4. 将战时行政措施与更广泛的制度变更区分，留下后续立法/修宪议程，而不是将单一命令描述为问题终结。
5. 决策后同时评估其目标、受影响群体与实际伤害。

**原创应用案例**：政策目标是终止一项压迫性制度，现有权限只能改变部分区域。应把有效范围说清并规划制度后续，不宣传为人人立刻获得完整自由。
