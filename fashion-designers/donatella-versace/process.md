## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从范思哲魅力的延续定题：大胆性感，明亮印花，贴身礼服，铂金色锋芒 | 明亮印花样 / 铂金色板 / 贴身礼服图 | 只定方向：大胆性感、明亮印花、贴身礼服、铂金色 | 约 10–20%，魅力方向可见、款式未定 | 一开始就定素色克制，性感就没了 |
| 2 草图 | 画出款式草图：贴身立裁，印花与身体对位，Versus 线年轻化 | 手绘草图 / 亮片印花对位小样 | 全系列贯通：贴身礼服—明亮印花—Versus 年轻化，不回头改 | 约 30–40%，贴身廓形初现、细节未定 | 草图丢了印花对位，魅力就乱了 |
| 3 选料 | 定亮片与印花并置面料、巴洛克印花延续 | 亮片印花库 / 巴洛克试样 / 铂金配样 | 只定面料与并置：亮片、印花、巴洛克、铂金色 | 约 50–60%，面料已定、版型未定 | 亮片一省，锋芒就没了 |
| 4 打版 | 贴身立裁打版：晚礼服合体与体积，试穿只改合体度与体积 | 立裁人台 / 贴身纸样 / 样衣试穿 | 只改版型与结构：贴身度、体积、印花对位 | 约 80–90%，版型已立，个别细节仍可留空 | 合体一松，性感就没了 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，亮片配饰成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 延续一丢就变复制 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：魅力方向可见、款式未定。
2. 第 2 步结束：款式草图已出，贴身廓形初现、细节未定。
3. 第 3 步结束：亮片与印花已定，版型未定。
4. 第 4 步结束：贴身版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、草图 20%、选料（印花定色）25%、打版 30%、成衣走秀 15%。印花定色步略长。
- 节奏提示：灵感慢（看范思哲魅力与明亮印花）、草图与选料中速、打版放慢（看贴身立裁）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从范思哲魅力的延续定题：大胆性感，明亮印花，贴身礼服，铂金色锋芒，明亮印花样 / 铂金色板 / 贴身礼服图。
- 草图：画出款式草图：贴身立裁，印花与身体对位，Versus 线年轻化，手绘草图 / 亮片印花对位小样。
- 选料：定亮片与印花并置面料、巴洛克印花延续，亮片印花库 / 巴洛克试样 / 铂金配样。
- 打版：贴身立裁打版：晚礼服合体与体积，试穿只改合体度与体积，立裁人台 / 贴身纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，亮片配饰成套，定稿。
