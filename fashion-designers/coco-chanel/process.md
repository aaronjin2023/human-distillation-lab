# Coco Chanel — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从男装与运动服借形定题：行动自由的巴黎女性，直筒廓形、黑白米三色 | 男装借形图 / 针织小样 / 斜纹软呢样 | 只定方向：行动自由的直筒廓形、黑白米三色、斜纹软呢 | 约 10–20%，自由方向可见、款式未定 | 一开始就收腰，自由感没了 |
| 2 人台剪裁 | 人台剪裁定形：在人台上直接以布定形，不画收腰纸样 | 人台 / 剪刀直接剪裁 / 斜纹软呢布样 | 全系列贯通：直筒上衣与裙，不画收腰、不画繁复装饰 | 约 30–40%，直筒廓形初现、细节未定 | 小样用了硬挺布，垂坠立不住 |
| 3 选料 | 定斜纹软呢、黑白米三色、金属链条包边、珍珠 | 斜纹软呢库 / 针织小样 / 链条包边配样 | 只定面料与装饰：斜纹软呢、黑白米、金属链条、珍珠 | 约 50–60%，面料已定、版型未定 | 面料改艳色印花，黑白米没了 |
| 4 打版 | 立裁直筒版型：试穿时只改肩线与裙长，不改直筒结构 | 立裁人台 / 直筒纸样 / 样衣试穿 | 只改版型与结构：肩线、裙长、直筒 | 约 80–90%，版型已立，个别细节仍可留空 | 打版一加束缚就散 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，模特行走看行动自由度，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 配饰一多就俗 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：自由方向可见、款式未定。
2. 第 2 步结束：人台剪裁已定形，直筒廓形初现、细节未定。
3. 第 3 步结束：斜纹软呢与黑白米已定，版型未定。
4. 第 4 步结束：直筒版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、人台剪裁 20%、选料 20%、打版 40%、成衣走秀 10%。打版步最长，见草稿 6.3 节示例。
- 节奏提示：灵感慢（看男装借形与针织）、人台剪裁与选料中速、打版放慢（看直筒立裁）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 人台剪裁 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 人台剪裁 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从男装与运动服借形定题：行动自由的巴黎女性，直筒廓形、黑白米三色，男装借形图 / 针织小样 / 斜纹软呢样。
- 人台剪裁：人台剪裁定形：在人台上直接以布定形，不画收腰纸样，人台 / 剪刀直接剪裁 / 斜纹软呢布样。
- 选料：定斜纹软呢、黑白米三色、金属链条包边、珍珠，斜纹软呢库 / 针织小样 / 链条包边配样。
- 打版：立裁直筒版型：试穿时只改肩线与裙长，不改直筒结构，立裁人台 / 直筒纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，模特行走看行动自由度，定稿。
