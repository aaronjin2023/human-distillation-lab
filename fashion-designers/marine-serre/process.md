# Marine Serre — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从再生未来主义定题：新月印花，再生面料，贴身叠穿 | 新月印花样 / 再生面料样 / 贴身叠穿图 | 只定方向：再生未来主义、新月印花、再生面料、贴身叠穿 | 约 10–20%，再生方向可见、款式未定 | 一开始就定全新面料，再生就没了 |
| 2 草图 | 画出款式草图：再生面料拼接，旧衣重组，新旧并置 | 手绘草图 / 再生拼接小样 | 全系列贯通：新月印花—再生拼接—贴身叠穿，不回头改 | 约 30–40%，再生廓形初现、细节未定 | 草图丢了新月印花，品牌签名就没了 |
| 3 选料 | 定再生面料与技术面料的混合 | 再生面料库 / 技术面料试样 / 混合配样 | 只定面料与混合：再生面料、技术面料、新月印花 | 约 50–60%，面料已定、版型未定 | 再生面料一省，生态就没了 |
| 4 打版 | 贴身叠穿打版：多层贴身，层数即廓形，试穿只改层数与贴合度 | 贴身纸样 / 叠穿试穿 / 样衣 | 只改版型与结构：叠穿层数、贴合度、运动剪裁 | 约 80–90%，版型已立，个别细节仍可留空 | 层数一乱，贴身叠穿就成了臃肿 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，新月配饰成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 运动一丢就变高级定制 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：再生方向可见、款式未定。
2. 第 2 步结束：款式草图已出，再生廓形初现、细节未定。
3. 第 3 步结束：再生面料已定，版型未定。
4. 第 4 步结束：叠穿版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 15%、草图 20%、选料（再生面料）25%、打版 25%、成衣走秀 15%。选料步略长，再生面料靠选料定。
- 节奏提示：灵感慢（看再生未来主义与新月印花）、草图与选料中速、打版放慢（看贴身叠穿）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从再生未来主义定题：新月印花，再生面料，贴身叠穿，新月印花样 / 再生面料样 / 贴身叠穿图。
- 草图：画出款式草图：再生面料拼接，旧衣重组，新旧并置，手绘草图 / 再生拼接小样。
- 选料：定再生面料与技术面料的混合，再生面料库 / 技术面料试样 / 混合配样。
- 打版：贴身叠穿打版：多层贴身，层数即廓形，试穿只改层数与贴合度，贴身纸样 / 叠穿试穿 / 样衣。
- 成衣走秀：成衣与走秀呈现：成衣缝制，新月配饰成套，定稿。
