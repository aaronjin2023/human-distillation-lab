## 一句话

- **这是谁：** 意大利·成衣 / 印花服装设计师，代表作《Pucci》、几何印花、滑雪服。
- **什么时候用他：** 需要按此人的风格设计其他题材的服装（廓形、面料、色彩、剪裁、细节）时，用这个 skill。
- **风格一句话：** 璞琪风格：几何涡旋印花，艳色，贴身针织，滑雪服式轻盈，真丝针织，欢快而图案化。
- **过程一句话：** 五步：灵感 → 草图 → 选料 → 打版 → 成衣走秀。

## 蒸馏范围（只限成果物）

- 材料：时装系列本身（Pucci、几何印花、滑雪服为主）+ 设计师本人关于设计的公开文字 + 权威展览图录与评论/研究。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（成衣 / 系列上直接可见）/ `artifact`（公开文字、图录、研究）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 品牌归属：只蒸设计师本人在任时期的已发表系列；其去世 / 离任后品牌在他名下的后续系列只作对照，不计入本人 skill 的 verbatim 证据。
- 翻译口径：蒸馏以时装系列本身为准；系列名以原文品牌名 / 通行译名为准，译名只作参照，不作为 `verbatim` 证据。
