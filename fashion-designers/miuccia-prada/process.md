# Miuccia Prada — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从智性时装定题：尼龙入奢华，丑 chic，克制的反讽 | 尼龙小样 / 丑 chic 并置板 / 意外面料样 | 只定方向：智性时装、丑 chic、尼龙与意外面料、带转折的极简 | 约 10–20%，智性方向可见、款式未定 | 一开始就定漂亮常规，智性就没了 |
| 2 草图 | 画出款式草图：简洁立裁，廓形克制，面料负责意外 | 手绘草图 / 尼龙小样 | 全系列贯通：简洁立裁—尼龙—丑 chic 并置，不回头改 | 约 30–40%，简洁廓形初现、细节未定 | 草图加了繁复廓形，克制就没了 |
| 3 选料 | 定尼龙与意外面料：工业面料做高级成衣 | 尼龙库 / 意外面料试样 / 蝴蝶结亮片配样 | 只定面料与意外：尼龙、意外面料、蝴蝶结亮片点缀 | 约 50–60%，面料已定、版型未定 | 尼龙一换成常规高级面料，材料革命就没了 |
| 4 打版 | 简洁立裁打版：试穿只改廓形克制度，不改面料的意外 | 立裁人台 / 简洁纸样 / 样衣试穿 | 只改版型与结构：简洁廓形、意外细节位置 | 约 80–90%，版型已立，个别细节仍可留空 | 廓形一繁复，智性就没了 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，尼龙包成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 反讽一丢就变极简 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：智性方向可见、款式未定。
2. 第 2 步结束：款式草图已出，简洁廓形初现、细节未定。
3. 第 3 步结束：尼龙与意外面料已定，版型未定。
4. 第 4 步结束：简洁版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 15%、草图 20%、选料（意外面料）25%、打版 25%、成衣走秀 15%。选料步略长，智性靠面料定。
- 节奏提示：灵感慢（看智性时装与尼龙入奢华）、草图与选料中速、打版放慢（看简洁立裁）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从智性时装定题：尼龙入奢华，丑 chic，克制的反讽，尼龙小样 / 丑 chic 并置板 / 意外面料样。
- 草图：画出款式草图：简洁立裁，廓形克制，面料负责意外，手绘草图 / 尼龙小样。
- 选料：定尼龙与意外面料：工业面料做高级成衣，尼龙库 / 意外面料试样 / 蝴蝶结亮片配样。
- 打版：简洁立裁打版：试穿只改廓形克制度，不改面料的意外，立裁人台 / 简洁纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，尼龙包成套，定稿。
