# Jonathan Anderson — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图 / 样衣 / 打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 定主题：以一件日常物（如拼图、番茄、陶器）为观念起点，定廓形错位方向与中性色盘 | 灵感板 / 面料小样 / 图片拼贴 | 只定方向：观念物、错位廓形、中性色、关键元素 | 约 10–20%，方向可见、款式未定 | 观念物只剩噱头，廓形没立住 |
| 2 草图 | 画出解构草图：不对称衣片、错位接缝、夸张体积先行，不画合体版 | 手绘草图 / 电脑绘图 / 立裁小样 | 全系列贯通，不回头改 | 约 30–40%，款式与廓形初现、细节未定 | 一对称就泄气，解构变常规 |
| 3 选料 | 定皮革与针织的材质对位：皮革定硬度与鞣制，针织定纹理，点缀色只定一处 | 面料库 / 打样 / 印花试色 | 只定面料与色彩，不改款式 | 约 50–60%，面料已定、版型未定 | 皮革太硬压住针织，对话变独白 |
| 4 打版 | 平裁为主打版：衣片错位拼接上人台，试穿只改错位幅度与体积，不改回合体 | 立裁人台 / 纸样 / 样衣试穿 | 只改版型与结构，不改面料 | 约 80–90%，版型已立，个别细节仍可留空 | 错位幅度一收就回合成体 |
| 5 成衣走秀 | 成衣缝制，模特行走时看错位廓形是否成立，定稿 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 走秀只剩奇观，衣服本身没成立 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：只有灵感板（主题、廓形、色彩、关键元素），款式未定。
2. 第 2 步结束：草图贯通全系列，廓形初现、细节未定。
3. 第 3 步结束：面料与色彩已定，版型未定。
4. 第 4 步结束：样衣已立，版型清晰，个别细节仍可留空。
5. 第 5 步结束：完成态，成衣走秀，通读统一。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：灵感 20%、草图 20%、选料 15%、打版 35%、成衣走秀 10%（打版最长，因为错位结构要反复试穿）。
- 节奏提示：灵感慢、草图与选料中速、打版放慢、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑设计现代题材，不声称复刻原过程）

- 灵感：定一个观念物（一只拼图包的几何切割）与一种错位廓形（肩线移位）
- 草图：画出不对称衣片与错位接缝的草图，不画合体收腰
- 选料：定西班牙皮革与针织的材质对位、中性色加一处陶土红点缀
- 打版：平裁错位拼接上人台，试穿只改错位幅度，不改回合体
- 成衣走秀：成衣缝制，模特行走时看错位廓形是否成立，定稿
- 节奏：灵感 20%、草图 20%、选料 15%、打版 35%、成衣走秀 10%（打版最长，因为错位结构要反复试穿）。
