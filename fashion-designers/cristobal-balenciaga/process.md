## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从建筑与雕塑定题：廓形由剪裁与面料骨感撑起，不靠身体 | 建筑图 / 加扎小样 / 雕塑廓形图 | 只定方向：建筑式廓形、茧形、去腰线、黑色 | 约 10–20%，雕塑方向可见、款式未定 | 一开始就贴身，雕塑感没了 |
| 2 立裁定形 | 人台立裁定形：茧形结构，肩与下摆收、中间鼓，体积悬空 | 人台 / 加扎布样 / 建筑式立裁 | 全系列贯通：茧形—沙漏—气球裙，体积悬空，不回头改 | 约 30–40%，雕塑廓形初现、细节未定 | 立裁贴了身体，体积就塌了 |
| 3 选料 | 定加扎硬挺真丝、黑色面料、雕塑体积面料 | 加扎库 / 硬挺真丝试样 / 黑色配样 | 只定面料与骨感：加扎、硬挺真丝、黑色 | 约 50–60%，面料已定、版型未定 | 面料改柔软，雕塑体积撑不起来 |
| 4 打版 | 建筑式打版：省道内藏，结构线藏于廓形内，表面干净 | 立裁人台 / 雕塑纸样 / 样衣试穿 | 只改版型与结构：茧形、省道内藏、腰部留空 | 约 80–90%，版型已立，个别细节仍可留空 | 省道一外露，表面就不干净了 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，模特行走看体积是否立住，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 装饰一多就俗 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：雕塑方向可见、款式未定。
2. 第 2 步结束：人台立裁已定形，茧形廓形初现、细节未定。
3. 第 3 步结束：加扎与黑色已定，版型未定。
4. 第 4 步结束：建筑式版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、立裁定形 20%、选料 20%、打版（立裁）40%、成衣走秀 10%。立裁步最长，廓形本体在剪裁。
- 节奏提示：灵感慢（看建筑与雕塑）、立裁与选料中速、打版放慢（看建筑式剪裁）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 人台立裁 / 加扎面料小样 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 立裁定形 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从建筑与雕塑定题：廓形由剪裁与面料骨感撑起，不靠身体，建筑图 / 加扎小样 / 雕塑廓形图。
- 立裁定形：人台立裁定形：茧形结构，肩与下摆收、中间鼓，体积悬空，人台 / 加扎布样 / 建筑式立裁。
- 选料：定加扎硬挺真丝、黑色面料、雕塑体积面料，加扎库 / 硬挺真丝试样 / 黑色配样。
- 打版：建筑式打版：省道内藏，结构线藏于廓形内，表面干净，立裁人台 / 雕塑纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，模特行走看体积是否立住，定稿。
