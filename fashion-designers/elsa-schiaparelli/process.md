# Elsa Schiaparelli — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从超现实艺术母题定题：龙虾、昆虫印花，shocking pink 定色 | 超现实画作 / 印花小样 / shocking pink 色板 | 只定方向：超现实母题、shocking pink、廓形克制 | 约 10–20%，超现实方向可见、款式未定 | 一开始就定素色，惊奇就没了 |
| 2 草图 | 画出款式草图：廓形克制，母题负责惊奇，印花位置定稿 | 手绘草图 / 超现实印花小样 | 全系列贯通：克制廓形—超现实印花位置，不回头改 | 约 30–40%，款式廓形初现、细节未定 | 草图加了繁复廓形，母题就被抢了 |
| 3 选料 | 定印花面料、shocking pink、针织蝴蝶结纹样 | 印花库 / shocking pink 试色 / 针织小样 | 只定面料与母题：超现实印花、shocking pink、针织 | 约 50–60%，面料已定、版型未定 | 印花改素面，超现实就没了 |
| 4 打版 | 合体剪裁服务于母题：试穿只改合体度，不改印花位置 | 立裁人台 / 合体纸样 / 样衣试穿 | 只改版型与结构：合体度、印花对位 | 约 80–90%，版型已立，个别细节仍可留空 | 错觉细节一画歪，机智就成了拙劣 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，超现实配饰成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 配饰一多就乱 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：超现实方向可见、款式未定。
2. 第 2 步结束：款式草图已出，克制廓形初现、细节未定。
3. 第 3 步结束：超现实印花与 shocking pink 已定，版型未定。
4. 第 4 步结束：合体版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 15%、草图 20%、选料（印花定色）25%、打版 25%、成衣走秀 15%。印花定色步略长。
- 节奏提示：灵感慢（看超现实画作与 shocking pink）、草图与选料中速、打版放慢（看合体与印花对位）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从超现实艺术母题定题：龙虾、昆虫印花，shocking pink 定色，超现实画作 / 印花小样 / shocking pink 色板。
- 草图：画出款式草图：廓形克制，母题负责惊奇，印花位置定稿，手绘草图 / 超现实印花小样。
- 选料：定印花面料、shocking pink、针织蝴蝶结纹样，印花库 / shocking pink 试色 / 针织小样。
- 打版：合体剪裁服务于母题：试穿只改合体度，不改印花位置，立裁人台 / 合体纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，超现实配饰成套，定稿。
