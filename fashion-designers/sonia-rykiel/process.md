# Sonia Rykiel — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从针织女王定题：条纹针织，poor boy 毛衣，反缝、无边处理 | 条纹针织样 / poor boy 毛衣样 / 反缝样 | 只定方向：针织女王、条纹针织、poor boy 毛衣、左岸从容 | 约 10–20%，针织方向可见、款式未定 | 一开始就定梭织，针织就没了 |
| 2 织片定形 | 织片定形：织片即版型，针织的弹力即结构，条纹宽度与配色定稿 | 织片小样 / 条纹配色样 / 针织机 | 全系列贯通：条纹针织—poor boy 毛衣—反缝无边，不回头改 | 约 30–40%，针织廓形初现、细节未定 | 织片改纸样，针织的弹力结构就没了 |
| 3 选料 | 定条纹针织面料：条纹的宽度与配色是设计本体 | 条纹针织库 / 配色试样 / 弹力试样 | 只定面料与条纹：条纹针织、宽度配色、黑与彩色条纹 | 约 50–60%，面料已定、版型未定 | 条纹一乱，针织女王就没了 |
| 4 打版 | 针织打版：反缝外露、无边处理，缝份外露即装饰 | 针织纸样 / 反缝试穿 / 样衣 | 只改版型与结构：反缝、无边、条纹对位 | 约 80–90%，版型已立，个别细节仍可留空 | 反缝一藏起来，工艺装饰就没了 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，贝雷帽成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 条纹一乱就俗 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：针织方向可见、款式未定。
2. 第 2 步结束：织片已定形，条纹廓形初现、细节未定。
3. 第 3 步结束：条纹针织已定，版型未定。
4. 第 4 步结束：针织版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、织片定形 15%、选料（纱线）25%、打版（织片）35%、成衣走秀 15%。织片步最长，针织本体在织片。
- 节奏提示：灵感慢（看条纹针织与 poor boy 毛衣）、织片与选料中速、打版放慢（看反缝与无边）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 织片小样 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 织片定形 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从针织女王定题：条纹针织，poor boy 毛衣，反缝、无边处理，条纹针织样 / poor boy 毛衣样 / 反缝样。
- 织片定形：织片定形：织片即版型，针织的弹力即结构，条纹宽度与配色定稿，织片小样 / 条纹配色样 / 针织机。
- 选料：定条纹针织面料：条纹的宽度与配色是设计本体，条纹针织库 / 配色试样 / 弹力试样。
- 打版：针织打版：反缝外露、无边处理，缝份外露即装饰，针织纸样 / 反缝试穿 / 样衣。
- 成衣走秀：成衣与走秀呈现：成衣缝制，贝雷帽成套，定稿。
