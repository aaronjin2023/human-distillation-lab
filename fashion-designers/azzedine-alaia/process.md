## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从身体雕塑定题：贴身针织裙，身体即版型，永恒黑 | 贴身针织样 / 身体雕塑图 / 黑色面料样 | 只定方向：身体雕塑、贴身针织、精确接缝、永恒黑 | 约 10–20%，雕塑方向可见、款式未定 | 一开始就定宽松，身体感没了 |
| 2 雕塑立裁 | 人台雕塑立裁定形：布在人台上按身体雕塑，精确接缝即剪裁 | 人台 / 针织布样 / 雕塑立裁 | 全系列贯通：贴身针织—精确接缝—弹力面料，不回头改 | 约 30–40%，贴身廓形初现、细节未定 | 立裁离了身体，雕塑就空了 |
| 3 选料 | 定弹力针织、皮革等贴身面料 | 弹力针织库 / 皮革试样 / 贴身配样 | 只定面料与张力：弹力针织、皮革、贴身 | 约 50–60%，面料已定、版型未定 | 面料改无弹力，贴身就没了 |
| 4 打版 | 贴身打版：针织在不同部位张力不同，合体靠面料张力不靠硬衬 | 人台 / 张力分区纸样 / 样衣试穿 | 只改版型与结构：张力分区、接缝位置、贴身度 | 约 80–90%，版型已立，个别细节仍可留空 | 张力分区一乱，身体感就散了 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，模特行走看贴身是否跟随身体，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 装饰一多就俗 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：雕塑方向可见、款式未定。
2. 第 2 步结束：人台立裁已定形，贴身廓形初现、细节未定。
3. 第 3 步结束：弹力针织已定，版型未定。
4. 第 4 步结束：贴身版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、雕塑立裁 20%、选料 20%、打版（立裁）40%、成衣走秀 10%。立裁步最长，贴身靠试穿定。
- 节奏提示：灵感慢（看身体雕塑与贴身针织）、立裁与选料中速、打版放慢（看张力分区）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 人台雕塑 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 雕塑立裁 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从身体雕塑定题：贴身针织裙，身体即版型，永恒黑，贴身针织样 / 身体雕塑图 / 黑色面料样。
- 雕塑立裁：人台雕塑立裁定形：布在人台上按身体雕塑，精确接缝即剪裁，人台 / 针织布样 / 雕塑立裁。
- 选料：定弹力针织、皮革等贴身面料，弹力针织库 / 皮革试样 / 贴身配样。
- 打版：贴身打版：针织在不同部位张力不同，合体靠面料张力不靠硬衬，人台 / 张力分区纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，模特行走看贴身是否跟随身体，定稿。
