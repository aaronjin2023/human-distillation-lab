# Azzedine Alaïa — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 定主题与场合：贴身针织裙、身体雕塑、永恒黑。 | 灵感板 / 面料小样 / 图片拼贴 | 只定方向：主题、廓形、色彩、关键元素 | 约 10–20%，方向可见、款式未定 | 一开始就定宽松，贴身没了 |
| 2 草图 | 画出款式草图：贴身廓形、接缝位置、裙长定稿。 | 手绘草图 / 电脑绘图 / 立裁小样 | 全系列贯通，不回头改 | 约 30–40%，款式与廓形初现、细节未定 | 草图接缝一乱就不是阿拉亚 |
| 3 选料 | 定面料：弹力针织、真丝、皮革，试张力与贴身度。 | 面料库 / 打样 / 印花试色 | 只定面料与色彩，不改款式 | 约 50–60%，面料已定、版型未定 | 面料改无弹，贴身立不住 |
| 4 打版 | 立裁与打版：人台立裁贴身版型，试穿只改接缝位置与张力分区。 | 立裁人台 / 纸样 / 样衣试穿 | 只改版型与结构，不改面料 | 约 80–90%，版型已立，个别细节仍可留空 | 张力分区一错就垮 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，模特行走看贴身是否跟随身体，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 装饰一多就俗 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：只有灵感板，方向可见、款式未定。
2. 第 2 步结束：草图已出，廓形初现、细节未定。
3. 第 3 步结束：面料已定，版型未定。
4. 第 4 步结束：样衣已立，版型已定、个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、草图 20%、选料 20%、打版（立裁）40%、成衣走秀 10%。立裁步最长，贴身靠试穿定。
- 节奏提示：灵感慢、草图与选料中速、打版放慢、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：定主题与场合：贴身针织裙、身体雕塑、永恒黑。
- 草图：画出款式草图：贴身廓形、接缝位置、裙长定稿。
- 选料：定面料：弹力针织、真丝、皮革，试张力与贴身度。
- 打版：立裁与打版：人台立裁贴身版型，试穿只改接缝位置与张力分区。
- 成衣走秀：成衣与走秀呈现：成衣缝制，模特行走看贴身是否跟随身体，定稿。
