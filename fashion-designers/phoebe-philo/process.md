# Phoebe Philo — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图 / 样衣 / 打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 定主题：以一种安静的日常状态为起点，定宽松廓形与低调色盘 | 灵感板 / 面料小样 / 图片拼贴 | 只定方向：安静主题、宽松廓形、低调色、关键元素 | 约 10–20%，方向可见、款式未定 | 极简变单调，廓形没精度 |
| 2 草图 | 画出极简草图：直线、落肩、长款，细节只留必要处 | 手绘草图 / 电脑绘图 / 立裁小样 | 全系列贯通，不回头改 | 约 30–40%，款式与廓形初现、细节未定 | 一加装饰就散，极简破了 |
| 3 选料 | 定双面羊绒与真丝：面料定垂感与厚度，色彩只定低饱和深浅 | 面料库 / 打样 / 印花试色 | 只定面料与色彩，不改款式 | 约 50–60%，面料已定、版型未定 | 面料一薄就塌，垂感没了 |
| 4 打版 | 平裁打版：版型精确度是本体，样衣试穿只改肩线落点与长度，不加装饰 | 立裁人台 / 纸样 / 样衣试穿 | 只改版型与结构，不改面料 | 约 80–90%，版型已立，个别细节仍可留空 | 版型一松就垮，精确度丢了 |
| 5 成衣走秀 | 成衣缝制，模特行走时看纵线是否干净，定稿 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 走秀一夸张就偏离安静 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：只有灵感板（主题、廓形、色彩、关键元素），款式未定。
2. 第 2 步结束：草图贯通全系列，廓形初现、细节未定。
3. 第 3 步结束：面料与色彩已定，版型未定。
4. 第 4 步结束：样衣已立，版型清晰，个别细节仍可留空。
5. 第 5 步结束：完成态，成衣走秀，通读统一。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：灵感 15%、草图 15%、选料 25%、打版 35%、成衣走秀 10%（选料与打版最长，面料与版型精度是本体）。
- 节奏提示：灵感慢、草图与选料中速、打版放慢、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑设计现代题材，不声称复刻原过程）

- 灵感：定一个安静的主题（图书馆里的克制）与一种宽松廓形（落肩直筒）
- 草图：画出直线、落肩、长款的极简草图，不画收腰与装饰
- 选料：定双面羊绒与真丝、米白驼灰黑四色
- 打版：平裁打版，试穿只改肩线落点与长度，不加装饰
- 成衣走秀：成衣缝制，模特行走时看纵线是否干净，定稿
- 节奏：灵感 15%、草图 15%、选料 25%、打版 35%、成衣走秀 10%（选料与打版最长，面料与版型精度是本体）。
