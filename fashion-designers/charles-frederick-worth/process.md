# Charles Frederick Worth — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从高级定制制度本身定题：按客户量体、活人模特展示，裙撑到臀垫的廓形演变 | 客户量体 / 活人模特 / 廓形演变图 | 只定方向：高级定制礼服、裙撑或臀垫廓形、深红墨绿金 | 约 10–20%，定制方向可见、款式未定 | 一开始就定直筒，定制体量没了 |
| 2 草图 | 画出礼服草图：胸衣、裙撑/臀垫、曳地裙摆三段定稿 | 手绘草图 / 活人模特小样 | 全系列贯通：胸衣—裙撑/臀垫—曳地裙摆，不回头改 | 约 30–40%，礼服廓形初现、细节未定 | 草图丢了臀垫，廓形变平 |
| 3 选料 | 定真丝锦缎、天鹅绒、蕾丝、刺绣线、流苏 | 锦缎天鹅绒库 / 刺绣试色 / 流苏配样 | 只定面料与装饰：锦缎、天鹅绒、蕾丝、刺绣、流苏 | 约 50–60%，面料已定、版型未定 | 面料改轻薄，裙摆撑不起来 |
| 4 打版 | 胸衣硬衬、裙撑/臀垫骨架先立，再上面料，活人模特试穿 | 立裁人台 / 裙撑骨架 / 活人模特试穿 | 只改骨架与结构：硬衬、裙撑/臀垫、裙摆长度 | 约 80–90%，骨架已立，个别细节仍可留空 | 骨架一软裙摆就塌 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，活人模特行走展示，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 走秀不成套，礼服像单件 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：定制方向可见、款式未定。
2. 第 2 步结束：礼服草图已出，裙撑/臀垫廓形初现、细节未定。
3. 第 3 步结束：锦缎与天鹅绒已定，版型未定。
4. 第 4 步结束：裙撑骨架已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、草图 20%、选料 20%、打版（骨架立裁）40%、成衣走秀 10%。骨架步最长。
- 节奏提示：灵感慢（看客户量体与活人模特）、草图与选料中速、打版放慢（看骨架立裁）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从高级定制制度本身定题：按客户量体、活人模特展示，裙撑到臀垫的廓形演变，客户量体 / 活人模特 / 廓形演变图。
- 草图：画出礼服草图：胸衣、裙撑/臀垫、曳地裙摆三段定稿，手绘草图 / 活人模特小样。
- 选料：定真丝锦缎、天鹅绒、蕾丝、刺绣线、流苏，锦缎天鹅绒库 / 刺绣试色 / 流苏配样。
- 打版：胸衣硬衬、裙撑/臀垫骨架先立，再上面料，活人模特试穿，立裁人台 / 裙撑骨架 / 活人模特试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，活人模特行走展示，定稿。
