# Jacques Fath — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从年轻战后魅力定题：沙漏收腰，褶裥裙摆如花瓣展开 | 花朵形裙摆图 / 天鹅绒雪纺小样 / 褶裥样 | 只定方向：沙漏廓形、收腰、蓬松褶裙、浪漫晚礼服 | 约 10–20%，魅力方向可见、款式未定 | 一开始就定直筒，年轻魅力没了 |
| 2 草图 | 画出款式草图：腰线极细，裙摆靠褶裥展开，花朵形裙摆定稿 | 手绘草图 / 褶裥小样 | 全系列贯通：沙漏收腰—褶裥裙摆—低领荷叶边，不回头改 | 约 30–40%，沙漏廓形初现、细节未定 | 草图丢了褶裥，裙摆就展不开 |
| 3 选料 | 定天鹅绒与雪纺、浪漫晚礼服面料 | 天鹅绒雪纺库 / 轻盈试样 / 浪漫配样 | 只定面料与轻盈：天鹅绒、雪纺、浪漫晚礼服 | 约 50–60%，面料已定、版型未定 | 面料改厚重，轻盈就没了 |
| 4 打版 | 褶裥打版：裙摆体积来自褶裥而非衬裙，试穿只改褶裥密度 | 立裁人台 / 褶裥纸样 / 样衣试穿 | 只改版型与结构：褶裥密度、腰线、裙摆 | 约 80–90%，版型已立，个别细节仍可留空 | 褶裥一乱，花朵形就散了 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，小帽手套成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 年轻感一丢就变隆重 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：魅力方向可见、款式未定。
2. 第 2 步结束：款式草图已出，沙漏廓形初现、细节未定。
3. 第 3 步结束：天鹅绒与雪纺已定，版型未定。
4. 第 4 步结束：褶裥版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、草图 20%、选料 20%、打版 40%、成衣走秀 10%。打版步最长，褶裙靠试穿定。
- 节奏提示：灵感慢（看年轻战后魅力与花朵形裙摆）、草图与选料中速、打版放慢（看褶裥展开）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从年轻战后魅力定题：沙漏收腰，褶裥裙摆如花瓣展开，花朵形裙摆图 / 天鹅绒雪纺小样 / 褶裥样。
- 草图：画出款式草图：腰线极细，裙摆靠褶裥展开，花朵形裙摆定稿，手绘草图 / 褶裥小样。
- 选料：定天鹅绒与雪纺、浪漫晚礼服面料，天鹅绒雪纺库 / 轻盈试样 / 浪漫配样。
- 打版：褶裥打版：裙摆体积来自褶裥而非衬裙，试穿只改褶裥密度，立裁人台 / 褶裥纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，小帽手套成套，定稿。
