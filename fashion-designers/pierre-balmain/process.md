# Pierre Balmain — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从战后巴黎优雅定题：Jolie Madame，建筑式收腰，钟形裙 | 建筑图 / 钟形裙图 / 刺绣样 | 只定方向：建筑式收腰、钟形裙、华丽晚礼服 | 约 10–20%，优雅方向可见、款式未定 | 一开始就定直筒，庄重感没了 |
| 2 草图 | 画出款式草图：收腰而不勒，钟形裙撑起，裙摆体积庄重 | 手绘草图 / 钟形裙小样 | 全系列贯通：收腰—钟形裙—晚礼服，不回头改 | 约 30–40%，钟形廓形初现、细节未定 | 草图丢了钟形，庄重感就散了 |
| 3 选料 | 定华丽面料、刺绣与珠饰、皮草披肩 | 面料库 / 刺绣珠饰试样 / 皮草配样 | 只定面料与装饰：华丽面料、刺绣、珠饰、皮草 | 约 50–60%，面料已定、版型未定 | 刺绣一省，华丽就没了 |
| 4 打版 | 建筑式收腰立裁：硬衬胸衣与柔和肩线对照，试穿只改腰线与裙长 | 立裁人台 / 建筑式纸样 / 样衣试穿 | 只改版型与结构：收腰、钟形裙、肩线 | 约 80–90%，版型已立，个别细节仍可留空 | 收腰一勒，建筑感就成了束缚 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，皮草披肩成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 庄重一丢就变休闲 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：优雅方向可见、款式未定。
2. 第 2 步结束：款式草图已出，钟形廓形初现、细节未定。
3. 第 3 步结束：华丽面料与刺绣已定，版型未定。
4. 第 4 步结束：建筑式版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、草图 20%、选料 20%、打版 40%、成衣走秀 10%。打版步最长。
- 节奏提示：灵感慢（看战后巴黎优雅与 Jolie Madame）、草图与选料中速、打版放慢（看建筑式收腰）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从战后巴黎优雅定题：Jolie Madame，建筑式收腰，钟形裙，建筑图 / 钟形裙图 / 刺绣样。
- 草图：画出款式草图：收腰而不勒，钟形裙撑起，裙摆体积庄重，手绘草图 / 钟形裙小样。
- 选料：定华丽面料、刺绣与珠饰、皮草披肩，面料库 / 刺绣珠饰试样 / 皮草配样。
- 打版：建筑式收腰立裁：硬衬胸衣与柔和肩线对照，试穿只改腰线与裙长，立裁人台 / 建筑式纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，皮草披肩成套，定稿。
