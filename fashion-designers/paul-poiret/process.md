# Paul Poiret — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从东方剧目与异域色彩定题：解放胸衣，直筒柱形、高腰线 | 东方纹样 / 异域色彩板 / 真丝小样 | 只定方向：解放身体的直筒廓形、东方主色、直筒裙或灯笼裤 | 约 10–20%，解放方向可见、款式未定 | 一开始就收腰，解放感没了 |
| 2 披挂定形 | 活人模特披挂定形：直筒柱形、灯笼裤收口、高腰线定稿，不画收腰 | 活人模特 / 布匹披挂 | 全系列贯通：直筒柱形—灯笼裤收口—高腰线，不回头改 | 约 30–40%，直筒廓形初现、细节未定 | 披挂加了胸衣，革命散了 |
| 3 选料 | 定真丝、绸缎、天鹅绒、东方印花、金线、流苏 | 真丝库 / 东方印花试色 / 金线配样 | 只定面料与装饰：真丝、绸缎、天鹅绒、东方印花、金线、流苏 | 约 50–60%，面料已定、版型未定 | 面料改硬挺，直筒垂不下来 |
| 4 打版 | 平裁直筒，灯笼裤试穿只改收口松紧，不改直筒结构 | 平裁纸样 / 灯笼裤试穿 / 活人模特 | 只改版型与结构：直筒、灯笼裤收口、高腰线 | 约 80–90%，版型已立，个别细节仍可留空 | 灯笼裤收口一松就垮 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，模特行走看垂坠与行动自由，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 东方色一淡就平，异域没了 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：解放方向可见、款式未定。
2. 第 2 步结束：披挂已定形，直筒廓形初现、细节未定。
3. 第 3 步结束：真丝与东方印花已定，版型未定。
4. 第 4 步结束：直筒版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 15%、披挂定形 20%、选料 25%、打版 25%、成衣走秀 15%。选料步略长，东方色彩靠面料定。
- 节奏提示：灵感慢（看东方剧目与异域色彩）、披挂与选料中速、打版放慢（看平裁直筒）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 活人模特披挂 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 披挂定形 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从东方剧目与异域色彩定题：解放胸衣，直筒柱形、高腰线，东方纹样 / 异域色彩板 / 真丝小样。
- 披挂定形：活人模特披挂定形：直筒柱形、灯笼裤收口、高腰线定稿，不画收腰，活人模特 / 布匹披挂。
- 选料：定真丝、绸缎、天鹅绒、东方印花、金线、流苏，真丝库 / 东方印花试色 / 金线配样。
- 打版：平裁直筒，灯笼裤试穿只改收口松紧，不改直筒结构，平裁纸样 / 灯笼裤试穿 / 活人模特。
- 成衣走秀：成衣与走秀呈现：成衣缝制，模特行走看垂坠与行动自由，定稿。
