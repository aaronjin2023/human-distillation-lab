# Kunihiko Morinaga — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图 / 样衣 / 打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 定主题：以日常物的非现实一面（如光影）为起点，定拼贴廓形 | 灵感板 / 面料小样 / 图片拼贴 | 只定方向：光影主题、拼贴廓形、白黑色、关键元素 | 约 10–20%，方向可见、款式未定 | 光影一弱就剩白布，科技没成立 |
| 2 草图 | 画出光影草图：三角形拼贴、光影印花先行 | 手绘草图 / 电脑绘图 / 立裁小样 | 全系列贯通，不回头改 | 约 30–40%，款式与廓形初现、细节未定 | 拼贴一多就乱，几何变拼凑 |
| 3 选料 | 定感光与反光面料：光影反应定功能，拼贴定几何 | 面料库 / 打样 / 印花试色 | 只定面料与光影，不改款式 | 约 50–60%，面料已定、版型未定 | 日常一过就平庸，非现实没了 |
| 4 打版 | 拼贴打版：三角形衣片拼接上人台，试穿只改拼贴位置，不改回常规 | 立裁人台 / 纸样 / 样衣试穿 | 只改版型与结构，不改面料 | 约 80–90%，版型已立，个别细节仍可留空 | 科技一堆就噱头，诗意没了 |
| 5 成衣走秀 | 成衣缝制，模特行走时看光影变化是否成立，定稿 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 走秀一暗就看不见光影 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：只有灵感板（主题、廓形、色彩、关键元素），款式未定。
2. 第 2 步结束：草图贯通全系列，廓形初现、细节未定。
3. 第 3 步结束：面料与色彩已定，版型未定。
4. 第 4 步结束：样衣已立，版型清晰，个别细节仍可留空。
5. 第 5 步结束：完成态，成衣走秀，通读统一。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：灵感 20%、草图 15%、选料 30%、打版 25%、成衣走秀 10%（选料最长，光影面料是本体）。
- 节奏提示：灵感慢、草图与选料中速、打版放慢、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑设计现代题材，不声称复刻原过程）

- 灵感：定一个主题（窗台咖啡的光影）与一种廓形（三角形拼贴）
- 草图：画出三角形拼贴、光影印花的草图
- 选料：定感光与反光面料、白黑两色、光影变化
- 打版：三角形衣片拼接上人台，试穿只改拼贴位置
- 成衣走秀：成衣缝制，模特行走时看光影变化是否成立，定稿
- 节奏：灵感 20%、草图 15%、选料 30%、打版 25%、成衣走秀 10%（选料最长，光影面料是本体）。
