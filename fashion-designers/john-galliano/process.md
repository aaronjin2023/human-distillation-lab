# John Galliano — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从历史幻想与戏剧化叙事定题：斜裁吊带裙，历史廓形挪用 | 历史廓形图 / 斜裁真丝样 / 叙事板 | 只定方向：浪漫戏剧、斜裁吊带裙、历史幻想、垂坠叙事 | 约 10–20%，戏剧方向可见、款式未定 | 一开始就定当代极简，历史幻想没了 |
| 2 垂坠立裁 | 人台垂坠立裁定形：布在人台上按叙事定形，斜裁使真丝贴身垂坠 | 人台 / 真丝布样 / 垂坠立裁 | 全系列贯通：斜裁吊带裙—历史廓形—垂坠叙事，不回头改 | 约 30–40%，斜裁垂坠初现、细节未定 | 立裁丢了斜裁，垂坠就没了 |
| 3 选料 | 定真丝、刺绣与羽毛的戏剧装饰面料 | 真丝库 / 刺绣羽毛试样 / 戏剧配样 | 只定面料与装饰：真丝、刺绣、羽毛、戏剧装饰 | 约 50–60%，面料已定、版型未定 | 装饰一省，戏剧就没了 |
| 4 打版 | 斜裁打版：试穿只改垂坠长度与领口，不改斜裁结构 | 人台 / 斜裁纸样 / 样衣试穿 | 只改版型与结构：斜裁角度、垂坠长度、历史领口 | 约 80–90%，版型已立，个别细节仍可留空 | 斜裁一改平裁，垂坠就没了 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，戏剧化走秀排练，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 戏剧一过就俗 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：戏剧方向可见、款式未定。
2. 第 2 步结束：人台立裁已定形，斜裁垂坠初现、细节未定。
3. 第 3 步结束：真丝与戏剧装饰已定，版型未定。
4. 第 4 步结束：斜裁版型已立，个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 15%、垂坠立裁 20%、选料 20%、打版 30%、成衣走秀 15%。走秀步略长，戏剧呈现是风格的一部分。
- 节奏提示：灵感慢（看历史幻想与戏剧叙事）、立裁与选料中速、打版放慢（看斜裁垂坠）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 人台垂坠立裁 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 垂坠立裁 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从历史幻想与戏剧化叙事定题：斜裁吊带裙，历史廓形挪用，历史廓形图 / 斜裁真丝样 / 叙事板。
- 垂坠立裁：人台垂坠立裁定形：布在人台上按叙事定形，斜裁使真丝贴身垂坠，人台 / 真丝布样 / 垂坠立裁。
- 选料：定真丝、刺绣与羽毛的戏剧装饰面料，真丝库 / 刺绣羽毛试样 / 戏剧配样。
- 打版：斜裁打版：试穿只改垂坠长度与领口，不改斜裁结构，人台 / 斜裁纸样 / 样衣试穿。
- 成衣走秀：成衣与走秀呈现：成衣缝制，戏剧化走秀排练，定稿。
