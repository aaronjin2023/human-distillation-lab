# Valentino Garavani — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 定主题与场合：Valentino Red 晚礼服、蕾丝刺绣、永恒优雅。 | 灵感板 / 面料小样 / 图片拼贴 | 只定方向：主题、廓形、色彩、关键元素 | 约 10–20%，方向可见、款式未定 | 一开始就定素面，优雅没了 |
| 2 草图 | 画出款式草图：收腰、长拖尾、蕾丝位置定稿。 | 手绘草图 / 电脑绘图 / 立裁小样 | 全系列贯通，不回头改 | 约 30–40%，款式与廓形初现、细节未定 | 草图红色一淡就不是 Valentino Red |
| 3 选料 | 定面料：真丝、雪纺、蕾丝，红色定色。 | 面料库 / 打样 / 印花试色 | 只定面料与色彩，不改款式 | 约 50–60%，面料已定、版型未定 | 蕾丝一少就平 |
| 4 打版 | 立裁与打版：收腰立裁，蕾丝对位，试穿只改腰线与拖尾长度。 | 立裁人台 / 纸样 / 样衣试穿 | 只改版型与结构，不改面料 | 约 80–90%，版型已立，个别细节仍可留空 | 拖尾一短体积就散 |
| 5 成衣走秀 | 成衣与走秀呈现：成衣缝制，蕾丝配饰成套，定稿。 | 成衣缝制 / 试穿 / 走秀排练 | 全系列统一，不改结构 | 100%，完成态 | 庄重一丢就变休闲 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：只有灵感板，方向可见、款式未定。
2. 第 2 步结束：草图已出，廓形初现、细节未定。
3. 第 3 步结束：面料已定，版型未定。
4. 第 4 步结束：样衣已立，版型已定、个别细节仍可留空。
5. 第 5 步结束：完成态，走秀定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 10%、草图 20%、选料（红色定色）25%、打版 30%、成衣走秀 15%。选料步略长，红色靠面料定。
- 节奏提示：灵感慢、草图与选料中速、打版放慢、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣走秀），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：定主题与场合：Valentino Red 晚礼服、蕾丝刺绣、永恒优雅。
- 草图：画出款式草图：收腰、长拖尾、蕾丝位置定稿。
- 选料：定面料：真丝、雪纺、蕾丝，红色定色。
- 打版：立裁与打版：收腰立裁，蕾丝对位，试穿只改腰线与拖尾长度。
- 成衣走秀：成衣与走秀呈现：成衣缝制，蕾丝配饰成套，定稿。
