# Rose Bertin — 设计过程规格 process.md（给图像 / 视频模型）

> 只按时装的设计逻辑写，不编造设计师本人的生活场景；有草图/样衣/打版记录可考者以记录为准，无记录者按系列结构反推，不声称复刻原过程。

## (1) 设计步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 用什么面料、做哪里 | 成衣状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 灵感 | 从凡尔赛宫廷礼仪与王后衣橱定题：礼服、裙撑宽度、粉白淡蓝主色 | 王后衣橱 / 宫廷礼仪 / 面料小样 | 只定方向：宫廷场合、裙撑廓形、粉白淡蓝、刺绣缎带羽毛 | 约 10–20%，宫廷方向可见、款式未定 | 一开始就定素面直筒，宫廷感没了 |
| 2 草图 | 画出礼服草图：胸衣、裙撑、裙摆三段定稿 | 手绘草图 / 裙撑小样 | 全系列贯通：胸衣—裙撑—裙摆三段，不回头改 | 约 30–40%，礼服廓形初现、细节未定 | 草图收了裙撑，钟形轮廓立不住 |
| 3 选料 | 定真丝锦缎、塔夫绸、蕾丝与刺绣线 | 锦缎库 / 刺绣试色 / 缎带羽毛配样 | 只定面料与装饰：锦缎、塔夫绸、蕾丝、刺绣、缎带、羽毛 | 约 50–60%，面料已定、版型未定 | 面料改成现代素棉，锦缎光泽没了 |
| 4 打版 | 胸衣硬衬、裙撑骨架先立，再上锦缎面料 | 立裁人台 / 裙撑骨架 / 样衣试穿 | 只改骨架与结构：硬衬、裙撑宽度、胸衣松紧 | 约 80–90%，骨架已立，个别细节仍可留空 | 骨架一软裙摆就塌，仪式感散了 |
| 5 成衣呈现 | 成衣与宫廷呈现：成衣缝制，层叠褶边与配饰成套，宫廷场合定稿。 | 成衣缝制 / 试穿 / 宫廷呈现 | 全系列统一，不改结构 | 100%，完成态 | 配饰不成套，礼服像单件 |

## (2) 每一阶段的成衣状态变化（过程视频的节奏）

1. 第 1 步结束：宫廷方向可见、款式未定。
2. 第 2 步结束：礼服草图已出，裙撑廓形初现、细节未定。
3. 第 3 步结束：锦缎与刺绣已定，版型未定。
4. 第 4 步结束：裙撑骨架已立，个别细节仍可留空。
5. 第 5 步结束：完成态，宫廷呈现定稿。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：灵感 15%、草图 20%、选料 20%、打版（骨架立裁）35%、成衣呈现 10%。骨架步最长，因为廓形本体在骨架。
- 节奏提示：灵感慢（看宫廷礼仪与王后衣橱）、草图与选料中速、打版放慢（看裙撑骨架立起）、走秀停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：灵感板 / 草图 / 面料小样 / 人台立裁 / 样衣试穿逐一出现，关键修改处用前后对比并排显示；每步左上角出小字步骤名（灵感 / 草图 / 选料 / 打版 / 成衣呈现），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍工作台 / 侧面 45° / 局部特写三机位轮换；灵感用全景，打版用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 件原作小图对照（只放成衣，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡人台；不要把过程剪成跳切，保留修改的连续性；不要虚构设计师本人的生活场景。

## (4) 过程示例（以本设计师的逻辑为例，不声称复刻原过程）

- 灵感：从凡尔赛宫廷礼仪与王后衣橱定题：礼服、裙撑宽度、粉白淡蓝主色，王后衣橱 / 宫廷礼仪 / 面料小样。
- 草图：画出礼服草图：胸衣、裙撑、裙摆三段定稿，手绘草图 / 裙撑小样。
- 选料：定真丝锦缎、塔夫绸、蕾丝与刺绣线，锦缎库 / 刺绣试色 / 缎带羽毛配样。
- 打版：胸衣硬衬、裙撑骨架先立，再上锦缎面料，立裁人台 / 裙撑骨架 / 样衣试穿。
- 成衣呈现：成衣与宫廷呈现：成衣缝制，层叠褶边与配饰成套，宫廷场合定稿。
