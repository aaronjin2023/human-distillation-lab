# W. E. B. Du Bois — 社会学研究过程规格 process.md（给文本/视频模型）

> 只按著作的研究逻辑写，不编造社会学家的生活场景；无田野笔记/调查档案可考者按著作结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 工具 | 写什么、写哪里 | 研究状态 |
|---|---|---|---|---|
| 1 问题 | 定一个种族问题与调查范围 | 文献梳理 / 概念辨析 | 只定骨架：核心问题、颜色线、调查社区、比较维度 | 约 10–20% 完成，问题可见、证据未定 |
| | 最容易做错：把种族问题写成个人偏见问题 | | | |
| 2 调查 | 入户调查与历史文献收集 | 入户调查 / 访谈 / 历史文献 | 全面收集，不急于下结论 | 约 40–50%，材料初现、粗糙未编码 |
| | 最容易做错：只收符合预期的社区，漏掉中产黑人社区 | | | |
| 3 数据 | 按种族与阶级交叉编码调查 | 分类 / 统计表 | 只整理材料与模式，不改问题 | 约 60–70%，模式已现、理论未满 |
| | 最容易做错：把统计数字误当作种族经验本身 | | | |
| 4 分析 | 以颜色线与双重意识统摄材料 | 概念建构 / 比较 / 反例检验 | 只改论证与理论，不改材料 | 约 85–90%，理论已立，个别证据仍可留空 |
| | 最容易做错：一加道德呼吁就偏离调查证据 | | | |
| 5 理论 | 统一、定稿、定名 | 通读 / 校对 / 定概念名与书名 | 全篇薄薄统一，不改结构 | 100%，完成态 |
| | 最容易做错：为求体系完整而把交叉经验硬塞进单一框架 | | | |

## (2) 每一阶段的研究状态变化（过程视频/文本生成的节奏）

- 第 1 步结束：只有问题与颜色线，社区调查尚未进入
- 第 2 步结束：入户调查堆积，种族与阶级交叉初现
- 第 3 步结束：交叉编码完成，模式清晰
- 第 4 步结束：理论密度骤升，双重意识解释个案
- 第 5 步结束：完成态：种族社会学定型
- 节奏建议：问题慢（让观者看清颜色线）、调查中速（看社区材料生长）、分析放慢（看双重意识论证）、定稿停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。不要把 5 步平均分配时间，按本社会学家特点分配（问题 15%、调查 35%、数据 20%、分析 25%、定稿 5%）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：社区调查表与历史对照逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 调查 / 数据 / 分析 / 理论）。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，分析用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放著作封面/田野页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构社会学家本人的生活场景；不要泄露真实被访者的隐私信息。

## (4) 过程示例（按本社会学家著作逻辑反推，不声称复刻原过程）

问题：定一个问题（费城黑人社区的真实状况）、一个概念（颜色线）、一个社区（第七区）。调查：以入户调查为底。数据：按种族与阶级交叉编码。分析：以双重意识统摄材料。定稿：只改概念名与篇章顺序。
