# Edward W. Said — 研究方法与技法 technique.md（Procedure，只限著作）

> v0.1（2026-10-26）。

- 方法组合：文本批判 50% / 历史比较 30% / 概念建构 20%。`impression`
- 数据来源：文学文本、殖民档案、旅行记、学术史文献、新闻与政治话语。`impression`
- 定义方式：批判性重构：先揭示一个概念（如“东方”）如何被权力生产出来，再追问它排除了什么。`impression`
- 论证结构：文本症候切入 — 话语系谱追溯 — 对位阅读（宗主与殖民地并置） — 权力批判 — 流亡者的开放立场。`impression`
- 核心概念群：东方学、他者、表征、对位阅读、文化与帝国主义、流亡、知识分子、世俗批评。`impression`
- 证据进入论证：先分类编码，再进入论证；反例须正面检验，不丢弃。`impression`
- 修改痕迹：概念名与篇章顺序的反复打磨见于著作版本与文集重排，蒸馏以成书为准。`artifact`
- 方法禁区：No neutral description of the East; No text without power; No nativist reversal; No separating culture from empire; No detached aestheticism。
