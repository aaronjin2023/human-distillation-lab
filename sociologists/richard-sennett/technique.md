# Richard Sennett — 研究方法与技法 technique.md（Procedure，只限著作）

> v0.1（2026-10-26）。

- 方法组合：田野访谈 40% / 历史比较 30% / 概念建构 30%。`impression`
- 数据来源：深度访谈、职业田野、历史文献、城市观察、文学与思想史材料。`impression`
- 定义方式：经验—概念往复定义：概念从访谈与田野中提炼，再回到历史中检验，定义是开放的。`impression`
- 论证结构：访谈场景或城市观察切入 — 叙事呈现 — 历史对照 — 概念提炼 — 合作与尊重的开放结论。`impression`
- 核心概念群：匠人、合作、公共人、性格腐蚀、尊重、叙事、技能、城市。`impression`
- 证据进入论证：先分类编码，再进入论证；反例须正面检验，不丢弃。`impression`
- 修改痕迹：概念名与篇章顺序的反复打磨见于著作版本与文集重排，蒸馏以成书为准。`artifact`
- 方法禁区：No nostalgia without history; No skill without narrative; No cooperation as mere technique; No character as private fate; No city without public life。
