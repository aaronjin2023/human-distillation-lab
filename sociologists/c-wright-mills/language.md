# C. Wright Mills — 理论语言 language.md（Interaction，只限著作）

> v0.1（2026-10-26）。

- 核心概念：社会学的想象力, 权力精英, 白领, 个人困扰与公共议题, 科层制, 权力结构。`artifact`
- 定义方式：理想类型与历史语境定义为主，概念随著作序列演变。`impression`
- 论证结构：悖论式开头（个人困扰背后是公共议题）—历史结构分析—权力结构揭示—结尾号召公共理性。`impression`
- 语气与距离：热烈、批判、公共性强；与权力保持审判距离，与读者直接对话。`impression`
- 案例与数据的呈现：案例先行或概念先行，数据只作论证的支撑，不单独成篇。`impression`
- 与读者的关系：与读者直接对话或理性辩论，不做布道式说教。`impression`
- 禁语言：不用道德审判式结论，不用无定义的流行词，不用脱离概念的统计语言。`impression`
