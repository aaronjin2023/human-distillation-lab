# Saskia Sassen — 研究方法与技法 technique.md（Procedure，只限著作）

> v0.1（2026-10-26）。

- 方法组合：统计调查 35% / 历史比较 35% / 田野调查 15% / 概念建构 15%。`impression`
- 数据来源：城市经济统计、跨国比较数据、移民与劳工田野、法律与制度文献。`impression`
- 定义方式：组合式定义：概念由领土、权威、权利三要素的重新组合界定，定义随组合变化。`impression`
- 论证结构：全球城市数据切入 — 跨国比较 — 组合重组分析 — 驱逐机制揭示 — 全球化的开放结论。`impression`
- 核心概念群：全球城市、领土、权威、权利、驱逐、全球化、移民、非正式经济、去国家化、全球集聚。`impression`
- 证据进入论证：先分类编码，再进入论证；反例须正面检验，不丢弃。`impression`
- 修改痕迹：概念名与篇章顺序的反复打磨见于著作版本与文集重排，蒸馏以成书为准。`artifact`
- 方法禁区：No globalisation as flat flow; No city as container; No state as given; No expulsion as accident; No global without the local。
