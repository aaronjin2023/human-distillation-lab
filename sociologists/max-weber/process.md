# Max Weber — 社会学研究过程规格 process.md（给文本/视频模型）

> 只按著作的研究逻辑写，不编造社会学家的生活场景；无田野笔记/调查档案可考者按著作结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 工具 | 写什么、写哪里 | 研究状态 |
|---|---|---|---|---|
| 1 问题 | 定一个价值关联的问题与理想类型 | 文献梳理 / 概念辨析 | 只定骨架：核心问题、理想类型、比较维度、研究边界 | 约 10–20% 完成，问题可见、证据未定 |
| | 最容易做错：把理想类型当作现实描述 | | | |
| 2 调查 | 收集历史文献与宗教文本 | 历史文献 / 比较个案 | 全面收集，不急于下结论 | 约 40–50%，材料初现、粗糙未编码 |
| | 最容易做错：只收支持命题的文明，漏掉反例文明 | | | |
| 3 数据 | 按理想类型编码历史个案 | 分类 / 比较表 | 只整理材料与模式，不改问题 | 约 60–70%，模式已现、理论未满 |
| | 最容易做错：把理想类型的纯粹性误当作历史的真实 | | | |
| 4 分析 | 以比较历史统摄材料 | 概念建构 / 比较 / 反例检验 | 只改论证与理论，不改材料 | 约 85–90%，理论已立，个别证据仍可留空 |
| | 最容易做错：一加价值判断就越界，理解变成评判 | | | |
| 5 理论 | 统一、定稿、定名 | 通读 / 校对 / 定概念名与书名 | 全篇薄薄统一，不改结构 | 100%，完成态 |
| | 最容易做错：为求体系完整而把开放问题写成封闭结论 | | | |

## (2) 每一阶段的研究状态变化（过程视频/文本生成的节奏）

- 第 1 步结束：只有问题与理想类型，历史材料尚未进入
- 第 2 步结束：历史个案堆积，比较维度初现
- 第 3 步结束：理想类型编码完成，模式清晰
- 第 4 步结束：理论密度骤升，比较历史解释差异
- 第 5 步结束：完成态：理解社会学定型
- 节奏建议：问题慢（让观者看清理想类型）、调查中速（看历史材料生长）、分析放慢（看比较论证）、定稿停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。不要把 5 步平均分配时间，按本社会学家特点分配（问题 20%、调查 25%、数据 20%、分析 30%、定稿 5%）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：理想类型表与文明对照图逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 调查 / 数据 / 分析 / 理论）。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，分析用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放著作封面/田野页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构社会学家本人的生活场景；不要泄露真实被访者的隐私信息。

## (4) 过程示例（按本社会学家著作逻辑反推，不声称复刻原过程）

问题：定一个问题（新教伦理与资本主义精神有何亲和）、一个类型（天职观）、一个比较对象（中国与印度）。调查：以宗教文本与经济史为底。数据：按理想类型编码。分析：以比较历史统摄材料，反例以类型边界解释。定稿：只改概念名与篇章顺序。
