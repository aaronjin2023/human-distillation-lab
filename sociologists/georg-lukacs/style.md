# Georg Lukács — 研究方法与理论风格规格 style.md（给文本模型）

> 只描述著作，不描述人生。引用原文时只引短句并注明出处。

## (1) 一句话风格（prompt-ready）

- EN: `In the style of Georg Lukács: reification, class consciousness, totality, realism, no empiricism without totality`
- ZH: 卢卡奇风格：物化、阶级意识、总体性、现实主义、没有总体性的经验主义。

## (2) 研究方法组合

- 方法配比：批判分析为主（约 60%）、概念建构为辅（约 25%）、历史比较为辅（约 15%）；无田野调查与统计调查。。`impression`（学界通说）
- 数据来源：哲学与文学文本、历史上的阶级意识个案；以总体性为证据骨架。。
- 抽样与案例选择：以阶级意识为案例单位，按物化程度取样；以无产阶级为核心对象。。

## (3) 概念与语言

- 核心概念群（5 个）：物化、阶级意识、总体性、现实主义、异化。`artifact`
- 定义方式：辩证定义：概念以对立统一界定，如物化既是意识形态又是社会现实；定义服务于总体性。。
- 禁概念 / 禁方法：不用无总体性的经验主义，不用无视阶级意识的分析，不用碎片化分析，不用道德评判。。

## (4) 论证结构

- 结构：总体—部分：先立总体性，再以物化分析部分，最后以阶级意识收束。。`impression`
- 开头方式：以物化的普遍性开篇；结尾方式：以阶级意识的历史前景收束。
- 证据呈现：哲学与文学文本对照；反例用总体性的不同层面解释。；反例处理：反例不删除，解释为总体性中尚未被意识到的部分。。

## (5) 语气与距离

- 语气：热烈、思辨、体系化的确信。`impression`
- 与研究对象的距离：与研究对象保持总体性俯瞰的距离；与读者的距离：向读者揭示物化的对话距离。

## (6) 该写什么 / 不该写什么

- 该写：物化、阶级意识、总体性、现实主义、异化。
- 不该写：无总体性的经验主义、无视阶级意识、碎片化分析、道德评判。
- Negative prompt: `No empiricism without totality, no ignoring class consciousness, no fragmentary analysis, no moralising`

## (7) 测试提示词示例（现代题材：剧本杀店里的角色扮演）

- Prompt: `In the style of Georg Lukács, analyse role-playing in a script-murder shop: reification, class consciousness in miniature, totality, realism, no empiricism without totality.`
- 中文对照：卢卡奇风格：分析剧本杀店里的角色扮演——物化、微缩的阶级意识、总体性、现实主义、没有总体性的经验主义。
- Negative: `No empiricism without totality, no ignoring class consciousness, no fragmentary analysis, no moralising`
- 检验点：是否出现物化与总体性；是否以总体性组织论证；是否拒绝碎片化分析。
