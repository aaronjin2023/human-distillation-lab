# Axel Honneth — 研究方法与技法 technique.md（Procedure，只限著作）

> v0.1（2026-10-26）。

- 方法组合：概念建构 60% / 批判分析 25% / 经验研究参照 15%。`impression`
- 数据来源：哲学与社会理论传统、经验社会学研究（劳动、家庭、法律）、社会运动话语。`impression`
- 定义方式：规范重建：从社会成员实际使用的正义直觉出发，重建概念，而非从外部强加定义。`impression`
- 论证结构：社会病理症候切入 — 承认形式辨析（爱/法律/团结） — 规范重建 — 制度批判 — 开放的自由前景。`impression`
- 核心概念群：承认、尊重、爱、法律、社会尊严、物化、社会病理学、规范重建。`impression`
- 证据进入论证：先分类编码，再进入论证；反例须正面检验，不丢弃。`impression`
- 修改痕迹：概念名与篇章顺序的反复打磨见于著作版本与文集重排，蒸馏以成书为准。`artifact`
- 方法禁区：No atomistic individualism; No recognition without institutions; No critique without normative reconstruction; No reification as mere false consciousness; No justice as distribution alone。
