# Ulrich Beck — 研究方法与技法 technique.md（Procedure，只限著作）

> v0.1（2026-10-26）。

- 方法组合：概念建构 55% / 统计与经验参照 20% / 历史比较 25%。`impression`
- 数据来源：环境与技术风险数据、福利国家文献、全球化经验研究、民意与制度材料。`impression`
- 定义方式：时代诊断式定义：概念即诊断（风险社会），定义包含对旧时代（阶级社会）的否定。`impression`
- 论证结构：风险事件切入 — 旧范式失效辨析 — 反身性现代化论证 — 世界主义前景 — 制度改革的开放结论。`impression`
- 核心概念群：风险社会、反身性现代化、世界主义、个体化、亚政治、有组织的无责任、风险共同体。`impression`
- 证据进入论证：先分类编码，再进入论证；反例须正面检验，不丢弃。`impression`
- 修改痕迹：概念名与篇章顺序的反复打磨见于著作版本与文集重排，蒸馏以成书为准。`artifact`
- 方法禁区：No class analysis alone; No national container of society; No risk as mere probability; No modernity without reflexivity; No globalisation as a single process。
