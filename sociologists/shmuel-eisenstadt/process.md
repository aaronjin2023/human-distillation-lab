# Shmuel N. Eisenstadt — 社会学研究过程规格 process.md（给文本/视频模型）

> 只按著作的研究逻辑写，不编造社会学家的生活场景；无田野笔记/调查档案可考者按著作结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 工具 | 写什么、写哪里 | 研究状态 |
|---|---|---|---|---|
| 1 问题 | 定一个多重现代性问题 | 文献梳理 / 概念辨析 | 只定骨架：核心问题、多重现代性、比较文明 | 约 10–20% 完成，问题可见、证据未定 |
| | 最容易做错：把多重现代性写成相对主义 | | | |
| 2 调查 | 收集帝国与文明的历史文献 | 历史文献 / 比较 | 全面收集，不急于下结论 | 约 40–50%，材料初现、粗糙未编码 |
| | 最容易做错：只收符合多重性的文明，漏掉趋同个案 | | | |
| 3 数据 | 按轴心与非轴心编码文明 | 分类 / 比较表 | 只整理材料与模式，不改问题 | 约 60–70%，模式已现、理论未满 |
| | 最容易做错：把文明的整齐误当作现代性的真实 | | | |
| 4 分析 | 以多重现代性统摄材料 | 概念建构 / 比较 / 反例检验 | 只改论证与理论，不改材料 | 约 85–90%，理论已立，个别证据仍可留空 |
| | 最容易做错：一加欧洲中心就失去比较的公正 | | | |
| 5 理论 | 统一、定稿、定名 | 通读 / 校对 / 定概念名与书名 | 全篇薄薄统一，不改结构 | 100%，完成态 |
| | 最容易做错：为求体系完整而把趋同硬塞进多重 | | | |

## (2) 每一阶段的研究状态变化（过程视频/文本生成的节奏）

- 第 1 步结束：只有问题与多重现代性概念，文明材料尚未进入
- 第 2 步结束：文明个案堆积，比较初现
- 第 3 步结束：轴心编码完成，模式清晰
- 第 4 步结束：理论密度骤升，多重现代性解释个案
- 第 5 步结束：完成态：比较历史定型
- 节奏建议：问题慢（让观者看清多重现代性）、调查中速（看文明材料生长）、分析放慢（看比较论证）、定稿停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。不要把 5 步平均分配时间，按本社会学家特点分配（问题 20%、调查 30%、数据 20%、分析 25%、定稿 5%）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：文明对照表与帝国比较图逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 调查 / 数据 / 分析 / 理论）。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，分析用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放著作封面/田野页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构社会学家本人的生活场景；不要泄露真实被访者的隐私信息。

## (4) 过程示例（按本社会学家著作逻辑反推，不声称复刻原过程）

问题：定一个问题（现代性是否只有一条路）、一个概念（多重现代性）、一组文明（欧洲、东亚、犹太）。调查：以帝国与文明文献为底。数据：按轴心编码。分析：以多重现代性统摄材料。定稿：只改概念名与篇章顺序。
