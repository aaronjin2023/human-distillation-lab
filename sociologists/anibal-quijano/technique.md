# Aníbal Quijano — 研究方法与技法 technique.md（Procedure，只限著作）

> v0.1（2026-10-26）。

- 主方法：批判分析与历史重构为主（约65%）、概念建构为辅（约25%）、比较为辅（约10%）。`impression`
- 方法组合的要点：以概念重构历史：殖民性不是过去，而是现代性的另一面。`impression`
- 数据来源：历史文献、理论文本、拉美社会结构材料。`artifact`
- 证据进入论证的方式：现代性神话—殖民性的揭示—种族分类的机制—去殖民的出路。`impression`
- 概念工具：殖民性、权力殖民性、现代性/殖民性、种族分类、知识殖民性、去殖民转向。`impression`
- 禁用的方法与概念：把殖民写成已结束的历史、把现代性写成中立进步。`impression`
- 修改痕迹：以著作版本、田野笔记与调查档案中的修订为准；无档案者按著作结构反推，不声称复刻原过程。`artifact`
