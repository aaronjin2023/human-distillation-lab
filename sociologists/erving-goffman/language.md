# Erving Goffman — 理论语言 language.md（Interaction，只限著作）

> v0.1（2026-10-26）。

- 核心概念：拟剧, 前台与后台, 污名, 互动秩序, 全控机构, 框架, 面子。`artifact`
- 定义方式：理想类型与历史语境定义为主，概念随著作序列演变。`impression`
- 论证结构：日常场景特写开头—拟剧概念展开—前台后台的切换—结尾回到互动秩序的自主性。`impression`
- 语气与距离：冷峻、机智、反讽；与研究对象保持观察距离，与读者共享发现的快感。`impression`
- 案例与数据的呈现：案例先行或概念先行，数据只作论证的支撑，不单独成篇。`impression`
- 与读者的关系：与读者直接对话或理性辩论，不做布道式说教。`impression`
- 禁语言：不用道德审判式结论，不用无定义的流行词，不用脱离概念的统计语言。`impression`
