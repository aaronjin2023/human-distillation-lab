# Judith Butler — 研究方法与技法 technique.md（Procedure，只限著作）

> v0.1（2026-10-26）。

- 方法组合：概念建构 65% / 文本批判 25% / 哲学论证 10%。`impression`
- 数据来源：哲学传统（福柯、德里达、奥斯汀）、文学与法律文本、政治话语、当代事件。`impression`
- 定义方式：解构式定义：概念通过揭示其建构过程来定义，定义即拆解本质。`impression`
- 论证结构：常识断裂切入 — 概念解构 — 述行论证 — 规范批判 — 脆弱与集会的开放结论。`impression`
- 核心概念群：性别操演、述行、脆弱、可泣性、身体、规范、集会、脆弱生命。`impression`
- 证据进入论证：先分类编码，再进入论证；反例须正面检验，不丢弃。`impression`
- 修改痕迹：概念名与篇章顺序的反复打磨见于著作版本与文集重排，蒸馏以成书为准。`artifact`
- 方法禁区：No gender as essence; No sex as prediscursive; No body without norms; No vulnerability as weakness; No performativity as performance。
