# Pythagoras — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。同一科学家不同时期说法不一、成果归属存疑、已证伪理论，均记入此处，不强行统一。

1. **本人著作无存，归属多为学派集体成果：** 毕达哥拉斯定理在巴比伦与中国已有实例，学派的贡献是证明与体系化，而非首次发现数值关系；定理归属应写“学派证明”，不单归个人。`artifact`
2. **无理数发现的传说不可靠：** 希帕索斯因泄露无理数被处死的传说流传甚广，但无可靠史料证实，属后人传说，不作事实蒸馏。`impression`
3. **“万物皆数”是当时模型：** 作为数学哲学有开创意义，但“数即实在”的形而上学主张已被现代科学取代，不作真理蒸馏。
4. **生卒为约数：** c.570–c.495 BCE 为学界约数。
