## 一句话

- **这是谁：** 数学，代表性成果：《代数学》、印度数字传播、算法概念。
- **什么时候用他：** 需要把一个解方程的步骤写成任何人都能照做的程序、或把一套数字系统讲清到能推广时，用这个 skill。
- **发现方法一句话：** In the style of Al-Khwarizmi, turn solving into a procedure: name each step, show it on one worked example, and write it so plainly that anyone can follow it without you
- **中文：** 花拉子米风格：把解题变成程序，每一步都命名、在一个例题上演示，写得明白到任何人不用你在场也能照做。
- **研究过程一句话：** 观察特例 → 猜想 → 证明 → 修正 → 发表（各步详见 process.md）。
