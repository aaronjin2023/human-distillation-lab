# Archimedes — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。同一科学家不同时期说法不一、成果归属存疑、已证伪理论，均记入此处，不强行统一。

1. **王冠传说不可靠：** “尤里卡”与王冠纯度检验的故事出自后人（维特鲁威）记载，阿基米德本人著作《论浮体》中陈述的是浮力命题，未记载王冠故事；传说只作传说蒸馏，不作著作内容。`artifact`
2. **《方法论》的文本史：** 《方法论》羊皮纸 1906 年重发现，文本有残缺与后人刮改，力学方法的细节以学界复原为准。`artifact`
3. **圆周率的界：** 阿基米德给出 3+10/71 < π < 3+1/7（约 3.1408–3.1429），这是夹逼的结果，不是 π 的“值”，转述时须写成区间。`verbatim`
