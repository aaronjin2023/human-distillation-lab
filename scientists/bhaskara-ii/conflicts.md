# Bhaskara II — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。同一科学家不同时期说法不一、成果归属存疑、已证伪理论，均记入此处，不强行统一。

1. **与婆罗摩笈多的传承关系：** 婆什迦罗二世接任乌贾因天文台台长，承接婆罗摩笈多传统：继承其零与负数运算法则、二次方程与不定方程的问题意识；修正其除零规则——把 0/0=0 改成 a/0 为 khahara（无穷量）。但 (a/0)×0=a 的写法按现代标准仍是错的；除以零在现代数学中无定义，khahara 的“无穷量”也不等于现代极限概念。蒸馏时标明“继承 + 修正 + 仍有错”，不写成全盘否定，也不写成全盘继承。`artifact`
2. **“微积分先驱”说法的限定：** 《天文系统之冠》天文部分有瞬时运动（tātkālika gati）的差分计算与“量取极大值时其变化为零”的表述，可译成现代记号下的罗尔定理雏形；但他没有极限概念、没有函数概念，也没有把这些洞见组织成通用方法，且无人接续。按 Plofker 等学者的提醒：能译成现代记号不等于发明了微积分。蒸馏时只写“微积分先驱思想 / 雏形”，不得写成“发明微积分”；“第一个发明微分系数/微积分”之类的说法不取。`artifact`
3. **《莉拉瓦蒂》标题传说：** 女儿莉拉瓦蒂的故事（算出婚期、水钟被珍珠堵塞、错过吉时、为安慰女儿而以其名著书）属传说，不作史实。该故事最早见于 1587 年波斯文译本（法伊兹）序言，晚于成书四百余年，无更早证据；书中向“莉拉瓦蒂”的亲切呼语是原文体例，不能反证女儿其人其事。蒸馏时传说只记此处，不进 style.md 与 process.md 的事实部分。`artifact`
4. **生卒为约数：** 1114 年生有《天文系统之冠》诗句为据；卒年 c.1185 为约数，部分资料作 1183 年，不取。
5. **四卷还是一部书：** 《莉拉瓦蒂》《种子计算》《行星计算》《球篇》有时被当作四部独立著作，有时被当作《天文系统之冠》的四卷；本蒸馏按后者（总集四卷）处理，书目上注明两种说法。`artifact`
6. **第七部著作存疑：** 除六部已知著作外，另有一部据称出自他的著作被多数学者视为后世伪作；本蒸馏不采用。`artifact`
