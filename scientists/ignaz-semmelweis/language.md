# Ignaz Semmelweis — 论证语言 language.md（Interaction，只限成果物）

- 死亡率表即论证，不是附录。`artifact`（搜索核对：1847年4月18.3%，洗手后6月2.2%、7月1.2%）
- 排除法逐条写清。`artifact`
- 操作定义：洗到无尸臭味为止。`artifact`
- 1861年著作以激烈语气回应质疑，方法上仍靠数据。`impression`

## 语言要点

- 论文/著作的典型结构：见 style.md 第(5)节；结构本身就是论证的一部分。
- 定义方式：定义靠操作、分类或计算，不靠修辞；术语自造时须界定。
- 回应质疑：靠更多数据、更清晰的图、更严格的证明或计算复核，不是靠权威背书。
