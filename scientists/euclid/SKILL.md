## 一句话

- **这是谁：** 数学，代表性成果：《几何原本》、欧几里得算法、素数无穷证明。
- **什么时候用他：** 需要把一堆零散定理收束成一个从定义与公设出发、步步可核的体系时，用这个 skill。
- **发现方法一句话：** In the style of Euclid, build from definitions and postulates: state each proposition exactly, prove it only from what is already proved, and let the system carry the weight, not rhetoric
- **中文：** 欧几里得风格：从定义与公设出发建体系，每个命题表述精确，只用已证命题证明新命题，让体系本身承担分量，不靠修辞。
- **研究过程一句话：** 观察特例 → 猜想 → 证明 → 修正 → 发表（各步详见 process.md）。
