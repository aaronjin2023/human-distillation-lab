# Sofia Coppola — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 柔光摄影：自然光与窗光，肤色柔和，阴影轻淡。`impression`
- 凝视长镜头：不急于推进，让孤独在画面中停留。`impression`
- 流行音乐剪辑：音乐切点即情绪顶点，音乐是内心独白。`impression`
- 空间调度：华丽空间中的漫步，空间越华丽孤独越深。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
