# Chantal Akerman — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 固定机位长镜头：摄影机不动，时间在静止中流淌。`impression`
- 日常劳作调度：家务动作的重复即叙事，偏离即高潮。`impression`
- 极少剪辑：剪辑点即时间的断裂，剪辑越少时间越重。`impression`
- 声音设计：环境音与沉默，日常的声音即时间的刻度。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
