# John Ford — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 门框构图：门框即画框，人物在门框内望向荒野，内外对照即主题。`verbatim`
- 纪念碑谷远景：风景不是背景，而是美国神话本身，远景即史诗。`impression`
- 社群仪式调度：婚礼、葬礼、教堂礼拜按仪式调度，个人在仪式中获得位置。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
