# Francis Ford Coppola — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 明暗对照摄影：侧光与烛光塑造面部，暗部占画面大半，权力藏在阴影里。`impression`
- 家族群戏调度：仪式场面深焦多层，权力人物居中，家人环绕。`impression`
- 平行剪辑：仪式与暴力交叉，音乐收束段落，时间跨度大。`impression`
- 声音设计：歌剧与环境音并置，寂静处只留脚步与呼吸。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
