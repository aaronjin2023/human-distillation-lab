# Steven Spielberg — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 反应镜头：先拍看的人，再拍被看之物，恐惧与惊奇写在脸上。`impression`
- 长镜头揭示：一次运动揭示整个空间，奇观在揭示中到达。`impression`
- 经典连续性剪辑：视线与动作匹配，观众永不迷路。`impression`
- 光影设计：逆光与暖金阳光写希望，阴影写危险，光即道德。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
