# Christopher Nolan — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 时间嵌套剧本：先定时间结构，再填人物与情感。`impression`
- IMAX 实拍：奇观以实体拍摄，数字特效只作辅助。`impression`
- 交叉剪辑：多条时间线并行，剪辑点即时间切换。`impression`
- 音效设计：时钟滴答与低频轰鸣构成时间的听觉。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
