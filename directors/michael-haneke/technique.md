# Michael Haneke — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 固定机位长镜头：摄影机不动，观众被迫注视。`impression`
- 画外暴力：暴力不在画面内，只留声音与余波。`impression`
- 静默调度：对白的空白即压迫，静默比台词更重要。`impression`
- 冷峻摄影：低饱和冷灰，体面空间的寒冷写在光影里。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
