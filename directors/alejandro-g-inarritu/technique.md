# Alejandro G. Iñárritu — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 多线剧本：先定交汇点（事故、相遇），再倒推各条线索的因果。`impression`
- 手持摄影：摄影机贴近人物呼吸，运动即情绪，不追求平稳。`impression`
- 貌似一镜到底：以暗藏的剪辑点串联长镜头，制造无法中断的时间感。`verbatim`
- 自然光实拍：《荒野猎人》坚持自然光拍摄，天气与光线即场面的一部分。`artifact`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
