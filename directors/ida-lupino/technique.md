# Ida Lupino — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 低成本实景：街道、汽车、旅馆实拍，预算限制反成风格，粗粝即真实。`impression`
- 禁忌题材的 B 级片形式：强奸、重婚等禁忌用 B 级片拍，社会批判藏在类型里。`impression`
- 车内威胁调度：后座的搭便车者即威胁本身，空间越小，紧张越大。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
