## 一句话

- **这是谁：** 丹麦·道格玛 / 挑衅导演，代表作《破浪》、《黑暗中的舞者》、《忧郁症》。
- **什么时候用他：** 需要按此人的风格拍其他题材的影片（短片、场景、镜头序列）时，用这个 skill。
- **风格一句话：** 冯·提尔风格：手持道格玛的粗粝，受难的女主角，挑衅即方法，摄影机随人物的信念而颤抖。
- **过程一句话：** 影片制作五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音。

## 蒸馏范围（只限成果物）

- 材料：影片本身（《破浪》、《黑暗中的舞者》、《忧郁症》为主）+ 导演本人关于影片的公开文字、分镜手稿、拍摄记录 + 权威影史分析。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（影片本身直接可见）/ `artifact`（公开文字、手稿、影史分析）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 在世者只蒸已发表作品。
