# Buster Keaton — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 实拍特技：倒塌房屋、火车追逐皆为真实机关与实景，拒绝替身与剪辑作弊，全景即证据。`verbatim`
- 扑克脸表演：无论灾难多大，表情绝不动摇，笑料来自表情与灾难的反差。`verbatim`
- 银幕穿越剪辑：《福尔摩斯二世》用剪辑让主人公走进银幕、在场景间跳跃，是早期元电影实验。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
