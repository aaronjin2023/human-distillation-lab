# Guillermo del Toro — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 手工美术：怪物与布景以实体模型、化妆与机械装置制作，质感先于特效。`impression`
- 色彩造型：琥珀、深青、血红三色定调，怪物肤色与场景同色系。`impression`
- 低机位儿童视角：摄影机常与孩子等高，成人世界被仰拍得庞大而可怖。`impression`
- 声音设计：水声、齿轮声与低鸣构成童话的听觉底层。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
