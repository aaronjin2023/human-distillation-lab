# Stanley Kubrick — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 一点透视构图：广角 + 对称，灭点置于画面中心，空间本身即压迫。`impression`
- 斯坦尼康运镜：匀速前推与跟拍，运动如机器般平稳，拒绝手持感。`impression`
- 多条重拍：以大量重复拍摄逼近精确，表演在重复中磨出冷峻。`artifact`
- 音乐对位：古典乐配暴力或太空画面，音乐与画面的反差即评论。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
