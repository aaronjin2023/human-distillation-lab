# William Wyler — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 深焦长镜头：前景、中景、背景同时清晰，观众自己选择看哪里，表演在纵深中完成。`impression`
- 多重拍摄（multiple takes）：以重拍著称，同一场戏拍数十条，只为表演的精确，方法为影史通说。`impression`
- 史诗与亲密并置：战车竞逐与两人对坐同片并存，规模对照即主题。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
