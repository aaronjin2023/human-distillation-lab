# Coen brothers — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 冷面调度：宽全景中小人物，摄影机冷静旁观，拒绝煽情。`impression`
- 对话停顿：对白的空白即喜剧与恐怖，停顿比台词更重要。`impression`
- 类型混合：黑色电影、西部、喜剧在同一结构中并存。`impression`
- 暴力克制：暴力突然、短暂、不渲染，余波靠停顿写。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
