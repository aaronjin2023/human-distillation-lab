# Orson Welles — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 深焦与天花板：低角度机位让天花板入画，纵深同时清晰，空间即权力。`verbatim`
- 开场长镜头：《历劫佳人》开场升降长镜头一镜穿越边境小镇，是影史名场面。`verbatim`
- 多视角闪回：《公民凯恩》按多人口述拼接一生，真相在叙述中分裂。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
