# Alice Guy-Blaché — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 叙事场面调度：最早把单镜头记录变成多场面叙事，故事按场次推进，人物进出即情节推进。`impression`
- 温和特效：遮片、倒放、双重曝光用于仙子现身与变身，效果服务故事而不喧宾夺主。`verbatim`
- Chronophone 同步声画实验：1906–1907 年约百部有声短片，歌声与画面同步录制，属早期有声尝试。`artifact`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
