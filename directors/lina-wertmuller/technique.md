# Lina Wertmüller — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 身体喜剧调度：演员的肢体与表情即讽刺，摄影机让位于表演。`impression`
- 群众场面：广角写人群，小人物在人群中挣扎。`impression`
- 讽刺剪辑：笑声与暴力交替，喜剧场面用长镜头展示。`impression`
- 色彩讽刺：艳丽色彩对照政治黑暗，阳光越亮讽刺越冷。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
