# Georges Méliès — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 停机再拍（substitution splice）：机位固定，停机换物再拍，成片上人物瞬间变身或消失。`verbatim`
- 叠印与多重曝光：同一画面内分身、巨头与幽灵并存，靠遮片分次曝光完成。`verbatim`
- 手工着色与彩绘布景：黑白底片逐格上色，布景按舞台布景绘制，机关布景可开合升降。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
