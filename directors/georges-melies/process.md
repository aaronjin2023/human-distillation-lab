# Georges Méliès — 影片制作过程规格 process.md（给视频模型复刻过程）

> 只按影片的制作逻辑写，不编造导演本人的生活场景；有分镜手稿 / 拍摄记录 / 访谈可考者以公开资料为准，无资料者按影片结构反推，不声称复刻原过程。

## (1) 制作步骤顺序表（5 步）

| 步骤 | 做什么 | 成片状态 |
|---|---|---|
| 1 剧本 | 剧本与机关设计：定一个魔术效果与一场奇观，画出布景机关与变身点，故事只为效果服务。 | 约 10–20% 完成，结构可见、正片未定 |
| 2 分镜 / 排练 | 布景与分镜：彩绘布景按舞台布景绘制，机位固定正面，标出每次停机换物的位置。 | 约 20–30%，镜头已定、画面未拍 |
| 3 拍摄 | 拍摄：固定机位一次拍成，停机换景、换装、换人，演员按默剧幅度正面表演。 | 约 40–50%，素材初现、粗糙 |
| 4 剪辑 | 剪辑：按场次拼接，叠化连接奇观段落，变身点不切，靠停机再拍本身完成。 | 约 60–70%，骨架已定、细节未满 |
| 5 调色 / 混音 / 定剪 | 着色与定剪：黑白底片手工着色，奇观段落重点上色，谢幕群像收尾。 | 100%，完成态 |

## (2) 每一阶段的成片状态变化（过程视频的节奏）

- 第 1 步结束：只有剧本与结构，观者看到故事骨架与人物关系。
- 第 2 步结束：镜头与调度已定，观者看到机位图与走位，但无画面。
- 第 3 步结束：有画面无节奏，观者看到场景成形、表演初现。
- 第 4 步结束：结构与节奏落点，观者看到影片骨架已定。
- 第 5 步结束：色彩与声音统一，观者看到完成态。
- 节奏建议：剧本慢（看清结构）、分镜中速（看镜头生长）、拍摄中速（看场景成形）、剪辑放慢（看节奏落点）、调色 / 混音停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。时间分配：剧本机关 20%、布景分镜 25%、拍摄 30%、剪辑 10%、着色定剪 15%。

## (3) 过程呈现的镜头与字幕建议

- 呈现：剧本页 / 分镜稿 / 拍摄现场 / 剪辑时间线逐段出现，关键修改处用删除线与替换镜头并排显示；每步左上角出小字步骤名（剧本 / 分镜 / 拍摄 / 剪辑 / 调色混音），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍剧本 / 侧面 45° 拍片场 / 剪辑台特写三机位轮换；剧本用全景，剪辑用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放影片剧照 / 海报，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡画面；不要把过程剪成跳切，保留制作的连续性；不要虚构导演本人的生活场景。

## (4) 过程示例（以代表作逻辑为例，不声称复刻原过程）

- 剧本：剧本与机关设计：定一个魔术效果与一场奇观，画出布景机关与变身点，故事只为效果服务。
- 分镜：布景与分镜：彩绘布景按舞台布景绘制，机位固定正面，标出每次停机换物的位置。
- 拍摄：拍摄：固定机位一次拍成，停机换景、换装、换人，演员按默剧幅度正面表演。
- 剪辑：剪辑：按场次拼接，叠化连接奇观段落，变身点不切，靠停机再拍本身完成。
