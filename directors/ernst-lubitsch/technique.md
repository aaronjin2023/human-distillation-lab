# Ernst Lubitsch — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 刘别谦式点睛（Lubitsch touch）：一个眼神、一次门开合即点出全部言外之意，笑料在省略处。`impression`
- 门与楼梯的空间语法：门即情节转折，楼梯即社交等级，空间本身会讲笑话。`impression`
- 省略剪辑：门关上即省略，观众自补门后的事，剪辑的留白就是笑点。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
