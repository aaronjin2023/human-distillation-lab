# Terrence Malick — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 魔幻时刻拍摄：只在日出日落前后拍外景，光线即场面。`impression`
- 耳语画外音：多声部低语与画面并行，哲学问题不给答案。`impression`
- 联想剪辑：自然空镜插入叙事，时间靠光影而非对白推进。`impression`
- 广角自然摄影：以广角写草原与天空，人物在自然中渺小。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
