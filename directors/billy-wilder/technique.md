# Billy Wilder — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 倒叙结构：影片以结局开场，再倒叙回因果，宿命感来自结构而非剪辑。`verbatim`
- 对白即武器：台词锋利如刀，妙语之后即剪辑点，笑声与寒意同生。`impression`
- 百叶窗阴影：光影即道德，百叶窗一出现，欺骗即开始。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
