# Alfonso Cuarón — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 长镜头调度：以一次拍成的运动承载整场戏，剪辑点藏在遮挡与转身之后。`impression`
- 自然光摄影：优先实景自然光与窗光，人工光只作补光，拒绝棚拍感。`impression`
- 声音设计：环境音先于音乐，街头声、脚步声与远处广播构成空间。`impression`
- 多层场面调度：前景、中景、背景同时有动作，观众自行选择看点。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
