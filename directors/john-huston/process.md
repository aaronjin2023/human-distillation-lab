# John Huston — 影片制作过程规格 process.md（给视频模型复刻过程）

> 只按影片的制作逻辑写，不编造导演本人的生活场景；有分镜手稿 / 拍摄记录 / 访谈可考者以公开资料为准，无资料者按影片结构反推，不声称复刻原过程。

## (1) 制作步骤顺序表（5 步）

| 步骤 | 做什么 | 成片状态 |
|---|---|---|
| 1 剧本 | 剧本：定虚假偶像与追逐者，故事按追逐—分裂—成空三段写，实景地点一次定清。 | 约 10–20% 完成，结构可见、正片未定 |
| 2 分镜 / 排练 | 分镜：画实景机位表，河流与山地一次定清，特写只留给贪婪。 | 约 20–30%，镜头已定、画面未拍 |
| 3 拍摄 | 拍摄：实景跋涉实拍，演员表演寡言，冒险段落按空间逻辑多机位。 | 约 40–50%，素材初现、粗糙 |
| 4 剪辑 | 剪辑：冷静拼接，对白推进阴谋，结尾宝藏成空处放慢。 | 约 60–70%，骨架已定、细节未满 |
| 5 调色 / 混音 / 定剪 | 定剪：冷调统一，配乐克制，成空收束。 | 100%，完成态 |

## (2) 每一阶段的成片状态变化（过程视频的节奏）

- 第 1 步结束：只有剧本与结构，观者看到故事骨架与人物关系。
- 第 2 步结束：镜头与调度已定，观者看到机位图与走位，但无画面。
- 第 3 步结束：有画面无节奏，观者看到场景成形、表演初现。
- 第 4 步结束：结构与节奏落点，观者看到影片骨架已定。
- 第 5 步结束：色彩与声音统一，观者看到完成态。
- 节奏建议：剧本慢（看清结构）、分镜中速（看镜头生长）、拍摄中速（看场景成形）、剪辑放慢（看节奏落点）、调色 / 混音停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。时间分配：剧本 20%、分镜 15%、拍摄 40%、剪辑 15%、定剪 10%。

## (3) 过程呈现的镜头与字幕建议

- 呈现：剧本页 / 分镜稿 / 拍摄现场 / 剪辑时间线逐段出现，关键修改处用删除线与替换镜头并排显示；每步左上角出小字步骤名（剧本 / 分镜 / 拍摄 / 剪辑 / 调色混音），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍剧本 / 侧面 45° 拍片场 / 剪辑台特写三机位轮换；剧本用全景，剪辑用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放影片剧照 / 海报，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡画面；不要把过程剪成跳切，保留制作的连续性；不要虚构导演本人的生活场景。
