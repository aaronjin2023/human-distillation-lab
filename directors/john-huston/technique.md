# John Huston — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 实景冒险：河流、山地、街头实拍，空间即考验，拒绝摄影棚假景。`verbatim`
- 硬汉对白：台词寡言，信息在潜台词里，对白剪辑推进阴谋。`impression`
- 宝藏叙事：虚假偶像驱动全片，追逐越久，幻影越真，结局越空。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
