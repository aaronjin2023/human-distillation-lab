# Carl Theodor Dreyer — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 面部特写系统：《圣女贞德受难记》以特写为全部语言，背景抹去，面孔即世界。`verbatim`
- 长镜头凝视：镜头久久停在面孔上，表情的微变即剧情，剪辑让位于凝视。`impression`
- 白光布光：高调白光抹去环境细节，人物从白光中浮现，灵性来自光的纯净。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
