# Céline Sciamma — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 凝视特写摄影：特写给女性的脸与目光，注视即爱。`impression`
- 目光调度：女性在画框内相视，目光的交换即叙事。`impression`
- 火光摄影：篝火与烛光写目光的温度，暖黄对照海蓝。`impression`
- 时间折叠剪辑：少女与女人、记忆与当下在剪辑中折叠。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
