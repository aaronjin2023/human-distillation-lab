# Céline Sciamma — 影片制作过程规格 process.md（给视频模型）

> 只按影片的制作逻辑写，不编造导演本人的生活场景；无分镜手稿 / 拍摄记录可考者按影片结构反推，不声称复刻原过程。

## (1) 制作步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 拍什么、拍哪里 | 成片状态 | 最容易拍错 |
|---|---|---|---|---|---|
| 1 剧本 | 剧本定回望骨架：记忆、注视、回望收束 | 剧本 / 大纲 / 即兴提纲 | 只定骨架：人物、冲突、场景、开头与结尾 | 约 10–20%，结构可见、正片未定 | 一开始就写细节，结构没了 |
| 2 分镜 / 排练 | 定镜头、定调度、定节奏 | 分镜脚本 / 故事板 / 排练 | 只定镜头与走位：机位图、景别表、演员走位 | 约 20–30%，镜头已定、画面未拍 | 分镜一松，调度就泄气 |
| 3 拍摄 | 实景柔光拍摄：凝视特写，缓慢横移 | 按导演拍摄习惯 | 全片贯通拍，不回头改剧本 | 约 40–50%，素材初现、粗糙 | 凝视一短爱情就散，火光一冷目光就丢 |
| 4 剪辑 | 目光与火光连接段落，时间折叠 | 剪辑台 / 数字剪辑 | 只改结构与节奏，不改拍摄素材 | 约 60–70%，骨架已定、细节未满 | 一剪快就断气，节奏断了 |
| 5 调色 / 混音 / 定剪 | 火光暖黄调色统一，海浪与音乐混音 | 调色 / 混音 / 字幕 | 全片薄薄统一，不改结构 | 100%，完成态 | 调色抢了风格，或混音盖了环境声 |

## (2) 每一阶段的成片状态变化（5 个检查点）

1. 第 1 步结束：只有剧本与结构，正片未定。
2. 第 2 步结束：镜头与走位已定，画面未拍。
3. 第 3 步结束：素材初现、粗糙，节奏未定。
4. 第 4 步结束：骨架已定，节奏落点已现，细节未满。
5. 第 5 步结束：完成态，色彩与声音统一。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：剧本 20%、分镜 10%、拍摄 35%、剪辑 20%、调色混音 15%。
- 节奏提示：剧本慢、分镜中速、拍摄中速、剪辑放慢、调色 / 混音停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：剧本页 / 分镜稿 / 拍摄现场 / 剪辑时间线逐段出现，关键修改处用删除线与替换镜头并排显示；每步左上角出小字步骤名（剧本 / 分镜 / 拍摄 / 剪辑 / 调色混音），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍剧本 / 侧面 45° 拍片场 / 剪辑台特写三机位轮换；剧本用全景，剪辑用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放影片剧照 / 海报，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡画面；不要把过程剪成跳切，保留制作的连续性；不要虚构导演本人的生活场景。

## (4) 过程示例（以本导演拍现代题材的逻辑为例，不声称复刻原过程）

- 剧本：定一个场景（一只坐在地铁里的约克夏犬）、定结构与核心母题。
- 分镜：按该导演的镜头语言画好机位、景别与人物走位。
- 拍摄：按分镜一次拍成，保留该导演的运镜与光影习惯。
- 剪辑：按该导演的剪辑节奏调整段落，删去禁区清单里的写法。
- 调色 / 混音：按该导演的色彩与声音习惯统一全片，定名。
