# Kathryn Bigelow — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 手持沉浸摄影：摄影机贴近身体，观众与人物同处危险。`impression`
- 多机位动作剪辑：同一动作多角度覆盖，剪辑加速即心跳加速。`impression`
- 身体特写：手、汗、引线的特写写压力，身体即叙事。`impression`
- 静默张力：动作前拉长静默，声音只留呼吸与环境声。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
