# D. W. Griffith — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 交叉剪辑：平行线索交替剪接，制造悬念与最后一分钟营救的加速感，奠定古典叙事语法。`impression`
- 特写的道德功能：特写不是装饰，而是让观众看清人物的道德选择与情感，丽莲·吉许的面部表演是载体。`impression`
- 光圈与遮片：光圈开合聚焦人物，遮片框定视线，淡色调区分时间与情绪。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
