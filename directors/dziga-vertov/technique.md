# Dziga Vertov — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 电影眼睛（Kino-Eye）：摄影机比人眼看得更真，捕捉人眼看不见的运动，理论见其公开文论。`artifact`
- 分屏与叠印：多重视点并置，同一时间多地并存，剪辑即并置的发现。`verbatim`
- 快慢并置：快动作、慢动作、定格、倒放并用，时间本身成为剪辑材料。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
