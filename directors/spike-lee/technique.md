# Spike Lee — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 滑轨镜头：人物静止、背景滑行，漂浮感即梦境与质问。`impression`
- 直视镜头：人物打破第四面墙，直接向观众发问。`verbatim`
- 历史影像插入：档案影像与当代叙事并置，历史撞进当下。`impression`
- 爵士乐剪辑：音乐切点即剪辑点，节奏即愤怒的速度。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
