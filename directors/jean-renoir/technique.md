# Jean Renoir — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 漫游的摄影机：摄影机跟随人物自由移动，不打断生活，长镜头即生活本身。`impression`
- 深焦群戏：前景、中景、背景同时有戏，观众自己选择看哪里。`verbatim`
- “人人都有道理”：对白不站队，每个人物皆有道理，冲突来自道理的并置。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
