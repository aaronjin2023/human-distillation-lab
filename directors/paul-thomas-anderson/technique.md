# Paul Thomas Anderson — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 跟踪长镜头：一镜承载群像的进出与权力转移。`impression`
- 群像调度：多人物在同一空间交错，观众自行选择看点。`impression`
- 音乐收束：段落以音乐顶点收束，音乐是情绪的支点。`impression`
- 特写对峙：父子与师徒的特写对切，沉默即冲突。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
