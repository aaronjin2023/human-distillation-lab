## 一句话

- **这是谁：** 德国 / 美国·情节剧，代表作《天堂所允许的一切》、《春风秋雨》、《深锁春光一院愁》。
- **什么时候用他：** 需要按此人的风格拍其他题材的影片（短片、场景、镜头序列）时，用这个 skill。
- **风格一句话：** 塞克风格：浓艳情节剧，镜子与窗户，Technicolor 的过度，郊区即鎏金牢笼，色彩中的情感，光泽下的反讽。
- **过程一句话：** 五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪，按本导演特点调整。

## 蒸馏范围（只限成果物）

- 材料：影片本身（《天堂所允许的一切》、《春风秋雨》、《深锁春光一院愁》为主）+ 导演本人关于影片的公开文字、分镜手稿、拍摄记录 + 权威影史分析。`artifact`
- 不写：私生活、心理诊断、传记轶事、电视剧（只作对照，不作蒸馏源）。
- 证据分级：`verbatim`（影片本身直接可见）/ `artifact`（公开文字、文献、修复说明）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 翻译口径：蒸馏以影片为准；片名以通行中文译名为准，异译记入 `conflicts.md`；外文引文只作参照，不标 `verbatim`。
