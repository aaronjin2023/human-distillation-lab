# Douglas Sirk — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 镜子与窗户的空间语法：镜中分裂、窗后被困，空间本身就是牢笼。`verbatim`
- Technicolor 过度：色彩越浓艳，情感越压抑，牢笼越真实。`impression`
- 情节剧的反讽：光泽表面下是批判，幸福越完整，反讽越深。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
