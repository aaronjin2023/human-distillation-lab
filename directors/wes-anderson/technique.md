# Wes Anderson — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 对称构图：正面平视、中心对称，画框即微缩景观。`impression`
- 急摇与横移：场景切换用急摇，段落内用横移展开布景。`impression`
- 粉彩美术：布景与服装按色卡精确搭配，色彩即情感。`impression`
- 章节与画外音：标题卡分章，画外音讲童话，画面是插图。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
