# Martin Scorsese — 技法与制作工序 technique.md（Procedure，只限影片）

> v0.1（2026-10-26）。

- 跟踪长镜头：摄影机贴身跟拍人物行走，一镜承载整场戏的欲望与权力转移。`impression`
- 音乐剪辑：摇滚乐切点即剪辑点，音乐不到顶点画面不切。`impression`
- 画外音自白：第一人称独白与画面并行，时间靠独白压缩。`impression`
- 定格与跳切：关键时刻定格，暴力场面跳切，节奏由音乐与情绪驱动。`impression`
- 制作流程：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音，已记入 process.md。`impression`
- 合作方式：与摄影、剪辑、配乐的合作以影片本身的署名与公开制作记录为准，不推测私人关系。`artifact`
