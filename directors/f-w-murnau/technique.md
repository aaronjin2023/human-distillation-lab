# F. W. Murnau — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 解放的摄影机：摄影机装在升降与移动装置上，可穿越窗户、升上屋顶、跟随人物，是早期运动镜头的代表。`impression`
- 主观镜头：镜头即角色的眼睛，吸血鬼视角与醉汉视角直接呈现，不靠字幕解释。`verbatim`
- 无字幕叙事：《最后的笑容》仅用一张字幕卡，故事全靠镜头与表演完成。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
