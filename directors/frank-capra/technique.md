# Frank Capra — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 疯狂喜剧对白：快速对切与重叠台词，节奏如乒乓，笑料来自语速与误解。`verbatim`
- 演讲调度：小人物站在人群中央演讲，群众反应镜头与演讲者特写交替，信念靠剪辑传递。`impression`
- 社群温暖布光：暖调柔光拍家庭与小镇，硬光只留给体制的冷漠。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
