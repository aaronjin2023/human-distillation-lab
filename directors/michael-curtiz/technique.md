# Michael Curtiz — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 流畅运镜：摄影机跟随人物自然运动，推拉摇移不露痕迹，是制片厂工匠的代表。`impression`
- 雾与阴影的空间分隔：烟雾区分里克酒吧的内外，阴影标示人物的过去与现在。`verbatim`
- 类型跨越：同一套流畅语法用于爱情、冒险、黑帮、歌舞，类型只是外衣。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
