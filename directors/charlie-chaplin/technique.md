# Charlie Chaplin — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 肢体哑剧：笑料全靠身体完成——八字步、拐杖旋转、面包舞，动作本身就是台词。`verbatim`
- 固定机位长镜头：笑料不切碎，一个镜头拍完一整串动作，节奏由演员的停顿控制。`verbatim`
- 悲情与滑稽并置：盲女段落与流水线段落同片并存，笑中带泪是其标志配方。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
