# Alfred Hitchcock — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 精确分镜：每一镜头事先画成分镜，拍摄即执行分镜，是作者控制的代表。`impression`
- 主观镜头：摄影机即观众的眼睛，观众与窥视者共享视角，悬念来自共享。`verbatim`
- 变焦推拉（dolly zoom）：镜头推近同时变焦拉远，眩晕感来自空间的扭曲。`verbatim`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
