# Hayao Miyazaki — 影片制作过程规格 process.md（给视频模型复刻过程）

> 只按影片的制作逻辑写，不编造导演本人的生活场景；有分镜手稿 / 拍摄记录 / 访谈可考者以公开资料为准，无资料者按影片结构反推，不声称复刻原过程。体裁：手绘动画。

## (1) 制作步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 拍什么、拍哪里 | 成片状态 | 最容易拍错 |
|---|---|---|---|---|---|
| 1 剧本 | 定女孩、定异世界、定冒险章节 | 剧本 + 设定图 | 只定骨架：人物、世界、开头与结尾 | 约 10–20%，结构可见、正片未定 | 世界观一写死就僵 |
| 2 分镜 | 定镜头、定飞行段落、定风景构图 | 分镜手稿（宫崎骏亲绘） | 只定镜头与走位：飞行线、风景层次 | 约 20–30%，镜头已定、画面未画 | 分镜一松就散，飞行没了 |
| 3 原画 | 逐帧手绘人物动作 | 原画 + 动画，逐帧手绘 | 全片贯通画，不回头改分镜 | 约 40–50%，动作初现、粗糙 | 笔触一僵就散，呼吸感没了 |
| 4 背景 / 摄影 | 水彩背景 + 赛璐珞摄影合成 | 水彩背景 + 摄影台 | 只合成为画面，不改原画 | 约 60–70%，画面已定、细节未满 | 背景一平就散，风景没了 |
| 5 配音 / 配乐 | 配音与久石让音乐混音 | 配音 / 配乐，音乐优先 | 全片薄薄统一，不改结构 | 100%，完成态 | 音乐一弱就散，情感没了 |

## (2) 每一阶段的成片状态变化（5 个检查点）

1. 第 1 步结束：只有剧本与设定图，世界未定。
2. 第 2 步结束：分镜手稿已定，飞行线与风景构图在场，画面未画。
3. 第 3 步结束：原画初现，动作的呼吸感在场，背景未定。
4. 第 4 步结束：背景与摄影合成完成，画面已定，细节未满。
5. 第 5 步结束：完成态，音乐统一、手绘接管一切。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：剧本 10%、分镜 20%、原画 40%、背景摄影 20%、配音配乐 10%。
- 节奏提示：原画步占 40%（看逐帧手绘成形）、背景摄影中速（看风景落位）、配音配乐停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：剧本页 / 分镜稿 / 拍摄现场 / 剪辑时间线逐段出现，关键修改处用删除线与替换镜头并排显示；每步左上角出小字步骤名（剧本 / 分镜 / 原画 / 背景摄影 / 配音配乐），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍剧本 / 侧面 45° 拍片场 / 剪辑台特写三机位轮换；剧本用全景，剪辑用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放影片剧照 / 海报，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡画面；不要把过程剪成跳切，保留制作的连续性；不要虚构导演本人的生活场景。

## (4) 过程示例（以本导演拍现代题材的逻辑为例，不声称复刻原过程）

- 剧本：定一只地铁里的约克夏犬、一个异世界般的车厢、一段飞行。
- 分镜：手绘分镜，犬在座位上，窗外云在动。
- 原画：逐帧手绘犬的动作，呼吸感来自笔触。
- 背景 / 摄影：水彩背景，云海与阳光合成。
- 配音 / 配乐：轻柔音乐，风声为主，结尾开放。
