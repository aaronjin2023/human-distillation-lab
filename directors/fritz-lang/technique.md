# Fritz Lang — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 建筑式构图：画面按建筑图纸组织，对称、纵深、几何线条先行，人物后置。`verbatim`
- 声音追踪：口哨声作为凶手的听觉标记，声画剪辑先于画面追踪，是早期声音设计的代表。`impression`
- 群众调度：群众如机器零件般排列与移动，个人在其中被追捕，调度即社会隐喻。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
