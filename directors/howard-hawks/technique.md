# Howard Hawks — 技法与制作工序（procedure）（technique.md，四维之一，只限影片）

> v0.1（2026-10-26）。只从影片里找证据；`verbatim` = 影片本身直接可见；`artifact` = 公开文字 / 文献；`impression` = 他人印象（学界通说）。

## 技法要点

- 重叠对白：人物同时说话，句与句重叠，节奏即职业效率，剪辑保持对白的密度。`verbatim`
- 深焦群戏：前景、中景、背景同时有动作，观众一眼看到群体的分工。`verbatim`
- 类型跨越：同一套职业群体语法用于西部、黑帮、黑色电影、喜剧，类型只是外衣。`impression`

## 工序

五步：剧本 → 分镜 / 排练 → 拍摄 → 剪辑 → 调色 / 混音 / 定剪。
