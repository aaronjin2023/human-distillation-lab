# Diderot — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 多部作品身后出版：《拉摩的侄儿》1805 年德译本首刊、1823 年法文版；《宿命论者雅克》1796 年出版；《达朗贝尔的梦》1830 年出版。身后出版的文本编辑与版本有校勘问题，引用须注明。`artifact`
2. 《百科全书》的集体性质：条目为多位作者合著，狄德罗为主编与主要撰稿人；蒸馏时只取其本人撰写或主编的条目方向，不将其全部条目归于一人。`artifact`
3. 其唯物主义的彻底性：早期自然神论与晚期唯物主义的转变是否彻底，学界有讨论。`impression`
4. 《拉摩的侄儿》的对话者立场：侄儿与“我”谁代表狄德罗，学界有讨论；蒸馏时按对话本身处理，不指认代言人。`impression`
