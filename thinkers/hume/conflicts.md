# Hume — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 缺失的蓝色：休谟本人承认此为例外，是否动摇“一切观念源于印象”的原则，学界有讨论。`artifact`
2. 《人性论》与重述本的关系：作者晚年称《人性论》为少年之作，以重述本为准；但《人性论》第一卷的怀疑论更为彻底，两本关系有讨论。`artifact`
3. “理性是激情的奴隶”：此说在道德哲学中的含义（理性不能单独产生动机）与通俗误读（理性无用）有别，蒸馏时按文本原意处理。`artifact`
4. 宗教立场：其宗教批判的立场（自然神论、怀疑论、无神论）学界有不同解读；《宗教对话录》的对话者立场尤有争议。`impression`
