# Edmund Husserl — 概念语言 language.md（Interaction，只限著作与思想体系）

> 只写思想怎么跟读者说话：核心概念的定义方式、术语系统、隐喻与意象、句式节奏、修辞习惯、与读者 / 对手的对话姿态。不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 术语多为自造的德语复合概念，译名需统一：epoché 译“悬置”，Lebenswelt 译“生活世界”，noesis / noema 译“意向活动 / 意向对象”。`artifact`
- “回到事情本身”是方法口号而非结论。`artifact`
- 描述语言力求无隐喻：侧显、充实、空虚等词均有技术含义。`impression`

## 修辞习惯总述

术语密集、句式极长、层层限定；定义先行，区分成对概念；少用比喻，爱用“回到……本身”的程式；语气是严格科学的自我要求。
