# Machiavelli — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 《君主论》与《论李维》的张力：前者为君主献策，后者赞美共和；学界有“两部作品是否矛盾”的长期争论，本稿按“情境分流”处理，不强行统一。`impression`
2. “马基雅维利主义”标签：后世多将其等同于“为达目的不择手段”，但其本人明确反对无谓的残酷与失信（《君主论》第 18 章的守信论述有条件限制）。`artifact`
3. 《君主论》写作意图：是献给美第奇的求职之作，还是讽刺君主制的隐微写作，学界有争议；蒸馏只用文本本身，不采纳任一意图说。`impression`
4. 切萨雷·博尔贾事例：马基雅维利将其奉为 virtù 典范，但博尔贾最终失势；其本人以 fortuna 解释，是否自洽，学界有讨论。`artifact`
