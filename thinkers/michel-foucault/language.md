# Michel Foucault — 概念语言 language.md（Interaction，只限著作与思想体系）

> 只写思想怎么跟读者说话：核心概念的定义方式、术语系统、隐喻与意象、句式节奏、修辞习惯、与读者 / 对手的对话姿态。不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 自造术语密集：知识型、话语、规训、生命政治、治理术，均有技术含义。`artifact`
- 开篇场景法：公开处决、全景监狱，都是论证的入口。`artifact`
- 反讽与反转句式是论证节奏。`impression`
- 讲稿体：法兰西学院讲座身后刊行，口语痕迹保留。`impression`

## 修辞习惯总述

历史叙述与概念发明并用；长句、括号、反讽；爱用“不是……而是……”的反转；开篇常以惊人场景（公开处决、圆形监狱）切入。
