# Hildegard von Bingen — 概念语言 language.md（Interaction，只限著作与思想体系）

> v0.1（2026-10-26）。只写思想怎么跟读者说话，不写私生活，不写“文笔优美”之类的空泛评价。

- 语言为拉丁语，兼及中古高地德语；术语以异象与自然词汇为主。`artifact`
- 句式多为异象叙述长句，歌唱性强。`artifact`
- 修辞：图像（光、绿、宇宙人）密集，譬喻为论证本身。`artifact`

## 概念系统

- 核心概念：异象（Vision）, 生命之绿（Viriditas）, 宇宙人（Cosmic Human）, 德性 / 恶习, 自然 / 医学, 光。`artifact`
- 术语须用该思想家自己的词；现代译名标注“今译”。
- 与读者 / 对手的对话姿态：见 style.md 第 (3) 节与 technique.md。
