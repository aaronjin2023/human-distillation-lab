# Christine de Pizan — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 卒年 c.1430 为约数：最后确证的作品为《圣女贞德的故事》（1429），1430 年后无音讯，卒年无确证。`artifact`
2. “女性主义先驱”称号是 20 世纪回溯性命名：其本人时代无“女性主义”概念；学界对其能否称为女性主义仍有分歧（见 World History Encyclopedia 讨论）。`impression`
3. 《妇女之城宝库》的性质：是《妇女之城》的续篇实践指南，还是独立作品，版本与编排有出入，蒸馏时以《妇女之城》为主。`artifact`
4. 其作品的“第一位职业女性作家”之说：指靠写作谋生的女性，属学界通说，但中世纪女性写作的边界（如修女、宫廷女性）存在不同界定。`impression`
