# Wang Yangming — 概念语言 language.md（Interaction，只限著作与思想体系）

> v0.1（2026-10-26）。只写思想怎么跟读者说话，不写私生活，不写“文笔优美”之类的空泛评价。

- 术语以心、良知、意、知、行为主，少用理气形而上学词汇；“心即理”一语即全篇纲领。`artifact`
- 句式短促有力，多格言断言（“知行合一”“致良知”），反问密集，第一人称直呼弟子。`artifact`
- 修辞：多用日常事例（孝亲、事君、读书）作比，少用宇宙论隐喻。`artifact`

## 概念系统

- 核心概念：心即理, 良知, 知行合一, 致良知, 格物（正其不正以归于正）, 意之动 / 意之发, 诚意。`artifact`
- 术语须用该思想家自己的词；现代译名标注“今译”。
- 与读者 / 对手的对话姿态：见 style.md 第 (3) 节与 technique.md。
