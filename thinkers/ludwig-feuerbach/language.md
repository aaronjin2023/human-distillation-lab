# Ludwig Feuerbach — 概念语言 language.md（Interaction，只限著作与思想体系）

> 只写思想怎么跟读者说话：核心概念的定义方式、术语系统、隐喻与意象、句式节奏、修辞习惯、与读者 / 对手的对话姿态。不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 术语多为颠倒后的日常词：爱、理性、意志本是人的谓词，被投射为神的属性。`artifact`
- “神学的秘密是人类学”——全书最核心的格言，可直接引用。`artifact`（通行译文；译文引文一律标 artifact）
- “我–你”对话取代独白式思辨：真辩证法是“我与你之间的对话”。`artifact`（《未来哲学原理》引文转述）
- 句式爱用对偶与反转，节奏如布道但内容反布道。`impression`

## 修辞习惯总述

格言式断言密集，爱用对偶与颠倒句式；句式中等偏短，结论常以警句收束；直接称呼读者，语气有布道式的热忱但对象是人而非神。
