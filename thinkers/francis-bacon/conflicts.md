# Francis Bacon — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. “知识就是力量”（scientia potentia est）的出处：常被归于培根，但拉丁原文与准确译法有讨论；其本人《学术的进展》中的表述为“知识与人的力量相遇”，今译格言为后世浓缩。蒸馏时注明此点。`artifact`
2. “形式”（forma）概念的形而上学含义：培根的形式论与亚里士多德的形式有承继亦有断裂，学界对其是否彻底摆脱经院形而上学有讨论。`impression`
3. 《新大西岛》未完成：科学共同体（所罗门宫）的细节为想象性描述，蒸馏时只取其制度想象，不作其科学方法论的组成部分。`artifact`
4. 培根与近代科学的关系：其归纳法对实验科学有启发，但其本人并非实验家；“培根是近代科学之父”的说法是后世简化。`impression`
