# Montesquieu — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 气候决定论：其气候解释法律的论述被后世批评为决定论；但其本人以“倾向”限定，且强调多因素，是否构成决定论，学界有讨论。`impression`
2. 英国政体的例证：其分权论以英国为主要例证，但对英国宪制的描述是否准确，学界有讨论（英国实为议会主权，非严格三权分立）。`artifact`
3. 奴隶制的论述：《论法的精神》第十五卷对奴隶制的论述有讽刺与认真的双重解读，学界有争议；蒸馏时注明此点。`artifact`
4. 政体三分类的周延性：共和、君主、专制是否穷尽一切政体，学界有讨论。`impression`
