# Martin Heidegger — 概念语言 language.md（Interaction，只限著作与思想体系）

> 只写思想怎么跟读者说话：核心概念的定义方式、术语系统、隐喻与意象、句式节奏、修辞习惯、与读者 / 对手的对话姿态。不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 术语多为自造：Dasein 译“此在”，Sorge 译“烦 / 操心”，das Man 译“常人”。`artifact`
- 词源追问是论证方法：追问希腊词源以恢复被遮蔽的存在经验。`impression`
- 后期语言诗化：荷尔德林引文进入论证，不是装饰。`impression`
- 句式迂回，破折号与连字符构成概念节奏。`impression`

## 修辞习惯总述

术语密集、自造复合词、词源追问；句式极长、迂回、层层限定；爱用破折号与连字符；后期多引荷尔德林等诗人，语气近于沉思而非论战。
