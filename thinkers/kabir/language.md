# Kabir — 概念语言 language.md（Interaction，只限著作与思想体系）

> v0.1（2026-10-26）。只写思想怎么跟读者说话，不写私生活，不写“文笔优美”之类的空泛评价。

- 语言为印地语口语体，混用印度教与伊斯兰词汇（罗摩、安拉并用）；汉语译名须标注今译。`artifact`
- 句式短促、歌唱性强，多反问与格言。`artifact`
- 修辞：譬喻（织布、水与器）密集，反讽尖锐。`artifact`

## 概念系统

- 核心概念：罗摩（内在之神）, 无形 / 无属性之神（Nirguna）, 虔信（Bhakti）, 上师（Guru）, 名号（Nam）, 破偶像 / 破仪式, 织布喻。`artifact`
- 术语须用该思想家自己的词；现代译名标注“今译”。
- 与读者 / 对手的对话姿态：见 style.md 第 (3) 节与 technique.md。
