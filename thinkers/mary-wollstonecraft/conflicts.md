# Mary Wollstonecraft — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 男女是否完全平等：其文本有模糊表述——一面主张理性平等，一面未明确宣称男女在一切方面完全平等；学界对其能否称为现代女性主义有讨论（见 Wikipedia 相关讨论）。`artifact`
2. 《女权辩护》第二卷未完成：作者本拟写更周密的第二卷，死前未完成；蒸馏只取已出版的第一卷。`artifact`
3. 其生平与声誉：戈德温《回忆录》（1798）披露其私生活，导致其声誉受损近一世纪；蒸馏只取著作，不取私生活，声誉史记此。`impression`
4. 《玛丽》的性质：小说与政论的边界，学界有讨论；蒸馏以《女权辩护》为主，《玛丽》为辅。`artifact`

- 《人类权利辩护》与伯克论战的细节未逐项核对
