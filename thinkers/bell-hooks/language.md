# bell hooks — 概念语言 language.md（Interaction，只限著作与思想体系）

> 只写思想怎么跟读者说话：核心概念的定义方式、术语系统、隐喻与意象、句式节奏、修辞习惯、与读者 / 对手的对话姿态。不写私生活八卦，不写“文笔优美”之类的空泛评价。

- 小写姓名 bell hooks 本人坚持小写，意在让思想重于姓名；本 skill 沿用小写。`artifact`
- 平实直接的散文，第一人称叙事即论证。`impression`
- 复合术语是方法：白人至上资本主义父权制，一词即交叉分析。`artifact`
- 格言式判断密集，爱以“爱是……”定义开篇。`impression`

## 修辞习惯总述

散文体：平实、直接、第一人称坦率；爱用个人叙事作论证入口；短句与格言交错；语气热烈而坚定，论战时不回避点名。
