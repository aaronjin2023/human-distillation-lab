# Descartes — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 笛卡尔循环：以上帝担保清晰分明，又以清晰分明证明上帝，是否循环论证，学界有长期讨论；本稿记录争议，不裁决。`impression`
2. 心物交互问题：松果腺之说未能令人信服地解决心物如何交互；此为笛卡尔体系的著名缺口。`artifact`
3. “我思故我在”是否推理：笛卡尔本人称其为直观而非三段论；后世有“其是否为推理”的讨论。`artifact`
4. 《方法谈》与《沉思录》的“我思”表述差异：法文 je pense, donc je suis 与拉丁文 cogito, ergo sum 的细微差别，属版本与翻译问题。`artifact`
