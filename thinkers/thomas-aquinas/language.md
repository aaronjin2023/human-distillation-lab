# Thomas Aquinas — 概念语言 language.md（Interaction，只限著作与思想体系）

> v0.1（2026-10-26）。只写思想怎么跟读者说话，不写私生活，不写“文笔优美”之类的空泛评价。

- 语言为拉丁语，逻辑严密、术语系统极精。`artifact`
- 句式多为经院长句，区分—推演—回应三段式。`artifact`
- 修辞：以引文（亚里士多德、奥古斯丁、圣经）服人，少用譬喻。`artifact`

## 概念系统

- 核心概念：存在（Esse）, 本质与存在, 五路（Five Ways）, 自然法, 德性（智德 / 义德 / 神德）, 类比（Analogia）, 信仰与理性。`artifact`
- 术语须用该思想家自己的词；现代译名标注“今译”。
- 与读者 / 对手的对话姿态：见 style.md 第 (3) 节与 technique.md。
