# Locke — conflicts.md

> 说法不一致 / 著作归属存疑 / 时期矛盾，保留，不统一。证据分级见草稿第 6.2 节。

1. 《政府论》的写作年代：传统认为两篇皆为光荣革命后（1689）所作，拉斯莱特（Laslett）考证第二篇写于 1679–1680 年排斥危机期间；写作年代影响对其意图的解读，学界有讨论。`artifact`
2. 宽容的边界：《论宽容》排除无神论者与天主教徒（当时语境），此边界与现代宽容观念有张力；蒸馏时如实记录，不现代化。`artifact`
3. 财产权与奴隶制：洛克本人参与卡罗来纳殖民与奴隶贸易，其财产论与奴隶制的张力为后世批判焦点；蒸馏只取其文本主张，批判记此。`impression`
4. “留有足够同样好的” proviso：货币发明后积累是否仍受此限，洛克文本有模糊处，学界有讨论。`artifact`
