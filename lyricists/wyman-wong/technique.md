# Wyman Wong — 技法与填词工序 technique.md（四维之 procedure）

> 只限歌词成果物，不写私生活。证据分级：`verbatim` / `artifact` / `impression`。

- 技法：先曲后词，按九声试唱；以俚语双关与自嘲推进，副歌一句反讽点题。 `impression`
- 押韵方式与字数对位：押韵：粤语九声与旋律咬合，押韵锋利，换韵处即笑点或转折；句长不齐，长短交错。 `impression`
- 标题取法：标题多取自歌中关键意象或副歌关键句。`impression`
- 修改痕迹：有手稿 / 采访可考者以手稿与采访为准；无手稿者按歌词结构反推，不声称复刻原过程。`artifact`
