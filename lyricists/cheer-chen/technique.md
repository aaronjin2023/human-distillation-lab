# Cheer Chen — 技法与填词工序 technique.md（四维之 procedure）

> 只限歌词成果物，不写私生活。证据分级：`verbatim` / `artifact` / `impression`。

- 技法：词曲双全；以旅行意象与自语推进，副歌一句领悟点题；标题常取自核心行为（旅行、吉他手）。 `impression`
- 押韵方式与字数对位：押韵：押韵宽松，近韵与自由体并用；句长不齐，长短交错；词曲双全，先词后曲者多。 `impression`
- 标题取法：标题多取自歌中关键意象或副歌关键句。`impression`
- 修改痕迹：有手稿 / 采访可考者以手稿与采访为准；无手稿者按歌词结构反推，不声称复刻原过程。`artifact`
