# Jonathan Lee — 技法与填词工序 technique.md（四维之 procedure）

> 只限歌词成果物，不写私生活。证据分级：`verbatim` / `artifact` / `impression`。

- 技法：词曲双全；以口语长句与自问自答推进，副歌一句点题；标题常取自核心隐喻（山丘、小小鸟）。 `impression`
- 押韵方式与字数对位：押韵：押韵宽松，近韵与自由体并用，副歌收紧；句长不齐，长句如说话，短句如叹息；换气口自然。 `impression`
- 标题取法：标题多取自歌中关键意象或副歌关键句。`impression`
- 修改痕迹：有手稿 / 采访可考者以手稿与采访为准；无手稿者按歌词结构反推，不声称复刻原过程。`artifact`
