# James Wong — 技法与填词工序 technique.md（四维之 procedure）

> 只限歌词成果物，不写私生活。证据分级：`verbatim` / `artifact` / `impression`。

- 技法：先曲后词，按粤语九声逐字试唱，字音与旋律贴合；副歌一句豪迈点题；标题常取自核心地标或意象。 `impression`
- 押韵方式与字数对位：押韵：粤语九声与旋律咬合，句尾押韵豪迈，换韵处即情绪转折；句长不齐，长短交错，换气口分明。 `impression`
- 标题取法：标题多取自歌中关键意象或副歌关键句。`impression`
- 修改痕迹：有手稿 / 采访可考者以手稿与采访为准；无手稿者按歌词结构反推，不声称复刻原过程。`artifact`
