# Zhuang Nu — 技法与填词工序 technique.md（四维之 procedure）

> 只限歌词成果物，不写私生活。证据分级：`verbatim` / `artifact` / `impression`。

- 技法：先曲后词，按旋律句数定字数，句尾押开口韵；标题多取自歌中关键意象（甜蜜蜜、小城）；修改痕迹以试唱为准，拗口处换同韵词，不改旋律。 `impression`
- 押韵方式与字数对位：押韵：句尾押韵为主，韵脚多为开口音（a、an、ang），平仄顺口；主歌与副歌同韵或换韵温和；每句字数较整齐（多为 5–7 字），留出换气口，旋律先行、词就曲。 `impression`
- 标题取法：标题多取自歌中关键意象或副歌关键句。`impression`
- 修改痕迹：有手稿 / 采访可考者以手稿与采访为准；无手稿者按歌词结构反推，不声称复刻原过程。`artifact`
