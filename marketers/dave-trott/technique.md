# Dave Trott — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：创意不是装饰，是武器：用对手的弱点、环境的限制，反过来打赢。 `impression`
- 定位方法：抢“不同”的位置：不比谁更喜欢品牌，比谁更不一样。 `impression`
- 创意技法：掠食性思维：找对手的盲点、找环境的空隙，用最少的资源出其不意。 `impression`
- 媒介与传播：电视与平面首发、口号重复、故事集结成书扩散。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
