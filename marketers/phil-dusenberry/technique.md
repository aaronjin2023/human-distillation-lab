# Phil Dusenberry — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：把渴望变成画面：人人都想成为的那个人，就是品牌最好的代言。 `impression`
- 定位方法：抢“成为他”的位置：不是卖饮料，是卖成为偶像的渴望。 `impression`
- 创意技法：偶像投射：用一个名字、一句歌，把全民的渴望浓缩成一句口号。 `impression`
- 媒介与传播：电视首发、体育场景、歌曲跟进；竞选广告则用清晨意象做国家叙事。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
