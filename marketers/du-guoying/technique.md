# Du Guoying — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：一个品类一个品牌：把一个单品做到极致，品牌就是品类代名词。 `impression`
- 定位方法：抢“品类代名词”的位置：小罐茶就是小罐茶，不解释。 `impression`
- 创意技法：单品爆破：一个产品、一个卖点、一个渠道，打透再换下一个。 `impression`
- 媒介与传播：电视与电商首发、单品集中爆破、口碑跟进。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
