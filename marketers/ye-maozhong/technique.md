# Ye Maozhong — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：中国消费者的心智要用中国话抢：一句大白话，比十句洋文案管用。 `impression`
- 定位方法：抢“一句话心智”的位置：把品牌说成一句人人会说的大白话。 `impression`
- 创意技法：大白话定位：找一个使用场景、一句口头禅，重复到成为常识。 `impression`
- 媒介与传播：电视与户外集中爆破、口号重复、渠道跟进。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
