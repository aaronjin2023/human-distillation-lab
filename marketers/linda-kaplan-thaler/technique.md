# Linda Kaplan Thaler — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：洞察藏在声音里：一声鸭叫比一页说明书更能让人记住保险。 `impression`
- 定位方法：抢“声音符号”的位置：用一个声音、一个角色抢占记忆。 `impression`
- 创意技法：声音与角色符号：把抽象产品变成一个会叫、会动的角色。 `impression`
- 媒介与传播：电视首发、角色系列化、声音符号跨媒介复用。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
