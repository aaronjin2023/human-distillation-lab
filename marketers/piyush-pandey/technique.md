# Piyush Pandey — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：印度广告要用印度话讲：方言、幽默、家庭情感，就是印度的心智。 `impression`
- 定位方法：抢“印度心”的位置：不是翻译西方广告，是讲印度自己的故事。 `impression`
- 创意技法：本土幽默：把产品放进印度家庭、印度街头、印度节日里。 `impression`
- 媒介与传播：电视首发、节日借势、系列化家庭场景。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
