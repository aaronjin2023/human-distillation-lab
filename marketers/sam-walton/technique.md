# Sam Walton — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：顾客要的不是一次便宜，而是每天都便宜、可信的价格。 `impression`
- 定位方法：抢“每天最低价”的位置：不是促销冠军，而是价格可信度第一。 `impression`
- 创意技法：价格即广告：把省下的成本变成每天的低价，让低价本身说话。 `impression`
- 媒介与传播：乡村小镇首发、门店即媒体；口碑与复购扩散，不靠华丽广告。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
