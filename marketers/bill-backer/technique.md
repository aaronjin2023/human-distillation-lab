# Bill Backer — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：一首歌比一千句广告词走得更远：旋律让人记住，歌词让人传唱。 `impression`
- 定位方法：抢“世界大合唱”的位置：可口可乐不是一瓶饮料，是全世界一起唱歌的理由。 `impression`
- 创意技法：音乐即概念：把品牌主张写成一首能唱的歌，让旋律完成传播。 `impression`
- 媒介与传播：电视首发、歌曲打榜、合唱场景扩散；歌比广告活得久。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
