# Deng Delong — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：定位要落到一句话、一个场景：怕上火，就喝王老吉。 `impression`
- 定位方法：抢“怕上火”的位置：把凉茶从药饮变成佐餐饮料。 `impression`
- 创意技法：定位即一句话：找对手的弱点、找消费者的场景，锁死一句。 `impression`
- 媒介与传播：定位咨询首发、广告重复定位句、渠道跟进。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
