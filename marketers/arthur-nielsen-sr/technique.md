# Arthur Nielsen Sr. — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：没有可信的数字，广告买卖就是讨价还价；先把“多少人看了”变成公认货币。 `impression`
- 定位方法：抢“行业通用货币”的位置：收视率不是一家之言，是买卖双方都认的尺子。 `impression`
- 创意技法：测量即产品：抽样、仪器、面板三件套，把观看行为变成可交易的数字。 `impression`
- 媒介与传播：面板与仪器首发、定期报告；媒体与广告主共同采信后扩散。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
