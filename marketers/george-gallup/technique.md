# George Gallup — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：问对人、问对问题，少数样本就能说出多数人的意见；民意可以被科学地听见。 `impression`
- 定位方法：抢“民意代言人”的位置：用科学抽样代替凭感觉猜民意。 `impression`
- 创意技法：抽样即创意：小样本、大代表性，问题设计决定答案质量。 `impression`
- 媒介与传播：报纸专栏首发民调结果、定期发布；准确预测扩散其公信力。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
