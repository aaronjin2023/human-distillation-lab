# Lester Wunderman — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：广告不必猜效果：每一封信、每一次回应都可计数，顾客会用回邮告诉你真相。 `impression`
- 定位方法：抢“可衡量的回应”的位置：广告不是艺术展览，是能算账的对话。 `impression`
- 创意技法：对话式创意：把邮箱当媒介，把回应机制（回邮卡、免费电话、订阅卡）做进创意本身。 `impression`
- 媒介与传播：直邮首发、杂志插卡、电话跟进；回应数据回流再优化下一轮。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
