# Hua Shan — 技法与营销工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。

- 洞察方法：品牌不用解释，要一眼认出来：超级符号就是不用思考的购买理由。 `impression`
- 定位方法：抢“超级符号”的位置：符号即战略，认出即购买。 `impression`
- 创意技法：符号即创意：找一个文化原型、一个超级符号，让品牌自带流量。 `impression`
- 媒介与传播：符号设计首发、包装与门店落地、广告重复符号。 `impression`
- 测试与复盘：把回应、销售与品牌追踪当作创意的一部分，用数据改下一轮，而非凭感觉拍板。`impression`
- 执行层次：Brief 定问题 → 洞察立一句 → 创意定概念 → 执行出物料 → 投放看数据 → 复盘沉淀方法，六层不可跳步。`impression`
- 修改痕迹：概念测试与修改证据以公开案例复盘为准，无公开复盘者不虚构修改过程。`artifact`
