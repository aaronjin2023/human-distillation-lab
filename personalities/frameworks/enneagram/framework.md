# 九型人格

本条采用Enneagram Institute的Riso-Hudson传统概括九类注意焦点：一型原则改进，二型关系帮助，三型成就目标，四型身份独特，五型知识边界，六型安全预备，七型选择可能，八型自主保护，九型和谐接纳。传统中另有三中心、翼型、连线和发展层次，但不同作者解释各异，不能将其中一套说成通用标准。
使用时明确流派，由本人阅读各型正反描述并反思长期动机；若使用RHETI等问卷，注明版本并由本人完成；请本人举出不合之处并保留不确定性。观察者不能凭职业、文风或一次冲突定型。
结合专家能力（设计推演）：本人确认的动机可用于访谈其决策理由，但知识规则必须由公开作品和可核行为支持。类型不能解释全部选择。
自检情景（设计推演）：专家经常纠错且表达谨慎，没有自述动机。预期记录纠错行为和情境，不判一型或六型，动机标为未知。
局限：九型在咨询、灵性与组织实践中有多种版本，类型描述并非实证定论。作者对RHETI识别能力的说法不视作独立验证。
实践界限：九型叙述容易让人觉得多个类型都“说中自己”，因此不能用描述的熟悉感当作验证。需区分本人当前的自我解释、理论传统的概念和外部可观察行为。动机涉及内在体验，未经本人陈述不可从一个行为反推。遇到流派冲突时保留来源分歧，不拼成统一体系。
