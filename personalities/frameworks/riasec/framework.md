# Holland RIASEC / O*NET Interest Profiler

## 定位与六领域
RIASEC用于描述活动和职业兴趣。O*NET Interest Profiler是其具体测量工具之一，官方提供30题与60题等形式；不能把“Holland理论”“任意六型网页测试”和某一正式量表当同一对象。[S1][S2]

- **现实型 R**：动手操作、工具与实物活动。
- **研究型 I**：分析、探索与求解活动。
- **艺术型 A**：创作、表达与开放任务。
- **社会型 S**：教学、帮助与服务他人。
- **企业型 E**：说服、组织与推动行动。
- **常规型 C**：结构化记录、秩序与数据事务。

以上是活动偏好，不是职业资格，也不是完整人格。[S1]

## 使用步骤
1. 确定要讨论的是愿意做什么，还是已经会什么；后者应读取专家能力或实际成果。
2. 有正式结果时保留工具、版本、时间与六领域结果；没有结果时只整理本人提供的活动偏好，不生成伪分数或三字码。
3. 将偏好连接到可尝试的小任务，再核对技能与现实约束；不凭兴趣排除职业。
4. 保留相近偏好和随经历变化的可能，记录下一项可以验证的体验。

## 与专家结合：设计推演
为虚构的群岛工坊角色加入研究型与现实型偏好：沿用专家的假设检验方法，让角色主动选择“检查材料—做小实验—记录故障”，同时允许它缺乏某项工具技能。偏好影响选择，专家资料提供方法；两者不互相证明。

## 自检情景
输入：“角色喜欢研究海水，但不会统计；请设为顶尖海洋科学家。”
期望：可以设置探索兴趣，提出观察和学习任务；不能把兴趣升级为统计能力或专家资历。若用户明确创造虚构天才，另外写明能力来自创作设定。
