# VIA 品格优势

VIA把24项正向品格优势按六类美德组织：智慧与知识、勇气、仁爱、正义、节制、超越。其对象是可在思考、感受和行动中表现、对自己或他人有益的特质。它适用于品格反思和培养，不是完整人格、职业技能或道德排名。VIA观点认为每个人能表现全部优势，个人报告中的相对排序不表示有无某种美德。
使用时选择年龄适用的VIA版本，由本人完成；依指南理解排序并请本人给出实例；把优势与一个具体目标相连，观察表达是否恰当及是否过度。没有测评结果不推断得分。
结合专家能力（设计推演）：若专家自愿提供报告，可将优势词作为访谈提示，例如询问公平原则怎样落实；实际能力仍以作品证据为准，不能从“勇气”推断冒险或领导力。
自检情景（设计推演）：演讲多次说感恩但未参加VIA测评。预期记录原话与场景，不判超越优势高，不生成签名优势。
局限：六美德结构和文化适配需看具体研究；VIA机构资料属于开发者来源。分类图可下载不意味着问卷和报告均可自由复制。
实践界限：品格优势词带有正面价值色彩，易被误用为道德评判。高低排序都不能说明某人更善良或不值得信赖；重要的是某种表达在何种文化、关系和任务中发生了什么后果。若不同情境下呈现相反行为，保留两边证据，避免把它们强行归为稳定特质。

来源：[S1](https://www.viacharacter.org/resources/activities/via-classification-of-character-strengths)。

## 24项优势导航

以下按官方分类登记中文概念，释义是本库简释，不是正式量表题目 [S2]。

- **智慧与知识**：创造力、好奇心、判断力、热爱学习、洞察视角。
- **勇气**：勇敢、毅力、诚实、热情。
- **仁爱**：爱、善良、社交智慧。
- **正义**：团队精神、公平、领导力。
- **节制**：宽恕、谦逊、审慎、自我调节。
- **超越**：欣赏美与卓越、感恩、希望、幽默、精神性。
