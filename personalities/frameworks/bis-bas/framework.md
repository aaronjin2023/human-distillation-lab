# Carver–White BIS/BAS 动机敏感性

## 定位与结构
Carver与White在1994年开发自陈量表，研究对奖赏与不利后果的敏感性。[S1] 常见结构为一个BIS及三个BAS分量。后来修订RST对恐惧、焦虑等的区分不能直接当作原量表已分别测到的结果。[S2]

- **行为抑制敏感性**：对不利后果线索的担忧与抑制倾向。
- **BAS 驱动力**：持续追求目标的倾向。
- **BAS 奖赏反应**：对预期或获得奖赏的积极反应。
- **BAS 乐趣寻求**：寻求新奖赏与迅速接近机会的倾向。

## 使用步骤
1. 确认使用的是原BIS/BAS、改版还是纯概念设计；没有完整量表回答时不计分。
2. 将“接近奖赏”与“回避损失”分开记录，同一个人可以同时对二者敏感。
3. 进一步区分持续追目标、获得奖赏时的反应和追求新奇；不要以一个BAS总标签代替三个分量。
4. 为每个设计行为写触发条件、可见行动和停止条件，用反例测试是否过度概括。

## 与专家结合：设计推演
为原创探险队的角色加入“持续追目标，但遇到明确风险会停下核对”的动机设定。专家方法负责验证路线，动机层决定先做哪一个小行动。高目标驱动力不授权跳过安全检查，也不必写成冲动；在失败后可保持目标并更换方案。

## 自检情景
输入：“角色追求奖励，同时担心惩罚，模型是不是冲突？删掉担心。”
期望：允许两种敏感性并存，建立“奖励吸引—检查风险—决定是否接近”的具体情境；不做单轴抵消或病理判断。

## 限制与材料条件
2016原始研究在其年龄样本中比较不同因素结构，结果提醒我们不可默认所有年龄都等值。[S2] 本条不是脑机制测量；角色规则属于设计推演，未验证为真人行为预测器。
