# Sixteen Personality Factor Questionnaire（16PF）

## 范围

16PF 是 Cattell 因素传统下的标准化人格测验。本条限定第五版，包含16个一级尺度与五个全局因素；其他版次须另行核对。16PF既不是16种人格类型，也不是MBTI的替代或转换表。

## 维度与含义

- **温暖 A**（`warmth`）：人际亲和与情感表达。
- **推理 B**（`reasoning`）：认知推理表现相关尺度，不能等同智商诊断。
- **情绪稳定 C**（`emotional_stability`）：情绪应对的相对稳定倾向。
- **支配 E**（`dominance`）：表达主张、影响互动的倾向。
- **活泼 F**（`liveliness`）：自发、活跃的表达。
- **规则意识 G**（`rule_consciousness`）：对规则与责任的重视。
- **社交大胆 H**（`social_boldness`）：陌生或群体场景中的社交胆量。
- **敏感 I**（`sensitivity`）：情感敏锐与柔和取向。
- **警觉 L**（`vigilance`）：对他人动机保持戒心的程度。
- **抽象性 M**（`abstractedness`）：偏向抽象想象或具体务实。
- **私密性 N**（`privateness`）：表达保留与策略性。
- **忧虑 O**（`apprehension`）：自我怀疑和担忧倾向。
- **开放改变 Q1**（`openness_change`）：对新方法与变革的接受。
- **自立 Q2**（`self_reliance`）：独立行动与群体依赖偏好。
- **完美主义 Q3**（`perfectionism`）：秩序、计划与自我要求。
- **紧张 Q4**（`tension`）：紧迫感与内在紧张。

## 实际使用步骤

1. 在解释前锁定 16PF 版次、国家/语言适配和常模；第五版和第六版材料不混用。
2. 由合资格的授权施测与计分流程获取16个一级尺度及其五个全局因子，不凭自制表或公开文字推分。
3. 解读保留连续尺度与配置，结合受测情境、有效性信息和报告说明。16个一级维度是尺度，不是16种互斥人格类型。
4. 不将16PF因子标签替换为MBTI类型；若作比较，须有特定研究证据。

## 与专家能力结合：设计推演

用于专家方法设计时，可以将相关一级尺度转为工作场景问题，例如 Q3计划性与Q4紧张度分别询问，并观察其如何影响交付与复核。不得把单个尺度直接映射成职位适配或能力，需结合实际任务样本。

## 自检情景

**输入：** 使用者拿到一段访谈文字，要求把专家分配到“16种16PF人格类型”，并换算为MBTI。

**期望行为：** 纠正两点：16PF提供连续尺度及组合因子，不是16型；没有规范施测和相应研究时不能从文字给分或转为MBTI。

## 版本与方法限制

本条的资料限定第五版；不同国家常模、语言适配和其他版次须另行核查。全局因子由初级尺度组合而来，不可脱离报告直接给人贴标签。
本条为公开来源改写的框架草稿，不是经验证的中文版量表，不执行施测。不同理论/工具的维度不强行映射；绝不将MBTI与此处维度互换。
