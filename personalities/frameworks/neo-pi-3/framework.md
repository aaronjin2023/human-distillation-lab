# NEO Personality Inventory–3（NEO-PI-3）

## 范围

NEO-PI-3 是商业化的五因素测量工具，标准长版含240题、五域与30个面向；PAR 的产品页面现提供2024年规范样本更新版，计分和报告通过其系统完成。其细面向结构与常见五因素表述相关，但不是所有大五问卷的替代名称。

## 维度与含义

- **神经质**（`neuroticism`）：焦虑、敌意、抑郁、自我意识、冲动与脆弱等六面向。
- **外向性**（`extraversion`）：温暖、合群、主张、活动、寻求刺激、积极情绪。
- **开放性**（`openness`）：幻想、审美、情感、行动、思想、价值。
- **宜人性**（`agreeableness`）：信任、坦率、利他、顺从、谦逊、温情。
- **尽责性**（`conscientiousness`）：能力感、秩序、尽责、成就追求、自律、审慎。

## 实际使用步骤

1. 确认 NEO-PI-3 的具体版次、语言、自陈/观察者表、适用年龄及规范样本；新版常模不得与旧版分数直接混用。
2. 按授权程序完成240题施测和发行方计分；先看五域，再结合对应的30个面向解释。
3. 解释必须使用 NEO 自身面向命名与手册，不能把其30面向映射成 BFI-2 的15面向；关联不等同。
4. 报告规范样本、版本及不确定性，不自行复算商业题本。

## 与专家能力结合：设计推演

该量表的面向结构可提示专家工作方式的具体访谈主题，例如审慎、秩序与自律是不同假设；应以授权测量报告或多场景可观察证据支持。专业知识、产出质量和岗位胜任仍需直接证据，不能由人格报告代替。

## 自检情景

**输入：** 一份 NEO-PI-3 旧版报告有30面向，用户要求转成 BFI-2 的15面向名称并套用新版常模。

**期望行为：** 拒绝机械一对一转换；标记工具与常模版次，分别解释各自结构，若要比较需引用合适的等值/关联研究而非自制换算。

## 版本与方法限制

发行方公布的数据属于产品技术资料，不能代替独立复核；新版规范、语言版与旧版需区分。题目版本/常模不能混用，具体施测与解释应依授权手册及资质要求。
