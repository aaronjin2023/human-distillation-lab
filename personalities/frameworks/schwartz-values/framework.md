# Schwartz 基本人类价值观

## 定位与版本
此框架讨论目标的重要性及其相对优先级。十价值模型用环状关系表示动机的相容与张力，SVS、PVQ是相关测量路径。[S1] 本条采用十价值；另有十九价值的细化版本，不把两种粒度混用。[S3]

- **自主**：重视独立思考与选择。
- **刺激**：重视新奇与挑战。
- **享乐**：重视愉悦体验。
- **成就**：重视符合社会标准的成功。
- **权力**：重视地位与资源控制。
- **安全**：重视个人与共同生活的稳定。
- **遵从**：约束可能破坏交往规范的行为。
- **传统**：重视传承习俗与观念。
- **仁爱**：重视亲近群体成员的福祉。
- **普遍关怀**：重视更广泛的人与自然。

## 使用步骤
1. 从实际选择或用户明确设定中提取“为哪个目标愿意牺牲什么”；每个取舍记录来源和情境。
2. 对同一决定列出受益与受损的价值，保留冲突。不能把同时重视安全和探索判为矛盾人格。
3. 区分表态、已观察的决定与编写者推演；没有可比较证据时不编造价值排序。
4. 正式测量须注明具体SVS/PVQ版本。这里的中文释义不作为正式题本。

## 与专家结合：设计推演
使用建筑专家的空间设计方法，另为虚构城市议会设定“普遍关怀与安全优先”。讨论防洪工程时，要求给出居民迁移负担、公共成本与受益分布，再比较方案。若改为“成就优先”，可以改变目标权重，但不能改写水文事实。价值层决定取舍，能力层检验办法。

## 自检情景
输入：“角色平时爱冒险，灾时主张保守方案，删掉其中一条使其一致。”
期望：保留两个情境，说明危机改变了目标优先级；询问或记录触发条件，不自动删证据，也不把“保守”当MBTI J。

## 限制与材料条件
本条说明的是个体价值框架，不能以国家平均值给个人赋值；设计规则是本库推演，并非量表验证过的行为预测。S3当前机构条目标为2014收录，关联DOI是2012研究，本文不把收录年份当新理论版本。
S1标注文章CC BY-NC-ND 3.0；不将这一许可泛化到所有SVS/PVQ题本或译本。本库仅作简要原创概念说明和设计推演，不提供文章译本、量表或评分键。
