# DiSC

D倾向直接推进结果与挑战，i倾向互动表达和动员，S倾向稳定节奏与支持，C倾向分析、准确和标准。Everything DiSC将风格视作混合连续组合，并可呈现相邻风格与优先事项。名称DISC虽广泛使用，但各供应商的问卷、轴线、图形和常模未必相同；Wiley页面将其定位为团队沟通工具，而非任职筛选。
使用时先登记供应商和产品版本，由本人完成或自愿分享报告；确认具体情境下的描述是否合适，再转成可协商沟通约定，例如先给结论、预留核查时间、提前说明变化。
结合专家能力（设计推演）：专家本人确认偏C时，可先展示来源与核查路径；偏i时可用互动案例，偏D时先讲决策点，偏S时说明变更影响。不可将沟通偏好等同能力或绩效。
自检情景（设计推演）：同事公开发言活跃且常索要数据来源，但无结果。预期只记录两个行为和场景，不输出i/C分数；标明无法跨供应商推断。
局限：不同版本和商业工具不可视为一个正式量表。Wiley的产品研究说明是供应方材料。不可用于招录筛选或推断岗位胜任力。
实践界限：风格描述是沟通假设，不可写成固定性格定论。记录时保留原始报告名称、施测时间和本人认可范围；过期结果或情境改变后，先询问是否仍适用。若报告与真实工作观察不同，分别保存自陈与观察，等待更多场景，而不是平均成单一标签。
