# ECR-R 成人亲密关系依恋维度

读取 [框架说明](framework.md) 获取维度、来源和具体自检情景；使用量表前查看 [元数据与材料条件](manifest.json)。

限定为关系领域，保留两个连续维度和关系对象。没有正式回答时不输出测评分数。不要从延迟回复、职业或一段聊天诊断某人为回避型人格；不能自动硬分四类。

输出时分开列出：有来源的框架概念、输入材料中的观察、设计推演与未知事项。研究原文、开发者说明与本库推演不相互替代。

与旧专家条目组合时，专家资料只贡献原本的专业方法；不把新角色设定归到专家本人。沿用 [本区说明](../../README.md) 的证据与范围约定。
