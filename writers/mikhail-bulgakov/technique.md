# Mikhail Bulgakov — 技法与写作工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。

- 体裁：长篇小说（《大师与玛格丽特》未完成，生前未发表）、中篇（《狗心》《致命的鸡蛋》）、戏剧（《白卫军》改编的《图尔宾一家的日子》）；本 skill 以《大师与玛格丽特》为准。`impression`
- 双线并行：莫斯科线（魔鬼到访）与耶路撒冷线（彼拉多）交替，两线的对应即全书的结构。
- 平实写幻想：越是荒诞（猫会说话、人会飞），句子越平实；平实本身就是幻想的凭证。
- 讽刺技法：以幻想审判现实，魔鬼的闹剧揭露莫斯科的虚伪；讽刺藏在闹剧之后。
- 未完成与焚稿：《大师与玛格丽特》多次重写，布尔加科夫曾焚毁初稿；‘手稿烧不掉’既是小说中的句子，也是成书史的写照。`artifact`
