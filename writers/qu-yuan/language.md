# Qu Yuan — 语言与读者关系 language.md（Interaction，只限作品）

- “兮”是节奏的骨架：每句一顿，咏叹由此生；删去“兮”，骚体即散。`impression`
- 香草即语言：兰蕙芷蘅不是装饰，是品格的编码；恶草（萧、艾）一出，对照即成。`impression`
- 第一人称“我”的强度：全篇以“我”统摄神话与现实，抒情主体不让位给叙事。`impression`
- 留白在问句里：《天问》的答案不在文中，在读者的追问里。`impression`（学界通说）
- 对话：诗中无人称对话；以自述、呼告与《天问》连珠问答推进抒情。`impression`
- “朝搴阰之木兰兮，夕揽洲之宿莽”——《离骚》以朝夕对举写采芳，时间词即抒情节奏。`verbatim`
- 楚地方言虚词：兮、些、只、羌，虚词的密度即楚辞的声口。`impression`
- 美人喻君的距离：以美人喻君，爱慕与怨怼同体，距离近而不得近。`impression`
