# James Baldwin — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 版本矛盾，保留，不统一。

1. 《向苍天呼吁》中文译名另有《去告诉它，在山上》；本文件夹用草稿译名，异译存此。
2. 《乔瓦尼的房间》出版年份 1956 年无争议；《向苍天呼吁》有 1952 年（摩根州立大学百年纪念页）与 1953 年（通说）两说，本文件夹以 1953 年为准。
3. 鲍德温的散文与小说孰为本体有争议：本人自认首先是小说家，但学界常以散文家论之；本文件夹小说与散文并重，不裁决。
4. 未完成的《记住这所房子》手稿后被改编为纪录片《我不是你的黑鬼》，改编本不作为蒸馏源。
