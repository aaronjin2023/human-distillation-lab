# Homer — 技法与写作工序 technique.md（Procedure，只限作品）

- 体裁：口头史诗，六音步；《伊利亚特》与《奥德赛》各二十四卷，是口头传统成文后的定本。`artifact`（密歇根大学荷马展览：约前 8 世纪下半叶口头创作、笔录成文）
- 程式化技法：套语（epithet）、程式化场景（宴饮、献祭、武装、航行）、目录（船名录）——皆为口头吟诵的记忆工具，也是风格本体。`impression` / `artifact`（帕里—洛德口头程式理论，学界共识）
- 明喻：长明喻（extended simile）是核心修辞，一个比喻可铺展十余行，把战场比作收割、风暴、狮群。`impression`
- 结构：半路切入 + 插叙 + 环形收束；神界议事与人间战争交替剪辑。`impression`
- 套语的示范：玫瑰色手指的黎明（程式化 epithet 的通行译法）一出，时间与场景同时被唤醒。`artifact`（程式化套语的通行译法）
- 神的议事：奥林匹斯的争吵与人间战争互为镜像，神界一开场，人间即有回响。`impression`
- 插叙的补史：半路切入后以插叙补前史，过去不是背景，是现在的一部分。`impression`
