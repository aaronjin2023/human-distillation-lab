# Haruki Murakami — 语言与读者关系 language.md（Interaction，只限作品）

- 语气即语言：平静的语调讲离奇的事，平静本身就是风格。`impression`
- 日常即语言：做饭、听唱片、煮意面等日常细节写得极细，超现实就藏在日常里。`impression`
- 音乐即语言：爵士乐名、曲名反复出现，节奏感来自音乐而非情节。`impression`
- 留白即语言：问题不解答，失踪的人不回来，读者自己承担未解之谜。`impression`
- 距离：叙述者与读者并肩而坐，像朋友讲一件怪事，不居高临下。`impression`（评论共识）
- 对话：对话简短、留白多，常岔开话题，信息在岔开处泄露；人物常答非所问，谜面留在对话里。`impression`
- 比喻的平实：比喻多取自日常物与音乐，不炫技，比喻一出，异世界即近。`impression`
