# Wisława Szymborska — 技法与写作工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。

- 体裁：抒情短诗为主，诗集《呼唤雪人》《盐》《巨大的数目》《桥上的历史》；本 skill 以短诗为准。`impression`
- 问句技法：一首诗即一个问题（‘为什么……？’），问题比答案重要；问句本身就是结构。
- 注视技法：对一个日常之物（石头、土豆）长时间注视，注视到它变得陌生；陌生即诗。
- 反讽收束：结尾常以一个反讽的转折收束，收束处就是诗眼。
- 数字技法：‘巨大的数目’——以数字的精确写历史的荒诞，数字越精确，荒诞越清晰。
