# Leo Tolstoy — 语言与读者关系 language.md（Interaction，只限作品）

- 思想即语言：人物的思想不是独白，是叙述的一部分；思想在句中生长、转折、自我反驳。
- 日常即语言：餐桌、舞会、收割——日常的细节即是意义的所在。
- 家庭即语言：一家即是世界，家庭的命运即是历史的命运。
- 怀疑即语言：没有不怀疑的英雄，怀疑越深，人物越真。
- 对话：客厅谈话即是历史的转折；人物在对话中暴露思想，对话多为长段辩论而非短促问答。`impression`
- 长句的呼吸：长句层层嵌套从句，思想在句中完成一次完整的转折才收束。`impression`
- 法语词的点缀：贵族人物言谈中夹杂法语，语言即阶层。`impression`
