# 世界观资料库

本区将现实思想与信念、虚构世界设定分别蒸馏，供人物设计、世界构建和多角度讨论使用。[浏览目录](CATALOG.md) · [加载入口](SKILL.md) · [机器目录](catalog.json) · [数量与引用校验](verification/build.json)。

本批共 **100 条：现实类 50 条、虚构类 50 条**。600 项维度记录中，293 项为来源概括、258 项为本库解读、49 项明确材料不足；共保留 116 条来源记录、114 个不同来源网址。这些数字表示资料覆盖，不是解释正确率或模拟能力评分。

## 收录口径

- **现实类**：哲学、宗教、认识论、伦理、政治与生态等思想视角。有些是较完整的信念体系，有些只回答特定问题；不能把它们视为互斥、同层级的完整世界观。分支、相近概念与内部争议保留在范围、张力和边界中。
- **虚构类**：文学、影视、动画及游戏中的世界设定。固定来源版本；同一宇宙的续篇或改编不因名称不同重复计数。作品中的制度或角色信念不等于作者赞同。
- 条目是资料选集，没有代表全世界思想、文化或所有热门作品，也不是按优劣排出的榜单。传统不等于族群；个人不必完整认同其文化或宗教中的所有观点。

## 每份资料包含什么

六个维度为：世界由什么构成、凭什么获得知识、主体能做什么、价值与取舍、秩序如何维持、变化如何发生。每个维度都区分三种状态：

| 标记 | 含义 |
|---|---|
| `source_summary` | 对已访问来源的概括；信念与虚构设定仍只在原语境内成立 |
| `synthesis` | 基于所列来源的本库解读，可讨论、修订，不冒充原典或官方设定 |
| `unknown` | 现有材料不足，不以通用模板补造规则 |

每条还有限定范围、来源位置、访问方式、内部张力、使用边界及一份明确标记的原创应用。`primary` 表示原典、作者或机构自述，不能据此宣称其经验事实已独立证实；`authoritative_secondary` 为权威二手解释。搜索摘要与打开正文分别记录，访问成功也不等于已读完整部作品。

`real.json` 与 `fictional.json` 是可追踪的正式输入；每条对应 `real/<slug>/` 或 `fictional/<slug>/` 下的 `SKILL.md` 和 `manifest.json`。目录中的别名用于发现，不用来自动合并概念。对已有人物库的关联使用精确作品 ID；不同版本仍须另行核对兼容性。

## 和人物、专家一起使用

1. 先选一个虚构世界规定物理、技术、制度与资源条件，再选一到两个现实思想视角解释角色如何理解它。
2. 从已有角色库选具体作品版本作为行为参考，再加入所需专家方法。世界规则、个人信念、专业方法和表达风格分别记录，使用[组合指南](../docs/composition-guide.md)。
3. 同时列出冲突：信念能否在这个世界成立？角色是否知道全部规则？新增规则会破坏哪些已有事件？无法兼容时保留分支版本，不强行拼成同一事实。
4. 用一个小场景检验行动与代价，标明来源条件、解释和原创部分。现实思想不能直接证明虚构技术，虚构世界也不验证现实的人类行为规律。

例如：在原创的封闭海上城市中设定有限淡水，以斯多葛视角描写一名维修员的可控行动，再用系统分析专家方法检查配给反馈。城市、人物、事件均是原创；只借用明确列出的框架，不宣称这是原作续写或对现实人口的预测。

## 维护与来源

在仓库根目录运行：

```sh
python3 scripts/build_worldviews.py self-test
python3 scripts/build_worldviews.py build
python3 scripts/build_worldviews.py validate
```

重建只读取随仓库提交的两个 JSON 文件，不自动抓网、不调用付费模型。结构校验验证引用、范围、生成文件和本地链接，不能证明所有解释正确或保证角色模拟效果。新增内容应先核读材料并记录具体支持位置。

保存原创概括及出处，不保存原作全文、剧本、题库或图片。链接材料和作品名称的权利仍归原权利人；收录不表示来源为公共领域，也没有将第三方内容重新授予许可。
