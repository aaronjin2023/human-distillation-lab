# 世界观加载入口

从 [目录](CATALOG.md) 或 [机器目录](catalog.json) 选择需要的条目，再读取相应 `SKILL.md`。中文名、别名或作品名称不确定时，查询 `real.json`、`fictional.json` 中的 `title` 和 `aliases`，核对 `scope`；不要一次加载整个资料库。

1. 明确用户需要的是世界客观规则、角色个人信念，还是对现实问题的分析视角。现实思想与虚构设定分开处理。
2. 固定条目 ID 和版本，按六维提取能改变行动的少量条件。每项判断保留来源 ID；区分来源概括、本库解读与未知。
3. 需要和专家、人格或文学角色组合时，按 [组合方法](README.md) 标注各层来源。专家不是世界规则的作者，人物也未必知道世界全部事实。
4. 输出条件、可选行动、代价、冲突和一个原创短场景；用户仅要求检索时直接返回相关条目，不强行创作。
5. 未知不能自动补成官方设定，改编冲突不能平均消除。用户要求原创补全时明确标记新增部分；不得假装掌握没有提供的全文、私人信仰或心理测量。

这是可讨论的资料集，不替代原典阅读、现实实证检验或正式专业意见。不要从民族、国籍、肤色或宗教标签推断某个真实个人的能力或全部信念。
