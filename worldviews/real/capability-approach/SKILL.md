# 能力进路

评价生活应看人实际能做什么、成为什么，而不只看资源或满意度。

类别：现实思想与信念 / 福利与正义评价视角 · ID：`real:capability-approach`

**范围**：限Sen、Nussbaum相关能力框架共同概念；不视为单一完整正义理论。

## 六个观察维度

- **世界由什么构成**（来源概括）：人有多样身体与社会条件，同样资源未必变成同样生活机会；资源、能力及已实现功能是不同评价对象。〔s1〕
- **凭什么获得知识**（来源概括）：评价需要了解资源如何在个人、社会和环境条件下转成实际机会；收入或主观满意度都可能遗漏重要剥夺。〔s1〕
- **主体能做什么**（来源概括）：能力关注人若选择便能实现的生活，而不只观察其当前做了什么；实质机会与本人能动性不可简单互换为强制达标。〔s1〕
- **价值与取舍**（来源概括）：实现福祉的自由具有重要道德地位；被剥夺者降低期待以适应困境，不表示低水平满意已足以证明处境正当。〔s1〕
- **秩序如何维持**（本库解读）：政策须考虑不同人的转换因素，形式上给同样资源可能仍不公平；具体能力清单、阈值和分配原则内部有争论。〔s1〕
- **变化如何发生**（本库解读）：改善应扩大真实可用的机会，而不是只增加名义权利；评估须辨认新增资源是否真正移除了限制。〔s1〕

## 张力与限制

- 选哪些能力及如何比较权重，没有唯一共同答案。
- 尊重选择与应对适应性偏好、严重剥夺之间有张力。

- 是可发展成多种理论的框架，不是Sen与Nussbaum全部观点一致。
- 不是公司人力技能模型，也不能拿强制统一生活方式替代能力自由。

## 原创应用

以下是本库设计的应用，非原典观点或官方续写。

1. 列出人实际想做却做不到的事情。
2. 找出资源到机会的转换障碍。
3. 优先移除障碍并保留选择权。

**场景**：虚构课程向所有学员发同样平板电脑，却要求线上考试。

**示例**：学校检查网络、辅助设备和照护时间，提供真正可用的参与条件，不把领到平板等同于平等学习机会。
