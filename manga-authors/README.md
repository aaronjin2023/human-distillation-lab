# 80位当代漫画家＋20位日系插画师 · 创作研究与绘画参谋

把公开作品、作者访谈和实际观察，整理成可供人或绘图助手使用的创作资料。作者是研究对象；输出时选择具体技法，服务于项目自己的角色、世界和故事。

[100人目录](CATALOG.md) · [加载入口](SKILL.md) · [从设定到漫画的流程](WORKFLOW.md) · [机器目录](catalog.json) · [校验回执](verification/build.json) · [内容复核](verification/review.md)

## 这次保存了什么

- **80位当代漫画家＋20位知名日系插画／同人画师**，按个人去重。5位连接已有漫画家条目，95位为本集合新增研究对象；这不是100位新加入全库的独立专家。abec与BUNBUN合并为一人，团体不占个人名额。
- 每人5个文件：`SKILL.md`记录范围、公开依据、分工、基本资料与来源；`drawing.md`给出8维绘画建议及落地检查；`prompts.md`提供插画、角色三视图、六格漫画3种模板；`manifest.json`保存同一资料的结构化版本；`task-contract.json`携带范围、必读文件、来源特征、步骤、检查点、替换项、冲突与未知。
- **300个提示词模板、600个语言版本**。角色三视图的英文版本保留中文技法规格，属于双语模板，不标成完整英语翻译。
- 线条、形体、构图、分镜、黑白、环境、表演、色彩共8个维度。每份方案带步骤、检查点和容易失败的做法。

本集合是资料与可加载的Skill，没有训练模型、安装100个全局插件或生成测试图片。旧专家文件继续保留，基本资料缺项不据姓名、国籍或作品题材推断。5位已有资料通过链接复用；本轮未核定的生卒与民族明确留空。

## 选材范围

以当代漫画创作为主，补入赤坂アカ、横槍メンゴ、裏那圭、外薗健、アベツカサ等较近作品的作者；插画部分包含米山舞、LAM、Mika Pikazo、望月けい、しぐれうい等。知名度为定性选材依据，没有虚构销量或热度排名。日系指视觉与创作语境，不要求或推断日本国籍。

优先2010年代后半至2020年代的原版卷、项目或方法访谈，也保留少量较早的代表性参考。`recent_focus`逐人说明所选作品、参考年、来源和日期含义；访谈发表年、画集出版年、封面原稿年、译版与再版年分开解释，不能把100张卡统称为100份2026最新画风。没有核定的年份留空。

初轮经典作者较多的研究已保存在[历史快照](archive/README.md)，不占当前精选100个名额。原专业目录保持原内容，仅为本轮仍入选的既有作者增加链接。

## 如何使用

向创作助手提供[入口](SKILL.md)，并说明题材、角色、情绪及输出形式，例如：

> 使用manga-authors，从目录选择适合“浮岛港口、成年修理工、温暖但有危险感”的三位研究对象。先比较他们的公开依据，再从线条、空间、人物表演各选一种通用方法，写成原创绘画方案。先做角色三视图，再安排六格漫画；保留世界设定和人物一致性。

也可直接选一位作者的研究卡。读取作品范围及任务契约后，选择“技法借鉴”或“指定作品阶段目标”。前者选兼容技法；后者逐项处理有来源的必要特征，不能以少数通用技法替代。姓名可标识目标，但不代表本人创作或背书。起稿提示不是完整执行单元。委托实际出图时，另外调用当前环境可用的图像工具或交给画师；本库本身不是绘图引擎。

## 证据如何读

| 标记 | 实际含义 | 不能推导的结论 |
|---|---|---|
| `search_excerpt` | 检索中实际出现的官方页面摘要或片段 | 已读全文、通读漫画、观察过内页 |
| `page_text` | 已打开网页正文 | 网页中未实际查看的图片细节 |
| `interview_text` | 已读公开访谈文字；区分作者、编辑、采访者 | 每句话均为作者本人说法、方法适用于整个生涯 |
| `visual_preview` | 已实际查看所指封面或合法预览 | 一张封面能证明整部漫画的分镜与全部画风 |
| `source_summary` / `visual_observation` | 有来源的事实摘要 / 限定画面的观察 | 本人背书、精确风格复刻已经验证 |
| `original_synthesis` | 本库据研究主题整理的原创应用建议 | 作者原话或经过实证的作者固定规则 |

`generation_mode=original-general-techniques`保留旧消费者的配方来源枚举，不代表本次执行模式；实际意图从`task_modes`选择。新增任务契约是已落地的可加载资料，专家意见服务仍未实现。

`method_evidence_source_ids`单独标出支持方法或视觉观察的依据；只证明出版署名的来源不计入该字段。具体覆盖率与访问方式以校验回执为准。每位的`known_gaps`说明未核范围；不能因文件齐全把这些缺口算作补齐。

任务契约保留研究范围和有来源的观察；识别项不自动等于已证风格。荒木先建立单封面契约样板，其余仅转交既有观察并标记待审；未批量验收100份风格。研究对象可以按作者筛选，目标模式决定保留项。按作者选择时，进一步区分作品阶段和具体视觉目标；不宣称本人创作、授权或担任顾问，也不承诺尚未验证的复现精度。保存的只有原创摘要、观察与来源链接，没有收录漫画扫描本、整章对白或训练图片集。

## 维护

`authors.json`是100份资料的唯一编辑源。修改后在仓库根目录执行：

```sh
python3 scripts/build_manga_authors.py --build
python3 scripts/build_manga_authors.py
python3 scripts/build_manga_authors.py --self-test
```

脚本同时核对80／20比例与研究阶段引用，并复用仓库的JSON写入、身份归一和本地链接检查，检查个人去重、署名引用、来源类型与支持声明、关键特征来源、8维完整性、任务契约完整性、核心方法变化传播、姓名允许正例、无来源反例、旧条目关联及生成文件一致性。结构校验不验证绘画效果，也不替代逐条来源审阅。后续实际出图应单独保存工具、模型、提示词版本、输入参考及评审结果，再决定哪些方案可进入项目常用资产。

本集合使用`manga-author-study`类型，独立于3684个历史专家分类条目的基本资料索引；未把同一作者重复登记成另一个自然人。
