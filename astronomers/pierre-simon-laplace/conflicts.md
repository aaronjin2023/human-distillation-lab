# Pierre-Simon Laplace — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **星云假说的地位**：拉普拉斯星云假说为当时假说，现代太阳系形成理论为其修正版（角动量问题等）；本文件夹标“当时假说 / 后世修正”，不作真理蒸馏。
2. **“不需要上帝”的引言**：拉普拉斯对拿破仑所言“我不需要那个假设”为后世转述，原文与语境有争议；本文件夹不以此为论证材料。
3. **稳定性证明的限度**：拉普拉斯的稳定性证明在后世严格数学意义上有局限（共振与混沌）；本文件夹按其历史贡献写，限度记此。
