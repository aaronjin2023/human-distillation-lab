# Riccardo Giacconi — 天文研究过程规格 process.md（给文本 / 视频模型）

> 只按研究的逻辑写，不编造天文学家本人的生活场景。不声称复刻某一项原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 工具 | 产出什么、做到什么程度 | 研究状态 | 最容易出错 |
|---|---|---|---|---|---|
| 观测 | 火箭与卫星 X 射线探测 | 探空火箭、乌呼鲁卫星 | X 射线计数原始数据 | 约 25% | 探测器本底太高；指向不准 |
| 数据 | 定位源并编表 | 计数分析、定位拟合 | X 射线源表 | 约 50% | 定位误差太大；假源混入 |
| 模型 | 推断源本质（吸积等） | 多波段证认、吸积模型 | 源本质候选模型 | 约 65% | 证认不全；模型先于成像 |
| 验证 | 成像与多波段复核 | 爱因斯坦天文台成像、光学证认 | 确认的源本质 | 约 88% | 只用一波段就定论；误差盒内多选一 |
| 发表 | 公布源表与证认结果 | 论文、源表 | 可复现的巡天文本 | 100% | 证认分级不写；源表不全 |

## (2) 每一阶段的研究状态变化（过程视频 / 长文本的节奏）

1. 观测结束：X 射线计数原始数据
2. 数据结束：X 射线源表
3. 模型结束：源本质候选模型
4. 验证结束：确认的源本质
5. 发表结束：可复现的巡天文本

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：观测30%、数据25%、模型20%、验证20%、发表5%。不要把 5 步平均分配时间，按天文学家特点分配。
- 节奏提示：观测慢（让观者看清仪器与目标）、数据中速（看数据生长）、验证放慢（看逐项排除）、发表停顿 2–3 秒（看完成态）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：望远镜 / 星图 / 数据图 / 论文逐行出现，关键修改处用删除线与替换值并排显示；每步左上角出小字步骤名（观测 / 数据 / 模型 / 验证 / 发表），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：X 射线源表特写 / 卫星全景 / 成像图局部放大三机位轮换三机位轮换；观测用全景，验证用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 项原发现小图对照（只放星图 / 数据图 / 论文页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡数据图；不要把过程剪成跳切，保留推理的连续性；不要虚构天文学家本人的生活场景；不要把已证伪的理论拍成“真理发现”。

## (4) 过程示例（以首个宇宙 X 射线源天蝎座 X-1 发现（1962 年）的逻辑为例，不声称复刻原过程）

观测：1962 年探空火箭 X 射线计数。数据：天蝎座 X-1 计数超出，定位。模型：致密天体吸积解释。验证：乌呼鲁巡天编表，爱因斯坦天文台成像证认。发表：X 射线源表论文，2002 年诺贝尔物理学奖。

- 节奏：观测30%、数据25%、模型20%、验证20%、发表5%。
