# Albert Einstein — 观测与推演技法 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 仪器与波段：思想实验与张量场方程；不依赖个人观测，以数学自洽与可检验预言为工具
- 观测方法：从等效原理出发写场方程，求静态宇宙解时引入宇宙学常数；再给出光线偏折、水星进动、引力红移三项可检验预言
- 模型建构：时空弯曲即引力；宇宙可由场方程描述；静态宇宙需宇宙学常数
- 证据处理：1919 年日食光线偏折、水星近日点进动符合预言；静态宇宙模型后被膨胀观测取代
- 误差与反例：反常数据保留并用于修正模型，不删除、不平滑掉。

## 方法要点

- 核心套路：观测 → 数据 → 模型 → 验证 → 发表。
- 工具与证据的关系：仪器极限与定标决定了能看到什么，也决定了论证的边界；换仪器或换定标要重新核对结论。
- 失败记录：研究中的失败与反例是方法的一部分，不是需要掩盖的污点。
