# Alan Guth — 观测与推演技法 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 仪器与波段：粒子物理 + 宇宙学：假真空衰变与指数膨胀的场论模型
- 观测方法：设早期宇宙经历指数膨胀：先算膨胀如何抹平曲率、拉大视界，再算量子涨落如何被拉伸为星系种子；给出可检验的谱形预言
- 模型建构：极早期的一次指数膨胀可同时解释宇宙的平坦、均匀与结构种子
- 证据处理：1981 年论文提出暴胀；暴胀的具体场模型未定，属理论框架而非已证实事实；原初引力波预言尚未被观测证实
- 误差与反例：反常数据保留并用于修正模型，不删除、不平滑掉。

## 方法要点

- 核心套路：观测 → 数据 → 模型 → 验证 → 发表。
- 工具与证据的关系：仪器极限与定标决定了能看到什么，也决定了论证的边界；换仪器或换定标要重新核对结论。
- 失败记录：研究中的失败与反例是方法的一部分，不是需要掩盖的污点。
