# Stephen Hawking — 观测与推演技法 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 仪器与波段：广义相对论 + 量子场论的半经典结合；思想实验与数学证明
- 观测方法：把量子场放在弯曲时空背景上算粒子产生：视界附近的量子涨落一半落入黑洞、一半逃逸为辐射；用几何方法证明奇点不可避免
- 模型建构：黑洞会辐射并缓慢蒸发；时空奇点是广义相对论的普遍结论；黑洞熵与面积成正比
- 证据处理：霍金辐射至今无直接观测证实，属理论预言；奇点定理获 2020 年诺贝尔奖的是彭罗斯部分，霍金未及获奖
- 误差与反例：反常数据保留并用于修正模型，不删除、不平滑掉。

## 方法要点

- 核心套路：观测 → 数据 → 模型 → 验证 → 发表。
- 工具与证据的关系：仪器极限与定标决定了能看到什么，也决定了论证的边界；换仪器或换定标要重新核对结论。
- 失败记录：研究中的失败与反例是方法的一部分，不是需要掩盖的污点。
