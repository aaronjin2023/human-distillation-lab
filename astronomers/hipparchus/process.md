# Hipparchus — 天文研究过程规格 process.md（给文本/视频模型）

> 只按研究的逻辑写，不编造天文学家本人的生活场景；无原始记录者按成果结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 工具 | 产出什么、做到什么程度 | 研究状态 | 最容易出错 |
|---|---|---|---|---|---|
| 巡天观测 | 定目标、定仪器、定观测计划 | 肉眼、照准仪 | 观测方案与原始记录：约 850 颗恒星的位置与亮度 | 约 15% | 巡天一漏，星表就有空洞 |
| 编目 | 采集、整理、校准数据 | 肉眼、照准仪 / 记录与校准 | 全量数据贯通，不先下结论：约 850 颗恒星的位置与亮度 | 约 40% | 亮度分级凭目测，标准不一 |
| 校准 | 建模型、拟合参数 | 新旧记录对照的差异分析 | 模型与参数：恒星相对黄道系统性移动 | 约 65% | 单星差异当成系统移动 |
| 交叉验证 | 预测检验、交叉验证、误差分析 | 独立样本、不同方法对照 | 只改模型与解释，不改原始数据 | 约 88% | 旧记录误差大，对照就失真 |
| 星表发表 | 统一、写成书 / 表、定名 | 通读、校对、定标题与图版 | 完成态：星表、岁差发现、星等分级 | 100% | 岁差数值估错就当作精确值发表 |

## (2) 每一阶段的研究状态变化（过程视频 / 文本生成的节奏）

1. 巡天观测结束：观测方案与原始记录：约 850 颗恒星的位置与亮度
2. 编目结束：全量数据贯通，不先下结论：约 850 颗恒星的位置与亮度
3. 校准结束：模型与参数：恒星相对黄道系统性移动
4. 交叉验证结束：只改模型与解释，不改原始数据
5. 星表发表结束：完成态：星表、岁差发现、星等分级

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：巡天观测 40%、编目 25%、校准 15%、交叉验证 15%、星表发表 5%。不要把 5 步平均分配时间，按天文学家特点分配。
- 节奏提示：观测慢（让观者看清仪器与目标）、数据中速（看数据生长）、验证放慢（看逐项排除）、发表停顿（看完成态）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：望远镜 / 星图 / 数据图 / 论文逐行出现，关键修改处用删除线与替换值并排显示；每步左上角出小字步骤名（巡天观测 / 编目 / 校准 / 交叉验证 / 星表发表），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：望远镜全景 / 数据图特写 / 论文局部放大三机位轮换；观测用全景，验证用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 项原发现小图对照（只放星图 / 数据图 / 论文页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡数据图；不要把过程剪成跳切，保留推理的连续性；不要虚构天文学家本人的生活场景；不要把已证伪的当时模型拍成“真理发现”。

## (4) 过程示例（以喜帕恰斯的代表性工作逻辑为例，不声称复刻原过程）

- 巡天观测：系统记录约 850 颗恒星的位置与亮度。
- 编目：按亮度分 1–6 等，按位置列表。
- 校准：统一测角标准与亮度分级。
- 交叉验证：与提莫查里斯等旧记录对照，发现系统性移动。
- 星表发表：星表与岁差结论成书（原书已佚，见于托勒密转述）。
- 节奏：巡天观测 40%、编目 25%、校准 15%、交叉验证 15%、星表发表 5%。
