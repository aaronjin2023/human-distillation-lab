# Robert Wilson — 观测与推演技法 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 仪器与波段：贝尔实验室霍姆德尔角天线、微波辐射计、系统误差排查
- 观测方法：与彭齐亚斯共同做排除法：逐项检验天线噪声、接收机、大气与地面辐射，剩余均匀信号无法归因于仪器；接受其宇宙学起源
- 模型建构：天空存在约 3 K 的各向同性微波背景，是大爆炸的余辉
- 证据处理：1965 年发现论文；1978 年诺贝尔奖与彭齐亚斯共享一半（各 1/4 份额）
- 误差与反例：反常数据保留并用于修正模型，不删除、不平滑掉。

## 方法要点

- 核心套路：观测 → 数据 → 模型 → 验证 → 发表。
- 工具与证据的关系：仪器极限与定标决定了能看到什么，也决定了论证的边界；换仪器或换定标要重新核对结论。
- 失败记录：研究中的失败与反例是方法的一部分，不是需要掩盖的污点。
