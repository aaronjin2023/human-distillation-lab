# Harlow Shapley — 观测与推演技法 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么发现 / 证明的，不写“性格如何导致他这样发现”。

- 仪器与波段：威尔逊山望远镜照相底片、球状星团中造父变星与 RR 天琴座变星
- 观测方法：用变星周光关系逐个定球状星团距离，再把星团的三维分布当作银河系形状的示踪物；分布中心即银心
- 模型建构：大银河系模型：银河系直径远大于此前估计，太阳远离银心；旋涡星云属于银河系内（此点后被证伪）
- 证据处理：球状星团分布不对称、集中于人马座方向；1920 年与柯蒂斯的大辩论；1924 年后哈勃的造父变星证明旋涡星云在银河系外
- 误差与反例：反常数据保留并用于修正模型，不删除、不平滑掉。

## 方法要点

- 核心套路：观测 → 数据 → 模型 → 验证 → 发表。
- 工具与证据的关系：仪器极限与定标决定了能看到什么，也决定了论证的边界；换仪器或换定标要重新核对结论。
- 失败记录：研究中的失败与反例是方法的一部分，不是需要掩盖的污点。
