# Eratosthenes — conflicts.md

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. 1. 草稿 v1 所列代表作“岁差观测”依据薄弱：岁差的发现一般归于喜帕恰斯，埃拉托斯特尼的成就是地球周长与黄道倾角；本次蒸馏已更正。
2. 2. 周长值 252,000 斯塔德的现代换算不确定：斯塔德长度本身有多种说法，约 39,459 公里一说仅为按某种斯塔德长度的换算，不作精确对应。
3. 3. 两城距离 5,000 斯塔德为王室测量、取整，非本人实测；一说埃拉托斯特尼未亲赴塞恩。
4. 4. 生卒年均为约数（c.276–c.194 BCE，一说卒于前 196）。
5. 5. 喜帕恰斯与托勒密后来采用了更小的地球周长值，该数值在中世纪成为通说。
