## 一句话

- **这是谁：** 美国·公园运动园林与景观设计师，代表作中央公园、展望公园、翡翠项链公园系统。
- **什么时候用他：** 需要按此人的风格画其他园林 / 景观题材（图像模型），或复建造园过程（视频模型）时，用这个 skill。
- **风格一句话：** 奥姆斯特德风格：美国公园运动，起伏草甸，蛇形湖，林地，曲折小径，田园、自然、开阔、民主。
- **过程一句话：** 造园五步：场地勘察 → 立意布局 → 叠山理水 → 栽植 → 养护成景。

## 蒸馏范围（只限成果物）

- 材料：园林 / 景观作品本身（中央公园、展望公园、翡翠项链公园系统为主）+ 设计师本人关于造园的公开文字 + 权威园林史说明与评论/研究。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（园内直接可见 / 原文直接可见）/ `artifact`（公开文字、园林图志、修复报告）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 翻译口径：蒸馏以园林实物与原文理论著作为准；中文设计师用原文，日文 / 法文 / 英文等用原文，译本只作参照，不作为 `verbatim` 证据。
