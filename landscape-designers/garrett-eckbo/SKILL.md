## 一句话

- **这是谁：** 美国·现代主义景观园林 / 景观设计师，代表作《生活的景观》《阿拉莫广场》《加州大学伯克利分校景观》。
- **什么时候用他：** 需要按此人的园林风格画其他园林 / 景观题材，或复建造园过程时，用这个 skill。
- **风格一句话：** 埃克博风格：美国现代主义景观，生活的景观，社会空间，几何平面配自由种植，以人为先，现代材料，艺术与生态一体。
- **过程一句话：** 造园五步：场地勘察 → 立意布局 → 叠山理水 → 栽植 → 养护成景。

## 蒸馏范围（只限成果物）

- 材料：园林 / 景观作品本身 + 设计师本人关于造园的公开文字 + 园林图志、修复报告、管理方说明与权威评论。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（园内直接可见 / 本人公开文字原文）/ `artifact`（成果物、文献、图志）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 翻译口径：蒸馏以园林实物与原文理论著作为准；中文设计师用原文，日文 / 法文 / 英文等用原文，译本只作参照，不作为 `verbatim` 证据。
