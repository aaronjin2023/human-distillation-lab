# al-Razi — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **卒年**：卒年：主流说法据比鲁尼为 925 年（卒于雷伊，享年约 60 岁）；另有说法为 923 年。生年约 865 年亦为约数。本文件夹用 c.865–c.925，923 年异说并存。
2. **乙醇发现**：乙醇发现：拉齐提纯乙醇并用于医药为通说，但“发现乙醇”一说在不同史料中表述不一（提纯与药用 vs 首次制得）；本文件夹写“乙醇提纯”，不写“首次发现乙醇”。
3. **《秘密之书》与《秘中之秘》**：《秘密之书》与《秘中之秘》：两部书名在不同目录与译本中易混淆，归属与内容范围有争议；本文件夹以《秘密之书》的分类体系为主，篇名异说记于此。
4. **失明原因**：失明原因：后世传说（豆食、受杖击等）说法不一，与化学成就无关，本文件夹不采信、不展开。
