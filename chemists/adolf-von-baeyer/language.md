# Adolf von Baeyer — 理论语言与论证方式 language.md（Interaction，只限成果物）

- 合成即证明：路线与对照表是论证主体。`artifact`
- 步骤语言：实验步骤写得可复现。`artifact`
- 对照语言：合成物与天然物逐项比对。`artifact`
- 回应质疑靠中间体鉴定记录。`impression`
- 理论段落短，事实段落长。`artifact`

## 语言要点

- 论文/著作的典型结构：结构本身就是论证的一部分。
- 定义方式：定义靠操作、分类或计算，不靠修辞；术语自造时须界定。
- 回应质疑：靠更多数据、更清晰的图、更严格的证明或计算复核，不是靠权威背书。
