# Jabir ibn Hayyan — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **生卒**：生卒：传统说法 c.721–c.815；另有说法卒于 c.806–816。生卒本身无可考档案，本文件夹用 c.721–c.815，异说并存。
2. **文集归属**：文集归属：现存约 215 篇贾比尔文集是否为一人所作，学界有争议；现代研究多认为文集约 850–950 年间编纂，贾比尔之名被一位或多位匿名作者用作署名，早期 8 世纪核心可能真实存在。本文件夹按“贾比尔文集传统”处理，不声称全部为其亲笔。
3. **硫汞理论**：硫汞理论：当时模型，后世证伪。金属并非由硫与汞构成；本文件夹只蒸其分类与操作逻辑，不把理论当真理。
4. **拉丁世界的影响**：拉丁世界的影响：中世纪拉丁文“格伯”（Geber）文集与阿拉伯贾比尔文集关系有争议，不在此处定论。
