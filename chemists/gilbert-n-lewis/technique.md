# Gilbert N. Lewis — 技法与实验工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么做实验 / 怎么建理论的，不写“性格如何导致他这样做”。

- 电子对结构式（点子式）推演：先排价电子，再定共享对
- 热力学测量：量热、自由能与平衡常数测定
- 电化学测定：电极电势与活度
- 光谱与偶极矩数据对照结构
- 酸碱判定：电子对接受/给予的操作检验
- 数据表呈现：键能、平衡常数成表，误差写清

## 方法要点

- 核心套路：观察 → 假设 → 实验 → 表征 → 理论。
- 工具与证据的关系：所用仪器与表征手段决定了能看到什么，也决定了论证的边界；换手段要重新核对结论。
- 失败记录：实验中的失败与反例是方法的一部分。
