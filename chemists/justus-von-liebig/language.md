# Justus von Liebig — 理论语言与论证方式 language.md（Interaction，只限成果物）

- 数据表即论证：元素分析表是论文核心。`artifact`
- 方法先行：论文先写装置与步骤。`artifact`
- 定量语言：碳氢含量与产率是论证主体。`artifact`
- 回应质疑靠装置改进与数据复现。`artifact`
- 教学语言：实验步骤写得可让学生复现。`impression`

## 语言要点

- 论文/著作的典型结构：结构本身就是论证的一部分。
- 定义方式：定义靠操作、分类或计算，不靠修辞；术语自造时须界定。
- 回应质疑：靠更多数据、更清晰的图、更严格的证明或计算复核，不是靠权威背书。
