# Carl Wilhelm Scheele — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **氧气优先权**：氧气优先权：舍勒约 1772–1773 年已制得氧气（“火空气”），但其著作 1777 年才出版；普里斯特利 1774 年发表在先；拉瓦锡给出氧化学说解释。三方贡献分开记，不单归一人。
2. **氯气命名**：氯气命名：舍勒 1774 年制得氯气，称“脱燃素盐酸气”；戴维 1810 年确认其为元素并命名氯。本文件夹记制得与定名分开。
3. **钼与钨**：钼与钨：舍勒鉴定钼酸与钨酸（矿物），单质分离由后人完成；本文件夹写“钼与钨的发现（鉴定）”，不写单质分离。
4. **嗅味检验**：嗅味检验：舍勒以嗅味检验物质为当时做法，有毒且危险；本文件夹只记历史事实，不作为可模仿的方法。
