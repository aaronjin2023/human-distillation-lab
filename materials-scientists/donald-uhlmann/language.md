# Donald R. Uhlmann — 理论语言 language.md（Interaction，只限成果物）

- 理论语言：玻璃形成动力学：成核速率与晶体生长速率随过冷度的竞争；时间-温度-转变（TTT）图；相分离（旋节分解与成核生长）决定微结构。 `artifact`
- 表征语言：DSC / DTA 测玻璃转变温度 Tg 与结晶峰；XRD 判非晶 / 结晶；光学显微与电镜看相分离与晶核；黏度与折射率测光学性能。 `artifact`
- 合成语言：玻璃熔制：氧化物配料高温熔融、澄清、成型；冷却速率是关键工艺参数（快冷得玻璃，慢冷结晶）；溶胶-凝胶与气相沉积作补充路线。 `artifact`
- 性能语言：优先保住玻璃的非晶稳定性与光学均匀性；可牺牲成型速度；光学应用保住折射率均匀，牺牲机械强度。 `artifact`

## 语言要点

- 论文 / 专利的典型结构：设计—合成—表征—测试—应用，结构本身就是论证的一部分。
- 定义方式：定义靠操作、分类或计算，不靠修辞；术语自造时须界定。
- 回应质疑：靠更多数据、更清晰的图、更严格的测试复核，不是靠权威背书。
