# Edgar Bain — 材料研究过程规格 process.md（给文本 / 视频模型）

> 只按研究的逻辑写，不编造人物本人的生活场景。不声称复刻某一项原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 仪器 | 做什么材料、测什么 | 研究状态 | 最容易出错 |
|---|---|---|---|---|---|
| 1 设计 | 定材料体系、性能目标与理论模型 | 相图 / 能带计算 / 文献调研 / 模拟 | 只定体系：成分、结构、性能目标、关键假设 | 约 10–20%，思路可见、样品未定 | 体系一定就改目标；模型不可检验 |
| 2 合成 | 制备样品 | 按人物习惯：等温转变与淬透性试验：TTT 曲线测奥氏体转变，端淬试验定淬透性，合金元素对转变的影响成系列记录 | 全流程贯通，不回头改参数 | 约 40–50%，样品初现、性能粗糙 | 参数一改就无对照；冷却或烧成条件一失就无样品 |
| 3 表征 | 测结构与成分 | TTT 曲线、端淬试验、金相、硬度；以转变图定热处理窗口 | 只测结构与成分，不下性能结论 | 约 60–70%，结构已定、机理未满 | 无结构证据就下性能结论 |
| 4 测试 | 测性能、验证机理 | 力学 / 电学 / 热学 / 生物学测试，按人物习惯 | 只测性能与机理，不改合成路线 | 约 85–90%，性能已立，个别数据仍可补测 | 对照一漏就分不清因果；单样品就宣称普遍规律 |
| 5 应用 | 转化、放大、定型 | 中试 / 器件集成 / 专利 / 标准 | 全流程薄薄统一，不改结构 | 100%，完成态 | 放大时改结构；应用宣称超出测试边界 |

## (2) 每一阶段的研究状态变化（过程视频 / 文本生成的节奏）

1. 设计结束：只有设计图与性能目标，样品未定。
2. 合成结束：有样品无数据，性能粗糙。
3. 表征结束：结构已定，机理未满。
4. 测试结束：性能曲线已立，个别数据仍可补测。
5. 应用结束：完成态，可转化定型。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配：设计 15%、合成 30%、表征 25%、测试 25%、应用 5%。不要把 5 步平均分配时间，按人物特点分配。
- 节奏提示：设计慢（看清思路）、合成中速（看样品生长）、表征放慢（看显微图像出现）、应用停顿（看完成态）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：实验台 / 电镜屏幕 / 数据曲线逐项出现，关键参数处用标注并排显示；每步左上角出小字步骤名（设计 / 合成 / 表征 / 测试 / 应用），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍实验台 / 仪器特写 / 数据屏幕三机位轮换；设计用全景，表征用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 项原作小图对照（只放材料照片 / 电镜图 / 性能曲线，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡样品；不要把过程剪成跳切，保留实验的连续性；不要虚构人物本人的生活场景。

## (4) 过程示例（以埃德加·贝恩的方法逻辑为例，不声称复刻原过程）

- 设计：定材料体系、性能目标与理论模型（等温转变模型：以 TTT 曲线定珠光体、贝氏体、马氏体区，贝氏体为中温产物）。
- 合成：等温转变与淬透性试验：TTT 曲线测奥氏体转变，端淬试验定淬透性，合金元素对转变的影响成系列记录。
- 表征：TTT 曲线、端淬试验、金相、硬度；以转变图定热处理窗口。
- 测试：按第(5)节指标量化性能，与模型对照。
- 应用：转化、放大、定型。
- 节奏：设计 15%、合成 30%、表征 25%、测试 25%、应用 5%。
