# Chu Ching-wu — 理论语言 language.md 朱经武（Interaction，只限成果物）

> v0.1（2026-10-26）。只写他的理论怎么跟学界说话，不写私生活。

- 电阻—温度曲线 + 压力—Tc 曲线是核心语言：两条曲线讲清组分与压力的作用
- 论证结构：双变量扫描—电阻下降—抗磁确认—可重复；双判据缺一不可
- 数据呈现：电阻—温度曲线、磁化率曲线、压力—Tc 曲线
- 回应质疑靠重复与标定：Tc 够不够高、压力准不准，再测一次便知

## 要点

- 核心套路：设计 → 合成 → 表征 → 测试 → 应用。
- 证据分级：`verbatim` / `artifact` / `impression`，见材料科学草稿第 6.5 节；译文与转述一律不标 verbatim。
