# Leo Baekeland — 理论语言 language.md（Interaction，只限成果物）

- 理论语言：缩聚交联：酚醛树脂由线型中间体交联成三维网络；反应程度决定可模塑性与最终硬度；热固性塑料的成型窗口。 `artifact`
- 表征语言：硬度与热稳定性测试；电绝缘测试；成型性观察；化学抗性测试；外观与尺寸稳定性。 `artifact`
- 合成语言：酚醛缩聚：苯酚 + 甲醛，碱 / 酸催化，控温控压；分阶段：可溶可熔中间体 → 热压成型 → 不溶不熔终产物；控反应程度是关键。 `artifact`
- 性能语言：优先保住成型后的硬度与热稳定性；可牺牲可重塑性；电木保住电绝缘与耐热，牺牲韧性。 `artifact`

## 语言要点

- 论文 / 专利的典型结构：设计—合成—表征—测试—应用，结构本身就是论证的一部分。
- 定义方式：定义靠操作、分类或计算，不靠修辞；术语自造时须界定。
- 回应质疑：靠更多数据、更清晰的图、更严格的测试复核，不是靠权威背书。
