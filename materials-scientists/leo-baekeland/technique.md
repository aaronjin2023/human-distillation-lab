# Leo Baekeland — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么做出这种材料的，不写“性格如何导致他这样做”。

- 合成：酚醛缩聚：苯酚 + 甲醛，碱 / 酸催化，控温控压；分阶段：可溶可熔中间体 → 热压成型 → 不溶不熔终产物；控反应程度是关键。
- 表征：硬度与热稳定性测试；电绝缘测试；成型性观察；化学抗性测试；外观与尺寸稳定性。
- 理论：缩聚交联：酚醛树脂由线型中间体交联成三维网络；反应程度决定可模塑性与最终硬度；热固性塑料的成型窗口。
- 性能：优先保住成型后的硬度与热稳定性；可牺牲可重塑性；电木保住电绝缘与耐热，牺牲韧性。

## 方法要点

- 核心套路：设计 → 合成 → 表征 → 测试 → 应用。
- 工具与证据的关系：合成条件与表征手段决定了能看到什么，也决定了论证的边界；换条件要重新核对结论。
- 失败记录：各步最容易出错的地方是方法的一部分。
