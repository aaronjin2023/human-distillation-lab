# Robert Hadfield — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么做出这种材料的，不写“性格如何导致他这样做”。

- 合成路线：系统配比试验：铁中加12–14%锰、约1.2%碳，1000°C加热后水淬得奥氏体锰钢；硅钢另以硅含量调磁性与力学
- 表征组合：三千余种试样逐一做成分分析、硬度、冲击与磨损试验；金相观察奥氏体组织
- 理论模型：合金元素—组织—性能对应表：锰稳奥氏体、加工硬化靠冲击诱导表面硬化
- 性能取舍：耐磨与冲击硬化优先，保住表面加工硬化，牺牲切削加工性与初始硬度

## 方法要点

- 核心套路：设计 → 合成 → 表征 → 测试 → 应用。
- 工具与证据的关系：合成窗口与表征手段决定了能看到什么结构，也决定了论证的边界；换合成条件要重新核对结论。
- 失败记录：过程中的失败与反例是方法的一部分。
