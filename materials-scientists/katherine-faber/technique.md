# Katherine T. Faber — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么做出这种材料的，不写“性格如何导致他这样做”。

- 合成：两相陶瓷烧结：基体粉末 + 第二相颗粒（球形、棒状、片状），控制粒径分布窄、体积分数与间距；热压 / 无压烧结，烧结温度与气氛按基体（氧化铝、碳化硅、莫来石）定。
- 表征：断裂韧性测试（SENB / 压痕法）先行于机理解释；光学与电子显微成像实测裂纹偏转角与扭转角，直接输入模型；XRD 与 SEM 看界面与第二相分布。
- 理论：Faber–Evans 模型：裂纹偏转（倾斜 + 扭转）降低裂纹尖端应力强度因子；棒状高长径比颗粒最有效，扭转分量主导增韧；能量释放率与平直裂纹对比量化增韧倍数。
- 性能：优先保住断裂韧性与裂纹偏转带来的有效延性；可牺牲部分强度与各向同性；热障涂层应用中保住热稳定性，牺牲致密度。

## 方法要点

- 核心套路：设计 → 合成 → 表征 → 测试 → 应用。
- 工具与证据的关系：合成条件与表征手段决定了能看到什么，也决定了论证的边界；换条件要重新核对结论。
- 失败记录：各步最容易出错的地方是方法的一部分。
