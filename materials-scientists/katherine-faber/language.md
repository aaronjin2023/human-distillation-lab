# Katherine T. Faber — 理论语言 language.md（Interaction，只限成果物）

- 理论语言：Faber–Evans 模型：裂纹偏转（倾斜 + 扭转）降低裂纹尖端应力强度因子；棒状高长径比颗粒最有效，扭转分量主导增韧；能量释放率与平直裂纹对比量化增韧倍数。 `artifact`
- 表征语言：断裂韧性测试（SENB / 压痕法）先行于机理解释；光学与电子显微成像实测裂纹偏转角与扭转角，直接输入模型；XRD 与 SEM 看界面与第二相分布。 `artifact`
- 合成语言：两相陶瓷烧结：基体粉末 + 第二相颗粒（球形、棒状、片状），控制粒径分布窄、体积分数与间距；热压 / 无压烧结，烧结温度与气氛按基体（氧化铝、碳化硅、莫来石）定。 `artifact`
- 性能语言：优先保住断裂韧性与裂纹偏转带来的有效延性；可牺牲部分强度与各向同性；热障涂层应用中保住热稳定性，牺牲致密度。 `artifact`

## 语言要点

- 论文 / 专利的典型结构：设计—合成—表征—测试—应用，结构本身就是论证的一部分。
- 定义方式：定义靠操作、分类或计算，不靠修辞；术语自造时须界定。
- 回应质疑：靠更多数据、更清晰的图、更严格的测试复核，不是靠权威背书。
