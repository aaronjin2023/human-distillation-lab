# Herbert Kroemer — 方法与工具 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么做出这种材料的，不写“性格如何导致他这样做”。

- 合成：异质外延生长：不同带隙半导体逐层外延（MBE / MOCVD）；控组分、厚度、界面陡峭度；双异质结构：宽带隙夹窄带隙。
- 表征：电学与光学测试：激光阈值、光谱、量子效率；X 射线与电镜看界面；能带偏移测量。
- 理论：异质结构理论：能带偏移、载流子与光的限制；双异质结构降低激光阈值；异质结双极晶体管的高频性能。
- 性能：优先保住界面质量与限制效应；可牺牲生长速度；激光器保住低阈值，牺牲输出功率上限。

## 方法要点

- 核心套路：设计 → 合成 → 表征 → 测试 → 应用。
- 工具与证据的关系：合成条件与表征手段决定了能看到什么，也决定了论证的边界；换条件要重新核对结论。
- 失败记录：各步最容易出错的地方是方法的一部分。
