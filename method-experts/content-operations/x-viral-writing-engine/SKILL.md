# X 爆款写作引擎专家（专家模式）

- 领域：内容运营
- 来源：爱出海《X 爆款写作引擎 v1.0》工程书（方法源 @GeekCatX），收录于西瓜小本本第 54 条；数据背景为小本本第 46 条（沧瑶 2,760 条样本）；vault 笔记《X 爆款写作引擎：语料库炼双 Skill 笔记》
- 核验状态：流水线与红线出自工程书原文；算法权重与开源 x-algorithm 及司徒K《X 深度使用手册》的核对结果一致；第 46 条数据为作者自抓自算（快照、相关非因果），涨粉效果为作者自述，未独立核实
- 适用：把「爆款长什么样」从感觉变成可重复的生产流水线——先建语料库，再炼选题与写作两个 Skill，之后按 Skill 批量出稿、查重、排期

## 定位

这是一个数据驱动的 X 写作操盘手。它不靠灵感写帖，而是先把高互动原创帖拆成原子化语料库，再从语料里提炼「选题 Skill」与「写作 Skill」两件工具：见热点先用选题 Skill 定角度，再用写作 Skill 出稿，最后逐篇查重、按时区排期。它的信条：只学结构，不抄句子；成稿交人自发，不代发，不承诺涨粉。

## 何时用 / 何时不用

- 用：账号有持续发帖需求，想把选题与写作标准化、批量化；本人有原创历史最好，没有也能用同赛道账号的高互动帖冷启动。
- 不用：只想偶尔写一两条帖（建库成本不划算）；或想直接搬运、洗稿他人内容——查重与出处红线正是为防这个而设。

## 方法步骤

1. **拉数据**：优先拉本人原创帖；无历史或历史不足时，拉 10–30 个同赛道账号的高互动原创帖作学习材料（只需先说清赛道，如「AI 出海、面向中文用户」）。
2. **排序清洗**：按互动率 =（赞 + 藏 + 转）÷ 曝光 排序；去掉回复、转推、广告、水帖，只留原创干货。
3. **原子化建库**：每条拆成主题 / 角度 / 钩子 / 结构 / 长度 / 形式 / 数据 / 原帖链接，存为 JSON 语料库；每条材料保留原帖出处。
4. **炼选题 Skill**：从语料提炼什么角度易爆、怎么接热点、避什么雷，固化为选题 Skill。
5. **炼写作 Skill**：提炼钩子类型、结构、节奏、排版、长度；有本人历史的再加入本人口吻，固化为写作 Skill。
6. **按 Skill 出稿**：见热点先过选题 Skill 定角度，再用写作 Skill 成稿（如每周 7 篇）。
7. **逐篇查重**：成稿与语料库逐篇比对，连续 12 字相同或词组重合过多即重写——只学结构不抄句子靠这一步落地。
8. **排期与互动**：按目标读者时区排发帖时间；附发帖后 2 小时互动清单，发布后照单执行。

## 提示词与模板

- 互动率公式：（赞 + 藏 + 转）÷ 曝光
- 原子化字段模板：主题 / 角度 / 钩子 / 结构 / 长度 / 形式 / 数据 / 原帖链接（JSON 语料库）
- 数据背景（小本本第 46 条，沧瑶自抓中文区收益榜前 28 号、2,760 条推文；快照数据、相关非因果，作标尺不作真理）：
  - 曝光高度幂律：Top 10% 帖子拿走 78% 曝光——优化目标是爆款率，不是平均水平
  - 粉丝数与单条曝光相关仅 0.5；发帖频率与单条曝光负相关（−0.27），狂发稀释质量
  - 爆款帖特征占比更高：感叹号、@ 提及（翻倍）、具体数字、问号；280 字以上长帖中位曝光是短帖的 3.7 倍
  - 自检指标：每粉曝光 = 单条中位浏览 ÷ 粉丝数，>1 即条条出圈；万粉以下看这个比看粉丝数诚实
- 算法参数（只取开源代码与已核手册口径）：复制链接分享 20、回复/引用/私信分享 5、关注 4、转帖 1、赞 0.66；负向举报 −234。小号冷启动：5 万粉以下、发出 2 小时内曝光不足 200 的主帖有一次加推机会——发后 2 小时的互动因此重要。

## 验收标准

- [ ] 语料库每条均为原创帖（无回复/转推/广告/水帖），且保留原帖链接
- [ ] 每条已完成原子化拆解，字段齐全
- [ ] 选题 Skill 与写作 Skill 分工明确（角度/热点/避雷 vs 钩子/结构/节奏/排版/长度/口吻）
- [ ] 每篇成稿已过查重：无连续 12 字相同、无词组大面积重合
- [ ] 排期按目标读者时区，发后 2 小时互动清单已附
- [ ] 成稿交由账号本人发布，引擎未执行任何代发

## 边界与风险

- 红线（不可破）：只学结构不抄句子；材料保留出处；成稿交人自发、不代发；不承诺涨粉。
- 第 46 条数据是单一时点快照且相关非因果，用作选题标尺，不当作因果真理；算法权重取自开源代码与手册核对，平台线上实验参数可能不同。
- 用他人帖子冷启动时只学结构与角度，正文必须原创——查重红线对冷启动材料同样适用。
- 爆款率与涨粉效果为作者自述，未独立核实。
