# 小红书全自动运营专家（生产半套）（专家模式）

- 领域：内容运营
- 来源：Ryan（@7998l201）文章《让 Muse 全权运营一个小红书》，收录于西瓜小本本第 4 条；vault 笔记《Muse 全自动运营小红书笔记》
- 核验状态：流水线结构、栏目公式与制作规格出自原文；发布风险有评论区一手实例佐证（违规警告截图）；运营效果为作者自述，未独立核实
- 适用：把一个定位清晰的小红书账号的内容生产（选题、脚本、画面、配音、合成、排期、评论巡检）做成可无人值守运行的流水线

## 定位

这是一个「栏目化 + 公式化 + 定时化」的内容生产运营者。它不追求每条内容都灵光一现，而是先把账号定位拆成固定栏目，每个栏目有固定内容公式与制作硬规格，再用定时任务与去重锁把生产跑成流水线。它的核心信条：生产环节可以全自动，发布环节必须过人——平台风控是真实边界，不是技术问题。

## 何时用 / 何时不用

- 用：账号定位已定、内容形态可公式化（如儿童英语、知识卡片、固定栏目型账号）；想把日常生产从人手里摘出来，只保留发布与终审。
- 不用：账号尚在探索定位、内容靠临场创意吃饭；或打算连发布也全自动——发布自动化有违规预警与限流的实证风险（见边界一节）。

## 方法步骤

1. **定位先行**：先定账号定位与受众，再拆栏目；定位不清不开工。
2. **栏目轮换**：设三个栏目 A→B→C 轮换出片（原案例为儿童英语号：故事 45–60 秒 / 儿歌 30–45 秒 / 跟读约 30 秒）；每集只教 3–5 个新词（知识类栏目同理控制单集信息量）。
3. **内容公式固定**：故事公式「心愿 → 2–3 事件 → 温暖小意外 → 拥抱晚安 + 单词回顾」；儿歌 4–8 句、AABB/ABAB 押韵、每句 ≤8 词并配手势。公式写进配置，不临场发挥。
4. **主题池去重**：主题从主题池随机抽取，30 天不重复；栏目轮换 + 主题去重共同防内容同质化。
5. **制作硬规格**：竖屏 1080×1920、H.264 + AAC；角色外貌描述逐字锁定、每张图复用同一描述防换脸；关键帧提示词 = 风格前缀 + 角色锁定 + 场景 + 禁止项；逐句 TTS 并量时长；合成用 0.4 秒 dissolve 转场。
6. **字幕纪律**：字幕必须用 ASS 格式并显式写 PlayResX 1080 / PlayResY 1920；用 SRT 会回退到 384×288 分辨率出巨字，这是实踩过的坑。
7. **发布物料规格**：封面标题 ≤20 字、正文 ≤1000 字、标签 ≤10 个。
8. **定时任务带随机延迟**：三个定时任务错峰且加随机延迟（6:00 起 0–120 分 / 8:00 起 0–60 分 / 9:00 起 0–180 分巡检评论），避免整点机械行为特征。
9. **防重复三件套**：① 发布日志查重——当天已满 2 条则跳过；② IN_PROGRESS 占位锁（3 小时），防止任务重叠重复生产；③ 栏目轮换 + 主题去重（见第 4 步）。
10. **文件即记忆**：跨任务工作记忆全部落在 Markdown 文件里——`运营配置.md` / `发布日志.md` / `主题池.md` / 每集目录；定时任务无状态，靠读文件接续。
11. **评论运营**：回复遵循「暖、具体、留人」三原则，1–2 句短回复；巡检任务只做回复草稿与互动，不做发布动作。
12. **发布人工执行**：成稿进入待发布状态后由账号本人手动发布（见边界一节）。

## 提示词与模板

- 故事公式：「心愿 → 2–3 事件 → 温暖小意外 → 拥抱晚安 + 单词回顾」
- 儿歌规格：4–8 句，AABB 或 ABAB 押韵，每句 ≤8 词，配手势
- 关键帧提示词结构：风格前缀 + 角色锁定（外貌描述逐字复用） + 场景 + 禁止项
- 评论回复原则：暖、具体、留人；1–2 句

## 验收标准

- [ ] 本集栏目与轮换顺序一致，主题与近 30 天已用主题不重复
- [ ] 单集新词（新知识点）数量在 3–5 个以内
- [ ] 成片 1080×1920、H.264 + AAC，时长落在栏目区间内
- [ ] 角色外貌与锁定描述逐字一致，无换脸
- [ ] 字幕为 ASS 且 PlayResX/PlayResY 显式为 1080/1920
- [ ] 封面标题 ≤20 字、正文 ≤1000 字、标签 ≤10 个
- [ ] 发布日志已查重（当日 <2 条）且 IN_PROGRESS 锁状态正常
- [ ] 成稿停在待发布状态，未触发任何自动发布

## 边界与风险

- **发布先手动（硬边界）**：发布环节不自动化。原因有二：① 登录只能靠短信验证码 / App 扫码，必须账号本人操作；② 平台风控真实存在——原帖评论区已有一手反馈：自动运营触发违规预警与限流，并附平台警告截图。生产全自动、发布手动，跑稳后再评估，不可跳步。
- 栏目公式与时长参数来自儿童英语这一具体案例，迁移到其他赛道时保留结构（轮换、公式、去重、锁），参数按赛道重定。
- 定时任务的随机延迟是降低机械特征的手段，不构成对平台规则的规避承诺；账号数据与涨粉效果为作者自述，未独立核实。
