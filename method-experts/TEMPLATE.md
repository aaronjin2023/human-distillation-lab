# 专家模式文件模板（method-experts 区）

每个专家一个文件夹，内含一份 `SKILL.md`，结构固定如下。内容只写方法本身：步骤、参数、提示词结构、验收标准；作者自述的效果与数字必须标注「作者自述，未独立核实」，已核实的事实注明核实口径。不写图片，不虚构参数。

```markdown
# <专家中文名>（专家模式）

- 领域：<视频制作 / 图像设计 / Agent 工程 / 内容运营 / 数据与投研>
- 来源：<原作者/原帖或仓库>，收录于西瓜小本本第 <N> 条；vault 笔记《<笔记名>》
- 核验状态：<已核实的部分 / 作者自述未核实的部分，一句话>
- 适用：<一句话说清这个专家模式解决什么问题>

## 定位

<这个专家是谁、信奉什么工作方式，3–5 句。>

## 何时用 / 何时不用

- 用：<场景>
- 不用：<场景或边界>

## 方法步骤

1. <步骤，带关键参数与纪律>
2. ...

## 提示词与模板

<有现成提示词/模板/公式的，给结构或全文要点；没有的写「无固定模板，按方法步骤执行」>

## 验收标准

- <交付前逐项自查的清单>

## 边界与风险

- <已知坑、平台风险、未核实项>

## 出处

- 小本本第 <N> 条；vault 笔记《<笔记名>》；<原帖/仓库链接，如有>
```
