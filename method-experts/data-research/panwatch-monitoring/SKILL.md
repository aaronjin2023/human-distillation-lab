# PanWatch 盯盘三段调度（专家模式）

- 领域：数据与投研
- 来源：阳阳（@tantanyuli）介绍帖 + 仓库 TNT-Likely/PanWatch，收录于西瓜小本本第 184 条；vault 笔记《PanWatch 盯盘侠：自托管 AI 盯盘助手笔记》
- 核验状态：仓库与帖文主张已逐项核实（见下）；投研结论的实际效果没有任何回测或实盘证据，未验证
- 适用：给一组自选持仓搭一个自托管的 AI 盯盘助手——盘前有展望、盘中有异动告警、盘后有复盘日报，研究结论先在模拟盘里验证，不碰真实下单

## 定位

这个专家是「值班盯盘员 + 投研班子调度员」：自己不喊单、不下单，只做三件事——按交易时段调度监控、用一条多角色深研流水线把异动啃透、把结论按纪律推送给人。它信奉自托管（数据与持仓在自己机器上）、调度绑交易日历（不做无差别 24 小时轮询）、信号先过模拟盘（没验证过的信号不算数）。

## 何时用 / 何时不用

- 用：需要长期盯 A 股 / 港股 / 美股的自选组合，要盘前展望、盘中异动监控、盘后复盘三段齐全；希望深研结论带完整推理轨迹可回溯；希望先用模拟盘验证一套信号再决定是否采信。
- 不用：需要真实下单执行（本模式只到研究与纸面跟踪为止）；只想看一次性的单票快评（直接问模型更快，不必部署整套系统）；无法自托管部署环境时。

## 方法步骤

1. **自托管部署**：Docker 部署 PanWatch，数据与持仓配置留在本机；模型层二选一先定好——本地 Ollama（数据不出本机）或 OpenAI 兼容的云端模型商（分析数据会发给模型商），敏感持仓优先本地。
2. **配市场与持仓**：覆盖 A / 港 / 美三市场，录入自己的持仓与自选，后续所有监控与深研都从持仓出发。
3. **三段调度绑交易日历**：盘前展望 → 盘中异动监控 → 盘后复盘日报，按用户排程只在合格交易日运行，节假日自动跳过。注意：帖称的「24 小时盯盘」是营销话术，实际就是这三段，不要按 24 小时轮询去配。
4. **异动监控配指标集**：技术指标用 MACD / RSI / KDJ / 均线 / 布林带 / 量比 / 支撑阻力 + K 线形态，异动触发后进入深研或告警。
5. **深研流水线（接 TradingAgents 的 9-Agent 班子）**：技术 / 情绪 / 新闻 / 基本面四位分析师分开啃 → 多空辩论 → 风控审查 → PM 拍板，产出一份决策备忘 + 完整推理轨迹，全程可回溯；单次深研约 3–5 分钟出结论（仓库口径）。
6. **告警纪律**：触发条件用组合条件（AND / OR）而不是单指标裸触发；每条告警配冷却期 + 每日限次，防告警轰炸把人训练成忽略告警。
7. **多通道分发**：结论推送到 Telegram / 企业微信 / 钉钉 / 飞书 / Bark / Webhook，选自己日常真会看的通道，不要全开。
8. **上实盘前先模拟盘**：任何新信号先走内置 Paper Trading 模拟盘验证（该模拟盘连 A 股 T+1 等市场规则都建了模），看按信号进出的净值曲线，再决定是否采信；未经模拟盘验证的信号只作参考，不作决策依据。

## 提示词与模板

无固定提示词模板，按方法步骤执行。唯一要照搬的结构是深研流水线的角色与产出格式：

```text
深研流水线：[技术分析师 / 情绪分析师 / 新闻分析师 / 基本面分析师]
  → 多空辩论（多头论证 vs 空头论证，各自摆证据）
  → 风控审查（仓位、波动、事件风险）
  → PM 拍板
产出：决策备忘（结论 + 依据 + 风险）+ 完整推理轨迹（每一步谁说了什么，可回溯）
```

## 验收标准

- 三段调度确实按交易日历触发，节假日无动作、无推送。
- 每份深研产出都带决策备忘和可回溯的推理轨迹，不是一句裸结论。
- 告警带冷却期和每日上限，连续触发时不会连环轰炸。
- 新信号先有模拟盘记录（含市场规则如 A 股 T+1 的约束），再谈采信。
- 数据路径与所选模型层口径一致：选了本地 Ollama 就确认没有数据外发；选了云端模型商就明确知道分析数据发给了谁。
- 全程无任何真实下单动作，产出只到研究结论与纸面记录为止。

## 边界与风险

- **本区硬边界**：本方法只用于研究、监控、回测与纸面跟踪；不下真实订单、不动用真实资金；实盘需要用户另行批准并先定资金上限与风控规则。
- 两处说法要打折：①「24 小时盯盘」是营销话术，实为绑交易日历的三段调度；②「数据不经第三方」只在本地 Ollama 下成立，选云端模型商时分析数据照样发给模型商。
- 效果零实证是硬伤：项目没有给出回测或实盘效果证据，9-Agent 的投研结论质量未经验证，必须先过模拟盘再采信。
- 项目本身活跃度以核查时为准：主仓库 2026-01-23 建仓，核查当日（2026-11-01）仍在推送，2,353★ / 426 forks（2026-11-04 复核口径）、MIT；上游 TradingAgents 119,160★、Apache-2.0——均为核查时读数，引用前复核。
