# AI 漫剧全流程专家（专家模式）

- 领域：视频制作
- 来源：梦老湿（@jackzhang123vip）长文与开源仓库 ai-manju-skills，收录于西瓜小本本第 146 条；vault 笔记《AI 漫剧全流程 Skill：从一句点子到发布包笔记》
- 核验状态：仓库 zhanghao123vip/ai-manju-skills 已核实存在（MIT，含 21 个题材 skills 目录；2026-11-01 复查为 35★ / 12 forks）；实跑数字（企划案页数、生成时耗、安装耗时）为作者自述附截图，未独立核实
- 适用：从一句点子端到端生产一季 AI 漫剧——立项、企划、全季资产库、分集剧本、逐集导演手册、逐集发布包，靠前置表格锁住长内容一致性

## 定位

这个专家信奉「做一次是作品，做成 SKILL 才是工具」。它不靠单条神提示词，而靠三样资产：①用「表」把一致性前置——身高、战力、地图、音色在动笔前先定死；②懂生成模型脾气的拆镜规则——模型的短板在分镜阶段就绕开；③把整套工作方式压成一个可跨模型搬运的 SKILL 文件。生产以五阶段推进，用户只需说「继续」，改稿指令（如「改：女主改成冷面师姐」）只动相关部分并检查前后矛盾。

## 何时用 / 何时不用

- 用：多集连续漫剧/动态漫的整季生产，尤其是角色多、集数长、一致性（外貌、战力、伏笔）容易崩的中长篇。
- 不用：单条短视频、一次性短片——前置建表与资产库的成本摊不回来；真人实拍短剧也不适用（资产体系是为生成画面设计的）。

## 方法步骤

1. 阶段一·立项卡：一句点子先落成立项卡，确认题材、受众与基本设定再往下走。
2. 阶段二·企划案：产出全季企划案。默认值：30 集、每集约 4 分钟、9:16 竖屏（默认值出自作者流水线，作者自述，未独立核实）。
3. 阶段三·全季资产库（动笔前先行）：先建「表」——全角色身高表（同框比例稳）、逐集战力表（越级取胜必须有看得见的理由、代价累积）、带尺寸的地图、角色音色表、伏笔回收表。再建资产——人物三视图 / 表情四态 / 服装卡 / 状态卡，每人钉 3–4 个永不变的外观特征；道具状态卡；场景空景卡 + 机位卡；特效统一纯黑底便于合成；伤势状态卡只进不退。
4. 阶段四·分集剧本：按资产库与各表写分集剧本，战力、伤势、伏笔状态以表为准，不凭记忆续写。
5. 阶段五·逐集导演手册：逐镜拆分并执行拆镜规则（见下），手册末尾附连续性检查表逐项自检；通过后打包逐集发布包。
6. 拆镜规则（懂模型脾气，硬纪律）：
   - 内心独白只标闭口、不入画，否则角色会张嘴；
   - 要数数的动作标后期合成，不让模型数数；
   - 踢飞、坠落等复杂动作拆成两条、各带首帧（作者实例：32 镜拆出 36 块视频提示词，作者自述，未独立核实）；
   - 运镜写身体部位，不写厘米；
   - 打斗分镜图只画接触前 / 后的稳定姿势；
   - 分镜图提示词压到约 130 字——外貌归资产图、动作归视频提示词（作者口径：从约 600 字压到平均约 130 字，作者自述，未独立核实）。
7. 连续性自检：把成稿手册丢回给模型挑错，检查项固化在每集手册末尾（作者实例挑出 25 项穿帮：清晨戏说「今夜」、站位无交代跳变、双手被锁却伸手、台词提到不存在的人、大件道具无人交代去向等，作者自述，未独立核实）。
8. 固化与迁移：整套流程压成单个约 2 万字节的 SKILL.md（无脚本、不依赖外部文件）；DeepSeek 整段粘贴即用，WorkBuddy 上传自装（作者自述 59 秒装好并自做 md5 校验与旧版备份），Claude Code 原生调用。题材切换时骨架不变、专属表更换，并逐题材单独设定 pacing 节奏，不共用一个节奏模板。

## 提示词与模板

无单条固定提示词模板，靠结构化资产执行，关键模板是三组「表」与卡：

- 一致性前置表：全角色身高表 / 逐集战力表 / 带尺寸地图 / 音色表 / 伏笔回收表
- 资产卡：人物三视图 + 表情四态 + 服装卡 + 状态卡（每人 3–4 个不变外观特征）/ 道具状态卡 / 场景空景卡 + 机位卡 / 特效纯黑底卡 / 伤势状态卡（只进不退）
- 题材专属表（21 题材同骨架异专属表，举例）：宫斗——位份服制表、信息差表；宅斗——家族关系树、账本钥匙去向；末日——物资总表、丧尸分级；年代文——票证物价表；悬疑——分钟级时间线、线索公平回收
- 推进指令模板：阶段间只说「继续」；改稿用「改：<具体改动>」，系统只动相关部分并检查前后矛盾

## 验收标准

- 五阶段产物齐全：立项卡 → 企划案 → 全季资产库 → 分集剧本 → 逐集导演手册 → 逐集发布包。
- 五张前置表在写剧本前已定稿；剧本与手册中的身高比例、战力变化、伤势状态、伏笔回收均可回溯到表。
- 每集手册末尾连续性检查已跑完，站位、时间、道具去向、台词指称类穿帮清零才交付。
- 拆镜规则逐项落实：独白闭口标注、计数动作标后期、复杂动作双条带首帧、运镜无厘米表述、打斗只画稳定姿势、分镜图提示词约 130 字。
- 题材 pacing 已按本剧题材单独设定，没有套用其他题材的节奏模板。

## 边界与风险

- 量化战绩（企划案 48 页、第 1 集手册 90 页、2 分 13 秒出立项卡与企划案、59 秒安装）均为作者自述附截图，未独立核实，引用时必须带口径。
- 仓库星数尚低、仍在快速修订（2026-11-01 有一次 21 题材全量修订），使用前先看仓库最新版本。
- 默认值（30 集 × 约 4 分钟、9:16）是作者流水线的出厂设定，不是行业标准，按项目需要改。
- 作者三原则可作执行心法：先让它看全、告诉它东西拿去干什么、做顺了固化成 SKILL。
