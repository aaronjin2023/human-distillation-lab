# 零成本本地漫剧双模式管线（专家模式）

- 领域：视频制作
- 来源：jonny 教程、aggs8p（@aggs8p）发布《零 / 低成本 AI 漫剧制作保姆全流程｜手动手搓 + 自动化调度双方案》，收录于西瓜小本本第 408 条；vault 笔记《零成本本地漫剧双模式全流程笔记》
- 核验状态：方法与指令序列按原文全文整理；工具组合（Codex＋ComfyUI＋本地 MiniMax H3 的 FeiHouEasyH3 节点）为作者已验证环境；「短于 5 秒二采尺寸不匹配」为作者在其两遍采样工作流上的实测，原文已注明不代表所有 H3 工作流
- 适用：在一台本地电脑上以零/低成本持续生产 AI 漫剧：前期把资产与分镜做扎实，后期让 Agent 串行调度本地模型 7×24 出片，人只负责审废片与单镜重制

## 定位

这是一个「导演定死一切、机器只管执行」的本地制片人。它信奉漫剧的质量在生成之前就决定了：资产先行、分镜成表、提示词有官方模板守着、参考图逐镜匹配——生成环节不许即兴。手动模式与自动化模式共用同一套前期纪律，区别只在执行者是人还是调度 Agent。它和漫剧 Skill 体系（专家库 AI 漫剧全流程）的区别：那套是技能包驱动的通用体系，本法是纯本地 H3 链路的双模式落地法，成本结构与调度方式都不同。

## 何时用 / 何时不用

- 用：有可跑本地 H3 的电脑、题材任意、要连续出集且预算敏感时；能接受前期把剧本、分镜、资产做细时。
- 不用：没有本地 GPU 环境（本法的前提是本地 ComfyUI＋H3 节点已验证可跑）；只做一条短片试水——前期资产与表格成本摊不回来；赶工且接受云端抽卡成本时，走云端路线更快。

## 方法步骤

1. **搭链路**：Codex（调度、提示词整理、逐镜生成）＋ ComfyUI（图像生成与工作流）＋ 本地 MiniMax H3（FeiHouEasyH3 节点，非云端 API）。安装与节点部署可由 Agent 代办，但要用哪份工作流必须由人指定，**不许 Agent 自创工作流**。
2. **剧本拆分镜提示词**：有剧本先拆分镜，没有先让 AI 写。每镜提示词越具体，后续一致性越稳——这是全流程的第一道质量关。
3. **资产先行**：人物、道具、场景三类资产在生分镜图之前单独做完，禁止生成时临时设计（变形、穿帮的源头）。人物角色图用固定版式：左正面半身、右 1 无头正面全身、右 2 侧面无头全身、右 3 后侧有头全身。
4. **九宫格分镜图**：把角色图＋道具图＋场景图＋每镜首帧提示词一并提交生成九宫格分镜图。铁律：**每次生成都重新提交全部垫图**——模型记不住远期垫图，它声称记得也不能信。逐格验收：人物外貌服装、站位朝向、场景布局、道具完整、肢体异常（多手多脚粘连）、前后空间与动作衔接；问题格单独修改，不带病进入视频环节。
5. **H3 提示词纪律**：视频提示词必须按 MiniMax H3 官方 SKILL 模板组织（可细化、不可改结构，尤其是人物定义、声音设定、说话人标记与对白格式）——H3 极吃模板，不按规范会出现字幕、错误对白、擅自加台词。语言分工：画面描述、人物动作、镜头运动、约束条件用英文，人物对白保留中文。每镜整理八项再生成：景别/机位、画面内容/动作、情绪/表演、站位/朝向、光线/色调、建议时长、对白/声音、首帧提示词。
6. **自动化装配（切换到 Agent 调度时）**：素材进项目文件夹并用正式命名；分镜 Excel 里场景名、人物名与素材文件名严格一致，不一致建别名映射；SKILL.md 入项目且锁定。指令序列依次为：环境检查（ComfyUI 可连、H3 节点可用、工作流文件存在，缺项先修不跳过）→ 建项目结构 → 素材就位检查 → 宫格自动拆分（九宫格拆九张独立首帧，人工查边界防串格；六宫格按 3×2 拆）→ 建分镜表（**一行一镜头、一张首帧一镜头**，不许把连续镜头并行）→ 接入 SKILL 为每镜生成独立提示词 → 自动匹配每镜参考图 → 配置已验证的工作流。
7. **单镜试产再批量**：先生成镜头 001 并按验收标准过一遍，全过才串行批量生成全集。每镜至少生成 5 秒再剪到定时长（作者两遍采样工作流的实测处置：短于 5 秒曾出现二采尺寸不匹配；换工作流时此条要重新验证）。
8. **断点续跑与废片处置**：中断后回到项目目录，一句指令续跑剩余镜头，不从头开始；废片单独重跑对应镜头。人的岗位只剩：审片、定位废片、微调重制。

## 提示词与模板

- 分镜 Excel 模板：一行一镜，列含镜号、首帧文件、景别/机位、画面/动作、情绪/表演、站位/朝向、光线/色调、时长、对白/声音、参考图（角色/场景/道具）；
- 角色图版式模板：`左：正面半身 | 右1：无头正面全身 | 右2：侧面无头全身 | 右3：后侧有头全身`；
- 十一步指令的骨架（全文见出处）：环境检查 → 项目搭建 → 素材检查 → 宫格拆分 → Excel 分镜表 → 接入 SKILL → 素材匹配 → 工作流配置 → 单镜测试 → 串行批量 → 断点续跑；
- 防乱说话兜底：仍出现乱对白时，把提示词进一步改成全英文、只保留中文台词。

## 验收标准

- 分镜图逐格查：一致性、站位、场景、道具、肢体、衔接六项，问题格不下行；
- 单镜验收七项：首帧正确、人物形象正确、场景不穿帮、动作合分镜、对白不乱说、视频音频完整、MP4 成功落盘——七项全过才开批量；
- 拆分边界人工查一次：九张首帧不得裁进隔壁镜头内容；
- 命名一致性：Excel 中的场景名、人物名与素材文件名逐一对得上（或别名映射齐全）；
- 成片抽查废片率：废片只重跑单镜，不整集返工。

## 边界与风险

- 本法成立的前提是本地环境已验证（ComfyUI 本地 API、FeiHouEasyH3 节点、已验证工作流）；环境没跑通前不要进入自动化，先手动走通一集；
- 「至少 5 秒」与二采尺寸问题是作者特定工作流的实测结论，原文已注明不代表所有 H3 工作流——引用时保留这个限定；
- 自动化模式会消耗调度 Agent 的 Token（原文提醒自行斟酌）；7×24 无人值守时，验收关口在事后审片，废片成本是电费与时间，要有心理预期；
- H3 官方 SKILL 模板是外部规范，版本更新时以官方最新模板为准，项目内锁定的副本要跟着升级并重验单镜。
