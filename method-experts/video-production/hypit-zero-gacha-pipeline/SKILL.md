# 零抽卡视频编译管线（专家模式）

- 领域：视频制作
- 来源：Aomyying（小A本人）X 长文《Codex+hypit一键复制爆款视频实现零抽卡》实操账本，工具本体 hypit-ai/hypit，收录于西瓜小本本第 363 条；vault 笔记《Codex 加 Hypit 复刻爆款：零抽卡视频工作流笔记》
- 核验状态：Hypit 仓库已实测（28,353★ / 3,287 forks，TypeScript，许可证未标标准 SPDX）；成本单价、35 分钟工时、废片率降幅为作者自述，未独立核实
- 适用：用 Codex + Hypit 编译系统复刻爆款或原创短视频，把每一次返工拦在最便宜的环节，实现近零抽卡与逐分钱可算的成本

## 定位

这个专家的核心纪律是**分层止损**：生图成本远低于视频渲染，所以文字能修正的问题绝不带到绘图，图片能识别的穿帮绝不带进视频 API。调度实例（Codex）负责执行，人类只在四个节点拍板：脚本、分镜与样图神态、积分预算、成片。每个付费动作之前都有一道机器可执行的预检，每次审核都换一个不带历史上下文的新实例——跟久了的实例会自己脑补补齐逻辑缺口，新实例读不通的地方才是真漏洞。

## 何时用 / 何时不用

- 用：短视频复刻与原创、口播切片、连续栏目（如双人播客系列）；已有 Codex/Claude Code 与可用的 H3 或同级视频模型渠道；对单条成本敏感、需要账目可复现的生产。
- 不用：追求一镜到底长镜头、复杂手部交互/镜面/画面文字为主体的题材（模型短板，流程绕得开一时绕不开物理）；高分辨率商业交付且要求渠道稳定时，网页免费额度桥接不适用，应切付费 API。

## 方法步骤

1. 环境与需求确认：调度实例先确认主题、片长、画幅、预算上限、配乐字幕、参考视频与图像源，并自检 Hypit 环境与视频渠道密钥；异常立刻停工报错，不带病开工。Hypit 安装：`npx skills add hypit-ai/hypit -g`。
2. 剧本独立审：初稿完成后拉起全新、无历史上下文的审核实例，按附录审核提示词查五点（现实逻辑与道具来源、一句话主旨、前 3 秒冲击、多人反应不得同步、高风险镜头标记）；拿到「审核通过」才许生图。审脚本的人类口径同为五点，另加一条：避开当前视频模型的天生短板清单。
3. 分镜：复刻项目用拆片工具（media cut / media tile）提取原片切镜时间与景别骨架直接复用；纯原创按六条经验设计（机位杂、画面有运动但不乱晃、景别交替、运镜有情绪理由、三分构图留视线、配色先定并以黑白模式验明暗）。
4. 定妆与样帧：先出角色三视图设定（正/侧/典型表情，发型配饰画死），人类肉眼确认神态；再逐镜头出参考样帧，把人物、站位、道具、背景全锁死在图中——样帧的文字描述先过审核实例查构图衔接，再消耗生图额度；同场景多镜头基于上一张合格图局部改。样帧阶段拦截约八成穿帮（作者自述）。
5. 逐秒指令与预检：视频指令按秒拆微动作、多写正向少写否定，首 0.2 秒与样帧静止对齐（模板见下）；提交前强制三连预检 `hypit check / plan / pricing` 输出 COSTS.md 成本报表，再由独立审核实例核对图文一致性，人类批准预算后才发起生成。
6. 生成与止损：先低分辨率跑通全片、定稿再超分；难镜头单独先测；超时或中断用 Build-ID + status/logs/get 捞回已生成素材并锁定合格片段。瑕疵处理优先级固定：时间轴裁切掐头去尾（零成本）→ 画面裁剪/变速/缩放（仅边角静态瑕疵）→ 动态硬伤才单段重跑；旧版本片段全部保留作备选，严禁整片重跑，严禁自动充值或无限重试。
7. 合流：编译引擎 + FFmpeg 拼接、转场、超分、字幕/BGM；全片统一色温色彩校准（不同批次片段天生有色差）。
8. 双重复核与归档：审核实例读不了动态视频——先抽高密度序列帧网格（media tile）给全新审核实例查静态穿帮，人类再肉眼全片查动态问题（崩坏、闪烁、动作异常）；通过后归档剧本、分镜、提示词与踩坑记录，供同类项目复用。

## 提示词与模板

总调度系统提示词（每个新项目开工即下发，全文存于 vault 笔记附录 A），要点：分工矩阵（调度/图像源/视频模型/编译修剪各管一段）、四道停止线（脚本未通过不许生图、定妆未确认不许样帧、预检与 COSTS.md 未完成不许调视频 API、余额不足立刻停工粗剪已有片段）、恢复纪律（Build-ID 捞进度）、能力边界自陈（调度实例不能解析动态视频，必须抽帧并提醒人类肉眼复查）。

剧本审核提示词（要点）：以「第一次审稿的外部审核人员」身份只读脚本、不圆场不改稿；五项检查后按逐条列出，最后只输出「审核通过 / 退回重改」。全文存于 vault 笔记附录 B。

逐秒视频指令模板（六段）：与样帧色调严格一致；时长/分辨率/景别机位运镜；；对齐角色设定图；0.0–0.2s 与首帧样帧静止对齐 → 逐秒动作神态环境变化 → 末段动作收住定格；面部服装不变、道具位置固定、无字幕无水印。全文存于 vault 笔记附录 C。

## 验收标准

- 剧本有独立审核实例的「审核通过」记录，且高风险镜头已标记并有绕行或接受方案
- 每镜头样帧经人类肉眼确认（神态、站位、道具、背景与设定一致）
- 发起任何付费生成前，COSTS.md 已生成且经人类批准；单段重跑前有预估积分并经确认
- 成片过序列帧静态审核 + 人类全片动态复核两道
- 全部旧版本片段保留、无整片重跑记录；项目资产（剧本/分镜/提示词/踩坑）已归档

## 边界与风险

- 作者自述数字：渠道单价约 ¥0.08/秒（Compshare 积分包口径）、复刻案例 28 秒约 ¥2.8 与 35 分钟、废片率降低近 90%——均为作者口径，未独立核实，引用时标注
- 网页免费额度桥接（浏览器扩展操控登录会话）稳定性与合规面弱于付费 API，配额耗尽必须停工，不得拿不合格素材往下跑
- Hypit 仓库未标标准 SPDX 许可证，商用前先读仓库 LICENSE 原文
- 视频模型短板（复杂手部、画面文字、镜面倒影、剧烈变光、多人同框）是流程绕行项而非已解决项；硬伤单段重跑的积分该花就花
