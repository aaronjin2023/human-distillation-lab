# 高速打斗运镜专家（专家模式）

- 领域：视频制作
- 来源：李悦君（@JunJun0321A）发布的 Skill「high-speed-combat-camera」全文，收录于西瓜小本本第 117 条；vault 笔记《高速打斗运镜 Skill 笔记》
- 核验状态：Skill 全文已从原帖取回并存档于 vault 笔记，公式与数值按原文；生成效果为作者设计口径，未独立核实
- 适用：给 Seedance 类视频生成模型写高速打斗、割草清场镜头时，把「人在动、镜头在发呆」改成镜头跟随、制造并放大速度的一镜到底运镜

## 定位

这个专家把打戏镜头当成一套可拼装的组合系统：档位 × 机位公式 × 拼接公式。核心信条是一镜到底、不硬切——镜头不是「拍完动作」，而是只服务三件事：看清动作轨迹、强化攻击方向与力量、用镜头速度制造压迫感。总纲一句话：让镜头贴着动作轨迹走、跟着攻击方向转、在命中点短暂停、在结尾留下下一击的空间。

## 何时用 / 何时不用

- 用：单挑打斗、群怪割草清场、追击连招等需要高速动作运镜的视频生成；用户提到打斗、割草、战斗运镜、动作镜头时即触发。
- 不用：文戏、慢节奏情绪镜头、需要硬切蒙太奇的剪辑型需求；本模式的所有公式都建立在「一镜到底」前提上，与分镜硬切的工作流不兼容。

## 方法步骤

1. 定档：先从速度四档里选本镜基调——Swift（快速跟拍）/ Whip（甩镜，落点轻微凝滞）/ Gentle（缓慢后拉）/ Shock（震动 0.3 秒）。
2. 套拼接公式组镜：1 个起手机位 + 1–2 个过程运镜 + 1 个命中处理 + 1 个尾帧 + 材质细节（前景草叶、碎石、拖影、运动模糊、冲击波），缺一环不算完整镜头。
3. 命中处理必做：命中瞬间特写落点，画面 0.15 秒凝滞锐化、碎屑悬停，随后轻微震动恢复运动——用这一停换「打中了」的实感。
4. 尾帧必留后手：停在下一击的前摇蓄力姿态（如中近景锁定低姿态蓄力 + 缓慢后拉），绝不停在摆 pose 的造型帧。
5. 环绕只绕交错点：高速错位时环绕攻守交错点半圈，焦点随攻守在两者间切换，不绕无关空间。
6. 输出写成一段连续描述：整镜写成一整段连续中文，不用分镜序号——分镜号会诱导模型自动切镜，破坏一镜到底。
7. 割草镜头额外交代两件事：主角的推进路线 + 敌人成片倒下；AOE 爆发用「特写锁冲击中心 → 急速后拉至全景」展开冲击半径。

## 提示词与模板

### 单挑机位公式（10 式）

1. 起手冲刺＝低机位全景 + 快速推镜，FOV 轻微拉宽
2. 高速错位＝环绕交错点半圈 + 焦点在攻守间切换
3. 腿法轨迹＝贴地跟拍，镜头低于膝盖
4. 腾空＝低机位仰拍 + 急速上摇，镜头轻微滞后于动作
5. 命中瞬间＝特写落点，画面 0.15 秒凝滞锐化、碎屑悬停，随后轻微震动恢复运动
6. 被震飞＝急速后拉 + 长拖影
7. 追击连招＝贴身侧移跟拍，每击镜头轻微前弹
8. 魔物反击＝反向推镜、焦点立刻切到威胁点
9. 高空压制＝仰拍 + 垂直拉镜跟随下砸
10. 尾帧＝中近景锁定低姿态蓄力 + 缓慢后拉，停在下一击前一瞬，不停在摆 pose

### 割草公式（群怪清场 5 式）

1. 入场破阵＝低机位广角横扫
2. 范围横扫＝贴腰线甩镜，掠过 3–5 名敌人被击飞
3. 穿透连斩＝跟拍穿阵、焦点前锁
4. AOE 爆发＝特写锁冲击中心，随即急速后拉至全景，震动 0.3 秒
5. 割草尾帧＝缓慢后拉，露出满地倒伏与未散烟尘

### 速度档位（4 档）

- Swift：快速跟拍
- Whip：甩镜，落点轻微凝滞
- Gentle：缓慢后拉
- Shock：震动 0.3 秒

### 景别搭配要点

- 起手对冲用全景；踢击命中用特写；AOE 用「特写→全景」急速后拉展开。

### 拼接公式（组镜模板）

一镜到底 ＝ 1 个起手机位 + 1–2 个过程运镜 + 1 个命中处理 + 1 个尾帧 + 材质细节（前景草叶 / 碎石 / 拖影 / 运动模糊 / 冲击波），输出为一段连续中文描述，少用分镜序号。原 Skill 另含模板 7 条与完整串联示例 2 条（单挑、割草各一，约 6–8 秒），全文存于 vault 笔记所引原帖。

### 总口诀

单挑：低机位冲，贴地跟；环绕错，甩镜追；特写打，震动停；后拉开，尾帧续。
割草加：广角扫，穿阵跟；弧线掠，后拉清。

## 验收标准

- 全镜一镜到底，无硬切、无模型自动切镜（检查输出文本里有没有分镜序号）。
- 命中点有 0.15 秒凝滞锐化 + 碎屑悬停 + 震动恢复，缺一项即「没打中感」。
- 尾帧停在下一击前摇蓄力，不停在摆 pose。
- 拼接公式五环齐全：起手 / 过程 / 命中 / 尾帧 / 材质细节。
- 环绕只绕交错点，焦点随攻守切换。
- 割草镜头同时交代推进路线与成片倒下；AOE 有特写→全景后拉。

## 边界与风险

- 本模式为提示词侧的运镜设计，效果取决于目标视频模型对连续运镜描述的执行力；作者口径的效果未经独立核实。
- 公式按 Seedance 类模型的脾气编写，迁移到其他视频模型时档位与凝滞时长可能需要回调，不要当作跨模型通用参数。
- 镜头轻微滞后、每击前弹等细粒度控制属于提示层引导，单次生成不保证精确命中，需留抽卡余量。
