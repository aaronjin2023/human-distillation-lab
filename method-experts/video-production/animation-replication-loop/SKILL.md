# 动效复刻逐帧验收闭环（专家模式）

- 领域：视频制作
- 来源：NiazMorshed2007/reanimate（GitHub，1,262★/MIT，2026-11-06 实测），经 GitHubDaily（@GitHub_Daily）帖收录于西瓜小本本第 337 条；vault 笔记《reanimate：录下原版逐帧对账的动效复刻 Skill 笔记》
- 核验状态：仓库 README、实例数据与限制均已逐项核对；帖面通过线（80ms / 2%）与仓库口径一致，仓库实例数更严；西瓜未实跑
- 适用：复刻网页动效（入场、悬停、滚动、3D 场景）到自己的项目，且要求节奏与缓动可量化对齐时

## 定位

这是一个「自己录自己比」的动效复刻验收师。普通做法是让 Agent 看一眼参考动效、写一遍代码就宣布完成，节奏、缓动、落点全凭感觉，必然不对。本专家的出发点是：**复刻的可信度来自同法录制的逐帧对账，而不是实现者的自评**——把原版录下来变成规格，把复刻版用完全相同的方式录下来，两边量时间误差与像素差，不过线就继续改，直到数字达标。

## 何时用 / 何时不用

- 用：目标动效在公开网页上（或有录屏/mp4/gif/Lottie），要落进已有前端项目（CSS / Framer Motion / GSAP / three.js 等），且「像不像」需要拿出数字时。
- 不用：动效只是灵感来源、不需要对齐时（直接写即可，走本闭环是浪费）；目标在登录墙后又拿不到录屏时；影视级视频动效（这是网页动效工具，不是视频合成）。

## 方法步骤

0. **备料**：确定输入形态——网页链接（首选）、录屏、mp4、gif、Lottie 五选一；定下验收档：默认档（时间误差 ≤80ms）或「一模一样」档（再加像素差 ≤2%、字体/颜色/间距对齐）。
1. **录原版**：用 Playwright 按真实触发方式录制（加载、滚动、悬停、离开、指针路径、拖拽、点击、无触发）：产物包括视频、逐帧画面、声明动画、计算样式、字体清单、所用动画库、逐帧元素轨迹。录法即规格——换一种录法，两边都不可比。
2. **读帧成规格**：把轨迹与关键帧读成可实现参数（时长、延迟、缓动曲线关键点、位移/缩放/透明度曲线）；弹簧动效按过冲量与稳定时间反推参数（不是读源码）。
3. **按栈重建**：沿用项目现有技术栈实现，不引入新库；字体、颜色、间距先对齐再谈动作。
4. **同法录复刻版**：触发方式、视口、录制参数与第 1 步完全一致。
5. **逐帧对账**：逐帧比时间误差与像素差，输出差异定位（哪一帧、哪个元素、差多少）；任一指标过线即回第 3 步修，通常 2–5 轮收敛。
6. **Canvas/WebGL 专项（可选）**：纯像素画布改用 `--gl` 追踪绘制调用——挂 three.js / Pixi / PlayCanvas / Babylon / OGL 场景图，导出 shader 源码、uniform 常量、逐属性动画曲线再拟合对比；配 `--clock virtual`（虚拟时钟逐帧推进 + 随机数播种）使两次录制可达字节一致，消除 GPU 速度差异。

## 提示词与模板

- 调用形态：`/reanimate <目标：链接或文件+时间段>，into <项目文件路径>`；可加档位词，如 `match it exactly` 走「一模一样」档。
- 对账报告模板：每轮输出「最大时间误差（ms）/ 像素差占比（%）/ 最差帧与元素 / 本轮改了什么」，没有这四项不算完成一轮。

## 验收标准

- 默认档：全部关键动效时间误差 ≤80ms。
- 一模一样档：时间误差 ≤80ms 且像素差 ≤2%，字体、颜色、间距逐项对齐。
- 参照仓库实例的实测水平（clerk 卡片 40ms 内 / <0.6%；liveblocks 面板 0ms / 0.7px；resend 魔方 25 秒精确 / 0.11%）——达不到这个量级时，先检查录法一致性，再怀疑实现。

## 边界与风险

- 登录墙后的页面、YouTube、Loom 不能直录，必须喂录屏；iframe 内的 canvas 需要 iframe 自身的 URL。
- 工人（Web Worker）时钟仍走真实时间，虚拟时钟只覆盖主线程与页面随机源；无法复现原站随机生成器时，粒子类动效改用模糊比对（密度、颜色、运动），不逐点对。
- 默认录制走软件渲染（SwiftShader）保跨机一致，慢；`--gpu hardware` 更快但引入机器差异。
- **权利边界（仓库自陈，必须遵守）**：原站的字体、图片与代码仍归其权利人；本方法产出的是「学成自己的起点」，商用前须确认所复制元素的权利状态。
- 工具运行环境：Bun 1.1+、macOS/Linux（Windows 未测试）；首跑会下载静态 ffmpeg 与 Playwright Chromium。
