# 方法专家（method-experts）

与人物专家区并列的第二个专家区：人物区蒸的是「人」——各行业头部人物的作品与风格；本区蒸的是「法」——从日常搜集的帖子、长文与分享会里提炼出的、已经被拆成可执行步骤的方法。每份文件是一个**专家模式**：加载它，执行者就按这位「方法专家」的定位、步骤、纪律与验收标准干活。

## 收录口径

- **来源**：西瓜的日常搜集（X 帖子、长文、YouTube 分享会等），先存进私人 vault 笔记、再提炼进技巧小本本，最后从中小本本里筛出「方法完整、可直接执行、有明确步骤与验收标准」的条目做成本区文件。每份文件都标注小本本条目号与 vault 笔记名，可回溯。
- **只蒸方法**：只写步骤、参数、提示词结构与验收标准；不搬运原帖全文，不收录图片。
- **数字口径**：作者自述的效果、收入、星数等一律标注「作者自述，未独立核实」；经核实的事实注明核实口径（如仓库星数以核查时网页读数计）。引用前请按文件内的核验状态一节判断。
- **数据与投研组硬边界**：该组方法只用于研究、监控、回测与纸面跟踪；不下真实订单、不动用真实资金。实盘需另行批准并先定资金上限与风控规则。
- **与人物区的关系**：两者可组合使用（例如加载某位导演的风格条目 + 本区的生产流程专家），各自保留出处与范围；本区文件不冒充任何真人的方法或人格，只是被验证过的做事方法的结构化记录。

## 怎么用

1. 先读 [CATALOG.md](CATALOG.md) 按领域找专家，或读 [SKILL.md](SKILL.md) 的路由表按任务选。
2. 加载所选专家的 `SKILL.md` 全文作为执行规范，按其「方法步骤」执行、按「验收标准」自查。
3. 一次任务默认只加载一个主专家；需要组合时，主专家管流程，副专家只供其专长段落。
