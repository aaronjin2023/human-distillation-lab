# 风格拆成数字规则专家（专家模式）

- 领域：图像设计
- 来源：观默（@guanmo_ai）「每天一个设计风格」系列·中世纪现代（Mid-Century Modern）一期，收录于西瓜小本本第 309 条；vault 笔记《中世纪现代风代码还原：纸的物理五规则笔记》
- 核验状态：仓库 guanmo-ai/design-style 已定位并核实（168★/7 forks/151 commits/19 个 Release，2026-10-20 建仓、仍活跃；帖称开源的短片＋风格图＋指南＋过程＋设计令牌属实）；帖称「第 13 期」与仓库内编号 017 不一致，原因不可核；仓库无标准开源许可证，授权为作者自述条款
- 适用：把一个历史/视觉风格（或客户嘴里的「复古温暖感」）翻译成代码与生图都能执行的参数规则，并固化成可复用的风格资产

## 定位

这个专家不写形容词，只写数字：风格 = 一组可测量的参数（抖动幅度、倾斜角、阴影色值、乘算关系、形状清单、底色占比）。每条规则都要能回答「偏离多少算不对」。还原的介质观是「物理隐喻优先」——先决定这个风格里每块色面在现实中是什么（一张能拿起来的纸），空间、阴影、色彩关系都从这个隐喻推导，而不是逐个效果调参。

## 何时用 / 何时不用

- 用：要用代码（Remotion/three.js/SVG）或生图复现一个明确的历史风格；要把风格沉淀为设计令牌跨视频/图片/网页复用；接到的需求只有形容词、没有规格时，先走本法翻译成参数再动手。
- 不用：风格本身没有可考的历史形态、纯靠即兴探索的创作；写实摄影风的还原（本法的形状库与叠印逻辑是平面印刷时代的工具）。

## 方法步骤

1. **选风格、先定物理隐喻**：确定目标风格与时代出处（如中世纪现代＝1950 年代平面设计）；再定一句介质隐喻统摄全篇——本例：「每一块色面都是一张能拿起来的纸」。
2. **轮廓参数化（剪刀代替尺子）**：不用完美直线，沿轮廓做 1–1.6px 的长波微抖，尖角保留；每块面微歪 ±3°。写规格时给区间不给感觉词。
3. **空间参数化（影子即高度）**：用物理隐喻定空间——纸离桌面越高，影子偏移越远、模糊越大；阴影色用暖棕 #3A1C0C 代替纯黑。一条规则定全片空间感，不逐元素调影。
4. **色彩参数化（叠印出第三色）**：禁用半透明渐变；两色重叠区用颜色乘算（multiply）生成第三色，写死配方——本例：黄 × 粉 = 橘 #F55F1E。色彩关系由印刷逻辑决定，不靠调色板手感。
5. **形状库（时代签名）**：列出该时代的标志形状作白名单——本例：腰果、回旋镖、星芒、球与棍；明确告别不属于该时代的默认形状（现代 UI 的圆角矩形）。形状本身即风格签名。
6. **底色与点缀比例**：暖白纸底 #FBF3E3 占 40%，点缀色清单写死——本例：番茄红、向日葵黄、Girard 粉、绿松石、钴蓝。
7. **固化为风格资产（系列化结构）**：每期/每种风格固定产出五件——① 15–20 秒动效短片（Remotion/three.js，画面、配乐、音效全部代码生成）；② 手写 SVG 风格图（本例 4 张）；③ 风格指南（历史/规则/色板/字体/AI 提示词）；④ PROCESS.md 制作过程；⑤ 设计令牌 tokens（ts/css/json 三格式，视频/图片/网页三端共用同一套数值）。

## 提示词与模板

参数表模板（任何风格先填这张表再动手，数值栏不许留空、不许写形容词）：

```text
物理隐喻：<每块色面在现实中是什么>
轮廓：抖动 <x–y px，长波/短波>；尖角<保留/圆化>；块面倾斜 <±n°>
空间：阴影偏移与模糊 = <由什么变量决定>；阴影色 <色值>
色彩：重叠规则 <乘算/其他，禁项写明>；配方 <色A × 色B = 色C（色值）>
形状库：<时代标志形状白名单>；禁用形状 <清单>
底色：<色值> 占 <百分比>；点缀色 <清单+色值>
```

已填样例（中世纪现代，即上表在本期的答案）：物理隐喻＝可拿起的纸；轮廓抖动 1–1.6px 长波、尖角保留、倾斜 ±3°；阴影随离桌高度变远变虚、暖棕 #3A1C0C；黄 × 粉乘算 = 橘 #F55F1E、禁半透明渐变；形状库＝腰果/回旋镖/星芒/球与棍，禁圆角矩形；纸底 #FBF3E3 占 40%，点缀＝番茄红/向日葵黄/Girard 粉/绿松石/钴蓝。

## 验收标准

- [ ] 参数表六项全部填了数字、色值或清单，无「温暖」「复古」「高级」等形容词残留
- [ ] 轮廓抖动落在指定区间内且尖角保留；块面倾斜不超 ±3°（本例规格，其他风格按自填表）
- [ ] 阴影全部由同一条物理规则生成，阴影色为指定色值而非纯黑
- [ ] 重叠区出现乘算第三色，无半透明渐变
- [ ] 画面只用形状库白名单内的形状，无禁用形状混入
- [ ] 底色占比与点缀色清单与参数表一致
- [ ] 若做成系列资产：短片、风格图、指南、PROCESS.md、tokens 五件齐全，且 tokens 三格式数值一致
