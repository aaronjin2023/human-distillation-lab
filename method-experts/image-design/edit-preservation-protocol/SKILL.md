# 连续编辑保持性测评与编辑提示词范式（专家模式）

- 领域：图像设计
- 来源：知识猫（@GeekCatX）长文《Seedream 5.5：可能是目前局部修改最强的 AI 模型》全文，收录于西瓜小本本第 425 条；vault 笔记《Seedream 5.5 深度测评：20 轮连续编辑保持性与 22 个实测提示词笔记》
- 核验状态：长文全文已逐段核读；模型名（Seedream 5.5 / Images 2.6）与全部实测数字为作者口径，未独立核实；本专家沉淀的是测评协议与提示词范式，不背书具体模型排名
- 适用：评估图像编辑模型的连续修改稳定性；给任何编辑模型写「只改一处、其余全保住」的编辑指令

## 定位

编辑模型的真实战场不是第一张图，而是第二十次「再改一点」：每改一次，脸、道具、背景、光色都跟着漂移，挑中的那张图就找不回来了。本法分两半：测评半——用接力式连续编辑 + 非目标保持项核对，把「漂移」量化出来；提示词半——编辑指令按「保留清单先行、只写一件变化」写，让模型没有自由发挥的余地。

## 何时用 / 何时不用

- 用：选型图像编辑模型；电商换色改款、视觉方案反复调整等要多轮接力的活；给编辑模型下精确指令
- 不用：一次性生成、无后续编辑需求的图；需要大幅重构画面的改图（那是重绘，不适用保持性框架）

## 方法步骤

1. **接力测评**：选一张信息密度高的图（人像 + 道具 + 背景标识 + 明确光色），只改一个目标（如衣服），连续改 N 轮（作者用 20 轮），每轮接上一轮的原文件继续，不换图、不重抽；对照模型同图同指令。
2. **双层评分**：第一层数目标命中轮数；第二层在若干检查点（作者取第 5/10/15/20 轮）核对五类非目标保持项——面部与发型、手部与所持物、背景标识、非目标细节（小道具）、构图与光色——统计「无明显变化」项数。两层分开报，不合成总分。
3. **交底偏差**：原图来源（是否由对照方生成）、两边原生尺寸、工具后端变体是否披露——都写进结论；保持性数字只描述可见变化，不外推成全题材排名。
4. **编辑提示词范式**：开头一句锁定「以唯一参考图为编辑原图，只改变 X」；接着逐项列保留清单（可见脸形五官、发型、服装款式与印花、姿势与接触点、完整构图、场景摆设，并明写不换人、不换装、不移动物体）；然后只写变化本身的物理细节（光源方向与位置、轮廓光形态、阴影走向与边缘、暗部可辨程度）；最后锁风格基调与输出规格，收尾「只输出一张编辑后的成图」。
5. **参考图分工**：姿势线稿只提取骨架、肢体方向、透视与画面占幅，不继承人偶外形；多参考时给每张图编号并声明优先级（线稿姿势为最高优先级，成图只供身份与服装）。
6. **两步纠错链**：第一步逐项纠正（把要求写成可核对条目：位置、占幅百分比、遮挡关系）；第二步若只需改取景，不重新生成——把「严格裁剪 + 等比放大」当编辑指令，给出精确裁剪矩形坐标并声明唯一允许变化是裁剪与缩放。
7. **交付验收**：文字逐行核对（文案锁定类任务）；信息图实测图形与数值的比例对应（作者验条长偏差）；文件类交付验文件本身（如透明 PNG 必须真的带 alpha 通道）——模型自称达标不算数。

## 验收标准

- 测评报告含双层数字与偏差交底，不给单一总分排名
- 编辑指令中保留清单可逐项核对，变化项只有一件且写到物理细节
- 纠错优先用指令纠错与裁剪指令，不整图重抽
- 交付物经文件级/像素级核验，而非目测「差不多」

## 边界与风险

- 作者实测中失败的案例（透明通道未交付、拼贴约束未落实、硬光细节不到位）说明：保持性再好的模型，文件格式与硬约束类要求仍会翻车，必须逐项验
- 20 轮接力与保持项清单是作者的测评设计，轮数与类别可按自己的业务图调整，不要机械照搬后当行业标准引用
