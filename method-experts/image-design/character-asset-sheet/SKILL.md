# 人物资产图建标专家（专家模式）

- 领域：图像设计
- 来源：Alex · Selin（@Alexvhyn）长文《瑟琳教你 AI 剧——关于人物资产图的一些事》，收录于西瓜小本本第 137 条；vault 笔记《人物资产图建标法：AI 短剧角色参考全套笔记》
- 核验状态：长文以图板为主，各板的文字核对口径已完整取到；「减少换脸换衣与细节漂移」为作者的方法主张，未独立实测
- 适用：为 AI 短剧的专属人物建立一整套可调用的资产图标准（脸、表情、角度、姿势、服装、手、材质七板），让人物在任何镜头里保持连贯

## 定位

这个专家是「先建标准、后做生产」派：定妆四视图只钉住脸和服装，本专家把表情、头部角度、姿势、手部、服装结构、材质全部预制成标准件，出镜时按镜头需求组装参考集，再以资产图校对首帧、尾帧、关键帧后才进视频。一条最易错的区分刻在骨子里：抬头/低头是人物动作，仰拍/俯拍是机位关系，两者必须分开标注——混标是角度参考最常见的错源。

## 何时用 / 何时不用

- 用：长线 AI 短剧/系列视频，同一人物要跨大量镜头复用，且会出现表情变化、多角度、动作戏、手部或服装特写。
- 不用：一次性单图或只需要脸＋服装锚点时——用真人角色定妆四视图（小本本第 48 条）＋脸部设定表（第 29 条）即可，建七板是浪费；姿势的大批量量产另有姿势图谱生产法（小本本第 106 条）互补，本专家管「建标」不管「量产」。

## 方法步骤

1. **建核心脸卡（板①）**：从一张标准脸出发，以骨相、眼距、鼻梁、发际线、小痣为锚；后续一切比较统一取景、光线与发型；近景看细节，远景结合头肩与身体一起判。
2. **建表情板（板②）**：按四维拆表情——眉毛（上扬/下压/放松）、目光（正/侧/上/下）、嘴型（闭合/微张/张开/紧抿）、面颊（提拉/紧绷/下落/放松）；每种情绪做轻、中、强三档，结合剧情判断该用哪档；对白嘴型随具体台词变，不用固定嘴型套对白。
3. **建头部角度板（板③）**：正面看眼距与鼻唇关系，左右转看近远眼、鼻翼与面颊透视，侧面看额—鼻—唇—下巴的连续轮廓；**抬头、低头标为人物动作，仰拍、俯拍标为机位关系，分开标注**。
4. **建姿势板（板④）**：一格只表达一个主动作；每格核对头向与目标、接触、承重与重心，奔跑类结合动态平衡；肩宽、腿长与衣装保持连贯，动作符合人物气质。
5. **建服装配件板（板⑤）**：版型、接缝与挂点固定，褶皱随动作变（不随镜头乱变）；镜头涉及配件操作时，补齐扣合、取出、肩背接触的操作参考图。
6. **建手部板（板⑥）**：核对手指数、掌指连接、关节方向、拇指位置与左右比例；握持类核对接触与承重，交叠类核对前后遮挡。
7. **建材质局部板（板⑦）**：均匀光线下拍清缝线与材质，按结构补足角度，配色与主设计一致，按图名归入整板。
8. **出镜调用（组装参考集）**：每个镜头先给核心脸卡＋场景参考图打底；再按分镜加头部角度板、表情板、姿势板；遇手部特写或服装道具特写，再加手部板/服装配件板。
9. **校对后进视频**：以资产图生成并校对首帧、尾帧、关键帧，三帧过关才进视频阶段；视频阶段按模式提交对应帧图，多图参考模式可补人物与场景图。

## 提示词与模板

无固定提示词模板，按方法步骤执行；交付物是下面这张七板清单（建标时逐板打勾）：

```text
板① 核心脸卡：骨相 / 眼距 / 鼻梁 / 发际线 / 痣（锚点清单）
板② 表情板：眉 × 目光 × 嘴型 × 面颊，四维 × 轻中强三档
板③ 头部角度板：正面 / 左右转 / 侧面；动作（抬头低头）与机位（仰俯拍）分开标
板④ 姿势板：一格一主动作；头向目标 / 接触 / 承重 / 重心核对
板⑤ 服装配件板：版型 / 接缝 / 挂点；褶皱随动；操作镜头补扣合/取出/接触参考
板⑥ 手部板：指数 / 掌指连接 / 关节方向 / 拇指位 / 左右比例
板⑦ 材质局部板：均匀光、缝线材质清楚、按图名归整板
调用公式：每镜头 = 核心脸卡 + 场景图 +（角度/表情/姿势板按分镜加）+（手部/服装板按特写加）
```

## 验收标准

- [ ] 七板齐全且命名归整，任一镜头需要的参考都能按调用公式组装出来
- [ ] 脸卡锚点（骨相、眼距、鼻梁、发际线、痣）在各板中不走样；比较时取景、光线、发型已统一
- [ ] 表情板四维齐全、轻中强三档分明；对白镜头嘴型与台词对应
- [ ] 角度板中动作与机位分开标注，无「低头写成俯拍」类混标
- [ ] 姿势板一格一主动作，承重与重心成立，比例与衣装连贯
- [ ] 服装板版型、接缝、挂点跨格固定；手部板指数、关节、拇指位无误
- [ ] 每个镜头进视频前，首帧、尾帧、关键帧已用资产图校对通过

## 边界与风险

- 建标成本在前期：七板全建只对长线复用的人物划算；短线项目请降级到第 48 条定妆四视图。
- 本方法是作者在长文中给出的建标标准，各板的具体生成提示词未在长文中逐条给出（长文以图板为主），执行时每块板仍需结合第 48 条的版式写法自行落词。
- 「减少漂移」的效果口径为作者主张，未独立核实；实际服从度取决于所用生图/生视频模型的多图参考能力，换模型先用一两个镜头试调用协议再全量推进。
