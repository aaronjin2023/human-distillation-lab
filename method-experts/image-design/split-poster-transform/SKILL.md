# 上保真下转译对开海报专家（专家模式）

- 领域：图像设计
- 来源：蛋黄堡（@Hamburgerai）系列帖（基准与多数变体），收录于西瓜小本本第 93 条；技术档案分支为 Gadgetify（@Gdgtify），小本本第 302 条；vault 笔记《照片转绘黄油饼干海报提示词笔记》《上原图下技术档案对开海报提示词笔记》
- 核验状态：基准与各变体提示词均在原帖正文公开，样例经逐张核对（水墨四张、荧光笔四张、拍立得科尔马一张、纪念币两张宽度实测等）；个别执行偏差已在下文标注；变体九的工具口径为作者自述，未独立核实
- 适用：把一张照片做成「上半原图保真、下半同主体换介质/换形态转译」的 3:4 竖版对开海报

## 定位

这个专家只做一件事：一张照片进，一张对开海报出。信奉「骨架钉死、只换下半模块」——上下分工、留白比例、文字纪律、避免清单全部写死在提示词里，可替换的只有下半的转译目标。转译不是换滤镜：下半必须是同主体的另一种工艺物、载体或信息形态，景物位置与上半严格对应。宁可少给，不给错——凡词面要求与样例实测冲突的，以实测为准标注。

## 何时用 / 何时不用

- 用：单张照片（动物、食物、风景、建筑、人物穿搭等）想做成有设计感的纪念物式海报；同一骨架批量换转译目标出系列图。
- 不用：需要多图叙事或大幅改构图的创作；主体本身识别性弱、轮廓不清的照片（转译后必然不可辨）；下半要承载大量文字信息的排版任务（本骨架的文字纪律是「只许一处或结构化少量」，技术档案变体除外）。

## 方法步骤

1. **定版式**：竖版 3:4，上下严格 1:1 两区。先在一句总纲里写死比例与分工，后文所有段落不得与之冲突。
2. **写上半保真段**：保留原图主体身份、结构、姿态、真实质感与色彩氛围；只许轻微高级调色、可自然扩背景；不得拉伸扭曲主体；不加任何文字、边框。（技术档案变体更严：原图完全不动，禁裁切/重绘/加字/覆盖。）
3. **选下半模块**：从变体谱系（见下表）选一个转译目标，或按同一语法自创新目标——新目标必须能回答三件事：载体是什么、明暗/色彩靠什么材质逻辑映射、主体轮廓如何落位。
4. **写下半转译段**（按序）：
   - 提取主体最具识别性的轮廓与姿态重构，景物位置与原图一一对应；
   - 构图比例写死：转译物占下半宽度约 2/5、略偏一侧、大片留白是默认值（个别变体有自己的实测值，见谱系表）；
   - 配色规则二选一并写明：从原图提三色（主体主色＋背景辅助色＋材质本色），或按变体锁死材质本色/固定语义色；
   - 材质写实细节逐项点名（如气孔、颗粒、碎屑、粉感），并明禁塑料感与油亮反光；
   - 旧物/手作类变体另附质感清单（磨损、露底、笔触、投影等）。
5. **写文字纪律**：全画文字只许出现在指定位置、指定规格（内容、大小写、词数上限、字体气质），其余处零文字。纪念币变体是例外：文字是器物结构件（字环＋年份）。
6. **附避免清单收尾**：按所选变体列禁项（灰脏、满版纹理、写实插画、广告感、多物堆叠、塑料感等）。
7. **出图后逐项验收**（见验收标准），不合格先改词再重出，不靠多抽碰运气。

## 提示词与模板

骨架结构（基准·黄油饼干版的段落顺序，换转译目标时只替换第 3 段）：

```text
[总纲] 每张上传照片单独输出一张 3:4 竖版海报，上下两区严格 1:1。
[上半] 保留原始照片（主体身份、结构、姿态、真实质感与色彩氛围），
       只做轻微高级调色，可自然扩背景，不得拉伸扭曲主体，不加任何文字边框。
[下半] 提取照片中最具识别性的主体轮廓与姿态，重构为<转译目标>；
       构图守「一物 + 大片留白」（约占下半宽度 2/5、略偏一侧、落在浅色纸面）；
       暗部/亮部的材质映射规则<逐项写明>；
       配色从照片提取三色（主体主色 + 背景辅助色 + 材质本色），暖调明亮；
       材质写实细节<逐项点名>，拒绝塑料感与油亮反光。
[文字] 只许出现在<指定位置>：<内容规格，如主体全大写英文名、一词、≤10 字母、
       粗无衬线、小而克制、居中>，画面其余处零文字。
[避免清单] <灰脏、满版纹理、写实插画、广告感、多物堆叠……>
```

## 验收标准

- 上下严格等分（3:4 竖版）；上半主体、构图与原图一致，未擅自加文字、边框或新元素。
- 下半的转译物确为同一主体，材质细节逐项到位（气孔、颗粒、粉感等按变体规格），无塑料感与油亮反光。
- 转译物宽度与留白符合所选变体的规格；已知实测偏差：变体七（鹅卵石）成图宽度常达下半的 3/4–5/6，超词面规格，出图后须实测复核。
- 文字只出现在指定位置、内容与规格正确（如英文名一词、≤10 字母）；其余画面零文字。
- 分界实测参考：变体八（纪念币）两张样本实测上半占比 59.6%/60.0%，与词面基本吻合；变体九上半在实践中时而原图保真、时而影棚重拍，不完全稳定，采用变体九时须逐张核对上半是否为原图场景。变体十按其自身规格为 75/25 分割（非等分），验收时按 75/25 与「破框元素只许 1–3 个原图已有元素、下段缩略图为原图未编辑版」核对。

## 边界与风险

- 本家族只做「照片的工艺转译」，不做人脸替换或身份伪造；人物类变体须保留原图主体身份（变体九的纪律：盘中每件单品必须对应真实穿搭，不得发明）。
- 技术档案分支（#302）带反捏造纪律：禁止编造精确尺寸、公差、日期与性能数字，标注只许写真实可见特征。
- 工具与模型口径多为作者自述，未独立核实；同一提示词在不同模型上执行漂移明显，出图必须逐张验收，不能默认词面规格即成图规格。
