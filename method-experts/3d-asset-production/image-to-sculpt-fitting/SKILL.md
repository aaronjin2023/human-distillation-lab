# 单图拟合雕塑法（专家模式）

- 领域：3D 资产生产
- 来源：gokayfem 开源 Skill 仓库 image-to-sculpt（84★/MIT，GitHub API 实测），DEXTUNE（@dextune）X 帖介绍，收录于西瓜小本本第 414 条；vault 笔记《Image 2 Sculpt：单图拟合 3D 雕塑的 Agent Skill 笔记》
- 核验状态：仓库经 GitHub API 实测（84 星 / 3 forks / MIT / Python，2026-11-08 建仓）；帖中数字与 README 逐项对得上；38 轮拟合、验收效果与约 $2/例成本、仓库自带测试结论均为作者自述，未独立核实
- 适用：把一张图（AI 图、实物照片、抠图 PNG、草图）拟合成可打印、可进引擎的 3D 雕塑网格，背面不靠编、验收逐项可量化

## 定位

这个专家的核心信念是**单图建 3D 的关键不在生成，在把关**。让 Agent 照图雕模型，通病是背面全靠编、生成视图自称的角度不是真角度、一张坏视图就把真体积切掉。对策是三条纪律：照片能看见的表面由照片锚定（焦距、深度、法线、遮罩），不许自由发挥；生成视图永不轻信——先靠搜索配准出真实相机角度、再查与其它视图的一致性，不合格拒收并记理由；留一个视图在拟合前冻结、永不参与推动曲面，只在最后做验证。拟合本身小步多轮、全程留档，验收给逐视图逐项表，不给总分。最终交付的不只是一块网格，还有 Blender 回放出的整条建模延时摄影。

## 何时用 / 何时不用

- 用：单张图起步要出雕塑网格（摆件、角色、道具的打印件或引擎资产）；背面可信度与验收数字比出图速度重要；能接受每例约数美元的 API 成本与 Blender 5.2+ 环境。
- 不用：场景房间、头发丝级结构、透明/镜面材质（Skill 明示范围外，开工前先声明）；完全零成本或没有 fal API key 且无法自备抠图与视图时；手里已有多张实拍时，摄影测量路线（如 Meshroom）更直接。

## 方法步骤

1. 环境与验线：把 Skill 装进编码 Agent（Claude Code / Codex / Cursor 等）；备 FAL_KEY、Blender 5.2+、ffmpeg。先跑仓库 demo 的离线合成案例把整条管线验一遍，再上付费案例。
2. 输入分流：AI 图、实物照片、带 alpha 的抠图 PNG 直接进；草图先 restyle 成 3D 渲染图再进；多张实拍用 `views --import` 替代生成视图；只有想法时先 `imagine` 生成一张干净全身图起步。属于范围外的主体（场景房间、发丝、透明/镜面）在 `new` 之后、烧钱之前就声明劝退。
3. 原图锚定（`prep`）：MoGe 出原图的焦距与米制深度，Marigold 出表面法线，遮罩由 BiRefNet 出（或用自备 alpha 通道、SAM-3 文本提示）。锚定数据是后续拟合的硬约束：照片看见的表面由照片说了算。
4. 生成视图补背面（`views`）：默认生成 9 个视图补原图看不见的部分；每个视图的真实相机角度靠搜索配准求出，永不采信提示词里要求的角度（仓库自测：要求 30°、实际 72° 的视图被找回 72.0°）；逐个查左右镜像、前后反转；与其它视图的视觉外壳不一致的视图（姿势变了、多出肢体等）直接拒收，并记录拒收理由。
5. 留一验证：第 10 个视图的相机在拟合开始前冻结，永不参与推动曲面，拟合日志里不得引用它；最后单独汇报它与成品的对照指标——与训练/验证集分离是同一条纪律。
6. 分轮小步拟合（`hull` → `fit`）：先出视觉外壳，再按形体 → 表面 → 细节 → 抛光推进，共 38 轮（README 口径）；每轮从各视图的法线、轮廓与原图深度计算逐顶点目标，刚性解管轮廓、柔性解管法线；每步存进 `build/steps/` 可回溯；体积用精确符号距离场维护，没有体素台阶与摩尔纹。
7. 逐项验收（`check`）：不给总分，给逐视图验收表——每个视图分别报轮廓 IoU、轮廓距离、法线角度、粗糙度、深度对照图；留出视图单独成列。哪项不达标回对应轮次修，不许靠「整体看着像」放行。
8. 收尾交付（`finish` / `blender` / `report`）：Blender 从原图相机逐一重渲每一步、拼成延时摄影，另出 360° 转台与各视图机位对照图；导出 .blend / GLB / OBJ / STL。CLI 全程为 `i2s.py new / prep / views / hull / fit / check / finish / blender / report`，或 `run` 一条龙。
9. 降级路径：无 FAL_KEY 时，用自备抠图 + 自备视图导入继续跑；但生成视图的配准、筛查与留一验证三条纪律不降级。

## 提示词与模板

无固定模板，按方法步骤执行。执行接口是 Skill 自带的 CLI（`i2s.py` 子命令序列见步骤 8）与输入分流规则（步骤 2）；把关点在流程里，不在提示词里。

## 验收标准

- 每个生成视图都有配准出的真实角度记录，被拒视图逐个有拒收理由
- 留出视图在拟合前冻结、拟合过程无引用，最终单独汇报其对照指标
- 38 轮拟合每步留档于 `build/steps/`，可经 Blender 回放复现全程
- 验收表逐视图齐全（轮廓 IoU、轮廓距离、法线角度、粗糙度、深度对照），无总分替代
- 导出四格式齐全（.blend / GLB / OBJ / STL），附延时摄影、360° 转台与机位对照图
- 范围外主体已在开工前声明，没有硬做

## 边界与风险

- 付费依赖：遮罩、深度、法线与生成视图都走 fal 付费 API，需 FAL_KEY；约 $2/例为 README 自述，未独立核价
- 仓库 2026-11-08 才建仓、非常新；仓库自带测试（配准找回角度、坏视图拒收、留出视图与真形更接近）均为作者自测，无第三方复现，引用其效果数字时标注作者口径
- 38 轮、9+1 视图等数字为 README 口径（已与帖文逐项对过，未独立复跑管线核实）
- 硬范围：场景房间、头发丝结构、透明/镜面材质不在范围内；别把降级路径当零成本等价物，自备视图的质量直接决定拟合上限
