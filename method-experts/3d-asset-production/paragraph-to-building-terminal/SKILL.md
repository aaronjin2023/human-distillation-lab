# 一段话代码建房终端法（专家模式）

- 领域：3D 资产生产
- 来源：wast3（@0xWast3）开源 Skill boomtown 及长文《How I Turn One Paragraph Into a House That Builds Itself on Screen》全文，收录于西瓜小本本第 424 条；vault 笔记《boomtown：一段话生成自建房屋终端的 Skill 笔记》
- 核验状态：长文全文与跟帖已逐段核读；仓库 8★/MIT 为 GitHub API 核；四栋成品的行数与出片效果为作者自述，未独立核实，Skill 未实测
- 适用：用编码 Agent 从一段文字描述生成可交互、可拆解、带组装动画的纯代码 3D 建筑/场景（单文件 HTML 终端形态）

## 定位

信奉「先拆分、后几何」：一段建房运行的大部分时间花在层级与部件边界上——决定什么算一个物体、谁站在谁上面——几何生成反而是机械活。产物永远是一棵可命名的部件树，每件可独立编辑、独立到达，绝不是一坨焊死的融合网格（门焊死在门框里的房子，造好的那一刻就已经完工不了）。指令不住在聊天里，住在一份岗位说明书文件中，每次运行重读、每条修正回写。

## 何时用 / 何时不用

- 用：建筑/场景的概念可视化、教学演示、需要「组装过程本身就是内容」的展示件；用编码 Agent（作者用 Claude Code）批量产同类结构
- 不用：需要真实建模精度与工程数据的场合；有机形态、角色类资产（本法是硬表面结构件的拆分逻辑）

## 方法步骤

1. **写岗位说明书**：把全部指令、清单与历次修正写进一个文件（如 JOB_DESCRIPTION.md），每次运行先读它。判断标准从「请求」升级为「可被判定失败的标准」。
2. **一段话输入**：用客户口吻写——数量、层数、一个不寻常的动作、材料（如「五个集装箱三层，一个横置悬挑 6.3 m」）。只给可证伪的具体量，不给「现代」「高级」这类形容词。
3. **PLAN → SPLIT → BUILD**：先列结构依赖顺序（PLAN），再定每个物体的起止边界（SPLIT），最后才对着定稿的计划生成几何（BUILD）。
4. **部件编号化**：每件给五个数值字段（如 id/name/start/dur/anchors 类），终端的一切展示（部件表、高度、立面、材料占比、组装计数）都从字段派生，不另行手打。
5. **anchors 推导组装顺序**：部件标注它所站立的依托件；到达顺序是接触关系的推论，不手写序列。部件数失控（远超十余件）说明描述失控，先改描述。
6. **六视图计算化**：地面眼高（1.6 m）、轴测左右、平面、正面、侧面全部由包围盒计算；相机距离按 UI 面板占用后的有效视野求解（fitToField），任何一栋都不手挪入位。
7. **两轮制：先墨线，后上色**：第一轮只有线稿（作者用红→紫渐变），专验几何——颜色会藏错误（墙偏 40 mm 上色后看不见）。第二轮只许上色、不许移动几何。墨线层保留即得 X 光视图。
8. **每件是按钮**：点击部件相机飞向它，飞行时长 0.3–0.9 秒封顶；信息卡数据全派生。UI 面板降饱和（玻璃质感），画面里只有主体配饱和。
9. **单文件交付**：three.js 内联进单个 HTML（作者约 1 MB、零外部资产、离线可开）——单文件即是可测试性：打开就能验，不掺环境。
10. **影片即 JSON + 步进渲染**：组装影片写成一个 JSON（4 个相机关键帧 + 3 个动作，相机沿样条永不停顿）；渲染用脚本以固定步长（1/24 秒）步进时钟逐帧截图再合成，不录屏，保帧帧等质。
11. **修正回写**：每条实测修正（饱和度 +15%、墨线远距保持 80% 粗细、去抖动、飞行时长上限等）粘回岗位说明书——在聊天里做的修正是一次性的，进文件的修正让下一次运行不再需要它。

## 提示词与模板

核心输入模板：一段话 = 数量 + 层数 + 一个不寻常的动作（带具体尺寸）+ 材料清单。安装（作者提供）：`npx skills add 0xwast3/boomtown -g -a claude-code`。

## 验收标准

- 产物是命名的部件树：任意一件可独立选中、编辑、隐藏，不牵动其他件
- 组装顺序与 anchors 依赖一致：没有部件在它的依托件之前到达
- 六视图均为计算结果，换一栋描述不需手调相机
- 墨线轮能暴露全部几何错误（贴合、悬空、错位），上色轮未移动任何几何
- 交付为单文件、断网可开；影片 JSON 改关键帧即可重渲

## 边界与风险

- 作者自述数字（各栋墨线行数、无显卡约 8 秒/帧的渲染速度）未独立核实
- 仓库极新（2026-11-07 建，8★），Skill 本体未在本地实测；先拿一栋小结构试跑再决定是否纳入生产线
