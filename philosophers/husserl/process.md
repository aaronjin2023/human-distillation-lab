# Edmund Husserl — 哲学写作过程规格 process.md（给文本/视频模型）

> 只按著作的写作逻辑写，不编造哲学家的生活场景；有手稿/版本可考者以手稿与版本证据为准，无手稿者按著作结构反推，不声称复刻原过程。

## (1) 写作步骤顺序表（5 步）

| 步骤 | 做什么 | 最容易写错 |
| 1 悬搁 | 把自然态度加括号 | 悬搁写成怀疑 |
| 2 描述 | 意向结构的耐心描述 | 描述流于印象 |
| 3 变易 | 本质变易找不变者 | 变易只举一例 |
| 4 还原 | 还原到纯粹意识 | 还原写成内省 |
| 5 体系 | 统一术语、定名 | 改动已定的描述 |

- 各步文本状态：问题约 10–20%（问题可见、论证未定）；概念约 30–40%（概念已立、论证初现）；论证约 60–70%（论证已通、反驳未补）；反驳约 85–90%（论证已稳，个别环节仍可留空）；体系 100%（完成态）。
- 第 1 步（悬搁）最容易写错：悬搁写成怀疑。
- 第 2 步（描述）最容易写错：描述流于印象。
- 第 3 步（变易）最容易写错：变易只举一例。
- 第 4 步（还原）最容易写错：还原写成内省。
- 第 5 步（体系）最容易写错：改动已定的描述。

## (2) 每一阶段的文本状态变化（5 个检查点）

1. 第 1 步结束：只有问题与靶子，论证未定。
2. 第 2 步结束：概念骨架已立，论证初现。
3. 第 3 步结束：论证链已通，反驳未补。
4. 第 4 步结束：反驳补上，论证变稳，个别处仍可留空。
5. 第 5 步结束：完成态，术语统一、章节定名。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：问题 10%、概念 25%、论证 35%、反驳 20%、体系 10%（按本家特点调整：格言体锻句步可占 50%，体系作者概念与论证步可占 60%）。
- 节奏提示：问题慢、概念中速、论证放慢、体系停顿。

## (3) 过程呈现的镜头与字幕建议

- 呈现：手稿/打字稿/屏幕逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 概念 / 论证 / 反驳 / 体系），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，论证打磨用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放著作封面/手稿页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构哲学家本人的生活场景。

## (4) 过程示例（以本家写现代题材的逻辑为例，不声称复刻原过程）

- 问题：定一个现代题材（自助结账机漏扫了一件商品，当事人是否该付款）、定靶子、定要回答谁、反驳谁。
- 概念：按本家的概念操作造概念、划区分，核心概念与对立概念成对出现。
- 论证：按本家的论证骨架一节节推进，不回头改概念。
- 反驳：预演最强的反对意见，哪里让步、哪里寸步不让。
- 体系：通读统一术语、定章节与标题，不改论证结构。
