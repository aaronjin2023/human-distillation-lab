# Thales — 哲学写作过程规格 process.md（给文本/视频模型）

> 只按著作的写作逻辑写，不编造哲学家的生活场景；有手稿 / 版本可考者以手稿与版本证据为准，无手稿者按著作结构反推，不声称复刻原过程。

## (1) 写作步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 写什么、写哪里 | 文本状态 |
|---|---|---|---|---|
| 1 定现象 | 列出要解释的现象：云、雨、风、潮汐 | 观察与记录 | 只列现象，不下结论 | 约10–20%，现象清单可见、本原未定 |
| 2 求本原 | 从现象中找共同者：水无处不在、滋养万物 | 归纳与类比 | 提出‘水是本原’的假说 | 约30–40%，假说已立、论证未展 |
| 3 汇聚证据 | 补更多水的事例：万物离水则死、潮湿无处不在 | 例证累积 | 一节一例，层层汇聚 | 约60–70%，证据已多、反驳未补 |
| 4 排除神话 | 说明神话解释为何多余：自然原因已够 | 替换论证 | 只写替换，不展开神学争辩 | 约85–90%，解释已稳，个别现象仍可留空 |
| 5 定格言 | 把结论压成一句可传诵的断言 | 格言化 | 全篇收束为一句本原命题 | 100%，完成态 |

- 第 1 步（定现象）最容易写错：一上来就给本原，现象列得太少。
- 第 2 步（求本原）最容易写错：把类比当证明，混淆‘像水’与‘是水’。
- 第 3 步（汇聚证据）最容易写错：只举顺例，不理反例。
- 第 4 步（排除神话）最容易写错：陷入与神话的正面争吵，偏离自然解释。
- 第 5 步（定格言）最容易写错：把断言写成体系，失去残篇的锋利。

## (2) 每一阶段的文本状态变化（过程视频 / 文本生成的节奏）

- 第 1 步结束：只有问题与靶子，论证未定。
- 第 2 步结束：概念已立，论证初现。
- 第 3 步结束：论证链已通，反驳未补。
- 第 4 步结束：反驳补上后论证变稳，个别环节仍可留空。
- 第 5 步结束：全篇统一，完成态。
- 节奏建议：现象快、汇聚中速、格言收束停顿；总时长延时版60–90秒，格言定格3秒。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。不要把 5 步平均分配时间，按哲学家特点分配。

## (3) 过程呈现的镜头与字幕建议

- 呈现：手稿 / 打字稿 / 屏幕逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 概念 / 论证 / 反驳 / 体系），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，论证打磨用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放著作封面 / 手稿页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构哲学家本人的生活场景。

## (4) 过程示例（按本书写作逻辑，不声称复刻原过程）

- 问题：定靶子与核心问题。
- 概念：造区分，核心概念与对立概念成对出现。
- 论证：按前提—推理—结论一节节推进。
- 反驳：预演最强的反对者，哪里让步、哪里寸步不让。
- 体系：统一术语、定章节与标题。
