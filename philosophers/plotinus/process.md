# Plotinus — 哲学写作过程规格 process.md（给文本/视频模型）

> 只按著作的写作逻辑写，不编造哲学家的生活场景；有手稿 / 版本可考者以手稿与版本证据为准，无手稿者按著作结构反推，不声称复刻原过程。

## (1) 写作步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么技法 / 工具 | 写什么、写哪里 | 文本状态 |
|---|---|---|---|---|
| 1 立太一 | 以否定立太一：非存在、非思想、非善 | 否定神学 | 只写否定，不下肯定定义 | 约10–20%，太一可见、层级未展 |
| 2 布流溢 | 展开太一—心智—灵魂—质料的层级 | 层级类比 | 一节一层级，光喻贯穿 | 约30–40%，层级已立、上升未出 |
| 3 释灵魂 | 讲灵魂的堕落与内转的可能 | 内转论证 | 一节一转折，服务上升 | 约60–70%，灵魂已明、观照未至 |
| 4 论观照 | 以观照与合一收束上升之路 | 观照论述 | 只写观照，不展开仪式 | 约85–90%，上升已明，个别环节可留空 |
| 5 定九章 | 以讲授稿编为九章，沉默收束 | 编次定稿 | 全篇以沉默收尾 | 100%，完成态 |

- 第 1 步（立太一）最容易写错：否定不彻底，偷偷给了肯定谓述。
- 第 2 步（布流溢）最容易写错：层级之间跳步，光喻断裂。
- 第 3 步（释灵魂）最容易写错：灵魂论变成心理学，失去形而上。
- 第 4 步（论观照）最容易写错：观照写成神秘体验报告。
- 第 5 步（定九章）最容易写错：把沉默写成体系结论。

## (2) 每一阶段的文本状态变化（过程视频 / 文本生成的节奏）

- 第 1 步结束：只有问题与靶子，论证未定。
- 第 2 步结束：概念已立，论证初现。
- 第 3 步结束：论证链已通，反驳未补。
- 第 4 步结束：反驳补上后论证变稳，个别环节仍可留空。
- 第 5 步结束：全篇统一，完成态。
- 节奏建议：否定慢、层级中速、上升放慢、沉默停顿；延时版60–90秒，否定步占25%。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。不要把 5 步平均分配时间，按哲学家特点分配。

## (3) 过程呈现的镜头与字幕建议

- 呈现：手稿 / 打字稿 / 屏幕逐行出现，关键修改处用删除线与替换词并排显示；每步左上角出小字步骤名（问题 / 概念 / 论证 / 反驳 / 体系），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍稿纸 / 屏幕特写 / 局部放大三机位轮换；问题用全景，论证打磨用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 部原作小图对照（只放著作封面 / 手稿页，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡稿纸；不要把过程剪成跳切，保留修改的连续性；不要虚构哲学家本人的生活场景。

## (4) 过程示例（按本书写作逻辑，不声称复刻原过程）

- 问题：定靶子与核心问题。
- 概念：造区分，核心概念与对立概念成对出现。
- 论证：按前提—推理—结论一节节推进。
- 反驳：预演最强的反对者，哪里让步、哪里寸步不让。
- 体系：统一术语、定章节与标题。
