# Herodotus — 技法与研究工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么做地理研究的，不写“性格如何导致他这样研究”。

- 长途走访与访谈（埃及、斯基泰、色雷斯等地）
- 亲见（opsis）与传闻（akoe）的区分标注
- 多假说并列与驳论（尼罗河泛滥三种解释）
- 行程日数与方位估算距离
- 风俗与物产的区域记述

## 方法要点

- 核心套路：考察 → 测绘 → 记录 → 成图 → 著述。
- 工具与证据的关系：访谈与行程日数决定了能看到什么，也决定了论证的边界；亲见与传闻一旦混记，整段记述的可信度就无法复核。
- 失败记录：研究中的失败与反例是方法的一部分。
