# Richard Chorley — 技法与研究工序 technique.md（四维之 procedure）

> 只限成果物。证据分级见地理学家草稿第 6.5 节。

## 考察与测绘工具

- 以系统论与模型为方法：先把地理现象划为系统与子系统，再以模型表达输入输出，最后以案例检验模型；编著与合著是主要形式，理论散见于导论与模型分类。`artifact`

## 制图与空间表达技法

- 系统框图与模型分类图：图要显示系统的输入、输出与反馈，模型图是论证的骨架。`artifact`

## 研究工序（考察—测绘—记录—成图—著述）

- 五步的本人版本：划系统 → 建模型 → 分类 → 案例检验 → 著述定稿；每步的易错点见该表。
- 修改痕迹：以地图底稿、版本修订与概念演变为证据；无底稿可考者按著作版本对照反推，不虚构修改过程。`artifact`

## 证据偏好与禁项

- 偏好：以系统论与模型为方法：先把地理现象划为系统与子系统，再以模型表达输入输出，最后以案例检验模型；编著与合著是主要形式，理论散见于导论与模型分类。禁项：无系统划分的模型套用、把模型当作现实本身、忽略模型的适用限度、把编著的集体成果写成个人独著。
