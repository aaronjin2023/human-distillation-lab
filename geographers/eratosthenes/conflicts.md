# Eratosthenes — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 年代争议，保留，不统一。

1. **地球周长数值两说**：传世引述多为 252,000 斯塔德；克莱奥美德斯的简化本作 250,000 斯塔德。两者并存，公里换算（约 39,000–46,000 公里）取决于斯塔德长度，现代折算误差在 −2.4% 至 +0.8% 之间（按 155–160 米计）。本文件夹用 252,000 斯塔德作代表数，不压缩成单一公里数。
2. **著作仅存残篇**：《地理学》与《论地球的测量》均已佚，内容多赖斯特拉波等后人引述重建；凡引述均按 `artifact` 或 `impression` 处理，不标 `verbatim`。
3. **生卒约数**：c.276–c.194 BCE 为通说约数，卒年亦有 194 BCE 之说，见草稿第 5 节。
