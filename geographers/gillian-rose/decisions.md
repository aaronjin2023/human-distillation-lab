# Gillian Rose — 决策逻辑 decisions.md（四维之 personality）

> 只写研究上的取舍，不写心理诊断。证据分级见地理学家草稿第 6.5 节。

## 反复做的选择

- 坚持：图像必须按三场域分析，观看的权力必须追问到底。拒绝：把图像当作透明证据。牺牲：牺牲分析的效率，保住方法的反思性。

## 坚持 / 拒绝 / 牺牲

- 坚持什么、拒绝什么、宁愿牺牲什么也要保住什么，见上段；具体禁区：`no treating an image as a transparent window, no image description without power analysis, no writing visual method as a technical checklist, no ignoring the researcher's own position of looking`。
- 决策的证据：以上取舍从成果物本身归纳（`artifact`），不是从传记推断。
