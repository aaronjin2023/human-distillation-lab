# Claudius Ptolemy — 技法与研究工序 technique.md（Procedure，只限成果物）

> v0.1（2026-10-26）。只写他怎么做地理研究的，不写“性格如何导致他这样研究”。

- 坐标表编制（约 8,000 个地点）
- 三种地图投影法（圆锥投影等）
- 本初子午线选定与经度换算
- 天文观测数据的地理应用
- 坐标可靠性标注

## 方法要点

- 核心套路：考察 → 测绘 → 记录 → 成图 → 著述。
- 工具与证据的关系：坐标与投影决定了能画出什么；投影一错全图失真，坐标表与地图必须能互相复核。
- 失败记录：研究中的失败与反例是方法的一部分。
