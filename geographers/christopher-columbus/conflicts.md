# Christopher Columbus — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 年代争议，保留，不统一。

1. **殖民争议（必须记录）**：哥伦布的航行开启了欧洲对美洲的殖民，伴随对原住民的暴力、奴役与疾病传播；本文件夹只蒸其航海日志与海岸测绘，殖民与暴力部分不作为蒸馏源，争议记于此，不作价值判断的统一结论。
2. **“发现美洲”之说**：美洲原住民早已居住，北欧人（莱夫·埃里克松）约 1000 年已抵北美；“发现”一词仅指欧洲地理认知的扩展，本文件夹不用“发现美洲”作中性表述。
3. **地球计算错误（当时模型 / 后世证伪）**：哥伦布沿用托勒密低估的地球周长与高估的欧亚跨度，误以为抵达亚洲；其计算错误是航行史的一部分，本文件夹如实记录，不把错误当作正确结论。
4. **首航日志版本**：传世本为拉斯卡萨斯的节略本，非哥伦布原稿；双重里程记录的说法见于节略本，学界有讨论。
