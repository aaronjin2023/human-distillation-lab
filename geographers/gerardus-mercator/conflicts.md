# Gerardus Mercator — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 时期矛盾，保留，不统一。

1. **投影的取舍**：墨卡托投影保角不保面积，高纬地区面积严重拉伸；这是投影本身的数学取舍，不是制图错误，本文件夹记为当时模型，不作‘错误地图’评价。
2. **《地图集》的刊行**：Atlas 一词由墨卡托用于地图集，1595 年逝世后由其子刊行；版本以逝世后刊本为准。
3. **生卒与代表作已核对**：1512–1594、墨卡托投影、《地图集》经草稿 v1 web 搜索核对（Britannica）。

4. **《地球一览》的归属与书名（硬错误，已纠正）**：本文件夹原列《地球一览》(Orbis terrae compendium) 为墨卡托本人代表作，书名拼写亦误。实为 Orbis Terrae Compendiosa Descriptio，1587 年由其子 Rumold Mercator 据其父 1569 年世界图缩编而成（HKUST 馆藏说明、State Library of NSW），墨卡托本人 1594 年卒，未亲刊此图。本文件夹已更正书名与归属，仍保留为代表作之一，但须注明为子缩编。
