# Michael Batty — 技法与研究工序 technique.md（四维之 procedure）

> 只限成果物。证据分级见地理学家草稿第 6.5 节。

## 考察与测绘工具

- 以城市统计、交通流与土地利用数据为材料，用复杂性科学与计算机模型模拟城市的涌现，再以模型与现实对照检验；数据、模型与模拟并重。`artifact`

## 制图与空间表达技法

- 网络与流的模型图：以节点、连线与模拟结果组织论述，图要显示城市如何从局部互动中涌现，不是静态区划。`artifact`

## 研究工序（考察—测绘—记录—成图—著述）

- 五步的本人版本：定问题 → 建模型 → 模拟 → 对照现实 → 著述定稿；每步的易错点见该表。
- 修改痕迹：以地图底稿、版本修订与概念演变为证据；无底稿可考者按著作版本对照反推，不虚构修改过程。`artifact`

## 证据偏好与禁项

- 偏好：以城市统计、交通流与土地利用数据为材料，用复杂性科学与计算机模型模拟城市的涌现，再以模型与现实对照检验；数据、模型与模拟并重。禁项：无数据支撑的模型断言、把模拟结果当作现实预测、忽略模型的假设与限度、把涌现说成神秘力量。
