# Mike Davis — 地理研究过程规格 process.md（给文本/视频模型）

> 只按成果物的研究逻辑写，不编造地理学家本人的生活场景；无手稿者按著作结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 — 方法 — 成果 — 易错 |
|---|---|
| 1 | 查档案 — 土地与开发档案 — 只记可核查的材料 — 易错：档案只挑符合论点的 |
| 2 | 追踪权力 — 开发商与国家 — 画权力图 — 易错：合谋无证据 |
| 3 | 扩展全球 — 灾难与贫民窟 — 比较案例 — 易错：比较只列现象 |
| 4 | 成文 — 揭露式论述 — 语言与证据对齐 — 易错：修辞压过证据 |
| 5 | 定稿 — 警告 — 结论落在权力 — 易错：警告写成宿命 |

## (2) 每一阶段的成果状态变化（过程视频/文本生成的节奏）

- 第 1 步结束：问题与路线可见，材料未齐，约 10–20% 完成。
- 第 2 步结束：空间骨架或模型骨架已定，细节全无，约 30–40% 完成。
- 第 3 步结束：材料已齐、论证未成，约 50–60% 完成。
- 第 4 步结束：地图或模型已立、文字未满，约 70–80% 完成。
- 第 5 步结束：论点、证据、地图三者对齐，100% 完成态。
- 节奏建议：考察与建模慢（让观者看清问题与骨架）、成图放慢（看符号与图例落点）、著述停顿（看完成态）。总时长建议：延时版 60–90 秒；过程版 3–5 分钟。按本人的特点分配时间，不平均分配。

## (3) 过程呈现的镜头与字幕建议

- 呈现：考察日记 / 测量手稿 / 地图底稿 / 模型草图逐页出现，关键修改处用新旧图并排显示；每步左上角出小字步骤名（考察 / 测绘 / 记录 / 成图 / 著述），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍地图 / 侧面 45° / 局部特写三机位轮换；考察用全景，成图用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 幅原作地图小图对照（只放地图与著作，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡地图；不要把过程剪成跳切，保留测绘与成图的连续性；不要虚构地理学家本人的生活场景。

## (4) 过程示例（按本人研究逻辑，不声称复刻原过程）

- 以 style.md §7 的测试题（新城区高楼的权力挖掘）为题，按上表 5 步走一遍：先定问题与材料，再建模型或画草图，然后整理记录、成图，最后著述定稿；每步的易错点见上表。
