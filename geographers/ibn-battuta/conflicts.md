# Ibn Battuta — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。说法不一致 / 归属存疑 / 年代争议，保留，不统一。

1. **卒年两说**：1368 或 1369 年（本次 web 搜索核对：World History Encyclopedia 与 Salem Press 均作 1368 或 1369；部分通俗来源只写 1369）。本文件夹用“1304–1369”从草稿，异说记于此，不压缩成单一年份。
2. **口述、笔录**：《游记》为伊本·白图泰口述、伊本·朱扎伊笔录（1355 年成书），部分细节被认为有笔录者的润色或作者的夸张；学界共识是核心行程可靠、个别细节存疑，本文件夹按此口径。
3. **行程里程**：约 12 万公里（75,000 英里）为通说估算，非实测值，以约数呈现。
