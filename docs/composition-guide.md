# 专家、人格与人类行为框架如何组合

组合时先定义任务和对象，再选择能改变具体行动的少量框架。下表是一份本库设计配方，不是经过验证的心理预测模型。

| 层 | 回答的问题 | 从哪里取资料 |
|---|---|---|
| 专家方法 | 如何完成这项专业工作 | 原36类专家条目的方法、作品与取舍 |
| 相对稳定的偏好与价值 | 在哪些方向上更愿意投入 | [人格与个体差异](../personalities/CATALOG.md) |
| 认知与行动过程 | 如何搜索、判断、行动和更新 | [人类行为与差异](../human-patterns/CATALOG.md) |
| 叙事中的行为材料 | 某种动机与价值冲突如何表现为行动 | [文学与影视角色](../fictional-characters/CATALOG.md)中的指定作品版本及引用证据 |
| 评论互动风格 | 看什么、怎么问、如何表达赞同或反对 | [DATUMOJ 评论区角色](../commentary-personas/CATALOG.md)中的作者设定与应用示例 |
| 情境与状态 | 当前有什么资源、机会、时间和身体条件 | 任务材料、直接观察、本人说明或明确创作设定 |
| 社会和生命历程 | 规则、关系与经历怎样改变选择 | 对应社会/发展框架及有出处的背景资料 |

## 操作

1. 明确是真人资料分析还是原创角色。真人材料中的未知不补造；原创角色可以设定，但写明是设计选择。
2. 选一个专家方法，加一到三个与问题最相关的框架。需要新解释时再增加，避免每次装载全库。
3. 对关键设定记录：依据、情境和时间、观察或推演、反例与未知。群体统计另列分析单位，不直接写进个人属性。
4. 把设定转成条件行为：遇到什么线索、有哪些备选行动、依据什么选择、什么新证据会改变决定。不要仅输出标签清单。
5. 做成对情景检查：同一角色换环境，行为是否合理改变；环境相同但有不同个人证据，是否体现差异。表现冲突时先检查输入和框架范围，不能编造分数裁决。

## 可直接加载的例子

[研究协作者](../profiles/research-collaborator/SKILL.md)借用专家的可检验假设方法，大五与价值观用于明确的原创偏好，COM-B和有限理性用于解释行动条件与搜索边界。

**场景A：** 同一位原创角色准备公开淡水调查来源，但上传入口故障。他保留原始记录，说明缺失并采用可核对的替代提交路径；不把失败解释为人格突然变差。

**场景B：** 入口可用，但方案太多且核查时间有限。他先列安全与可维护性门槛，找到满足门槛且有证据的可行方案；重大未知仍阻塞结论，不能以“够好”为由省掉必要条件。

上述行为是本库创作示例，不是对爱因斯坦或任何真人的预测。文化、族群、肤色、性别或年龄都不作为能力加成；若某次任务确有相关身体或环境条件，直接记录那个条件和支持方式。

使用角色资料时，从目录选择具体作品，再以 `profile_id`（`characters.jsonl` 中的 `id`）固定叙事版本。例如借用某一版角色在利益冲突中的取舍方式，与专家方法组合成新人物；保留 `evidence_ids`，并写明哪些来自材料、哪些是新增设定。`identity_id` 用于查找同一人物的其他版本，不把它们的相反判断平均成一个“最终人格”。资料中的未知维度继续留空；需要创作补充时注明为合成设定。

评论区角色用 `datumoj-72:NN` 指定身份。例如用严核实检查事实、问开开追问假设、沈默然给出克制异议。专家方法负责事实与专业判断，评论角色负责注意焦点和说话方式；原站趣味参数不能换算成人格得分，也不以角色名推断真实评论者的心理。

## 冲突与应用边界

已核对事实和用户任务约束优先于角色设定。专家方法不能赋予未具备的资质，偏好不能抹掉现实障碍；理论解释与输入不符时保留其他解释。不同框架的同名构件不自动相同，不换算不兼容分数。

当前支持资料选用、可解释角色设计和假设生成；未构建真人评分服务、群体能力排名、心理诊断或可靠的行为预测引擎。
