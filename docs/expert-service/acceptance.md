# 验收与推进计划

0.1.0 · 本文定义未来验收；[本轮已执行检查](../audits/2026-11-01-library-quality/repair-verification.json)只证明资料／构建／文档检查，不证明服务可运行。[索引](README.md)。

## 1. 阶段门槛

| 阶段 | 必须交付 | 可以宣称什么 |
|---|---|---|
| 资料修复 | 已确认缺陷修正、来源不足降级、正反例、当前文件完整性 | 修复回执中对应项通过，不能扩张为全库效果通过 |
| 设计评审（本轮） | 知识契约、状态／恢复、OpenAPI、正负示例、跨层回归计划 | 设计可审阅；文档静态校验不等于HTTP测试 |
| 人工咨询样板 | 两类真实任务各至少3个，包含资料不足和冲突，保存完整输入输出／版本 | 某样板在限定条件下可用，不等于自动服务完成 |
| 最小运行服务 | single链路、认证隔离、幂等、持久恢复、预算、结构化意见 | 对应运行用例已测；再决定是否接入真实项目 |
| 多席与扩展 | 两轮协议完整，缺席诚实降级，同预算对照及盲评 | 仅在显示增益的任务上开放多席 |

只有用户再次授权开发才进入运行服务阶段。模型通道、计费来源、部署地址、资料保留与备份必须在实施时核对，不能从本文推导已经配置。

| 世界观 | 死亡笔记私人正义主题探讨 | 用开端简介直接判某规则行动成功，未知前提当满足 |

结构测试捕获损坏、漂移和字段遗漏；来源支持、方法应用与作者辨识须由语义／产物评审判断。评论／世界观的正确性不能只靠“ID存在”验收，仍需逐主张证据核对；本轮没有制作自动语义裁判。

## 3. 效果实验

至少12个未用于修卡的留出任务，世界评审和创作简报／产物评审各6个，覆盖简单题、跨领域冲突、缺资料和范围外任务。先冻结评分rubric，再准备A通用模型、B同模型读同方法证据包、C服务组织三组。B/C固定材料可见范围、总调用／token预算和模型设置；记录预算实际消耗及不可控提供商差异。输出匿名随机顺序交给至少一位领域评审和调用项目负责人；有分歧保留原评语。

每例检查：是否解决实际决策，硬约束违反数，事实与引用支持比例，关键未知／反例是否遗漏，验证行动能否执行，用户修改量、用时和调用资源。条件性回答不是失败，伪造确定性是失败。小样本不能推出普遍准确率或成本优势。

首版准入建议：关键硬约束违反／伪造来源／跨项目材料泄露为0；每例必要未知都显式保留；至少10/12例被评为“无须实质重写即可用于下一步决策”。C对B在关键质量上不得退步，多席仅在至少两个跨域案例展现可指出的新增价值时开放。阈值为待用户验收的设计目标，不能报告为已达成；不达标则修资料／流程或缩小用途。

漫画另外先补荒木同阶段多张参考，固定同题／同模型／同设置比较原配方与项目转写；保留请求、结果、判据、失败归因。通过后再扩其他作者，不能通过一次静态对照替全部100人授予画风还原能力。

## 4. 运行故障与接口用例（待实现后执行）

- 同项目同key并发创建十次只产生一个任务；不同body同key409；跨项目key互不复用。
- 在提交任务事务前／后断网，重放不重复创建或扣费；提供商outcome_unknown不盲目重试。
- 过期If-Match、漏答问题、改硬约束、deadline期间等待、第三次澄清均按契约结束。
- 重启worker、租约到期、旧worker迟到，不能重复提交步骤；预算仍跨重启累计。
- 取消与完成同时提交只有一个终态；取消后的迟到响应仅归档；后补费用不改变原答案。
- 缺一席、只完成一轮、来源重叠、评分分歧都不能伪装共识；预算不足auto解释降级。
- A项目不能查B项目任务／制品，均404；恶意材料中的指令不能触发文件／网络工具。
- 发布包关键文件改动必须拒载；错误source_ref、缺硬约束检查、遗漏必要方法项不能发布结果。

## 5. 维护与证据

当前117项方法正文SHA基线只保证经审阅版本没有悄然变化；合法正文修改须先审阅diff，再显式更新对应项，不能在普通validate时自动接受新hash。生成内容比较同时验证源→产物等值，不能只给损坏产物重算hash。

文档检查可用含 `jsonschema >= 4` 的现有Python环境运行 `python scripts/check_service_docs.py`；脚本不安装依赖、不访问网络、不启动服务。它检查JSON Schema、内部引用、操作与合成正负例，不声称覆盖完整OpenAPI元规范或运行语义。

每次运行验收记录实际命令／请求、时间、输入及输出digest、环境／模型、断言、失败和未测项。历史回执保留；新回执关联当前版本，绝不改旧记录制造“当时已通过”。用户采纳是一项反馈，不自动使输出成为知识库事实。
