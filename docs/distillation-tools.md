## 本次适配

本次蒸馏对象是人格理论、测量工具与相关框架。按用户指定范围收集公开官方页面、作者材料及原始研究，写成概念、维度、使用步骤、限制和设计推演；不套用人物模板去生成虚构经历。框架之间的相似术语并非可直接换算的测量结果。

保留上游 `verbatim` / `artifact` / `impression` 的来源形式区分，但不把原话形式当作更高的科学证据等级。正文为原创改写和明确标记的设计推演；来源实际访问到摘要、全文或片段的区别在条目元数据中标注。

上游 `personality-extractor.md` 将“INTJ”列在心理诊断标签示例中，这一表述不准确。本库区分 MBTI 类型偏好与临床诊断：不由单一行为推定类型，也不把 MBTI 当诊断工具。该纠正在本库适配层记录，没有私自改写已安装上游版本。
