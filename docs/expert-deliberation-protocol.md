# 专家讨论协议：基于 RAND 德尔菲方法的项目适配

版本：1.0 · 2026-11-01 · 状态：本库默认讨论规范，尚未实现工作台执行引擎。

[填写会议记录](expert-deliberation-template.md) · [资料组合](composition-guide.md) · [领域入口](../domains/README.md)

本库多个专家方法或角色共同评议一个方案时，默认遵循本协议：**独立初评 → 匿名反馈 → 分歧澄清 → 独立复评 → 保留分歧的决策记录**。它规范如何收集和比较意见，不保证意见正确，也不授权将模拟角色的判断称为真人专家意见。

## 1. 采用的依据与适用范围

依据：Dmitry Khodyakov、Sean Grant、Jack Kroger、Melissa Bauman，*RAND Methodological Guidance for Conducting and Critically Appraising Delphi Panels*，RAND，2023，TL-A3082-1。[原出版入口](https://www.rand.org/t/TLA3082-1)。本轮依据用户提供的72页PDF，核读关键方法章节并查看附录图表；不把原PDF复制进仓库。

文件指纹 SHA-256：`108aff3396724f31cfc77a065539d6a9d89eb96698bbb45b96da2e833b45f49e`。下文页码为书内印刷页码，PDF页序加8；例如正文第26页是PDF第34页。

| 手册依据 | 本库采用方式 |
|---|---|
| 第5–7、43–45页：匿名、迭代、群体统计、受控反馈 | 保留四项核心条件；缺项如实标记，不能称完整遵循 |
| 第13–15、23–24页：按问题选方法、成员与专业范围 | 按实际议题选人，覆盖相关学科与受影响者视角 |
| 第17–18、28–30页：共同材料、预试、清楚问题 | 先核证据与题意，再冻结题目和量表 |
| 第19–20、25–26页：预定轮数，防止强迫共识 | 默认两轮评分；需要三轮须在首轮前写明；结束时允许无共识 |
| 第24–25、30–31页：个人上轮答案、匿名反馈、中立主持 | 反馈含本人旧答、完整分布、支持理由与少数异议 |
| 第33–37页：预定分析、稳定性、缺失值与权重 | 显示分母与分布；不以名望或自信程度加权 |
| 第37–40、51、53–56页：透明报告与质量审查 | 保存过程、限制和偏离说明，不用核对表冒充有效性认证 |

适合：存在不确定性、跨领域取舍或多种可行方案的问题，例如世界设定融合、文明资源制度、叙事与视觉方案比较。单条事实查询、单专家资料读取、明确约束下的简单改稿，不自动升级成多轮会议。可通过计算、实验或可靠资料回答的问题先核实；事实不能靠多数票改写。[手册第12–14页]

纯创意发散可以作为准备阶段。若仅头脑风暴而未重复评议同一问题，不把它标为完成德尔菲评议。

## 2. 主持、席位与材料

主持者负责题目、证据整理、匿名反馈和记录；默认不参与评分。项目负责人负责最终选择，通常为用户或用户已授权的项目主对话。采用建议不自动触发发布、付费调用或其他外部操作。

每次先填写记录模板并冻结：议题与选项、世界设定版本、硬约束、首轮证据包、席位资格、评分维度与锚点、评分轮数、共识口径、缺失处理和允许的题目修改范围。正式评分前用一个样题检查歧义和量表方向，记录预试修正；预试不计为首轮。

选席位以问题相关性为先，再按需要检查专业、地域与生活年代；民族和名望不提供能力分或额外票权。同一人物的跨专业条目及别名不能重复计票。资料未知继续留空。[手册第15、23–24、36页；AI去重规则为本库适配]

项目默认用4–7个相关视角，具体数量可在首轮前调整；这不是 RAND 规定的人数。登记每项题目的合格席位名单和不可缺少的领域。受影响者视角需要保留，但 AI 编写的“居民意见”必须标为模拟，不能冒充访问过真实居民。

每个席位记录：匿名编号、实际类型（真人／AI方法视角）、所用研究卡及版本、相关能力与缺口、立场或利益假设、来源重叠。AI另记执行实例、模型与共享上下文情况；同一实例不能改几个署名重复投票。真人与AI分别汇总，不能混成一个“专家人数”。

共同证据包区分：

- **来源事实**：可定位的出处、日期、适用条件和核读范围。
- **分析推断**：假设、推导结果和可能推翻判断的证据。
- **原创设定**：用户已固定或正在比较的世界规则。
- **价值取舍**：项目偏好、受影响对象及代价。

所有席位取得同一版本的共同材料，各自方法资料另登记。新增事实先核来源再同步给所有合格席位；多个角色引用同一文献只构成同一来源。历史专家方法可启发提问，失效知识不能压过现行证据。

## 3. 一次讨论如何进行

| 阶段 | 执行动作 | 必须保留的产物 |
|---|---|---|
| 准备／Round 0 | 明确问题与候选项，补充遗漏选项，核材料并预试；冻结会前约定 | 问题版本、证据包、席位表、分析口径 |
| 评分第1轮 | 各席位先独立读材料并回答；不看其他席位答案或主持者偏好的结论 | 原始评分、简要理由、引用、反例、改变判断的条件 |
| 受控反馈 | 主持者去署名整理每题完整分布，归纳支持、反对与不确定理由；回传本人旧答 | 同一版群体摘要＋各席位个人旧答 |
| 分歧澄清 | 用中立问题核对定义、证据或价值冲突；让反对理由得到回应 | 分歧清单、澄清答复、共同新增材料及变更记录 |
| 评分第2轮 | 对同一版本题目和量表再次独立作答；允许改分或坚持原答 | 新评分、变化或不变的理由、仍保留的异议 |
| 结束与选择 | 按预定轮数停止汇总，报告倾向、分歧和缺口，负责人另作选择 | 最终分布、异议、待验证事项、选择及其理由 |

“独立”指首轮信息不相互泄露，不等于模型在统计上独立。若同一上下文已经看过其他答案，不能补写成盲评；记录已受影响。本轮执行环境不能隔离上下文时，标为“单模型多视角推演”，不得声称完成独立首轮。

反馈采用稳定编号，隐藏名望和个人署名，保留理解论据所需的专业背景与来源。主持者可以保有身份映射。资料本身可能暴露研究对象，AI也可能推断身份，所以通常只能承诺部分匿名，不承诺完全不可识别。

主持者应问“哪些条件使两个判断不同”“哪项证据会改变看法”，不得要求异议方迁就多数、按预设结论改分或把少数理由从摘要中删去。反馈中的理由必须能追溯到原始答复；合并同义意见时保留编号映射。[手册第24、30–31、35页]

第1轮已出现一致意见的项目仍进入第2轮，至少留一次看过反馈后的复评机会。默认两轮评分；若会前选定三轮，则再重复反馈与独立评分一次。不能看见结果不满意才增加轮次，也不能“讨论到全部同意”。轮数是这次评议的研究设计，不是整个项目的执行预算；新证据可以启动新的、有版本记录的评议。

只改错字且不变语义时记录修订；改变命题、选项、量表、硬约束或重要情境时建立新版本。不同版本分开报告，不能用旧分和新分宣称意见变稳定。要声称新版本完成本协议，也须对该版本完成至少两轮可比评分；否则标为未完成评议。

## 4. 评分与结果口径

先指定一个主判断问题，例如“在锁定世界规则与资源条件下，此方案满足目标的程度”。可增加可行性、目标适配、代价可控性等辅助维度，但每个维度单独评分，不把不同构念直接相加。各选项使用同一组问题与量表。

以下数值是**本库创作讨论的默认约定，不是 RAND 的统一标准或已验证的AI共识算法**。如需其他口径，在首轮前说明并冻结；不能为改变结果而事后调门槛。[手册第29、33–36页]

| 事项 | 本库默认约定 |
|---|---|
| 评分 | 1–9；1–3明确不支持，4–6混合／条件尚未满足，7–9支持；各档另附本题具体锚点 |
| 无法作答 | 单列“证据不足／超出能力／未返回”，不算5分、0分或反对票，不代填上一轮答案 |
| 有效覆盖 | 每题有效评分数 n 至少4、n／本题预定合格席位数至少80%，且会前指定的必要领域均有有效答复；任一不满足则标“覆盖不足” |
| 支持倾向 | 覆盖合格，至少75%的有效分在7–9且没有1–3分；同时单列所有附加条件 |
| 反对倾向 | 覆盖合格，至少75%的有效分在1–3且没有7–9分 |
| 其他结果 | 覆盖合格但未满足以上条件，标“未形成一致倾向”，保留两端理由；不得把4–6分都当支持 |
| 展示 | 原始匿名评分、1–9各分频数、中位数、最小值与最大值、各段人数／有效分母、缺失数／预定分母 |
| 权重 | 默认等权；自报把握程度只解释不确定性，不作为加权或概率校准依据 |

“支持倾向”在AI组只能写成**本次模拟视角的支持倾向**。不能改写成“多位真人专家一致认可”“方案正确概率75%”或“科学事实已确立”。即使是真人组内共识，也须保留样本、方法和证据限制。

每题比较两轮的完整分布，并报告同一席位的分值变化及可配对人数；成员退出导致分布改变时明确标注。默认不做显著性推断，也不把中位数相同视为稳定。若另以稳定性作为判据，须事先给出可计算定义及成员变化处理方式。[手册第34–37页]

两个记录规则的演算例子，**不是已举行会议的数据**：

- 六席评分为 `8,8,8,8,7,2`：支持段5／6，中位数8，范围2–8；仍有明确反对，按本库默认规则不能称一致支持。需要展示第六席的理由。
- 六席只有 `8,8` 返回：有效覆盖2／6，尽管返回者全支持，也只能记“覆盖不足”，不能说全体达成共识。

经核验确实违反硬约束或关键事实的方案单独标明冲突，不能被高分抵消。未经核实的反对意见先进入待验证清单，不自动变成永久否决权。最终选择可以接受已知取舍，但负责人必须写明依据、保留的风险以及为什么采纳或不采纳少数建议。

## 5. 面向蒸馏专家的明确适配

| 原手册面向真人研究的内容 | 本项目的处理与理由 |
|---|---|
| 第29页建议不设“不知道”选项，并讨论最佳判断及允许缺答的替代做法 | AI资料不足时允许明确弃答，优先防止编造；弃答和中间分不同，分母与缺口公开。这是有意偏离该项建议 |
| 参与者有真实专业经验、身份及利益关系 | 蒸馏卡仅提供方法视角，不具有本人经验或授权；作者名不能提供票权或替代引用 |
| 匿名减少社会地位影响 | 使用去署名反馈和隔离首轮，记录实际能做到的匿名程度；单模型换角色不等于多位独立专家 |
| 第22、39页建议并行重复面板以检验结果可重复性 | 可在重要议题中预先设计独立复核；重复同一模型与同一材料不自动成为独立验证，本协议未实现此能力 |
| 第40页的前瞻注册与真人参与保护 | 本库先保存有日期和版本的会前协议，不冒称公开注册；若将来招募真人或开展正式研究，另按该研究要求处理知情参与、隐私及适用审查 |

## 6. 交付与质量检查

完整记录使用[模板](expert-deliberation-template.md)。结论至少包括：当前推荐、适用条件、每项分布与分母、少数意见、证据缺口、最小验证行动、负责人决策。未定事项不静默写入世界正史或后续资产规范；确需先行创作时注明暂定规则、影响范围与重开条件。

从 RAND 的 DCAT 四项核心条件提取以下检查，逐项写“满足／不满足／未核”并指向记录位置，不用总分抵消关键缺项：[手册第43–45、51、56页]

1. 匿名程度是否事先说明，执行中是否保持？
2. 同一题目是否至少有两轮可比的独立评分，并有复评机会？
3. 群体结论是否由真实留存的评分及预定口径得出？
4. 是否反馈群体分布、理由和各自旧答，包含异议？

另检查选人理由、共同材料与预试、题目和量表、缺失及成员变化、协议偏离、分析与最终选择是否透明；真人参与项目另检查相关参与保护。本段是项目自检，不是对官方DCAT的完整翻译，也不构成 RAND 认证。只有文档或模拟演算时，不得报告实际面板执行通过。
