# 专家讨论记录模板

[执行协议](expert-deliberation-protocol.md) · 协议版本1.0

复制到具体项目的决策记录目录填写；本文件是空模板，不代表已经进行专家会议。首轮前冻结A至C及D部分的答复格式，之后保留修改记录，不回填一个看似预先约定的门槛。

## A. 议题与约定

- 会议ID、日期、协议版本：
- 当前模式：AI方法视角／真人评议／混合但分组统计／单模型多视角推演。
- 问题、选项及不在本次范围内的事项：
- 世界设定／项目目标版本与硬约束：
- 为什么需要多视角迭代，能先核实的事实有哪些：
- 主持者、记录者、最终决策负责人；主持者是否评分及理由：
- 评分轮数：默认2；改为3或其他设计的会前理由：
- 匿名程度与首轮上下文隔离方式；无法保证之处：
- 预试题、结果、修正事项及正式题目冻结时间：
- 每项合格席位名单、必要领域、覆盖门槛：
- 停止安排、问题修改规则、缺失处理：
- 共识口径：采用协议默认值／其他已在首轮前明确的口径。
- 对原手册和本库默认值的偏离及原因：

## D. 首轮独立答复

每个席位分别填写，不展示他人答案。理由提供可核对的简要说明，不要求不可见的内部思维过程。

- 席位ID、实际类型、题目ID／版本、材料版本、时间：
- 评分1–9，或明确弃答类别：
- 判断及条件：
- 证据ID与适用范围：
- 最强反例／最关键代价：
- 哪些新证据会使判断改变：
- 把握程度及其依据（不是校准概率，不用于加权）：
- 是否已接触其他答案或主持者倾向；若是，说明污染范围：

## E. 主持反馈与澄清

| 题目／版本／轮次／分组 | 预定合格数 | 有效数／覆盖率 | 各匿名原始分与1–9频数 | 中位数、最小值、最大值 | 支持／中间／反对人数与分母 | 缺答类别、必要领域覆盖 | 按预定规则的结果 |
|---|---|---|---|---|---|---|---|
| 待填 | | | | | | | |

- 主要支持理由及对应匿名答复：
- 少数／反对理由及对应匿名答复（不得删去）：
- 分歧属于事实、定义、模型假设还是价值取舍：
- 中立澄清问题与各方答复：
- 新增共同材料、来源核验和版本变化：
- 发给每席的个人反馈：本人原评分与理由＋上述统一摘要。

## F. 独立复评

再次使用D部分字段，并增加：上轮分值、新分值、变化或坚持的理由、已回应与仍保留的异议。会前约定第三轮时，再复制E和F；不能为凑共识临时加轮。

跨轮比较：同题同版本的匿名分布、逐席变化、可配对人数、退出与缺失。若题目或情境有实质变化，单列新版本，不将不可比评分连成“趋同过程”。

## G. 最终选择与待验证事项

- 每项最终状态：支持倾向／反对倾向／未形成一致倾向／覆盖不足／未完成评议。
- 推荐及适用条件；AI结果必须带“本次模拟视角”限定：
- 仍成立的少数意见、证据缺口与事实／硬约束冲突：
- 最小验证行动、负责人、成功或失败的可观察判据：
- 决策负责人选择了什么、为什么；与评分倾向不同的理由：
- 已确认设定与暂定设定分别列出；影响哪些世界规则或资产：
- 哪些新证据会重开该议题：
- 材料、题目、人员、阈值或流程的实际偏离：
