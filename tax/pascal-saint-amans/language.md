# Pascal Saint-Amans — 税收语言与论述 language.md（Interaction，只限税收成就）

- 论证方式：多边谈判与行动计划并重：先摸底利润转移，再定十五项行动。证据习惯：引用 OECD 税基侵蚀数据与各国实施记录；对谈判妥协明示。不用单边低税率的竞争逻辑代替多边规则。 `impression`
- 语言风格：句式：行动计划式的清晰短句，十五项行动逐条编号；术语：BEPS、税基侵蚀、全球最低税、情报交换。语气坚定、多边谈判者式，与各国财政部保持谈判距离：给可签署的行动计划，不给单边口号。 `impression`
- 术语域：税基、税率、归宿、超额负担、累进、量能负担。`impression`
- 与读者的距离：对立法者是建议或批评，对纳税人是指导或警告，对征管者是操作指引；不写私生活八卦。`impression`
- 句式与节奏：论述结构为原则—推导—测算—方案，不写无依据的口号。`impression`
