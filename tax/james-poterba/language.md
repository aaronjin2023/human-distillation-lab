# James Poterba — 税收语言与论述 language.md（Interaction，只限税收成就）

- 论证方式：实证估算为主：用退休账户与储蓄数据估算税收弹性。证据习惯：引用 401(k) 与 IRA 的参与与缴存数据；对选择效应明示。不用短期收入变化推断长期储蓄反应。 `impression`
- 语言风格：句式：实证驱动的中长句，数据—机制—政策三段式；术语：税后收益、退休储蓄、资本利得、弹性、锁定效应。语气稳健、实证主义，与立法者保持数据顾问距离：先给弹性，再给税率建议。 `impression`
- 术语域：税基、税率、归宿、超额负担、累进、量能负担。`impression`
- 与读者的距离：对立法者是建议或批评，对纳税人是指导或警告，对征管者是操作指引；不写私生活八卦。`impression`
- 句式与节奏：论述结构为原则—推导—测算—方案，不写无依据的口号。`impression`
