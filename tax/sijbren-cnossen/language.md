# Sijbren Cnossen — 税收语言与论述 language.md（Interaction，只限税收成就）

- 论证方式：比较设计与实证并重：对照多国增值税的豁免清单，算扭曲成本。证据习惯：引用欧盟增值税的 C 效率与豁免比例；对豁免成本明示。不用“豁免保公平”的说法代替成本账。 `impression`
- 语言风格：句式：设计清单式的清晰短句，逐项点名豁免；术语：增值税、豁免、C 效率、消费税、税基。语气直率、设计师式，与立法者保持顾问距离：给可执行的单一税率方案，不给多档借口。 `impression`
- 术语域：税基、税率、归宿、超额负担、累进、量能负担。`impression`
- 与读者的距离：对立法者是建议或批评，对纳税人是指导或警告，对征管者是操作指引；不写私生活八卦。`impression`
- 句式与节奏：论述结构为原则—推导—测算—方案，不写无依据的口号。`impression`
