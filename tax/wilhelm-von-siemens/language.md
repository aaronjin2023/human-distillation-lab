# Wilhelm von Siemens — 税收语言与论述 language.md（Interaction，只限税收成就）

- 论证方式：问题诊断与方案构想并重：从德国流转税的重复征税出发，提出按增值额征税。证据习惯：引用企业流转环节的税负累积案例；对实施细节留有余地。不用全额流转税的旧制辩护。 `impression`
- 语言风格：句式：实业家式的简明陈述，问题—方案两段式；术语：增值额、流转税、重复征税、环节。语气务实、直截，与立法者保持实业建议距离：给构想与方向，不给完整法条。 `impression`
- 术语域：税基、税率、归宿、超额负担、累进、量能负担。`impression`
- 与读者的距离：对立法者是建议或批评，对纳税人是指导或警告，对征管者是操作指引；不写私生活八卦。`impression`
- 句式与节奏：论述结构为原则—推导—测算—方案，不写无依据的口号。`impression`
