# Dong Qichang — conflicts.md（保留，不统一）

1. **南北宗论的归属**：南北宗之分最初由莫是龙提出、董其昌阐发，是定论；但“王维为南宗之祖”是董其昌的建构，现代画史多有商榷，记入此处，不统一。
2. **“以境之奇怪论”引文**：董其昌《画禅室随笔》“以境之奇怪论，则画不如山水；以笔墨之精妙论，则山水决不如画”是画史广引之语，本 skill 只作画面依据，不展开画论争论。
3. **晚期分期**：晚期笔法更淡雅的说法是学界共识，但具体以哪几幅为晚期代表，各家说法不一，记入此处，不统一。
4. **《秋兴八景图》版本**：传世有多个版本，蒸馏以博物馆藏本的画面特征为准。
