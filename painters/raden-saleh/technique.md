# Raden Saleh — 技法与工序 technique.md（只限作品）

> v0.1（2026-10-26 网络核对后建立）。

Procedure：他怎么画出来的？只从画作里找媒材、底子、笔法、层序、修改痕迹。

- 媒材：布面油画；拉登·萨利赫在欧洲学习 20 年（1829–1852），习得学院派油画技法。`artifact`
- 《迪波内戈罗被捕》1857 年作，是对荷兰画家皮内曼 1830 年《迪波内戈罗投降》的回应与颠覆：被捕者挺立不屈，荷兰人头大可笑，未画荷兰旗。`artifact`
- 动物画：狮子、虎、马的解剖准确，毛发层层叠加，是其在欧洲成名的题材。`artifact`
- 热带风景：爪哇丛林首次成为画的主体而非背景，是印尼绘画的开创。`artifact`
- 层序：起稿 → 底色 → 分层 → 细化 → 罩染。
