# Raden Saleh — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **生年：** 一说 1811 年（维基百科、新加坡国家美术馆），一说 1807 年（v2 第 6 节第 5 条）；本 skill 以 1811 年为主，另说记于此。
2. **《狮子猎手》年代：** 任务名单作 1842 年；个别资料将狮子题材作品记为 1840 年前后，未核对到确切出处，见 known_gaps。
3. **族裔：** 阿拉伯—爪哇裔，哈德拉米家族之后；本 skill 只写画作，不写族裔考证。
4. **《迪波内戈罗被捕》的解读：** “颠覆皮内曼”是近年学界的主流解读，但画家本人的文字未见，解读的边界记入此处。
