# Caravaggio (Michelangelo Merisi) — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 光即语言：光本身就是内容——光是召唤、是审判、是启示，暗是尘世，光一到，人才醒。
- 黑暗即语言：暗部不是背景，是深渊——人物从黑暗中浮现，又随时会沉回去。
- 定格即语言：画面是决定性瞬间的前一秒——刀未落下、手未收回，时间停在最紧张处。
- 写实即语言：圣徒的脏脚与皱纹不是缺陷，是真实——神圣不在理想里，在市井里。
- 浅空间即语言：人物贴近画面，观者无处可退，只能直面。
- 视线引导：光束 → 基督的手 → 马太的脸 → 税吏群，视线随光走。
