# Van Gogh — 画面语言 language.md（Interaction，只限作品）

> v0.2（2026-10-26 审计修订：删除未核实的信件归属）。

- 笔触即语言：笔触方向 = 形体方向 = 情绪方向；天空旋、山丘横、柏树竖，三向对撞构成画面节奏。`verbatim`
- 色彩即语言：补色对撞（黄—蓝、橙—紫）代替灰阶明暗；夜空的色彩比白天更浓烈，是画面上的事实（v0.1 所写“致妹妹信原意”未找到出处，已删除该归属，见 conflicts.md 第 7 条）。
- 构图即语言：大面积天空 + 一条暗前景压底；主体顶边、不留安全边距，观者被拉进画面。
- 光影即语言：光是画出来的（星月自发光），不是照出来的；阴影是彩色的。
- 视线引导：旋涡中心 → 星月 → 柏树顶 → 村庄，视线在画面里转圈，不是一眼看完。
