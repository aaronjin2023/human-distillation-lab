# Kitagawa Utamaro — 技法与工序 technique.md（只限作品）

> v0.1（2026-10-26 网络核对后建立）。

Procedure：他怎么画出来的？只从画作里找媒材、底子、笔法、层序、修改痕迹。

- 媒材：多色木刻版画（锦绘），纸本；与北斋、广重同为四人分工。`artifact`
- 大首绘（ōkubi-e）：只画头与肩的大特写，是歌麿开创并与之绑定的体裁。`artifact`
- 云母粉底：在背景上撒云母粉（muscovite），出银白闪光，是《当世三美人》的豪华工艺。`artifact`
- 《当世三美人》约 1792–93 年作，竖幅大判，三角构图，三人各有家纹可辨。`artifact`
- 面容的个性化：三人初看相似，细看口鼻眼各有差别，是当时浮世绘中少见的写实程度。`artifact`
- 层序：线稿 → 主版 → 分版 → 叠印 → 云母粉底收尾。
