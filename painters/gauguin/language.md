# Paul Gauguin — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 平涂即语言：平涂 = 象征，红田野不是红土，是“血与生命”的象征；平涂一出渐变，象征就没了。`verbatim`
- 轮廓即语言：深色轮廓如彩色玻璃铅条，线越重，象征越强。
- 红黄即语言：红与黄是全画的象征色，红 = 血与生命，黄 = 神圣。
- 分隔即语言：树干斜线分隔现实与幻象，线一过即是梦境。
- 简化即语言：形体简化不是画不完，是“原始”的语法——越简，越神圣。
