# Piet Mondrian — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

- 媒材：布面油彩，平涂；晚期《百老汇爵士乐》用小色块与彩色线。`artifact`
- 新造型主义：1917 年与凡·杜斯堡等创办《风格》杂志，只用横竖线与三原色。`artifact`
- 《百老汇爵士乐》：1942–1943 年纽约时期，黑线断成彩色小方块，节奏如爵士乐与城市网格。`artifact`
- 演变：早期风景与树 → 立体主义 → 新造型主义网格 → 纽约彩色节奏。只按作品序列。
- 层序：网格起稿 → 白底 → 原色分格 → 黑线收直 → 检查平衡。
