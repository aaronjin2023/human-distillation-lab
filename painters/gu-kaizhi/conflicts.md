# Gu Kaizhi — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。只限作品。

1. **无亲笔原作：** 现存《洛神赋图》《女史箴图》《斫琴图》皆为后世摹本 / 传本，非顾恺之亲笔。`artifact`（大英博物馆：女史箴图为 5–8 世纪作品，可能摹自晋代原作；洛神赋图辽宁本为宋摹本，学界共识）——本 skill 只蒸“传顾恺之风格的范式”，不声称复刻原作。
2. **生卒约数：** c.344–c.406，一说 345–406；本 skill 保留 c.（约），不写精确年份。`artifact`
3. **《女史箴图》残缺：** 大英博物馆本缺前三景，另有南宋纸本全卷十二景藏故宫博物院；两本分段与设色有出入，蒸馏以大英博物馆本为主，纸本作对照。`artifact`
4. **《洛神赋图》多本：** 北京故宫、辽宁省博、弗利尔美术馆各藏宋摹本，构图大同小异、细节与设色有别；不以某一本为准，取共有的线与分段。`artifact`
5. **画论真伪：** 《论画》等文字为传世画论，版本有出入；引用的“传神写照，正在阿堵中”为通说，个别字句版本不同，见 language.md 标注。
