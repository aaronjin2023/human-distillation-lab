# Georges Seurat — 母题与演变 motifs.md（Memory，只限作品序列）

> v0.1（2026-10-26）。只限作品。

反复母题与作品序列演变。早期素描现实主义 → 中期点彩定型（1884 年）→ 晚期更科学（以 1884–1886 年《大碗岛》为准）。

- 反复母题：大碗岛人群、阿尼埃尔浴者、马戏团、河岸风景。`verbatim`
- 《大碗岛的星期天下午》1884–1886 年与《阿尼埃尔的浴者》1883–1884 年：前者是“休闲的秩序”，后者是“劳动的秩序”，一闲一劳构成修拉的两个极点。
- 演变：早期素描与现实主义影响，中期点彩定型（1884 年），晚期更趋科学、构图更严；31 岁早逝，晚期短暂。`impression`（学界分期通说）
- 系列性：大碗岛与阿尼埃尔是其最系统的母题序列，同一河岸在不同点彩里反复变奏。
