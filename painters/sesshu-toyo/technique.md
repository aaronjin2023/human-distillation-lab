# Sesshū Tōyō — 技法与工序 technique.md（只限作品）

> v0.1（2026-10-26 网络核对后建立）。

Procedure：他怎么画出来的？只从画作里找媒材、底子、笔法、层序、修改痕迹。

- 媒材：纸本水墨为主，间有绢本；墨分浓—淡—干—湿，纸的吸水性即画面的一部分。`verbatim`
- 泼墨（hatsuboku）：湿墨泼洒成形，趁湿以浓墨线收住，是《破墨山水图》（1495，传）的核心技法。`artifact`
- 师法夏圭一路：以南宋院体山水为骨，改以日本式的锐利折角与高对比，近景重、远景淡。`artifact`（维基百科“Sesshū Tōyō”）
- 《秋冬山水图》为国宝，东京国立博物馆藏，1470 年代作；《四季山水图》长卷 1486 年作，毛利美术馆藏。`artifact`
- 《慧可断臂图》1496 年作，人物大幅、线条沉重，与山水一路的轻逸形成对照。`artifact`
- 层序：淡墨起稿 → 湿墨晕染 → 浓墨勾皴 → 枯笔点睛 → 落款；几乎无修改痕迹。
