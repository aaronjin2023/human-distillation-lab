# Jean-Honoré Fragonard — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 笔触即语言：快笔 = 愉悦与动势，慢笔只给面部与飞鞋，速度本身就是情绪。`verbatim`
- 弧线即语言：秋千弧线 + 裙摆弧线 + 飞鞋弧线，三弧同向，视线被带着上下飞。
- 光斑即语言：阳光透过树叶的斑点是画面的节奏点，亮处即视线落点。
- 色彩即语言：奶油粉 + 叶绿 = 私密花园的甜与生机，艳而不俗靠提亮不靠加黑。
- 私密即语言：观者被放在“偷看”的位置，丘比特噤声的手势直接对观者说话。`verbatim`
