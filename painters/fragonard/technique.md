# Jean-Honoré Fragonard — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

媒材、底子、笔法、层序、修改痕迹，只从画作与技法报告里找。

- 媒材：布面油画；《秋千》1767 年，私人委托作品，题材是情人的幽会（画面上有飞鞋与示意噤声的丘比特小像）。`artifact`
- 笔法：羽毛状流畅笔触，树叶碎笔点染，衣裙长笔带飞动感；速度感是风格本体。
- 层序：淡线起稿 → 亮调底色 → 树叶与人物分层 → 高光细化 → 暖色罩染。
- 《爱情的历程》是组画（多幅连作），同一爱情追逐主题分幅推进；蒸馏时按组画逻辑，不只取单幅。`artifact`
- 修改痕迹：画面上少见大幅改动；速度与一次性是其特点，改动多在素描阶段。`impression`（弗拉戈纳尔研究通说）
