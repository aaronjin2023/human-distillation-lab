# Masaccio — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 透视即语言：空间本身就是内容——画是一扇窗，窗外是与现实同一法则的世界。`impression`（大英百科全书：马萨乔把绘画当作窗后的真实世界）
- 光即语言：统一的光源是理性的象征，全幅只有一个太阳。
- 体积即语言：人物如古典雕塑般站立，衣纹的明暗三段即身体的结构。
- 连续叙事即语言：同一画面三个时刻，时间在空间里展开，观者的视线就是叙事的顺序。
- 视线引导：灭点 → 基督头部 → 左右人物 → 远山，视线在透视空间里走直线。
- 留白即语言：远景的淡与空不是没画完，是空气透视——空间越深，颜色越淡。
