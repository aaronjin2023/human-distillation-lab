# Wang Wei — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

## 媒材与底子
- 纸本水墨为主，间有绢本；淡墨晕染宜纸，雪雾靠纸的留白。`artifact`
- 用色极淡：墨为主，间施淡赭、花青、淡石绿，不作青绿重彩。`verbatim`（辋川 / 雪溪摹本）

## 核心技法：破墨与淡染
- 王维被后世称为水墨山水之祖、“破墨”之法与之相联；但破墨的具体面貌在传世摹本上并不一致，见 conflicts.md。`artifact`（画史通说）
- 淡染：以水破墨，墨色由浓到淡自然过渡，山形如雾中剪影。`verbatim`
- 少皴：与北宋山水繁密皴擦相对，王维一路皴极少，山体以晕染见形。`artifact`（董其昌一路的描述）
- 诗画合一：画上有诗，诗即画意；苏轼“诗中有画，画中有诗”即指此。`artifact`（苏轼评语）

## 层序
- 淡墨起稿 → 淡墨铺底 → 浓墨略加 → 枯笔点染 → 题诗钤印。淡字贯穿始终。
