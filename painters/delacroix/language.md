# Eugène Delacroix — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 色彩即语言：补色对撞 = 能量，红绿、黄蓝一撞，画面就“烧”起来。`verbatim`
- 对角线即语言：斜线 = 冲锋与倾倒，视线被斜线带着冲向自由女神 / 滑向萨达那帕拉。
- 笔触即语言：笔触方向 = 情绪方向，笔触越乱，场面越烈。
- 烟雾即语言：远景烟雾溶化不是没画完，是战场的语法——清晰只给前景尸体与旗帜。
- 金器即语言：萨达那帕拉的金器与白袍是红床上的节奏点，亮处即视线落点。
