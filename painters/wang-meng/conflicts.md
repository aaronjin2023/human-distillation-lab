# Wang Meng — conflicts.md（保留，不统一）

1. **生卒年份**：1308–1385 为通说；个别网络资料误写 1271–1368（与元代起讫混淆），本 skill 以 1308–1385 为准。
2. **《葛稚川移居图》版本**：传世有多个版本，2011 年拍卖的《稚川移居图》成交价 4.025 亿元是拍卖纪录，不是真伪结论；蒸馏以博物馆藏本为准。`artifact`
3. **晚期分期**：晚期笔法更苍厚的说法是学界共识，但具体以哪几幅为晚期代表，各家说法不一，记入此处，不统一。
4. **与董其昌的关系**：董其昌推崇王蒙、视其为南宗正脉是定论，但“王蒙影响董其昌多深”各家说法不一，不展开。
