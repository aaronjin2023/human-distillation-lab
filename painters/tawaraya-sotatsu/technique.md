# Tawaraya Sōtatsu — 技法与工序 technique.md（只限作品）

> v0.1（2026-10-26 网络核对后建立）。

Procedure：他怎么画出来的？只从画作里找媒材、底子、笔法、层序、修改痕迹。

- 媒材：纸本金地设色屏风为主；金箔、银粉、矿物颜料、墨并用。`verbatim`
- 垂洒法（tarashikomi）：第二层在第一层未干时加上，墨色与色彩自然晕化，是宗达最具标志性的技法。`artifact`
- 与本阿弥光悦合作和歌料纸装饰，是琳派“诗画一体”的源头之一。`artifact`
- 《风神雷神图屏风》无署名、无印章，仍被公认为宗达真迹，是日本美术史的特例。`artifact`
- 《莲池水禽图》以墨色垂洒表现水、蒸气与光，全幅几乎无直线，与雪舟的锐利形成对照。`artifact`
- 层序：金地 → 淡墨起稿 → 垂洒 → 平涂 → 勾线。
