# Tawaraya Sōtatsu — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **卒年：** 已定为 c.1570–c.1640（英文维基；2026-10-26 用户定夺）。另一说 c.1643（法/波兰语维基、Encyclopedia.com；arthistoryreference 作 c.1600–1643）记于此，生卒均不确切。
2. **生年与出身：** 生年约 1570，出生地不详；谷文晁称其原籍能登、姓或为野村，皆为后人说法，未确证。
3. **风神雷神屏风归属：** 无署名无印章，归属宗达是学界共识而非实物自证；本 skill 按共识写，记入此处。
4. **琳派之名：** “琳派”并非当时自称，是后人按光琳之名追认的流派概念；宗达与光悦只是“先驱”，非严格意义上的同门。
