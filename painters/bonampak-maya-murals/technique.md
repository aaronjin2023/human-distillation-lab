# Bonampak Maya Murals — 技法与工序 technique.md（只限作品）

> v0.1（2026-10-26 网络核对后建立）。

Procedure：他怎么画出来的？只从画作里找媒材、底子、笔法、层序、修改痕迹。

- 媒材：湿壁画（fresco）——颜料画在湿灰泥上，灰泥干后颜色即渗入墙体；每厅无灰泥接缝，说明每厅一次画完。`artifact`
- 颜料：矿物色——红赭、玛雅蓝、孔雀石绿、黄赭、淡紫，黑线勾边。`artifact`
- 团队：非一人之作，是大师加助手的大团队，另有灰泥工、颜料工与书吏参与。`artifact`
- 波南帕克壁画殿（1 号建筑）：三厅，约 790 年，恰帕斯玛雅低地；1946 年由吉尔斯·希利发现；雨水渗入形成的碳酸钙薄层意外保护了壁画。`artifact`
- 约 281 个人物，约三分之一有题铭、约一成题铭空白、其余无题铭；空白题铭的原因有政治变局、工程中断等多种说法。`artifact`
- 层序：灰泥 → 红底 → 平涂 → 勾线 → 题铭。
