# Piero della Francesca — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 几何即语言：构图本身就是内容——网格、中轴线、对称即秩序，秩序即神圣。`impression`（学界共识）
- 静止即语言：人物不动、不笑、不哭，静止不是冷漠，是永恒——时间在画面上停住了。
- 淡彩即语言：颜色淡而准，每一块颜色都在网格里有自己的位置，不多不少。
- 间隔即语言：人物之间的空隙与建筑的间隔是“静”的来源，密了就吵。
- 光即语言：清澈均匀的日光，不制造戏剧，只照亮秩序。
- 视线引导：中轴线 → 基督 → 远山河流，视线在几何中走直线。
