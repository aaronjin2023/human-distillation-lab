# Gustave Courbet — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

媒材、底子、笔法、层序、修改痕迹，只从画作与技法报告里找。

- 媒材：布面油画；调色刀是其标志性工具，颜料堆积如泥。`artifact`（奥赛美术馆藏品说明）
- 底子：暗色底，土调从底子就定下；亮部靠铅白厚涂一次提亮。
- 笔法：调色刀厚涂 + 笔刷并用；刀痕本身就是画面语言。
- 层序：暗调底色 → 横排起稿 → 调色刀厚涂分层 → 面部细化 → 土色罩染。
- 《画室》1854–1855 年（《画家的工作室：真实的寓意》）：画家本人居中，左右分“支持者”与“世界”，是其现实主义宣言式的群像；1855 年世博会外自建“现实主义馆”展出。`artifact`
