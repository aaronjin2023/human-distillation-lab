# Diego Velázquez — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 空气即语言：空气本身就是内容——人物在空气中呼吸，空间不是空的，是有质感的。
- 镜子即语言：镜中人是画外人，画中人看画外人；观看本身就是内容——谁在看谁？
- 松动即语言：笔触的松动不是画不准，是看得准——眼睛看到的是色块与光，不是线条。
- 灰调即语言：灰不是无色，是所有颜色的混合——真实世界的颜色就是灰的。
- 宫廷即语言：宫廷的庄重与日常并存——公主、侍女、侏儒、狗同处一室，等级在空气中淡化。
- 视线引导：公主 → 镜面 → 画家 → 观者，视线在画内画外循环。
