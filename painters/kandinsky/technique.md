# Wassily Kandinsky — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

- 媒材：布面油彩；另有大量水彩习作与版画。`artifact`
- 《论艺术的精神》：色彩与音乐通感是画家公开的理论文字，黄色如小号、蓝色如大提琴等对应关系见该书。`artifact`
- 构成系列：即兴（Improvisation）、印象（Impression）、构成（Composition）三类命名是画家本人的分类。`artifact`
- 《构成VII》：1913 年作，30 余幅习作在先，正稿据载四天完成，主题与洪水、末日、复活有关——主题解读见 conflicts.md。`artifact`
- 层序：小稿 → 底色和弦 → 色层分层 → 黑线收形 → 罩染收尾。
