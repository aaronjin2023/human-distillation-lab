# Antoine Watteau — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 笔触即语言：轻笔 = 轻盈与短暂，重笔只给丝绸高光与面部，轻重本身就是情绪。`verbatim`
- 雾即语言：远景溶化不是画不完，是“梦”的语法——清晰只给近处人物。`verbatim`
- 视线引导：人物回望与斜线链牵着观者从前景走向船，再望向远山。
- 色彩即语言：粉彩 + 银灰 = 克制的高贵，艳色只点一处（红衣、丘比特），不铺满。
- 人物即语言：同一群人既在出发又在告别，神情游移不定——画面不给唯一答案。`impression`（学界共识：去 / 留的暧昧）
