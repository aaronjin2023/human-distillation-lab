# Antoine Watteau — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

媒材、底子、笔法、层序、修改痕迹，只从画作与技法报告里找。

- 媒材：布面油画，薄涂 + 透明罩染为主；素描底稿常用红粉笔 / 三色粉笔，线条轻快。`artifact`（卢浮宫藏品说明与素描研究）
- 底子：浅色底，银灰调从底子就定下；色彩靠多层薄涂叠出，不靠厚涂。
- 笔法：羽毛状碎笔触，远景溶化、近景稍实；衣纹用短笔的明暗点出，不勾死线。
- 层序：淡线起稿 → 银灰底色 → 人物淡彩分层 → 面部手部细化 → 雾气罩染。
- 修改痕迹：画面上少见大幅改动，人物位置多在素描阶段已定；油彩层薄，改动空间小。`impression`（瓦托研究通说）
- 雅宴画（fête galante）：1717 年《发舟西苔岛》为入选法国皇家绘画雕塑学院的呈交作品，学院为此新设“雅宴画”类别。`artifact`
