# Ni Zan — 技法与工序 technique.md（Procedure，只限作品）

## 媒材与纸

- 纸本水墨为主，极少设色；墨分浓—淡—干—湿，纸的吸水性即画面的一部分。`verbatim`
- 折带皴：以方折短笔横向叠擦画坡石，棱角如折带，是倪瓒最具辨识度的皴法。`artifact`（画史通说）

## 一河两岸

- 定式构图：近岸（枯树 + 坡石 + 茅亭或空屋）— 中景大片空白水面 — 远岸低矮远山，三段式。`verbatim`（《六君子图》《渔庄秋霁图》）
- 《六君子图》（1345 年，上海博物馆藏）：六株枯树立于近岸小坡，隔水远望低山；黄公望题诗“六君子”命名。`artifact`（维基百科“六君子图”；上海博物馆说明）
- 水面不画一笔水纹，空白即水。`verbatim`

## 笔法与层序

- 笔法：枯笔、干笔为主，中锋写树、侧锋皴石；逸笔草草，看似草草实则一笔不苟。`artifact`
- 层序：淡墨起稿 → 淡墨远山 → 折带皴近岸 → 枯笔写树 → 题款钤印。
- 修改痕迹：画面上几乎无修改痕迹，枯笔一笔错即废。`impression`（学界共识：逸笔一次成形）

## 书法与题款

- 题款与印章是构图的一部分，落位计入画面平衡；《六君子图》的多方题跋本身就是画面史。`verbatim` / `artifact`
- 倪瓒自题“仆之所谓画者，不过逸笔草草，不求形似，聊以自娱耳”是画家本人关于画作的公开文字。`artifact`（倪瓒自题，见画史引述）
