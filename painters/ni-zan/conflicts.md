# Ni Zan — conflicts.md（保留，不统一）

1. **《六君子图》的题名**：画名来自黄公望的题诗，不是倪瓒自题；画上另有宾客题跋，最末一方题跋作于黄公望去世之后。`artifact`（维基百科“六君子图”）
2. **早期作品归属**：倪瓒早期作品存世少，1345 年之前的画风分期主要靠题款与风格推断，个别作品归属有争议，记入此处，不统一。
3. **“逸笔草草”自题的出处**：该语见于倪瓒自题，画史广引，但具体题于哪幅画上说法不一，本 skill 只按画作特征蒸馏，不以题语定分期。
4. **《渔庄秋霁图》版本**：传世有多个版本 / 摹本，蒸馏以博物馆藏本的画面特征为准，不以拍卖图录为准。
