# Giotto di Bondone — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 体块即语言：人物的重量与体积就是情感——蹲伏、俯身的身体比面部表情更先说话。`verbatim`
- 对角线即语言：山坡斜线把视线从天空的天使引向地面的基督，连接天与地。`verbatim`
- 群像即语言：人物的疏密与重叠就是叙事节奏，没有主角独白，只有集体的哀悼。
- 金底的消失即语言：不用金底，圣人回到地面上，神圣性从体积与情感里来，不从金光里来。`impression`（学界共识）
- 留白即语言：天空与山坡的大面积单纯色块是“静”，人物组的密集是“动”，静衬动。
- 视线引导：天使群 → 山坡斜线 → 基督头部 → 圣母的手，视线沿对角线走到底。
