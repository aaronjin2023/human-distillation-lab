# Giotto di Bondone — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **生年不确定：** c.1267 年是通行说法，也有 c.1266、c.1276 等说法；卒年 1337 年无争议。`artifact`
2. **阿西西归属：** 阿西西圣方济各教堂上层教堂壁画是否出自乔托本人，学界有争议，部分认为是助手或后人所作；本 skill 以无争议的斯克罗维尼礼拜堂为准。`artifact`
3. **《哀悼基督》年代：** 斯克罗维尼礼拜堂壁画年代通说为 1304–1306 年，也有 1303–1305 年的写法；本 skill 不写单幅年份，只写礼拜堂工期。`artifact`
4. **乔托与奇马布埃的关系：** 瓦萨里称乔托为奇马布埃弟子，此说无同时代文献证实，属后世传记说法；本 skill 不采用。`impression`（瓦萨里的说法，可靠性存疑）
