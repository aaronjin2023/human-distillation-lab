# Shen Zhou — conflicts.md（保留，不统一）

1. **《庐山高》的功能**：画史研究认为此画尺幅巨大、为厅堂陈设而作，不同于一般文人小品；其对角线构图受浙派宫廷画家影响的说法见于研究文献，记入此处，不展开。
2. **《山水册》的版本**：传世《山水册》有多个版本，蒸馏以博物馆藏本的画面特征为准，不以拍卖图录为准。
3. **晚期分期**：晚期笔法更苍润的说法是学界共识，但具体以哪几幅为晚期代表，各家说法不一，记入此处，不统一。
4. **与浙派的关系**：沈周是否受浙派影响，画史有不同说法；本 skill 只按画面特征蒸馏，不以影响说定风格。
5. **“明四家”成员（已定夺，2026-10-26）**：通说为沈周、文徵明、唐寅、仇英；另一说法以祝允明代仇英（见文徵明 conflicts.md）。本 skill 按通说。
