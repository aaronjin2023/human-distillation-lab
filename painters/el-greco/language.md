# El Greco (Doménikos Theotokópoulos) — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 拉长即语言：身体的拉长就是内容——灵魂在向上升，肉体被拉长是灵魂的重量。
- 上下两界即语言：下层人间、上层天国，两界在同一画面上；死亡不是终点，是上升。
- 冷绿即语言：冷绿与柠檬黄的酸性是“非人间”的颜色，天国不是暖的，是冷的。
- 天空即语言：天空的翻卷是灵魂的翻卷，云不是背景，是情感。
- 金衣即语言：圣徒的金衣是下层唯一的暖与亮，是天国照进人间的光。
- 视线引导：伯爵遗体 → 圣徒 → 天国灵魂 → 天空，视线向上升。
