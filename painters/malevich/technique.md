# Kazimir Malevich — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

- 媒材：布面油彩，平涂；《黑方块》1915 年首版，画家一生复制四次，版本间有差异。`artifact`
- 至上主义：1915 年提出，几何形至上、感觉至上，黑方块被画家称为“绘画的零点”。`artifact`
- 黑方块画法：黑块非纯平，表面有裂纹与笔痕，边缘略不直——手工感是画面的一部分。`verbatim`
- 白底：白不是空，是无限；形漂浮于白中，无重力、无方向。`artifact`
- 层序：定位 → 白底 → 黑方块 → 漂浮几何 → 检查黑白。
