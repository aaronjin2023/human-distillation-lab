# Ancient Egyptian Tomb Painting — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **年代：** 一说约前 1350 年（v2 名单），一说约前 1325 年（大英博物馆教学资料）；本 skill 以 v2 的约前 1350 年为主，另说记于此。
2. **墓的位置：** 1820 年发现后位置佚失，2008–09 年科学分析推定在德拉·阿布·纳加一带，未确证。
3. **画师身份：** 画师无名；有评论称其天赋堪比文艺复兴大师，但身份无从考证——“不知名大师”是学界共识。
4. **宴会舞女的正面面孔：** 乐师正面相对是特例还是规范松动，学界有不同解读；本 skill 按画面事实写，不统一。
