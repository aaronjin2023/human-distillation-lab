# Ancient Egyptian Tomb Painting — 技法与工序 technique.md（只限作品）

> v0.1（2026-10-26 网络核对后建立）。

Procedure：他怎么画出来的？只从画作里找媒材、底子、笔法、层序、修改痕迹。

- 媒材：灰泥墙面上的矿物颜料；墙先涂厚层泥草灰泥，再涂薄层细灰泥。`artifact`（大英博物馆内巴蒙墓教学资料）
- 颜料：赭石、孔雀石、青金石、烟灰、白垩等天然矿物与材料，笔为芦苇、麻线束成。`artifact`
- 起稿：先以红赭在线上打网格、画轮廓，再上色；网格是古埃及画的“比例尺”。`artifact`
- 内巴蒙墓：十八王朝，墓主为底比斯神庙的书记与谷物计数官，约前 1350 年；墓于约 1820 年发现，位置后佚，11 块壁画残片现藏大英博物馆。`artifact`
- 《沼泽猎鸟图》《宴会舞女图》《花园池塘图》是大英博物馆的镇馆级藏品，被称为现存最伟大的古埃及绘画。`artifact`
- 层序：打底 → 网格 → 红赭轮廓 → 平涂 → 黑线勾边题铭。
