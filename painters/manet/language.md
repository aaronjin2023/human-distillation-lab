# Édouard Manet — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 直视即语言：裸女直视观者，目光 = 对抗，观者从偷看者变成被审视者。`verbatim`
- 扁平即语言：扁平不是画不完，是现代主义的语法——空间压扁，人物才直面观者。
- 黑白即语言：黑与白两块对撞，中间无灰调过渡，对撞本身就是冷峻。
- 当代即语言：野餐篮、衣物、酒吧都是当代物，神话题材被当代生活替换。
- 失调即语言：远景人物比例失调不是画错，是扁平空间的宣言。
