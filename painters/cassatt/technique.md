# Mary Cassatt — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

媒材、底子、笔法、层序、修改痕迹，只从画作与技法报告里找。

- 媒材：布面油画 + 粉彩 + 版画并行；受日本浮世绘影响极深，高视点、扁平图案、陡峭透视皆源于此。`artifact`
- 底子：浅色底，蓝调从底子就定下；色彩靠扁平色块叠出，不靠渐变。
- 笔法：平滑清晰，结构感强；与莫奈的碎笔同源，但更重结构、更重线条。
- 层序：清晰素描 → 淡底 → 蓝与暖肤分层 → 图案细化 → 冷色统一。
- 《蓝扶手椅上的小女孩》1878 年：女孩横卧蓝椅、直视观者，狗卧另一椅，是其最著名的儿童题材；蓝椅是全画的主色。`artifact`（美国国家美术馆藏品说明）
