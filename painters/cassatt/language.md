# Mary Cassatt — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 高视点即语言：高视点 = 日本风，观者从高处俯视母子，视点本身就是观察的宣言。`verbatim`
- 蓝即语言：蓝是卡萨特的签名色，蓝一出即是画面中心，其余全退为暖肤。
- 图案即语言：地毯与墙纸的扁平图案不是装饰，是空间本身——图案即是室内。
- 结构即语言：母子结构清晰、实在，结构越实，亲密越真；结构一散，亲密就没了。
- 冷静即语言：卡萨特不美化母子——疲惫、专注、等待都是画面的一部分。
