# Michelangelo Buonarroti — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **修复争议：** 1980–1990 年西斯廷天顶画清洗去除了数百年烟尘，有学者认为同时去除了米开朗基罗的干壁补色与阴影层，修复得失至今有争议；本 skill 以修复后可见面貌为准，并注明此争议。`artifact`
2. **范围限定：** 本 skill 只蒸绘画；米开朗基罗的雕塑与建筑成就极大，但按 v2 名单规定不在蒸馏范围，文件内不写雕塑与建筑的技法。
3. **天顶画早期人物偏小：** 早期三幅诺亚场景人物偏小，一般解释为米开朗基罗误判了天顶尺寸，也有认为是故意为之；本 skill 只写画面事实。`artifact`
4. **《最后的审判》遮羞布：** 后期为裸体人物加绘遮羞布，非米开朗基罗本人所画；本 skill 以原作为准，不写遮羞布版本。`artifact`
