# Qiu Ying — conflicts.md（保留，不统一）

1. **生年两说**：本 skill 用 c.1494–1552（中文维基：考订约生于弘治甲寅 1494 年；2026-10-26 用户定夺）。部分资料作 c.1498–1552（如 Facts and Details），记于此。`artifact`
2. **《汉宫春晓图》版本**：传世有多个版本，台北故宫藏本为代表；蒸馏以故宫藏本的画面特征为准。
3. **真伪风险**：仇英画作传世摹本、代笔极多，画史称其临古几可乱真，后人仿仇亦多；蒸馏只能以博物馆藏与权威图录所载作品为准，不以拍卖图录为准。
4. **晚期分期**：晚期笔法更精纯的说法是学界共识，但具体以哪几幅为晚期代表，各家说法不一，记入此处，不统一。
5. **“明四家”成员（已定夺，2026-10-26）**：通说为沈周、文徵明、唐寅、仇英；另一说法以祝允明代仇英（见文徵明 conflicts.md）。本 skill 按通说。
