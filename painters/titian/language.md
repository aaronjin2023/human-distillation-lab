# Titian (Tiziano Vecellio) — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 色彩即语言：颜色本身就是内容——群青的深、朱红的暖、胭脂红的艳，都是情感，不用作装饰。
- 光即语言：暖金光线是威尼斯的光——水面、天空、皮肤都被同一种光照亮，光即统一。
- 皮肤即语言：皮肤的温度与光泽是感性的来源，画皮肤就是画生命。
- 对角线即语言：酒神从空中跃下的对角线是动感的来源，视线随对角线上升。
- 罩染即语言：透明层次是“深”的来源，颜色越罩越深、越亮，不是一次涂成的。
- 视线引导：酒神 → 阿里阿德涅 → 随从 → 海天，视线在对角线上走。
