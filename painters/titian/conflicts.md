# Titian (Tiziano Vecellio) — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **生年：** c.1488 年为通行说法，也有 c.1480、c.1490 年的说法；卒年 1576 年无争议。`artifact`
2. **作坊分工：** 作坊规模大，部分作品由助手执行，提香本人参与程度各幅有别；晚期作品归属争议较多。`artifact`
3. **晚期笔触：** 晚期自由笔触是视力衰退还是有意为之，旧说认为是视力衰退，现多认为是有意为之；本 skill 只写画面事实。`impression`
4. **《乌尔比诺的维纳斯》寓意：** 画中维纳斯的身份与寓意（婚礼画、肖像、寓言）有争议；本 skill 不采信任何一说。`artifact`
