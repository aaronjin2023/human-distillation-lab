# Artemisia Gentileschi — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **《朱迪思》版本：** 那不勒斯版与乌菲齐版孰先孰后有争议；本 skill 以那不勒斯版为准，两版差异见 technique.md。`artifact`
2. **父女作品区分：** 阿特米西娅与其父奥拉齐奥的作品易混淆，部分作品归属有争议；本 skill 只用公认的阿特米西娅原作。`artifact`
3. **卒年：** c.1656 年为通行说法（那不勒斯瘟疫），也有 1652 年后下落不明的说法；本 skill 写 c.1656 并注明。`artifact`
4. **传记解读：** 关于画家的法庭记录常被用来解读《朱迪思》与《苏珊娜》，此种“传记式解读”学界有争议；本 skill 只蒸画作，不采用传记解读。`impression`
