# Frida Kahlo — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

- 媒材：布面油彩，平滑薄涂；间用金属板油画。`artifact`
- 自画像：143 幅画中至少 55 幅是自画像，自画像是核心方法。`artifact`
- 《两个弗里达》（1939）：两个弗里达并坐，心脏以血管相连，一着特瓦纳服、一着欧式白裙。`verbatim`
- 《断柱》（1944）：躯干剖开，断裂的爱奥尼柱代脊柱，钢架束身、钉子刺体。`verbatim`
- 层序：起稿 → 背景肤色底色 → 衣饰分层 → 面部细化 → 罩染收尾。
