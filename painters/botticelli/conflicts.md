# Sandro Botticelli — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **《春》的寓意：** 《春》的寓意至今无定论（有说是婚礼画、有说是新柏拉图主义寓言），各家说法不一；本 skill 不采信任何一说，只写画面事实。`artifact`
2. **《维纳斯的诞生》年代：** 通说约 1485 年，也有约 1483–1485 年的写法；本 skill 不写单幅年份。`artifact`
3. **晚期风格转变：** 晚期风格转暗是否因萨沃纳罗拉影响，学界有争议（也有认为是个人风格演变）；本 skill 只写画面变化，不写原因。`impression`
4. **模特身份：** 维纳斯的模特是否为西蒙内塔·韦斯普奇，无文献证实，属后世传说；本 skill 不采用。`impression`
