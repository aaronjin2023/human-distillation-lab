# Edgar Degas — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 裁切即语言：裁切 = 现场感，人物被画边裁掉一半，观者才相信这是“撞见”不是“摆拍”。`verbatim`
- 姿态即语言：舞者姿态是瞬间——伸展、弯腰、系鞋带，姿态本身就是台词。
- 粉彩即语言：粉彩的粉末感 = 薄纱与肌肤的质感，粉一出即是舞裙。
- 冷静即语言：德加自称现实主义者，不美化舞者——疲惫、伸展、等待都是画面的一部分。
- 视点即语言：俯视与仰视并存，非常规视点本身就是观察的宣言。
