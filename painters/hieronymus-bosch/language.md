# Hieronymus Bosch — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 密集即语言：密密麻麻的小人物就是内容——世界是拥挤的，人是渺小的，细节即世界。
- 三联即语言：左中右三段即过去、现在、未来，时间在空间里展开，观者的视线就是道德的审判。
- 怪诞即语言：混合生物不是装饰，是寓意的载体——不合常理的形体即不合道德的行为。
- 灰绿即语言：色彩的灰与冷是“尘世”的颜色，乐园的暖是短暂的，地狱的暗红是结局。
- 高视点即语言：从高处俯瞰，人如蚁蝼，道德判断来自上帝的视角。
- 视线引导：伊甸园 → 乐园 → 地狱，视线从左向右走，结局在右边。
