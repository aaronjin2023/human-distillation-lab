# Jan van Eyck — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 细节即语言：细节本身就是内容——每一件器物都有自己的材质与象征，细节即意义。
- 镜子即语言：凸面镜映出画外两人，画面之外还有画面；镜子是“在场”的证据。`verbatim`
- 光即语言：窗光清澈，光在金属与玻璃上的反射是质感的来源，也是真实的证据。
- 象征即语言：狗（忠诚）、拖鞋（圣地）、单支烛（神在）、水果（丰饶）——器物即语言，见 motifs.md。
- 室内即语言：房间的三面（地板、墙面、天花板）即空间，空间即秩序。
- 视线引导：夫妇 → 吊灯 → 凸面镜 → 镜中两人，视线在室内循环。
