# Pierre-Auguste Renoir — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 光斑即语言：阳光斑驳 = 欢愉，亮处即视线落点，光斑越碎，聚会越活。`verbatim`
- 肌肤即语言：肌肤如珍珠般闪烁，白里透粉、粉里透蓝，肌肤本身就是光。
- 人群即语言：人群满幅、无主次，人人都是主角——聚会本身就是题材。
- 暖色即语言：朱红与铬黄是全画的暖源，暖一出即是阳光，冷色只作点缀。
- 闪烁即语言：笔触越碎，光越闪；笔触一连，印象就没了。
