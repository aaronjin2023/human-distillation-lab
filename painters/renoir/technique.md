# Pierre-Auguste Renoir — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

媒材、底子、笔法、层序、修改痕迹，只从画作与技法报告里找。

- 媒材：布面油画；早期瓷器彩绘出身，对釉彩光泽敏感，肌肤珍珠感与此有关。`artifact`（雷诺阿研究通说）
- 底子：浅色底，暖调从底子就定下；色彩靠羽毛状碎笔叠出，不靠调和。
- 笔法：羽毛状破碎笔触，轻快闪烁；与莫奈的碎笔同源，但更暖、更重人物。
- 层序：淡线起稿 → 暖调底色 → 人物与光斑分层 → 肌肤细化 → 暖色罩染。
- 晚期“安格尔式”转向：1880 年代中期后线条收紧、造型更实（《游船上的午餐》1880–1881 年已见端倪），与早期纯印象派碎笔不同；本 skill 以早期—中期印象派为准，晚期转向见 conflicts.md。`artifact`
