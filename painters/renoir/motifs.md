# Pierre-Auguste Renoir — 母题与演变 motifs.md（Memory，只限作品序列）

> v0.1（2026-10-26）。只限作品。

反复母题与作品序列演变。早期印象派碎笔 → 中期“安格尔式”转向（1880 年代中期）→ 晚期浴女古典化（以 1876–1881 年两幅为准）。

- 反复母题：舞会、聚会、浴女、阳光下的肌肤、巴黎郊游。`verbatim`
- 《煎饼磨坊的舞会》1876 年与《游船上的午餐》1880–1881 年：前者是“露天舞会”，后者是“阳台聚会”，一舞一聚构成雷诺阿印象派的两个极点。
- 演变：早期印象派碎笔与暖色，中期“安格尔式”转向（线条收紧），晚期浴女系列更趋古典、造型更实；本 skill 以早期—中期为准。`impression`（学界分期通说）
- 系列性：浴女系列是其最系统的母题序列，同一浴女在不同光色里反复变奏。
