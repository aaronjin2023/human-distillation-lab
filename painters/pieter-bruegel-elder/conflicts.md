# Pieter Bruegel the Elder — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **月令组画原数：** 月令组画原为六幅，现存五幅，缺失一幅（4 月或 5 月）下落不明；本 skill 以现存五幅为准。`artifact`
2. **《巴别塔》版本：** 《巴别塔》有大版（维也纳）与小版（鹿特丹）两幅，孰先孰后有争议；本 skill 以大版为准。`artifact`
3. **生年：** c.1525 年为通行说法，也有 c.1530 年的说法；卒年 1569 年无争议。`artifact`
4. **父子区分：** 老勃鲁盖尔与其子小勃鲁盖尔（亦画农民题材）的作品易混淆，归属需仔细核对；本 skill 只用公认的老勃鲁盖尔原作。`artifact`
