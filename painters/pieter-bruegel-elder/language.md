# Pieter Bruegel the Elder — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 高视点即语言：从高处俯瞰，人如蚁蝼，风景即世界——人是风景的一部分，不是风景的主人。
- 四季即语言：光色随季节变化，冬季冷、夏季暖；季节即时间，时间即生活。
- 密集即语言：密密麻麻的小人物就是内容——生活是拥挤的，人人都在劳作嬉戏。
- 对角线即语言：前景猎人沿对角线下坡，视线引向远方，近与远在同一画面里。
- 雪地即语言：雪地的白是“静”，人物的动是“动”，静衬动。
- 视线引导：前景猎人 → 中景村庄 → 远景溜冰者，视线在风景中走远。
