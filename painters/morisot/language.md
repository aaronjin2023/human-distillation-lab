# Berthe Morisot — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 薄纱即语言：薄纱 = 母爱与保护，纱越透，爱越深；纱一实，温柔就没了。`verbatim`
- 苍白即语言：白与银灰是全画的主色，苍白不是没画完，是“轻”的语法。
- 目光即语言：母亲的目光 = 台词，视线被目光牵着望向摇篮，再望回母亲。
- 轻笔即语言：笔触越轻，画面越温柔；笔触一重，轻盈就破了。
- 室内即语言：室内一角不是背景，是女性世界的全部——家庭即是世界。
