# Dante Gabriel Rossetti — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 红发即语言：红发 = 罗塞蒂的签名，红一出即是画面中心，其余全退为绿与蓝。`verbatim`
- 象征即语言：石榴、鸟、花不是装饰，是台词——石榴 = 囚禁，鸟 = 灵魂，花 = 爱情。
- 扁平即语言：背景扁平装饰图案不是没画完，是中世纪的语法——图案即空间。
- 白肤即语言：苍白肌肤与红发对撞，白越白，红越红。
- 梦境即语言：女子仰首、目光游移，神情不定——画面不给唯一答案。
