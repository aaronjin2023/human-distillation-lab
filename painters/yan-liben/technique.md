# Yan Liben — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

## 媒材与底子
- 绢本设色；绢面宜重彩平涂与淡染并用。`verbatim`
- 颜料：朱砂、石绿、石青、赭石、花青、藤黄，帝王用朱红最重。`verbatim`

## 核心技法
- 铁线描一路的坚实线条：线粗细变化小，靠顿挫与转折见骨力，与顾恺之游丝线相对。`artifact`（画史通说）
- “重彩 + 淡染”：衣纹处重彩设色后以淡色晕染，见《历代帝王图》“重彩设色、衣纹淡染受佛教艺术影响”的说法。`artifact`
- 人物按等级设形设色：帝王体量最大、设色最重；侍从递减。`verbatim`（《步辇图》《历代帝王图》画面可见）
- 面部刻画：以眉眼口鼻的微差写帝王个性，如《历代帝王图》十三帝各具神态，褒贬见于面相。`artifact`（博物馆 / 图录说明）

## 层序
- 淡墨起稿 → 铁线勾形 → 重彩平涂 → 淡染晕染 → 点睛题款。
