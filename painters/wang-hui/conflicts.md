# Wang Hui — conflicts.md（保留，不统一）

1. **“保守”的评价**：画史称王翚“保守”、反映元宋传统，是定论式的评价；但“保守是缺点还是本事”各家说法不一，本 skill 只写画面特征，不以评价定风格。`artifact`（画史通说）
2. **《康熙南巡图》的分工**：王翚为总设计师、众画工分段作画是定论；但具体哪一段出自王翚亲笔，各家说法不一，本 skill 不以南巡图定风格。`artifact`（苏富比藏品说明）
3. **《仿黄公望富春山居图》版本**：传世有多个版本，普林斯顿藏本实为临王鉴仿黄公望之作；蒸馏以博物馆藏本的画面特征为准。
4. **晚期分期**：晚期笔法更从容的说法是学界共识，但具体以哪几幅为晚期代表，各家说法不一，记入此处，不统一。
