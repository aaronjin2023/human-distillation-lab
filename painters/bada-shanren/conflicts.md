# Bada Shanren — conflicts.md（保留，不统一）

1. **白眼的解读**：白眼被解读为对明亡的愤怒，此说流行于 20 世纪初清亡民国之际；吴昌硕 1926 年题诗亦持此说。`artifact`（Smarthistory；亚洲艺术报）——本 skill 只写画面上的白眼，不以解读定风格；另说见 motifs.md。
2. **荷茎四变五**：《荷花水鸟图》底部四茎、向上变五茎，荷茎本不分枝，是有意为之还是笔误，画史无定论，记入此处，不统一。`artifact`（Smarthistory）
3. **“八大山人”名号**：1684 年起用此号是定论；但名号的拆字解读（如“哭之”“笑之”）各家说法不一，本 skill 不写拆字解读。
4. **晚期分期**：1690 年代笔法更趋抽象的说法见于亚洲艺术报梳理，但具体以哪几幅为晚期代表，各家说法不一，记入此处，不统一。
