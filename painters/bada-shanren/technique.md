# Bada Shanren — 技法与工序 technique.md（Procedure，只限作品）

## 媒材与纸

- 纸本水墨为主，几乎不用设色；墨分浓—淡—干—湿，纸的吸水性即画面的一部分。`verbatim`
- 简笔一路：笔法简而精，是八大区别于徐渭狂笔的关键。`artifact`

## 核心技法：白眼与简笔

- 白眼：鱼鸟的眼珠翻上，只露眼白，是八大最具辨识度的画法；画面上直接可见。`verbatim` / `artifact`（Smarthistory）
- 简笔：荷花两笔成形，鱼身几笔成形；以最少的笔写最多的意。`artifact`（Smarthistory：荷花两笔即成，体积与轻盈并存）
- 荷茎：荷茎通贯全幅，底部四茎、向上变五茎——荷茎本不分枝，是八大有意为之的“怪笔”，画史无定论，见 conflicts.md。`artifact`（Smarthistory）

## 笔法与层序

- 笔法：中锋为主，大胆、凝练；一笔是一笔，不反复描。
- 层序：淡墨起稿 → 淡墨大形 → 浓墨写眼勾形 → 枯笔点染 → 题款钤印。
- 修改痕迹：画面上几乎无修改痕迹，简笔一笔错即废。`impression`

## 师法

- 山水学董其昌，笔法简练、幽静；花鸟自成一家，学徐渭而化出自己的冷峻。`artifact`（画史通说）
- 1690 年代笔法更趋抽象，墨色层次更广（由湿而轻、由重而暗）。`artifact`（亚洲艺术报梳理）
