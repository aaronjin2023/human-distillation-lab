# Peter Paul Rubens — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 动感即语言：身体的卷动就是内容——生命是运动的，静止即死亡。
- 肉感即语言：丰满的肉体不是装饰，是生命力的证据——皮肤的温度与光泽即生命。
- 丰盈即语言：色彩的浓烈、构图的饱满、人物之多，都是“丰盈”——世界是富足的。
- 对角线即语言：基督斜垂的对角线是重力的化身，视线随身体下滑，感到重量。
- 小稿即语言：油彩小稿的自由笔触是“想”的痕迹，巨幅是“想”的实现。
- 视线引导：基督身体 → 圣母 → 使徒 → 背景，视线在旋涡中循环。
