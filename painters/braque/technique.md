# Georges Braque — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

- 媒材：布面油彩，常掺沙；综合立体主义时期发明拼贴（papier collé）与模板字母。`artifact`
- 与毕加索共创立体主义：1908 年《莱斯塔克的房子》被评为“小方块”，立体主义得名与此有关。`artifact`
- 切面更安静：比毕加索更均衡、更克制，色彩更 muted。`impression`（学界共识）
- 拼贴：1912 年起用拼贴与模板字，平面性进一步加强。`artifact`
- 层序：起稿切面 → 土调底色 → 切面分层 → 字母收形 → 罩染收尾。
