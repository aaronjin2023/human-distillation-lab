# Francisco de Goya — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **黑色绘画年份：** 约 1819–1823 年，各家写法不一（1819–1823 / 1820–1823）；本 skill 写约 1819–1823 年。
2. **《农神食子》题名：** “农神食子”是后人据题材所加的题名，非画家本人题款；画中人物是否为农神，学界有不同说法，记入此处。
3. **黑色绘画是否 intended 公开：** 画在私人住所墙上，生前未展出，是私密作品还是未完成作品，学界有争议；本 skill 只写“墙面原作、后揭取上画布”。
