# Francisco de Goya — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

媒材、底子、笔法、层序、修改痕迹，只从画作与技法报告里找。

- 媒材：布面油画为主；黑色绘画（约 1819–1823 年）是直接画在住所墙面灰泥上的油画，后揭取转移上画布。`artifact`
- 底子：暗色底，黑夜从底子就定下；亮部靠厚涂骨白一次提亮。
- 笔法：粗、快、涂抹式；晚期更自由，近乎干擦与刮擦。
- 层序：暗调底色 → 亮部提灯光 → 暗部压平 → 血与白衣最后点 → 黑色罩染。
- 版画一路：蚀刻 + 飞尘腐蚀版（《洛斯·卡普里乔斯》1799 年、《战争的灾难》1810–1820 年间）是其另一成果物，线条腐蚀感与油画粗粝感同源；本 skill 以油画为准，版画只作参照。`artifact`
