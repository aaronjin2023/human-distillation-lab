# Francisco de Goya — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 光即语言：提灯光 = 审判，被照亮者即受害者，背光者即行刑者，光本身就是立场。`verbatim`
- 对峙即语言：亮左 / 暗右两块对撞，观者一眼读出谁是谁，无中间地带。
- 白衣即语言：中央白衣男子的张开双臂是画面的十字架，姿态本身就是台词。
- 黑即语言：暗部近乎纯黑不是没画完，是恐惧的语法——黑里什么都没有，也什么都有。
- 粗粝即语言：笔触不打磨、不美化，粗粝本身就是拒绝粉饰的态度。
