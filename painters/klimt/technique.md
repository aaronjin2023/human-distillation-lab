# Gustav Klimt — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

- 媒材：布面油彩 + 金箔、银箔；《阿黛尔一世》为油彩、金、银 on canvas。`verbatim` / `artifact`
- 金色时期：金箔技法受拉文纳拜占庭马赛克启发，画面大面积贴金。`artifact`
- 人物画法：面部与手细腻写实，衣袍与背景完全装饰化，写实与装饰在同一画面并置。`verbatim`
- 纹样系统：男性矩形、直线几何纹；女性圆形、螺旋、花卉纹——两性对照是画面语言的一部分。`verbatim`
- 层序：起稿 → 金色底 → 人物肤色 → 衣袍分区填色 → 贴金描纹 → 罩染收边。
- 早期另有学院派壁画与大学天顶画一路，本 skill 以金色时期为准，见 conflicts.md。
