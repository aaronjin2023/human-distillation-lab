# Gustav Klimt — 母题与演变 motifs.md（Memory，只限作品序列）

> v0.1（2026-10-26）。只限作品。

- 反复母题：拥抱的恋人、女性肖像、朱迪思、达那厄、生命之树、三世代女性。`verbatim`
- 《吻》：一对恋人跪于花毯，男俯身吻女，女仰面承接——拥抱是克里姆特最核心的母题。`verbatim`
- 《阿黛尔一世》：肖像 + 金色纹样包围，人物几乎被装饰吞没，肖像画变成装饰画。`verbatim`
- 演变：早期学院写实 → 1897 年维也纳分离派 → 金色时期（约 1907–1908《吻》）→ 晚期色彩更艳、纹样更松。分期只按作品序列，见 conflicts.md。
- 女性形象贯穿始终：从神话女性到委托肖像，女性是画面中心，男性多为配角或缺席。
