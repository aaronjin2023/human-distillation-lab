# Jean-François Millet — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 弯腰即语言：弯腰 = 劳动本身，姿态越低，尊严越高；直立反而失去了米勒。`verbatim`
- 剪影即语言：劳动者只剩剪影，面部几乎看不见，剪影越暗，尊严越重。
- 金黄即语言：麦田金黄 = 收获与永恒，暖金是全画的唯一亮色。
- 寂静即语言：画面上几乎无动势，寂静本身就是田园的语法；动势一多，庄严感就破了。
- 横排即语言：三人横排如浮雕，观者一眼读出“劳动”，无歧义。
