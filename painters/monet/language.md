# Claude Monet — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。只限作品。

笔触、线条、构图、色彩、光影、透视、视线引导，只描述画面怎么跟观者说话。

- 碎笔即语言：碎笔 = 瞬间，笔触越碎，光越闪；笔触一连，印象就没了。`verbatim`
- 并置即语言：补色并置 = 光，蓝与橙并置处即是光斑，不用白颜料画光。
- 无黑即语言：不用纯黑、不用黑色轮廓线，阴影是彩色的——黑一出，印象就破了。
- 水面即语言：睡莲水面满幅、无地平线，水面本身就是画面，倒影即是真实。
- 系列即语言：同一题材反复画，光一变，画就变——时间本身就是题材。
