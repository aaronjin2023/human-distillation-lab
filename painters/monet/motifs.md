# Claude Monet — 母题与演变 motifs.md（Memory，只限作品序列）

> v0.1（2026-10-26）。只限作品。

反复母题与作品序列演变。早期布丹影响 → 中期印象派定型（1872 年）→ 晚期吉维尼睡莲（1896–1926 年）。

- 反复母题：睡莲、水面、干草堆、鲁昂大教堂、国会大厦、日出海港。`verbatim`
- 《日出·印象》1872 年与睡莲系列（1896–1926 年）：前者是“印象派之名”，后者是“晚年水面”，一始一终构成莫奈的两个极点。
- 演变：早期受布丹与马奈影响，中期印象派定型（1872–1886 年），晚期吉维尼睡莲系列更趋抽象、水面满幅。`impression`（学界分期通说）
- 系列性：干草堆、鲁昂大教堂、睡莲是其最系统的系列，同一题材在不同光色里反复变奏。
