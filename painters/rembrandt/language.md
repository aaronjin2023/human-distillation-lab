# Rembrandt van Rijn — 画面语言 language.md（Interaction，只限作品）

> v0.1（2026-10-26）。

- 光即语言：光本身就是内容——光是内心的光，照亮的不是形体，是人。
- 黑暗即语言：暗部不是背景，是深渊——人物从黑暗中浮现，光一到，人才醒。
- 厚涂即语言：厚涂的肌理是“触摸”的证据——画是可以用手感知的，皮肤、织物、金光都有厚度。
- 群像即语言：群像不是排排站，是戏剧——每个人物都有自己的光与位置，群像即社会。
- 晚期即语言：晚期笔触越自由、情感越深——画得越少，说得越多。
- 视线引导：光束 → 队长 → 民兵 → 暗部，视线随光走。
