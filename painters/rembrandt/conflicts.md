# Rembrandt van Rijn — conflicts.md（保留，不统一）

> v0.1（2026-10-26）。

1. **《夜巡》裁切：** 《夜巡》1715 年为挂入新址被裁去左侧与顶部三条，现存面貌非原作全貌；原貌只能靠早期摹本推测。`artifact`
2. **《夜巡》之名：** “夜巡”之名是后世所加，原作实为日间场景，因清漆变暗而被误认为夜景；本 skill 以画面现貌为准。`artifact`
3. **《浪子回头》年代：** 通说约 1668 年，也有约 1666–1669 年的写法；本 skill 不写单幅年份。`artifact`
4. **作品数量：** 伦勃朗传世油画约 300 幅，归属有争议，部分作品为作坊参与；本 skill 以公认原作为准。`artifact`
