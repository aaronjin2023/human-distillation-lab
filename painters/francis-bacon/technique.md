# Francis Bacon — 技法与工序 technique.md（Procedure，只限作品）

> v0.1（2026-10-26）。只限作品。

- 媒材：布面油彩，常以照片、电影剧照为图像来源（非写生）。`artifact`
- 教皇系列：1949–1971 年约 50 幅仿委拉斯开兹教皇像变体，1953 年《仿委拉斯开兹教皇英诺森十世像习作》为代表。`artifact`
- 肉：带肉的人像、屠宰场的肉是反复母题，肉即人体的隐喻。`verbatim`
- 涂抹：用布、刷、刮刀涂抹颜料，形体在涂抹中扭曲。`verbatim`
- 层序：盒框起稿 → 黑底 → 肉体涂抹 → 口眼细化 → 罩染收尾。
