# Inoue Yuichi — 技法与书写工序 technique.md（四维之 procedure）

> 只从书法作品里找什么：笔法、纸笔墨、书写顺序、修改痕迹。不写“性格如何导致这样写”。

- 笔法：自制帚笔大幅运笔，全身发力，墨胶调和，枯润飞白并存，笔触如泼如扫。`verbatim`
- 纸笔墨：纸：大幅和纸；笔：自制帚笔；墨：墨加胶调和；运笔全身发力，起笔重按，收笔飞白。`artifact`
- 书写顺序：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款，已记入 process.md；刻本 / 抄本者按其传本工序（书丹 → 刻石 → 拓本，或划线 → 抄写 → 描饰）。
- 修改痕迹：真迹存世者以原作涂改、添字为准；摹本 / 刻本 / 拓本传世者，修改痕迹多已失，不可虚构。
- 传本：真迹存世（纸本墨书，大字一字书；部分藏于东京国立近代美术馆等）
