# Donald Jackson — 技法与书写工序 technique.md（四维之 procedure）

> 只从书法作品里找什么：笔法、纸笔墨、书写顺序、修改痕迹。不写“性格如何导致这样写”。

- 笔法：鹅毛笔与宽头笔并用：笔画清晰有力，起收笔干净，字母结构严谨而富表现力。`verbatim`
- 纸笔墨：鹅毛笔；羊皮纸；先划线后书写；彩绘与金饰后加。`artifact`
- 书写顺序：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款，已记入 process.md；刻本 / 抄本者按其传本工序（书丹 → 刻石 → 拓本，或划线 → 抄写 → 描饰）。
- 修改痕迹：真迹存世者以原作涂改、添字为准；摹本 / 刻本 / 拓本传世者，修改痕迹多已失，不可虚构。
- 传本：真迹存世；在世（1938–），只蒸已发表作品；《圣约翰圣经》1998–2011年完成，藏于圣约翰大学
