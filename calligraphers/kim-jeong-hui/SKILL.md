## 一句话

- **这是谁：** 朝鲜·隶书 / 行书（秋史体）书法家，代表作《岁寒图题诗》, 《阮堂体》（后世所称书体）, 行书诗卷。
- **什么时候用他：** 需要按此人的风格书写其他文字 / 题材时，用这个 skill。
- **风格一句话：** 秋史体：隶书取法汉碑而参以行意，笔法古拙，提按顿挫分明，枯笔与涩笔并用；结字欹侧古拙，疏密对比强烈，行距紧而字距松，题诗与画面呼应。
- **过程一句话：** 六步：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款；碑刻 / 刻本 / 抄本者按其传本工序调整。
- **传本情况：** 真迹存世；《岁寒图》题诗与秋史体作品多有藏地可考


## 蒸馏范围（只限成果物）

- 材料：书法作品本身 + 书法家本人关于书法的公开文字 + 权威著录、博物馆说明与评论 / 研究。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（字迹本身直接可见，可指认到具体作品）/ `artifact`（公开文字、著录、博物馆说明）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 传本口径：真迹存世者以真迹为 `verbatim` 证据；真迹已佚 / 无确证墨迹者以摹本 / 刻本 / 拓本 / 后世著录为证据，必须注明传本情况，不得把摹本证据写成真迹证据。译文 / 转述一律不得标 `verbatim`。
