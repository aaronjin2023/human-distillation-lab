# Ibn Muqla — 技法与书写工序 technique.md（四维之 procedure）

> 只从书法作品里找什么：笔法、纸笔墨、书写顺序、修改痕迹。不写“性格如何导致这样写”。

- 笔法：按后世著录：以芦苇笔斜切笔尖，菱形墨点为度量单位，alif高以点数计。`artifact`
- 纸笔墨：芦苇笔斜切；菱形墨点为度量；alif高3/5/7点不等，余字母按点与圆推算。`artifact`
- 书写顺序：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款，已记入 process.md；刻本 / 抄本者按其传本工序（书丹 → 刻石 → 拓本，或划线 → 抄写 → 描饰）。
- 修改痕迹：真迹存世者以原作涂改、添字为准；摹本 / 刻本 / 拓本传世者，修改痕迹多已失，不可虚构。
- 传本：无确证传世真迹，仅见著录；作品只知于伊本·纳迪姆等后世文献
