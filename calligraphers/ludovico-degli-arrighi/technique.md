# Ludovico degli Arrighi — 技法与书写工序 technique.md（四维之 procedure）

> 只从书法作品里找什么：笔法、纸笔墨、书写顺序、修改痕迹。不写“性格如何导致这样写”。

- 笔法：鹅毛笔斜体：笔画流畅倾斜，提按分明，字母连写，起收笔尖锐。`artifact`
- 纸笔墨：鹅毛笔；纸本；斜体连写；字帖为刻本，笔法证据须经刻工转译。`artifact`
- 书写顺序：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款，已记入 process.md；刻本 / 抄本者按其传本工序（书丹 → 刻石 → 拓本，或划线 → 抄写 → 描饰）。
- 修改痕迹：真迹存世者以原作涂改、添字为准；摹本 / 刻本 / 拓本传世者，修改痕迹多已失，不可虚构。
- 传本：刻本 / 抄本传世；《书法手册》为1522年刊刻的斜体字帖
