# Kim Saeng — 技法与书写工序 technique.md（四维之 procedure）

> 只从书法作品里找什么：笔法、纸笔墨、书写顺序、修改痕迹。不写“性格如何导致这样写”。

- 笔法：据后世著录与集字碑：行草流畅，提按分明，笔势圆转，取法二王一路。`artifact`
- 纸笔墨：传本为刻石与拓本：原笔法只能从集字笔画的提按转折间接推断；不可声称复刻原书写过程。`artifact`
- 书写顺序：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款，已记入 process.md；刻本 / 抄本者按其传本工序（书丹 → 刻石 → 拓本，或划线 → 抄写 → 描饰）。
- 修改痕迹：真迹存世者以原作涂改、添字为准；摹本 / 刻本 / 拓本传世者，修改痕迹多已失，不可虚构。
- 传本：无确证亲笔真迹；传世为后世集字刻石与拓本（太子寺碑，954年刻，集金生字而成；18世纪拓本集存韩国国立中央博物馆）
