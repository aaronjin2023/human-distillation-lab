# Choi Chi-won — 技法与书写工序 technique.md（四维之 procedure）

> 只从书法作品里找什么：笔法、纸笔墨、书写顺序、修改痕迹。不写“性格如何导致这样写”。

- 笔法：碑铭行书：中锋为主，提按清晰，笔画劲健，兼有唐人碑版的方整与行书的流动。`artifact`
- 纸笔墨：书丹后刻石：先书丹于石，再由刻工刊刻；拓本为二次转译，笔法证据须打折。`artifact`
- 书写顺序：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款，已记入 process.md；刻本 / 抄本者按其传本工序（书丹 → 刻石 → 拓本，或划线 → 抄写 → 描饰）。
- 修改痕迹：真迹存世者以原作涂改、添字为准；摹本 / 刻本 / 拓本传世者，修改痕迹多已失，不可虚构。
- 传本：刻本 / 拓本传世；碑铭原石与拓本为主要传本
