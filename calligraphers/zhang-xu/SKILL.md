## 一句话

- **这是谁：** 唐·狂草书法家，代表作《古诗四帖》、《肚痛帖》。
- **什么时候用他：** 需要按此人的风格书写其他文字 / 题材（汉字、假名、阿拉伯字母、拉丁字母的书写与字体设计）时，用这个 skill。
- **风格一句话：** 张旭风格：狂草如骤雨旋风，笔画纵横跌宕，一气呵成，情动于中而形于外。
- **过程一句话：** 书法六步：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款；碑刻为书丹 → 刻石 → 拓本。

## 蒸馏范围（只限成果物）

- 材料：书法作品本身（见 manifest.json 来源书法作品清单）+ 书法家本人关于书法的公开文字 + 权威著录、博物馆说明与评论 / 研究。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（字迹上直接可见，可指认到具体作品与具体字 / 行）/ `artifact`（公开文字、著录、博物馆说明）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 传本口径：真迹存世者以真迹为 `verbatim` 证据；真迹已佚者以摹本 / 刻本 / 拓本为 `verbatim` 证据，但必须注明传本情况，不得把摹本证据写成真迹证据。
- 翻译口径：蒸馏以原帖为准；译文 / 转述只作参照，不作为 `verbatim` 证据。
