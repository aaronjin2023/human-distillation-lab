## 一句话

- **这是谁：** 明·行书 / 楷书书法家，代表作《滕王阁序》、《千字文》。
- **什么时候用他：** 需要按此人的风格书写其他文字 / 题材（汉字书法、题字、字体设计）时，用这个 skill。
- **风格一句话：** 文徵明风格：吴门行楷温润雅正，小楷精绝，行书温和流畅，墨淡而雅，晚年大字更放。
- **过程一句话：** 书法六步：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款。

## 蒸馏范围（只限成果物）

- 材料：书法作品本身（见下）+ 书法家本人关于书法的公开文字 + 权威著录说明与评论 / 研究。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（字迹上直接可见）/ `artifact`（公开文字、著录、研究）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 传本口径：真迹存世者以真迹为 `verbatim` 证据；真迹已佚者以摹本 / 刻本 / 拓本为 `verbatim` 证据，但必须注明传本情况，不得把摹本证据写成真迹证据。
- 翻译口径：蒸馏以原帖为准；译文 / 转述只作参照，不作为 `verbatim` 证据。
