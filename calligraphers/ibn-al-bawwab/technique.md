# Ibn al-Bawwab — 技法与书写工序 technique.md（四维之 procedure）

> 只从书法作品里找什么：笔法、纸笔墨、书写顺序、修改痕迹。不写“性格如何导致这样写”。

- 笔法：誊抄体：芦苇笔，笔画粗细均匀而有力，起收笔干净，字母挺拔。`verbatim`
- 纸笔墨：芦苇笔斜切；纸本；黑墨书写，金饰描绘；先写经文后加饰。`artifact`
- 书写顺序：选纸 → 蘸墨 → 起笔 → 行笔 → 收笔 → 落款，已记入 process.md；刻本 / 抄本者按其传本工序（书丹 → 刻石 → 拓本，或划线 → 抄写 → 描饰）。
- 修改痕迹：真迹存世者以原作涂改、添字为准；摹本 / 刻本 / 拓本传世者，修改痕迹多已失，不可虚构。
- 传本：真迹存世：切斯特·比替抄本（都柏林切斯特·比替图书馆，MS 1431），现存最早草书体《古兰经》纸本抄本之一
