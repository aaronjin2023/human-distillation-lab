# Antoni Gaudí — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 悬链线模型：以悬链线倒置定拱形，是其结构设计方法。 `verbatim` / `artifact`
- 抛物线拱与树形柱：柱分叉如树，拱如抛物线，结构即自然。 `artifact`
- 建造逻辑：悬链线模型—放线—砌筑抛物线拱—曲面—马赛克；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、砖、彩色陶瓷、铁；色板：陶土暖色、马赛克蓝绿、石灰；禁色：不用平白立面，不用直角盒子。 `impression`
- 结构体系：结构：抛物线拱与倾斜柱，结构即自然形态；圣家堂的树形柱是其结构发明。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
