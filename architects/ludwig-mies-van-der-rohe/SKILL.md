# Ludwig Mies van der Rohe — 密斯·凡·德·罗 (1886–1969) · 建筑师蒸馏 v0.1

> 状态：试蒸草稿 v0.1，2026-10-26。只蒸建筑作品与建筑成就，不蒸私生活。名单位置：architects-top100-draft v1 #41，现代主义 / 国际风格。模板：architects-top100-draft.md 第 6 节（画家模板改编为建筑师）。

## 一句话

- **这是谁：** 现代主义 / 国际风格建筑师，代表作《巴塞罗那德国馆》、《西格拉姆大厦》、《范斯沃斯住宅》。
- **什么时候用他：** 需要按此人的风格设计其他题材的建筑（住宅、公共建筑、城市空间）时，用这个 skill。
- **风格一句话：** 密斯风格：少即是多、钢与玻璃盒子、通用空间、石灰华与大理石墙面、十字形钢柱，没有装饰，没有坡屋顶。
- **过程一句话：** 建筑五步：场地分析 → 概念设计 → 方案深化 → 施工图 → 建造。

## 蒸馏范围（只限成果物）

- 材料：建成建筑本身 + 建筑师本人关于建筑的公开文字、图纸、模型与施工记录 + 权威说明与评论/研究。`artifact`
- 不写：私生活、心理诊断、传记轶事。
- 证据分级：`verbatim`（建筑本身直接可见，可指认到具体建筑与部位）/ `artifact`（公开文字、图纸、模型、施工记录、博物馆与事务所说明）/ `impression`（他人印象，须注明是谁），矛盾记入 `conflicts.md`。
- 在世者口径：已故建筑师，蒸馏以建成作品与公开文献为准。
- 合作口径：合作作品按“主创 + 合作”处理，分工见 conflicts.md，不把合作成果独占为一人之功。
