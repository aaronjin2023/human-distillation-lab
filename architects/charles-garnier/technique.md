# Charles Garnier — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 大楼梯：大理石楼梯是歌剧院的空间中心，流线即仪式。 `verbatim` / `artifact`
- 铁构藏石后：铁屋顶承重，石立面表情，结构与表情分工。 `artifact`
- 建造逻辑：定楼梯—放线—砌筑—铁构屋顶—大理石—鎏金；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、铁、大理石、金；色板：多彩大理石、鎏金、深红；禁色：不用极简白墙。 `impression`
- 结构体系：结构：铁构屋顶与石砌立面，铁即结构藏于石之后；大楼梯以大理石与铁并用。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
