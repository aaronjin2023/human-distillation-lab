# Joseph Paxton — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 模块化预制：铁肋与玻璃皆按模块预制，现场只拼装。 `verbatim` / `artifact`
- 大跨铁肋拱：肋拱的跨度即大厅的全部空间。 `artifact`
- 建造逻辑：模块设计—工厂预制—现场拼装—玻璃—落成；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：铁、玻璃、木；色板：铁灰、玻璃蓝、白；禁色：不大面积涂彩，不用砖石贴面。 `impression`
- 结构体系：结构：铁肋拱与玻璃幕，预制模块现场拼装；水晶宫的模块化是其结构发明。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
