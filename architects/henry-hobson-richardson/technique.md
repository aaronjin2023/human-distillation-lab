# Henry Hobson Richardson — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 粗石砌筑：粗石的肌理即立面的全部装饰。 `verbatim` / `artifact`
- 圆拱与厚墙：圆拱的跨度与墙的厚度互相成全。 `artifact`
- 建造逻辑：选石—放线—砌筑厚墙—圆拱—塔楼；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：粗石、砖；色板：暖红粗石、深灰、木色；禁色：不用白灰泥，不大面积涂彩。 `impression`
- 结构体系：结构：石砌承重，圆拱与厚墙；三一教堂的塔楼与圆拱是其手笔。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
