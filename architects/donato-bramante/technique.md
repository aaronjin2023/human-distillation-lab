# Donato Bramante — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 集中式平面：圆堂以中心定一切，柱廊与穹顶皆向心。 `verbatim` / `artifact`
- 长轴线庭院：以轴线组织高差与视线，是其城市尺度技法。 `artifact`
- 建造逻辑：定中心—放线—砌筑柱廊—穹顶—庭院；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、砖、灰泥；色板：石灰、大理石白、砖红；禁色：不大面积涂彩。 `impression`
- 结构体系：结构：集中式穹顶，柱廊承托檐部；贝尔维德雷中庭以长轴线组织高差，是其城市尺度的手笔。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
