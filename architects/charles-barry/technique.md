# Charles Barry — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 哥特复兴立面：塔楼、尖顶与尖拱的垂直节奏是其立面发明。 `verbatim` / `artifact`
- 轴线平面：议会厅与大厅以轴线组织，是其平面技法。 `artifact`
- 建造逻辑：定轴线—放线—砌筑—塔楼—尖拱；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、砖；色板：石灰黄、灰；禁色：不大面积涂彩。 `impression`
- 结构体系：结构：石砌承重，尖拱与肋拱为哥特结构语言；威斯敏斯特宫的塔楼与立面是其手笔。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
