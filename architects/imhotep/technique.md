# Imhotep — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 石砌阶梯体逐层内收，以自重与收分求稳定，不依赖拱与拉结。 `verbatim` / `artifact`
- 柱廊石柱仿芦苇束与木构形态，凹槽刻痕即结构装饰合一。 `artifact`
- 建造逻辑：采石—运输—放线—分层砌筑—雕饰；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石灰石（粗石砌筑、精细贴面并用）、花岗岩门楣；色板：石灰石暖灰、沙漠土黄、赭石红、矿物蓝（少量彩绘）；禁色：不做大面积亮彩平涂，不用金属光泽面。 `impression`
- 结构体系：结构：实心石砌阶梯体，荷载逐层内收；柱为石仿木束柱与凹槽柱，承重即形式；无拱、无穹顶，靠砌体自重稳定。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
