# Mimar Sinan — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 六角/八角支撑穹顶：墩柱位置即穹顶的全部结构逻辑。 `verbatim` / `artifact`
- 半穹顶跌落：半穹顶既分担侧推力，又组织空间层次。 `artifact`
- 建造逻辑：选址—放线—砌筑墩柱—穹顶—尖塔—贴砖；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、砖；内饰：伊兹尼克瓷砖、大理石；色板：石灰、瓷砖蓝、绿、赭石；禁色：外立面不大面积涂彩。 `impression`
- 结构体系：结构：穹顶由六角或八角墩支撑，半穹顶分担侧推力；尖塔细长，结构与形式合一。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
