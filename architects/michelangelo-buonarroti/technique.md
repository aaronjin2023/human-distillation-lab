# Michelangelo Buonarroti — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 巨柱式：壁柱跨越多层，立面以巨柱定秩序。 `verbatim` / `artifact`
- 穹顶鼓座：高鼓座抬升穹顶，穹顶成为城市天际线。 `artifact`
- 建造逻辑：定穹顶—放线—砌筑鼓座—穹顶合拢—广场铺装；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、砖、灰泥；色板：石灰灰、大理石白、深灰阴影；禁色：不大面积涂彩。 `impression`
- 结构体系：结构：穹顶双壳与鼓座，巨柱式壁柱承托檐部；劳伦齐亚纳楼梯以石阶的雕塑感组织流线。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
