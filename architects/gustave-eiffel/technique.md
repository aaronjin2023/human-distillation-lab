# Gustave Eiffel — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 铁桁架计算：风荷载计算定出曲线的收分，是其工程本体。 `verbatim` / `artifact`
- 铆接节点：铆钉即结构，节点不隐藏。 `artifact`
- 建造逻辑：计算—工厂预制—现场吊装—铆接—落成；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：铁、钢；色板：铁灰、古铜；禁色：不用砖石贴面，不大面积涂彩。 `impression`
- 结构体系：结构：铁桁架与铆接节点，曲线收分抗风；加拉比高架桥的拱即结构。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
