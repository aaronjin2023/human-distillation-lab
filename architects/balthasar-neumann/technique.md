# Balthasar Neumann — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 椭圆厅：椭圆与圆形组合的平面，是其空间发明。 `verbatim` / `artifact`
- 灰泥与壁画：灰泥即结构装饰合一，壁画天花是厅的全部色彩。 `artifact`
- 建造逻辑：定椭圆—放线—砌筑—楼梯—灰泥壁画；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、砖、灰泥、金；色板：白、金、淡彩壁画；禁色：不大面积深色。 `impression`
- 结构体系：结构：椭圆厅的穹顶与楼梯，灰泥即结构装饰合一；十四圣徒教堂的椭圆与圆形组合是其平面发明。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
