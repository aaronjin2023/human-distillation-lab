# Leon Battista Alberti — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 音乐比例：开间与高度按1:2、2:3等数比，是其设计方法。 `verbatim` / `artifact`
- 壁柱立面：壁柱不承重，却要合乎柱式定则，立面即秩序。 `artifact`
- 建造逻辑：比例定稿—放线—砌筑—立面贴石—室内拱顶；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、大理石贴面、灰泥；色板：大理石白、灰石灰、赭石；禁色：不大面积涂彩。 `impression`
- 结构体系：结构：梁柱与拱券，壁柱只作立面秩序，不承重亦要合乎比例；圣安德烈亚的筒形拱顶是其结构手笔。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
