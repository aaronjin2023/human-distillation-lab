# Andrea Palladio — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 九宫格平面：三乘三方格，中央厅定一切，平面即立面。 `verbatim` / `artifact`
- 神庙式门廊：三角楣与柱廊是别墅的脸，比例即身份。 `artifact`
- 建造逻辑：九宫格放线—砌筑—门廊—穹顶—灰泥；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：砖、白灰泥、石；色板：白灰、石灰灰、砖红；禁色：不大面积涂彩，不用金色。 `impression`
- 结构体系：结构：梁柱与拱券，神庙式门廊以三角楣收束；圆厅别墅四面门廊，穹顶居中。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
