# Francesco Borromini — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 曲面承重墙：凹凸墙面既是结构又是形式，墙即空间。 `verbatim` / `artifact`
- 几何平面：椭圆与复杂几何由平面放线定出，平面即设计。 `artifact`
- 建造逻辑：几何放线—砌筑曲面墙—穹顶—采光塔—灰泥；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：砖、白灰泥、石；色板：白灰、石灰灰；禁色：不大面积涂彩，不用金色。 `impression`
- 结构体系：结构：曲面砖墙承重，穹顶以交错拱收束；圣卡洛的椭圆平面与曲面墙是其结构发明。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
