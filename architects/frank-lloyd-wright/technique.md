# Frank Lloyd Wright — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 悬挑结构：混凝土板悬挑出石砌核心，是其结构发明。 `verbatim` / `artifact`
- 壁炉核心：中央壁炉是平面的组织中心，结构与生活合一。 `artifact`
- 建造逻辑：读地形—定壁炉核心—悬挑—开放平面—景观；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、木、砖、混凝土；色板：石灰、木色、砖红、秋叶金；禁色：不用古典石材贴面，不用高层玻璃幕墙。 `impression`
- 结构体系：结构：悬挑混凝土板与石砌壁炉核心，结构即形式；流水别墅的悬挑是其结构发明。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
