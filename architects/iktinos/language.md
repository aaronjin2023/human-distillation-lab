# Iktinos — 空间与材料语言 language.md（Interaction，只限建筑作品）

- 柱廊即语言：柱距、柱影与台阶构成建筑的全部修辞。 `impression`
- 内殿幽暗与柱廊明亮的对比，是仪式空间的明暗语法。 `impression`
- 空间序列：体量：长方形围柱式，水平舒展而庄重；空间序列：台阶—柱廊—前廊—内殿，仪式轴线居中；尺度：柱高与柱距按多立克比例，台基与柱身均有肉眼难察的微曲修正。 `impression`
- 光线与阴影：光线：柱廊光影节奏是主角——柱影随日照移动；内殿幽暗，仅东门进光；环境：立于卫城高台，顺应地形，远望即城市地标。 `impression`
- 材料质感与色彩：主材：彭特利大理石，精细打磨；色板：大理石白、暖灰、赭石（彩绘残迹）、深蓝（局部）；禁色：不大面积涂彩，不用金色贴面。 `impression`
- 室内外交界：柱廊光影节奏是主角——柱影随日照移动；内殿幽暗，仅东门进光；环境：立于卫城高台，顺应地形，远望即城市地标；视线引导靠空间序列与开洞，不靠附加装饰。`impression`
