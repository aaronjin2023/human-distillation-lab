# Guarino Guarini — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 交错肋架穹顶：肋的交错既是结构又是采光组织。 `verbatim` / `artifact`
- 几何放线：星形与复杂几何由平面放线定出。 `artifact`
- 建造逻辑：几何放线—砌筑—肋架穹顶—采光塔—灰泥；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：砖、灰泥、石；色板：白灰、石灰灰；禁色：不大面积涂彩。 `impression`
- 结构体系：结构：交错肋架穹顶，肋即结构即装饰；圣洛伦佐的穹顶以肋的交错组织光线。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
