# Johann Bernhard Fischer von Erlach — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 纪功柱：螺旋浮雕柱身既是纪念碑又是立面构图。 `verbatim` / `artifact`
- 轴线宫殿：宫殿与园林以同一轴线组织。 `artifact`
- 建造逻辑：定穹顶—放线—砌筑—纪功柱—园林；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、砖、灰泥；色板：石灰白、赭石；禁色：不大面积涂彩。 `impression`
- 结构体系：结构：中央穹顶与纪功柱，柱身螺旋浮雕；美泉宫的横向宫殿体量是其城市尺度手笔。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
