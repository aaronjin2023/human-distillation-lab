# Filippo Brunelleschi — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 双壳穹顶人字形砌法：无脚手架自承重，是其结构发明的本体。 `verbatim` / `artifact`
- 线性透视：灭点即空间组织，建筑按透视法放线。 `artifact`
- 建造逻辑：放线—砌筑墩柱—人字形砌筑穹顶—合拢—贴面；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：砖、灰石（pietra serena）、白灰墙；色板：灰石灰、白、砖红、陶土；禁色：不大面积涂彩，不用金色。 `impression`
- 结构体系：结构：双壳穹顶，人字形砌法与环箍，无木支撑自承重；育婴堂的轻拱廊是梁柱与拱的轻盈组合。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
