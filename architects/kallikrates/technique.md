# Kallikrates — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 爱奥尼柱式：涡卷柱头与细长柱身的比例控制，是其核心技法。 `verbatim` / `artifact`
- 高台小神庙的台基与柱廊一体化放线，体量虽小，定位极严。 `artifact`
- 建造逻辑：采石—运输—放线—立柱—架梁—雕饰；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：彭特利大理石；色板：大理石白、淡灰、赭石彩绘残迹；禁色：不大面积涂彩，不用深色石材。 `impression`
- 结构体系：结构：爱奥尼梁柱体系，涡卷柱头，柱身细长；帕特农神庙的柱式与细部亦有其手笔，结构即装饰。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
