# Augustus Pugin — 建筑设计与结构技法 technique.md（Procedure，只限建筑作品）

> v0.1（2026-10-26）。

- 尖拱与肋拱：尖拱的垂直感是其结构语言。 `verbatim` / `artifact`
- 材料真实：石就是石，木就是木，不用灰泥伪装。 `artifact`
- 建造逻辑：定尖拱—放线—砌筑—彩色玻璃—细部；从方案到施工图的深化方式是：概念定体量与结构意向，方案深化定平面、立面、剖面，施工图只定构造与节点，不改概念。`impression`
- 材料与构造：主材：石、木、彩色玻璃；色板：石灰灰、彩色玻璃蓝红、木色；禁色：不用灰泥伪装石材，不用古典柱式。 `impression`
- 结构体系：结构：尖拱与肋拱，石砌承重；彩色玻璃即围护，结构与装饰合一。 `verbatim` / `artifact`
- 修改痕迹：图纸与施工变更以建成作品与测绘为准；无施工记录者按建成作品反推，不声称复刻原过程。`artifact`
