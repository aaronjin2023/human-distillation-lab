# Fatmata Binta — 菜品语言 language.md（Interaction，只限菜品）

- 味型即语言：谷物本味先行，花生香随后，辣收尾。`impression`
- 共食即语言：席地围坐分享，餐桌本身在说话。`artifact`
- 主味：富拉尼游牧菜的谷物本味与发酵酸，fonio 小米绵香打底；辅味：花生香、干辣椒辣、香草；禁味：浪费、进口替代、过甜；层次质朴多层，酸度中等，讲求就地取材与零浪费。 `impression`
- 摆盘：席地而坐的垫子用餐，器皿质朴，色彩取谷物与食材本色；食材：西非本土与富拉尼传统物产；上菜节奏：分享式，谷物与炖菜并行。 `impression`
- 食客的第一口体验：第一口先觉主味，随后是辅味与香气，收尾是本味或酸提亮；第一口即检验标准。`impression`
