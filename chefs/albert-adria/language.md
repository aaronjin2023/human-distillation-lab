# Albert Adrià — 菜品语言 language.md（Interaction，只限菜品）

- 味型即语言：橄榄油香先行，番茄酸随后，惊奇收尾。`impression`
- 小份即语言：多道小盘依次上，玩味在说话。`impression`
- 主味：西班牙小吃的酸鲜与橄榄油香，分子技法玩味重构；辅味：番茄酸、蒜香、烟熏辣椒；禁味：厚重正餐、大份量、直白油腻；层次玩味多层，酸度中高，讲求小份多样的惊奇。 `impression`
- 摆盘：小吃吧的玩味精致，小盘多份，色彩鲜明；食材：西班牙本地时令为先；上菜节奏：多道小吃依次上，分享式。 `impression`
- 食客的第一口体验：第一口先觉主味，随后是辅味与香气，收尾是本味或酸提亮；第一口即检验标准。`impression`
