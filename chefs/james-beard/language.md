# James Beard — 菜品语言 language.md（Interaction，只限菜品）

- 味型即语言：本味先行，香草随后，实在收尾。`impression`
- 家常即语言：丰盛分享上桌，食客的第一口是踏实。`impression`
- 主味：美式家常的咸鲜与黄油香，本地物产本味为先；辅味：香草、烟熏、酸提亮；禁味：照搬法餐的繁复、过甜；层次直接清晰，讲求食材本味与季节。 `impression`
- 摆盘：美式家常的丰盛实在，器皿质朴，色彩取食材本色；食材：美国本地时令物产为先；上菜节奏：家常分享，前菜—主菜—甜点。 `impression`
- 食客的第一口体验：第一口先觉主味，随后是辅味与香气，收尾是本味或酸提亮；第一口即检验标准。`impression`
