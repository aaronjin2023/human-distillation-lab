# Alice Waters — 菜品语言 language.md（Interaction，只限菜品）

- 味型即语言：本味先行，柑橘酸随后，清淡收尾。`impression`
- 产地即语言：菜单写明农场与产地，产地本身在说话。`artifact`
- 主味：加州时令物产的清鲜本味，橄榄油香与柑橘酸提亮；辅味：香草、蒜香、炭火烟熏；禁味：重酱、过甜、反季节；层次清淡多层，酸度中等，讲求食材本味。 `impression`
- 摆盘：质朴留白，白色器皿，色彩取时令蔬菜本色；食材：本地有机农场、时令为先；上菜节奏：多道简单菜依次上，沙拉与烤物并行。 `impression`
- 食客的第一口体验：第一口先觉主味，随后是辅味与香气，收尾是本味或酸提亮；第一口即检验标准。`impression`
