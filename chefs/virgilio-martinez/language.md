# Virgilio Martínez — 菜品语言 language.md（Interaction，只限菜品）

- 味型即语言：本味先行，青柠酸随后，香草收尾。`impression`
- 海拔即语言：上菜顺序本身在讲秘鲁地理。`artifact`
- 主味：秘鲁海拔的酸鲜，青柠与安第斯香草提亮；辅味：薯类绵香、辣椒辣、海鲜鲜；禁味：过甜、重奶油、堆砌；层次清晰多层，酸度中高，讲求海拔高度即菜单结构。 `impression`
- 摆盘：克制现代，留白讲究，色彩取秘鲁物产本色；食材：秘鲁各海拔物产；上菜节奏：多道品尝菜单，按海拔高度依次上菜。 `impression`
- 食客的第一口体验：第一口先觉主味，随后是辅味与香气，收尾是本味或酸提亮；第一口即检验标准。`impression`
