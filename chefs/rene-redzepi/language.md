# René Redzepi — 菜品语言 language.md（Interaction，只限菜品）

- 味型即语言：本味先行，发酵酸随后，野草香收尾。`impression`
- 风景即语言：盘面在讲北欧的季节与土地。`impression`
- 主味：北欧时令的清鲜酸，发酵酸与野味香并行；辅味：烟熏、松针香、海藻咸鲜；禁味：进口奢华、重酱、过甜；层次清淡多层，酸度中高，讲求本地野味与发酵的深度。 `impression`
- 摆盘：北欧极简，天然器皿（石、木、陶），留白大，色彩取时令本色；食材：丹麦本地与野味，时令为先；上菜节奏：多道品尝菜单，季节依次亮相。 `impression`
- 食客的第一口体验：第一口先觉主味，随后是辅味与香气，收尾是本味或酸提亮；第一口即检验标准。`impression`
