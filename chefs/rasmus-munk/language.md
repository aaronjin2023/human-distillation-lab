# Rasmus Munk — 菜品语言 language.md（Interaction，只限菜品）

- 味型即语言：体验先行，酸鲜随后，反差收尾。`impression`
- 空间即语言：餐厅的灯光与声音也是菜品的句子。`impression`
- 主味：体验优先，酸鲜与香气反差并行；辅味：烟熏、甜、苦的意外组合；禁味：直白饱腹、无体验的家常；层次实验性多层，讲求味觉、视觉、听觉的整体体验。 `impression`
- 摆盘：沉浸式体验，器皿与空间本身即菜品一部分；食材：丹麦时令为先，部位服务于体验；上菜节奏：多幕体验菜单，故事依次递进。 `impression`
- 食客的第一口体验：第一口先觉主味，随后是辅味与香气，收尾是本味或酸提亮；第一口即检验标准。`impression`
