# human-distillation-lab

人物蒸馏实验室：把各行业头部人物的成果物，蒸馏成可复用的 skill。

## 第一类：100 位画家

人类历史上最杰出的 100 名各流派画家（v2 名单）：西方 62、中国 24、日本 5、非洲 1（集合体）、美洲 1（集合体）、阿拉伯—伊斯兰 3、蒙古 1（集合体）、东南亚 3。名单与修订记录见 `painters-top100-draft-v2.md`（v1 见 `painters-top100-draft.md`）。

只蒸作品：画作本身 + 关于画作的公开文字与题款 + 博物馆说明。不碰私生活。

## 目录结构

- `painters-top100-draft.md` / `painters-top100-draft-v2.md`：名单、模板与修订记录
- `第一次实验.md`：实验计划
- `painters/<画家>/`：每位画家一个文件夹，共 100 个

每个画家文件夹 9 个文件：

- `SKILL.md`：总览，怎么用这个 skill
- `style.md`：图像风格规格（给图像模型）：prompt-ready 风格描述、色板（颜料名，不编 HEX）、笔触构图、该画 / 不该画、1 条现代题材测试提示词
- `process.md`：作画过程规格（给视频模型）：5 步、5 个检查点、延时节奏、机位
- `technique.md`：技法
- `language.md`：画面语言
- `motifs.md`：母题与演变
- `decisions.md`：画中决策逻辑
- `conflicts.md`：争议与未核实项
- `manifest.json`：元数据（画家、时期、流派、代表作、来源、版本、known_gaps）

## 怎么用

图像模型：按 `style.md` 的风格描述 + 测试提示词，画其他题材。例如齐白石 skill 的测试题是“齐白石风格，一只小约克夏犬坐在地铁座位上”。

视频模型：按 `process.md` 的 5 步与检查点，复刻作画过程。
