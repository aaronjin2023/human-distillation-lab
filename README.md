# human-distillation-lab

人物蒸馏实验室：把各行业头部人物的成果物，蒸馏成可复用的 skill。

只蒸作品：作品本身 + 关于作品的公开文字与权威说明。不碰私生活。
在世人物照收（口径 C）：在世不在世都可以，只蒸已发表的成果物，不碰未发表手稿与私人生活，在世者标 `living_person: true`。

## 目录结构

- `painters-top100-draft.md` / `painters-top100-draft-v2.md`：画家名单、模板与修订记录
- `writers-top100-draft.md` / `thinkers-top100-draft.md` / `scientists-top100-draft.md` / `musicians-top100-draft.md`：四类名单（均已定稿）
- `第一次实验.md`：实验计划
- `painters/<画家>/`、`writers/<文学家>/`、`thinkers/<思想家>/`、`scientists/<科学家>/`、`musicians/<音乐家>/`：每人一个文件夹，各 100 个

每个文件夹 9 个文件：

- `SKILL.md`：总览，怎么用这个 skill
- `style.md`：风格规格（给生成模型）：prompt-ready 风格描述、该用 / 不该用、1 条现代题材测试提示词
  - 画家：图像风格规格（颜料名色板，不编 HEX）
  - 文学家：写作风格规格（文本模型用）
  - 思想家：论证与思想框架规格
  - 科学家：发现方法与理论风格规格
  - 音乐家：作曲风格规格（音乐模型用）
- `process.md`：过程规格（给视频模型）：5 步、5 个检查点、节奏、机位
  - 画家：作画过程；文学家：写作过程（构思—草稿—修改—定稿）；思想家：思想展开过程（问题—概念—论证—结论—反驳）；科学家：研究过程（观察—假设—实验/证明—发表与修正）；音乐家：作曲过程（动机—草稿—配器—排练）
- `technique.md`：技法
- `language.md`：作品语言
- `motifs.md`：母题与演变
- `decisions.md`：作品中的决策逻辑
- `conflicts.md`：争议与未核实项
- `manifest.json`：元数据（人物、时期、领域、代表作、来源、版本、known_gaps；在世者标 `living_person: true`）

## 怎么用

- 图像模型：按画家 `style.md` 的风格描述 + 测试提示词，画其他题材。例如齐白石 skill 的测试题是“齐白石风格，一只小约克夏犬坐在地铁座位上”。
- 文本模型：按文学家 / 思想家 / 科学家 `style.md` 的风格与论证规格，写其他题材、回应现代议题、提出假说或设计实验。
- 音乐模型：按音乐家 `style.md` 的作曲风格规格，为新场景作曲。
- 视频模型：按各 `process.md` 的 5 步与检查点，复刻创作 / 研究过程。
