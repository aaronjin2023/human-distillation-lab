# human-distillation-lab

只蒸作品：作品本身 + 关于作品的公开文字与权威说明。不碰私生活。
在世人物照收（口径 C）：在世不在世都可以，只蒸已发表的成果物，不碰未发表手稿与私人生活，在世者标 `living_person: true`。

## 怎么用

- 图像模型：按画家 `style.md` 的风格描述 + 测试提示词，画其他题材。例如齐白石 skill 的测试题是“齐白石风格，一只小约克夏犬坐在地铁座位上”。书法 `style.md` 同理，给图像模型按书法风格写字。漫画 / 建筑 / 园林 / 服装 `style.md` 同理，给图像模型按各风格出图。
- 文本模型：按文学家 / 思想家 / 科学家 / 诗人 / 编剧 / 作词人 / 哲学家 / 社会学家 / 心理学家 `style.md` 的风格与论证规格，写其他题材、回应现代议题、提出假说或设计实验。
- 音乐模型：按音乐家 / 作曲家 `style.md` 的作曲风格规格，为新场景作曲；按歌手 `style.md` 的演唱风格规格，演绎新曲。
- 视频模型：按各 `process.md` 的 5 步与检查点，复刻创作 / 研究过程；按导演 `style.md` 的镜头语言与剪辑规格，拍其他题材。
