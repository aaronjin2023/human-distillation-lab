# Carl Rogers — 心理学研究过程规格 process.md（给文本 / 视频模型）

> 只按研究的逻辑写，不编造心理学家的生活场景；有原始论文 / 实验记录可考者以原始文献为准，无原始记录者按理论与实验结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 研究状态 |
|---|---|---|
| 1 问题 | 定问题：治疗中什么因素带来改变——是技术，还是治疗关系？界定共情、接纳与真诚的操作化定义。 | 约 10–20% 完成，问题可见、方法未定 |
| 2 假设 | 提假设：治疗师的共情、接纳与真诚程度越高，来访者的自我概念越趋向整合，成长越明显。 | 约 30–40%，假设已定、设计未定 |
| 3 实验 / 研究 | 做工作：录音记录治疗对话，逐字转录；治疗师以非指导性倾听回应，不贴标签、不给建议，只做映照与澄清。 | 约 60–70%，数据已收、分析未做 |
| 4 数据 | 分析数据：评定治疗师回应的共情准确性，测量来访者自我概念的前后变化；处理录音中沉默与停顿的含义。 | 约 85–90%，结论已立，个别结果仍可留空 |
| 5 理论 | 成理论：整合为以人为中心治疗理论，写清适用边界（成长取向的来访者）与未解问题（严重精神障碍的适用性）。 | 100%，完成态 |

- 每步最容易做错的地方：第 3 步治疗师一给建议就偏离非指导性立场；第 4 步若只看自我报告不看行为改变，就会高估疗效。

## (2) 每一阶段的研究状态变化（过程视频 / 文本生成的节奏）

- 检查点：每步结束时研究状态如上表所示——第 1 步只有问题与概念、第 3 步有原始数据无结论、第 4 步效应与图表骤现、第 5 步定稿为完成态。
- 节奏建议：问题慢（让观者看清概念）、假设中速（看预测生长）、实验 / 研究中速（看数据积累）、数据分析放慢（看逐项检验）、理论停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。时间分配：问题 15%、假设 10%、临床工作 45%、数据 15%、理论 15%。临床步最长，看对话逐句展开。

## (3) 过程呈现的镜头与字幕建议

- 呈现：实验记录 / 数据表 / 概念图逐行出现，关键修改处用删除线与替换概念并排显示；每步左上角出小字步骤名（问题 / 假设 / 实验 / 数据 / 理论），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍实验记录 / 屏幕特写 / 局部放大三机位轮换；问题用全景，数据分析用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 项原作小图对照（只放实验装置图 / 数据图 / 著作封面，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡记录；不要把过程剪成跳切，保留研究的连续性；不要虚构心理学家本人的生活场景；涉及人类被试或动物的实验，必须在字幕中注明伦理争议与现代伦理标准，不作美化。

## (4) 过程示例（按本人的研究逻辑反推，不声称复刻原过程）

- 问题：定问题：治疗中什么因素带来改变——是技术，还是治疗关系？界定共情、接纳与真诚的操作化定义。
- 假设：提假设：治疗师的共情、接纳与真诚程度越高，来访者的自我概念越趋向整合，成长越明显。
- 实验 / 研究：做工作：录音记录治疗对话，逐字转录；治疗师以非指导性倾听回应，不贴标签、不给建议，只做映照与澄清。
- 数据：分析数据：评定治疗师回应的共情准确性，测量来访者自我概念的前后变化；处理录音中沉默与停顿的含义。
- 理论：成理论：整合为以人为中心治疗理论，写清适用边界（成长取向的来访者）与未解问题（严重精神障碍的适用性）。
- 节奏：问题 15%、假设 10%、临床工作 45%、数据 15%、理论 15%。临床步最长，看对话逐句展开。
