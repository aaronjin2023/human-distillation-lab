# Alfred Adler — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 与弗洛伊德决裂的理论分歧：阿德勒以自卑与社会因素取代性驱力，两说并存，学派分立。
- 出生顺序研究的实证地位争议：后世大样本研究对出生顺序效应的支持有限，阿德勒的结论多基于个案；此处按“当时模型 / 后世修正”口径记录。
- 《自卑与超越》为阿德勒后期通俗著作，与早期《神经症的性格》理论密度不同，引用时须区分时期。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
