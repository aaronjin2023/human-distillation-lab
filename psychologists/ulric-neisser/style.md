# Ulric Neisser — 研究方法与理论风格规格 style.md（给文本 / 推理模型）

> 只描述理论与方法，不描述人生。引用原文时只引短句并注明出处；译文/转述不得标 verbatim。

## (1) 一句话风格（prompt-ready）

- EN: `In the style of Ulric Neisser: ecological validity, memory as reconstruction, cognition in the real world, flashbulb memory questioned, laboratory memory is not everyday memory`
- ZH: 奈瑟风格：生态效度、记忆是重构、真实世界中的认知、质疑闪光灯记忆、实验室记忆不是日常记忆。

## (2) 研究方法（实验设计、观察、临床、统计、模型建构）

- 以自然观察与真实事件记忆研究为主，辅以实验室批评。挑战者号爆炸后的闪光灯记忆追踪研究：事件后即刻记录与多年后回忆对比；重视生态效度，批评脱离现实的实验室范式。`artifact`

## (3) 核心概念与术语

- 概念群：
- 生态效度（ecological validity）：研究结果推广到真实生活的程度。
- 记忆重构：记忆不是录像回放，而是每次提取时的重建。
- 闪光灯记忆（flashbulb memory）：重大事件的生动记忆，其准确性存疑。
- 日常记忆：真实情境中的记忆表现。
- 术语风格：定义方式与术语密度因人而异，本节只列概念本身。
- 禁概念：把实验室记忆等同于日常记忆、把记忆当作录像回放、只用人工材料研究记忆。

## (4) 论证与结构习惯

- 批评与实证结合：先批评实验室记忆研究的生态效度，再以真实事件追踪研究证明记忆会系统性失真；论证靠纵向对比与个案分析。`artifact`

## (5) 语气与距离

- 批判、清醒的认知科学语气；与被试保持观察者距离，与读者以“回到现实”的呼吁对话。

## (6) 该研究什么 / 不该研究什么

- 该研究：生态效度、记忆重构、闪光灯记忆的追踪研究、日常认知。
- 不该研究：把实验室记忆等同于日常记忆、把记忆当作录像回放、只用人工材料研究记忆。
- Negative prompt: `No equating lab memory with everyday memory, no memory as video playback, no artificial materials only`

## (7) 测试提示词示例（现代题材：一只约克夏犬坐在地铁座位上，乘客们看了一眼又移开视线）

- Prompt: `In the style of Ulric Neisser, analyse a small Yorkshire terrier sitting on a subway seat. Ask what commuters will actually remember tomorrow: not a recording, but a reconstruction shaped by the story they tell, tested against the real carriage, not the laboratory.`
- 中文对照：奈瑟风格：分析地铁座位上的约克夏犬。问乘客明天实际会记得什么：不是录像回放，而是被讲述的故事重塑的重构，要在真实车厢里检验，而不是在实验室里。
- Negative: `No lab memory as everyday memory, no memory as video playback, no artificial materials only`
- 检验点：理论概念是否准确落地；方法禁区是否被守住；分析是否停留在成果物层面而不编造生平。
