# Alan Baddeley — 研究方法与理论风格规格 style.md（给文本 / 推理模型）

> 只描述理论与方法，不描述人生。引用原文时只引短句并注明出处；译文/转述不得标 verbatim。

## (1) 一句话风格（prompt-ready）

- EN: `In the style of Alan Baddeley: working memory as a workbench, phonological loop, visuospatial sketchpad, central executive, episodic buffer, dual-task evidence, memory in action`
- ZH: 巴德利风格：工作记忆是一张工作台、语音环路、视空间画板、中央执行器、情节缓冲器、双任务证据、行动中的记忆。

## (2) 研究方法（实验设计、观察、临床、统计、模型建构）

- 以实验室双任务实验为主，辅以脑损伤个案与应用研究。操纵语音与视空间任务的双重负荷，测量干扰效应；用失忆症个案检验模型成分的分离。`artifact`

## (3) 核心概念与术语

- 概念群：
- 工作记忆（working memory）：主动保持与操作信息的系统。
- 语音环路（phonological loop）：保持言语信息的子系统。
- 视空间画板（visuospatial sketchpad）：保持视觉与空间信息的子系统。
- 中央执行器（central executive）：分配注意、协调子系统的控制成分。
- 情节缓冲器（episodic buffer）：整合多模态信息并连接长时记忆。
- 术语风格：定义方式与术语密度因人而异，本节只列概念本身。
- 禁概念：把短时记忆说成一个被动仓库、忽略注意与控制的作用、只用单一任务研究记忆。

## (4) 论证与结构习惯

- 实验序列与模型修正并重：先以双任务实验证明短时记忆不是单一仓库，再提出三成分模型，最后根据新证据加入情节缓冲器；论证靠干扰效应与个案分离。`artifact`

## (5) 语气与距离

- 严谨、务实的应用认知语气；与被试保持实验者距离，与读者以模型图与应用案例对话。

## (6) 该研究什么 / 不该研究什么

- 该研究：工作记忆多成分模型、双任务干扰效应、语音环路与视空间画板、情节缓冲器与应用记忆。
- 不该研究：把短时记忆说成一个被动仓库、忽略注意与控制的作用、只用单一任务研究记忆。
- Negative prompt: `No short-term memory as a passive store, no ignoring attention and control, no single-task-only memory research`

## (7) 测试提示词示例（现代题材：一个人深夜刷短视频停不下来）

- Prompt: `In the style of Alan Baddeley, analyse a person who cannot stop scrolling short videos late at night. The phonological loop repeats the video's words, the sketchpad holds its images, the central executive is overloaded, and the episodic buffer binds it all into one more night that feels continuous.`
- 中文对照：巴德利风格：分析深夜刷短视频停不下来的人。语音环路重复着视频里的话，视空间画板留住画面，中央执行器已经超载，情节缓冲器把这一切绑成又一个感觉连续的夜晚。
- Negative: `No short-term memory as passive store, no ignoring attention, no single-task-only research`
- 检验点：理论概念是否准确落地；方法禁区是否被守住；分析是否停留在成果物层面而不编造生平。
