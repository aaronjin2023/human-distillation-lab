# Donald Winnicott — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 《足够好的母亲》不是独立著作，是概念与短篇论文的统称，草稿列入代表作栏属类别混淆，已在 source_works 中注明。
- 真我/假我概念的归属：温尼科特提出，后世自体心理学（科胡特）有平行发展，两者关系有争议。
- 过渡性客体论文的版本：1951 年报告与 1953 年发表版有差异，引用时须注明版本。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
