# Edward Titchener — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 草稿代表作栏《结构主义体系》并非著作原名：铁钦纳遗著为 Systematic Psychology（《系统心理学》，1929 年遗著出版），此处已按原名修正；异译记此。
- 无意象思维争论：库尔佩学派主张思维可无意象，铁钦纳坚持思维必有感觉与意象基础，争论无定论，两说并存。
- 铁钦纳与冯特的关系常被简化为师徒复制：铁钦纳自认正统冯特学派，但其结构主义比冯特更窄（只取元素分析，舍弃民族心理学与意志论）。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
