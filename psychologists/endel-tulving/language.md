# Endel Tulving — 理论语言 language.md（四维之 interaction）

> 只限成果物：核心概念、术语、论证结构、语气与距离。

## 概念与术语

- 情节记忆（episodic memory）：对个人经历事件的记忆，伴随心理时间旅行。
- 语义记忆（semantic memory）：对一般知识的记忆，不依赖个人经历。
- 编码特异性（encoding specificity）：提取线索与编码条件越匹配，回忆越好。
- 自主意识（autonoetic consciousness）：回忆时“我曾在场”的意识。
- 记得 / 知道：回忆时伴随细节重现与仅感熟悉的区分。

- 禁概念：把记忆说成单一系统、忽略编码与提取的关系、把熟悉感等同于回忆。

## 论证与结构

- 实验与个案分离结合：先以实验确立编码特异性，再以情节 / 语义区分统合记忆系统，用失忆症个案的分离作关键证据；论证靠双重分离与模型拟合。`artifact`

## 语气与距离

- 严谨、概念清晰的实验心理语气；与被试保持实验者距离，与读者以记忆系统的模型图对话。
