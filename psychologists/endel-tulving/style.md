# Endel Tulving — 研究方法与理论风格规格 style.md（给文本 / 推理模型）

> 只描述理论与方法，不描述人生。引用原文时只引短句并注明出处；译文/转述不得标 verbatim。

## (1) 一句话风格（prompt-ready）

- EN: `In the style of Endel Tulving: episodic versus semantic memory, encoding specificity, autonoetic consciousness, remember versus know, mental time travel, retrieval cues matter`
- ZH: 图尔文风格：情节记忆与语义记忆之分、编码特异性、自主意识、记得与知道之分、心理时间旅行、提取线索很重要。

## (2) 研究方法（实验设计、观察、临床、统计、模型建构）

- 以实验室记忆实验为主，辅以神经心理学与脑成像研究。操纵编码条件与提取线索，因变量是回忆正确率与“记得 / 知道”判断；用失忆症个案检验情节与语义记忆的分离。`artifact`

## (3) 核心概念与术语

- 概念群：
- 情节记忆（episodic memory）：对个人经历事件的记忆，伴随心理时间旅行。
- 语义记忆（semantic memory）：对一般知识的记忆，不依赖个人经历。
- 编码特异性（encoding specificity）：提取线索与编码条件越匹配，回忆越好。
- 自主意识（autonoetic consciousness）：回忆时“我曾在场”的意识。
- 记得 / 知道：回忆时伴随细节重现与仅感熟悉的区分。
- 术语风格：定义方式与术语密度因人而异，本节只列概念本身。
- 禁概念：把记忆说成单一系统、忽略编码与提取的关系、把熟悉感等同于回忆。

## (4) 论证与结构习惯

- 实验与个案分离结合：先以实验确立编码特异性，再以情节 / 语义区分统合记忆系统，用失忆症个案的分离作关键证据；论证靠双重分离与模型拟合。`artifact`

## (5) 语气与距离

- 严谨、概念清晰的实验心理语气；与被试保持实验者距离，与读者以记忆系统的模型图对话。

## (6) 该研究什么 / 不该研究什么

- 该研究：情节记忆与语义记忆的区分、编码特异性、自主意识与心理时间旅行、记得 / 知道的判断。
- 不该研究：把记忆说成单一系统、忽略编码与提取的关系、把熟悉感等同于回忆。
- Negative prompt: `No single memory system, no ignoring encoding-retrieval match, no equating familiarity with recollection`

## (7) 测试提示词示例（现代题材：一只约克夏犬坐在地铁座位上，乘客们看了一眼又移开视线）

- Prompt: `In the style of Endel Tulving, analyse a small Yorkshire terrier sitting on a subway seat. Ask what commuters will remember: semantic facts about the breed, or an episodic memory of this ride, with autonoetic consciousness, retrieved only if the cue matches how it was encoded.`
- 中文对照：图尔文风格：分析地铁座位上的约克夏犬。问乘客会记得什么：关于这个品种的语义知识，还是一次带自主意识的情节记忆——只有提取线索与编码时匹配，它才会被取出来。
- Negative: `No single memory system, no ignoring encoding-retrieval match, no familiarity as recollection`
- 检验点：理论概念是否准确落地；方法禁区是否被守住；分析是否停留在成果物层面而不编造生平。
