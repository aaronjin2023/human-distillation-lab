# Ivan Pavlov — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 巴甫洛夫与行为主义的关系：巴甫洛夫本人是生理学家，华生借用其条件反射建立行为主义，两者目标不同，不可混同。
- 第二信号系统（语言）的理论地位：巴甫洛夫晚年提出，实证基础较弱，后世评价不一；此处按“当时模型 / 后世修正”口径记录。
- 《条件反射》为讲义与论文的统称，英文 Conditioned Reflexes（1927）为讲义英译本，引用时须注明版本。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
