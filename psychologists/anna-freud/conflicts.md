# Anna Freud — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 与克莱因的儿童分析争论（1930–1940 年代英国精神分析学会的“论战”）：安娜·弗洛伊德主张儿童分析须重现实与自我，克莱因主张早期幻想与客体关系；两派分立，无定论。
- 防御机制分类的归属：安娜·弗洛伊德系统化了防御机制，但部分机制（如升华、投射）源自其父著作，归属须注明。
- 《正常与病理》为晚期讲稿整理，引用时须注明版本与讲稿性质。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
