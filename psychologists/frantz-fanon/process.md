# Frantz Fanon — 心理学研究过程规格 process.md（给文本/视频模型）

> 只按研究的逻辑写，不编造心理学家的生活场景；有原始论文/实验记录可考者以原始文献为准，无原始记录者按理论与实验结构反推，不声称复刻原过程。过程类型：临床观察—自由联想/访谈—解释—个案验证—理论建构（临床个案）。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 用什么方法 / 工具 | 研究什么、写哪里 | 研究状态 | 最容易做错 |
|---|---|---|---|---|---|
| 1 临床观察 | 从个案与临床现象中定研究问题 | 临床观察 / 访谈 / 个案记录 | 只定问题与核心概念：反复出现的症状、冲突、关系模式 | 约 10–20%，问题可见、解释未定 | 概念不清就无法操作化，问题须先定操作化定义。 |
| 2 自由联想 | 收集无意识材料 | 自由联想 / 梦的解析 / 移情观察 / 儿童游戏观察 | 只收集材料：联想、梦、口误、移情，不急于下结论 | 约 30–40%，材料已聚、解释未定 | 假设不可检验或预测方向不明，后续设计无从谈起。 |
| 3 解释 | 提出解释，连接症状与无意识冲突 | 理论推演 / 象征解读 / 发展史重构 | 只定解释：核心冲突、防御机制、发展阶段，备择解释并列 | 约 60–70%，解释已立、验证未做 | 第 2 步处境分析中殖民处境一被简化为背景，症状即退回个体解释；处境是病因，不是布景。 |
| 4 个案验证 | 在后续治疗与新个案中检验解释 | 纵向个案追踪 / 治疗过程观察 / 对照个案比较 | 只做验证：解释是否带来症状变化与新的联想材料 | 约 85–90%，结论已立，个别个案仍可留空 | 数据一忽略异常结果或误读效应，结论即失真。 |
| 5 理论建构 | 形成或修正理论、定名、推广边界 | 概念整合 / 定理论名 / 写清适用边界 | 全篇薄薄统一，写清适用边界与未解问题 | 100%，完成态 | 理论一超出适用边界，推广即失效；须写清边界与未解问题。 |

## (2) 每一阶段的研究状态变化（5 个检查点）

1. 第 1 步结束：只有问题与概念，方法未定。
2. 第 2 步结束：假设已定，设计未定。
3. 第 3 步结束：数据已收（或材料已聚），结论未出。
4. 第 4 步结束：效应与图表骤现，结论已立，个别结果仍可留空。
5. 第 5 步结束：完成态，理论统一、边界写清。

- 节奏：延时版 60–90 秒；过程版 3–5 分钟。分配建议：问题 15%、假设 10%、临床观察 45%、解释 15%、理论 15%（临床观察步最重）。
- 节奏提示：问题慢（让观者看清概念）、假设中速（看预测生长）、实验/观察中速（看数据积累）、数据分析放慢（看逐项检验）、理论停顿（看完成态）。

## (3) 过程呈现的镜头与字幕建议

- 呈现：实验记录 / 数据表 / 概念图逐行出现，关键修改处用删除线与替换概念并排显示；每步左上角出小字步骤名（问题 / 假设 / 实验 / 数据 / 理论），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍实验记录 / 屏幕特写 / 局部放大三机位轮换；问题用全景，数据分析用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 项原作小图对照（只放实验装置图 / 数据图 / 著作封面，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡记录；不要把过程剪成跳切，保留研究的连续性；不要虚构心理学家的生活场景；涉及人类被试的实验必须在字幕中注明伦理争议与现代伦理标准，不作美化。

## (4) 过程示例（以本心理学家研究现代题材的逻辑为例，不声称复刻原过程）

- 问题：定一个现代题材（一个人刷短视频停不下来）与核心概念。
- 假设：按此人的理论提出可检验假设与预测方向。
- 实验/观察：按此人的方法执行研究，收集数据或临床材料，不回头改假设。
- 数据：分析数据、检验假设，处理异常结果。
- 理论：形成或修正解释，写清适用边界与未解问题。
