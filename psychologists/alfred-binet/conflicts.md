# Alfred Binet — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- IQ 并非比奈所创：智商（IQ = 心理年龄 / 实足年龄 × 100）是斯特恩（1912）提出、推孟（1916）推广的，比奈本人只用心理年龄；把 IQ 归于比奈是常见误读。
- 《儿童智力测验》不是单一著作名：比奈—西蒙量表有 1905、1908、1911 三版，引用时须注明版本。
- 比奈测验的初衷（识别需特殊教育的儿童）与后世滥用（大规模筛选与分流）之间的张力：本蒸馏只取编制方法，应用史记入 conflicts。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
