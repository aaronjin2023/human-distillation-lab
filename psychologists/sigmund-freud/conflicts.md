# Sigmund Freud — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 可证伪性争议：波普尔（Karl Popper）批评精神分析不可证伪；支持者认为临床解释有其验证逻辑，争论无定论，两说并存。
- 俄狄浦斯情结的普遍性争议：鲍斯等人从印度材料质疑其普遍性；本蒸馏只取弗洛伊德的理论表述，跨文化批评记入 conflicts。
- 《超越快乐原则》的死驱力概念在弗洛伊德学派内部亦有分歧：部分后继者淡化或否定死驱力。
- 译名争议：Es / Ich / Über-Ich 译本我—自我—超我为通行译法；Trieb 译驱力 / 本能两说并存。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
