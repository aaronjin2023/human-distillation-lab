# Karen Horney — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 与正统弗洛伊德学派的决裂：霍妮否定阴茎嫉羡与性驱力中心论，1930 年代后脱离纽约精神分析学会；两说并存，学派分立。
- 《女性心理学》为后人编选的论文集（1967），非霍妮生前成书，引用时须注明编选性质。
- 三种人际策略的实证地位：后世人格研究部分支持其结构，但分类边界有争议。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
