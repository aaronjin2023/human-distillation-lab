# Gustav Fechner — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 费希纳定律的普适性有争议：后世史蒂文斯幂定律（1957）指出感觉量与刺激强度的关系多为幂函数而非对数函数，费希纳定律只在部分感觉通道近似成立；此处按“当时模型 / 后世修正”口径记录。
- 《韦伯—费希纳定律》不是独立著作，是定律名，草稿列入代表作栏属类别混淆，已在 source_works 中注明。
- 晚期泛灵论与美学著作与早期心理物理学的科学形象有张力：本蒸馏只取测量方法与定律，晚期思辨记入 conflicts。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
