# William James — conflicts.md（说法不一致 / 争议，保留，不统一）

> 同一心理学家不同时期说法不一、实验复制失败、理论归属存疑、译名争议，记入此处，不强行统一。

- 《心理学原理》（1890）与《心理学简编》（1892，Briefer Course）常被混同：前者两卷本，后者为教学简写本，引用时须区分。
- 情绪的詹姆斯—兰格理论中兰格（Carl Lange）的独立贡献常被略去：两人各自独立提出，理论归属应并列。
- 实用主义是否属于心理学成果物有争议：本蒸馏只取其与心理学相关部分（真理检验、习惯、自我），哲学体系本身不在范围。

- 通用口径：已证伪或已修正的理论按“当时模型 / 后世修正”记录，不删改原理论表述；涉及人类被试的经典实验，伦理争议与现代标准只记录、不美化。
