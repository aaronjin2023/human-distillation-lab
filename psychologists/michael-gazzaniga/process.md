# Michael Gazzaniga — 心理学研究过程规格 process.md（给文本 / 视频模型）

> 只按研究的逻辑写，不编造心理学家的生活场景；有原始论文 / 实验记录可考者以原始文献为准，无原始记录者按理论与实验结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 研究状态 |
|---|---|---|
| 1 问题 | 定问题：两半球切断后，心智还是统一的吗？界定半球分离与解释器的操作化定义。 | 约 10–20% 完成，问题可见、方法未定 |
| 2 假设 | 提假设：两半球可独立加工信息；左脑会为右脑的行为编造解释。 | 约 30–40%，假设已定、设计未定 |
| 3 实验 / 研究 | 做实验：向裂脑病人的左右视野分别呈现刺激，比较言语报告与左手选择的分离；记录解释器的编造。 | 约 60–70%，数据已收、分析未做 |
| 4 数据 | 分析数据：比较两半球反应的系统分离；检验解释器编造的模式；处理个别病人的半球差异。 | 约 85–90%，结论已立，个别结果仍可留空 |
| 5 理论 | 成理论：整合为解释器与模块化心智理论，写清适用边界（裂脑病人研究）与未解问题（正常脑的模块边界）。 | 100%，完成态 |

- 每步最容易做错的地方：第 3 步刺激呈现一不精确控制视野就无法分离半球；第 4 步若把解释器的编造当作真实原因，就会误读数据。

## (2) 每一阶段的研究状态变化（过程视频 / 文本生成的节奏）

- 检查点：每步结束时研究状态如上表所示——第 1 步只有问题与概念、第 3 步有原始数据无结论、第 4 步效应与图表骤现、第 5 步定稿为完成态。
- 节奏建议：问题慢（让观者看清概念）、假设中速（看预测生长）、实验 / 研究中速（看数据积累）、数据分析放慢（看逐项检验）、理论停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。时间分配：问题 15%、假设 15%、实验 40%、数据 20%、理论 10%。实验步最长，看两半球反应逐项分离。

## (3) 过程呈现的镜头与字幕建议

- 呈现：实验记录 / 数据表 / 概念图逐行出现，关键修改处用删除线与替换概念并排显示；每步左上角出小字步骤名（问题 / 假设 / 实验 / 数据 / 理论），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍实验记录 / 屏幕特写 / 局部放大三机位轮换；问题用全景，数据分析用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 项原作小图对照（只放实验装置图 / 数据图 / 著作封面，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡记录；不要把过程剪成跳切，保留研究的连续性；不要虚构心理学家本人的生活场景；涉及人类被试或动物的实验，必须在字幕中注明伦理争议与现代伦理标准，不作美化。

## (4) 过程示例（按本人的研究逻辑反推，不声称复刻原过程）

- 问题：定问题：两半球切断后，心智还是统一的吗？界定半球分离与解释器的操作化定义。
- 假设：提假设：两半球可独立加工信息；左脑会为右脑的行为编造解释。
- 实验 / 研究：做实验：向裂脑病人的左右视野分别呈现刺激，比较言语报告与左手选择的分离；记录解释器的编造。
- 数据：分析数据：比较两半球反应的系统分离；检验解释器编造的模式；处理个别病人的半球差异。
- 理论：成理论：整合为解释器与模块化心智理论，写清适用边界（裂脑病人研究）与未解问题（正常脑的模块边界）。
- 节奏：问题 15%、假设 15%、实验 40%、数据 20%、理论 10%。实验步最长，看两半球反应逐项分离。
