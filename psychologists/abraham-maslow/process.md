# Abraham Maslow — 心理学研究过程规格 process.md（给文本 / 视频模型）

> 只按研究的逻辑写，不编造心理学家的生活场景；有原始论文 / 实验记录可考者以原始文献为准，无原始记录者按理论与实验结构反推，不声称复刻原过程。

## (1) 研究步骤顺序表（5 步）

| 步骤 | 做什么 | 研究状态 |
|---|---|---|
| 1 问题 | 定问题：健康、优秀的人有什么共同特征？界定自我实现与高峰体验的操作化定义。 | 约 10–20% 完成，问题可见、方法未定 |
| 2 假设 | 提假设：人的需要按层次组织，低层满足后高层出现；自我实现者共享一组可描述的特征。 | 约 30–40%，假设已定、设计未定 |
| 3 实验 / 研究 | 做研究：选取被认为自我实现的人物作传记分析，辅以访谈与问卷收集高峰体验报告，不做实验室操纵。 | 约 60–70%，数据已收、分析未做 |
| 4 数据 | 分析数据：归纳自我实现者的共同特征，整理高峰体验的描述；处理取样偏差与主观报告的问题。 | 约 85–90%，结论已立，个别结果仍可留空 |
| 5 理论 | 成理论：整合为需求层次理论与自我实现理论，写清适用边界（成长取向的描述框架）与未解问题（层次顺序的实证支持不足）。 | 100%，完成态 |

- 每步最容易做错的地方：第 3 步取样一偏向杰出人物就无法推广到普通人；第 4 步若把主观报告当作客观测量，就会夸大高峰体验的普遍性。

## (2) 每一阶段的研究状态变化（过程视频 / 文本生成的节奏）

- 检查点：每步结束时研究状态如上表所示——第 1 步只有问题与概念、第 3 步有原始数据无结论、第 4 步效应与图表骤现、第 5 步定稿为完成态。
- 节奏建议：问题慢（让观者看清概念）、假设中速（看预测生长）、实验 / 研究中速（看数据积累）、数据分析放慢（看逐项检验）、理论停顿（看完成态）。
- 总时长建议：延时版 60–90 秒；过程版 3–5 分钟。时间分配：问题 15%、假设 15%、传记与访谈 40%、数据 15%、理论 15%。研究步最长，看个案特征逐项归纳。

## (3) 过程呈现的镜头与字幕建议

- 呈现：实验记录 / 数据表 / 概念图逐行出现，关键修改处用删除线与替换概念并排显示；每步左上角出小字步骤名（问题 / 假设 / 实验 / 数据 / 理论），不配画外音讲人生，只配步骤字幕。
- 机位（视频版）：俯拍实验记录 / 屏幕特写 / 局部放大三机位轮换；问题用全景，数据分析用特写。
- 成片结尾：定格完成态 3 秒 + 并排出 2–3 项原作小图对照（只放实验装置图 / 数据图 / 著作封面，不放肖像）。
- 禁忌：不要用 AI 生成的“假手”长时间遮挡记录；不要把过程剪成跳切，保留研究的连续性；不要虚构心理学家本人的生活场景；涉及人类被试或动物的实验，必须在字幕中注明伦理争议与现代伦理标准，不作美化。

## (4) 过程示例（按本人的研究逻辑反推，不声称复刻原过程）

- 问题：定问题：健康、优秀的人有什么共同特征？界定自我实现与高峰体验的操作化定义。
- 假设：提假设：人的需要按层次组织，低层满足后高层出现；自我实现者共享一组可描述的特征。
- 实验 / 研究：做研究：选取被认为自我实现的人物作传记分析，辅以访谈与问卷收集高峰体验报告，不做实验室操纵。
- 数据：分析数据：归纳自我实现者的共同特征，整理高峰体验的描述；处理取样偏差与主观报告的问题。
- 理论：成理论：整合为需求层次理论与自我实现理论，写清适用边界（成长取向的描述框架）与未解问题（层次顺序的实证支持不足）。
- 节奏：问题 15%、假设 15%、传记与访谈 40%、数据 15%、理论 15%。研究步最长，看个案特征逐项归纳。
